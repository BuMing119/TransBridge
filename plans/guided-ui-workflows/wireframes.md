# S01 低保真线框图与组件状态

这些图冻结信息层级、主动作和返回关系，不规定 FR24 的颜色、圆角、字体、主题令牌或最终尺寸。

## 1. 开始中心

```text
┌ TransBridge ─────────────────────────────────────────────────────────┐
│ [开始]                                         [任务 1] [设置] [帮助] │
├──────────────────────────────────────────────────────────────────────┤
│ 开始翻译                                                            │
│ 选择一个 ESP / ESM / ESL；工程名称和常用设置会自动准备。              │
│                                                                      │
│                  [ 选择插件开始翻译 ]                                │
│                                                                      │
│ 继续工作                                                             │
│ ┌ 上次：MyMod · 默认版本 · 有未保存恢复信息 ┐  [继续]                 │
│ ├ Recent A · PluginA.esp · 昨天              ┤  [打开]                │
│ └ 失败任务 · 写回 PluginB · 原因…            ┘  [查看详情]            │
│                                                                      │
│ 其他                                                                │
│ [打开本地工程] [创建空工程▾] [FOMOD 安装包翻译]                      │
└──────────────────────────────────────────────────────────────────────┘
```

| 状态 | 标题/原因 | 主动作 | 次级动作 | 默认焦点 |
|---|---|---|---|---|
| 无历史 | “选择插件开始翻译” | `project.create_from_source` | 打开工程、空工程、FOMOD | 选择插件 |
| 可自动恢复 | 不显示开始中心，直接恢复 Workbench | 无 | 用户可稍后返回开始中心 | Workbench 当前任务 |
| 恢复失败 | 显示稳定 diagnostic 和所属工程 | `project.open` 或修复后重试恢复 | 其他最近工程 | 失败摘要/修复动作 |
| 有有效 checkpoint | 显示 owner、任务类型和输入摘要 | `task.resume` | 查看详情、放弃记录 | 继续任务 |
| 记录过期 | 解释 identity/checkpoint 不匹配 | 无 | 打开所属工程、移除记录 | 原因文本 |
| 有活动工程但主动返回 | 顶部提示“工程仍保持打开” | 选择插件开始另一工程 | 返回当前工程 | 返回当前工程 |

开始中心不读取 ParaTranz/LLM 配置作为显示前置，也不直接创建 repository 数据。

## 2. 插件建项 draft（开始中心同页推进）

```text
┌ 创建本地翻译工程 ────────────────────────────────────────────────────┐
│ 插件       MyMod.esp                         [重新选择]               │
│ 工程名称   [ MyMod_______________________ ]                          │
│ 已有译文   [ 不导入 ▾ ]  [选择 EET/XT/Strings/已翻译插件]            │
│                                                                      │
│ ▸ 高级解析设置                                                       │
│                                                                      │
│ 摘要：将创建本地工程 “MyMod”、默认翻译版本并解析 1 个插件。           │
│ [返回]                                      [创建并开始翻译]          │
│                                                                      │
│ 失败：PROJECT_… 原因…… [修改高亮字段] [查看技术详情]                 │
└──────────────────────────────────────────────────────────────────────┘
```

| 状态 | 主动作 | 规则 |
|---|---|---|
| draft 无效 | disabled + 原因 | 焦点落第一个无效字段，不写 staging |
| validating/staging | 取消请求（若真实支持） | 防重复提交；旧 active 不变 |
| success | 进入新 Workbench | 一次发布 project/version/projection |
| failure | 修复并重试 | 保留 draft，清 staging，新提交使用新 operation identity |

## 3. Workbench

```text
┌ MyMod（本地工程） / 默认（翻译版本） ─ [未保存修改] [保存] [⋯] ─────┐
│ MyMod.esp（插件）                         [切换翻译内容 ▾]            │
├──────────────────────────────────────────────────────────────────────┤
│ 下一步：有 328 条尚未翻译                         [开始 AI 翻译]      │
│ 可选：[导入已有译文]  [暂时收起引导]                                  │
├──────────────────────────────────────────────────────────────────────┤
│ 328 未翻译 · 14 待检查 · 972 已完成                                  │
│ [搜索________________] [常用状态 ▾] [标签 ▾] [高级筛选 ▾]            │
│ ┌ 词条表：保持 row identity / selection / scroll / 增量渲染 ───────┐ │
│ │ …                                                               │ │
│ └─────────────────────────────────────────────────────────────────┘ │
│ 当前选择：24 条   [AI 翻译] [检查] [写回/发布]             [更多▾]   │
└──────────────────────────────────────────────────────────────────────┘
```

| 状态 | 主动作 | 原因/恢复 | 保存状态 |
|---|---|---|---|
| 无工程 | `project.create_from_source` | 打开已有工程 | 不显示虚假“已保存” |
| 空工程 | `translation.import_source` | 说明支持的来源 | 已保存/dirty 真实投影 |
| 有未翻译 | `translation.ai.run` | 无 AI 配置时就地修复，也可手工翻译 | 持续可见 |
| 待检查 | `translation.review` | 聚焦问题筛选 | 持续可见 |
| 待发布 | `publish.write` | 同步/发布作为次级分支 | 持续可见 |
| 保存失败 | `project.save` | diagnostic + 保持 dirty | “保存失败，可重试” |
| task running | `task.open_activity` | 不禁用无关浏览/编辑能力 | 显示运行不等于已保存 |

统计摘要可点击但不与主动作竞争；删除、移除、覆盖全部进入“更多/管理”安全层。

## 4. AI 快速运行

```text
┌ AI 翻译：MyMod.esp / 当前筛选 328 条 ────────────────────────────────┐
│ 模式       (● 翻译) (○ 润色) (○ 混合)                              │
│ 作用域     [当前筛选 ▾]   预计 328 条 / 约 42k Token                 │
│ 覆盖策略   [仅空译文 ▾]                                              │
│                                                                      │
│ 配置状态   OpenAI · model-x · 可用                  [修复配置]        │
│ ▸ 高级配置（Provider / 模型 / Embedding / 术语 / 后处理）            │
│                                                                      │
│ [返回 Workbench]                                  [开始翻译]         │
└──────────────────────────────────────────────────────────────────────┘
```

| 状态 | 主动作 | 呈现规则 | 默认焦点 |
|---|---|---|---|
| ready | `translation.ai.run` | RunSpec 摘要完整；长期配置只读摘要 | 开始翻译 |
| 缺配置 | 修复第一个阻塞配置 | 一次列出全部缺口，不逐个弹消息框 | 修复配置 |
| 空 scope | 返回 Workbench 调整范围 | 不创建 run | 作用域 |
| running | `task.open_activity` | 显示 Run ID、进度和真实 cancel 能力 | 任务投影 |
| partial/failed | 定位失败项或 `task.retry` | retry 新 Run ID；显示日志/报告能力 | 错误摘要 |
| completed | 检查结果 | 回到原筛选与选择；可再次运行 | 检查结果 |

任务开始后只置前一次任务投影，不反复抢焦点；修改长期配置不改变已创建 RunSpec。

## 5. 操作计划（上传/下载/写回/FOMOD 共用骨架）

```text
┌ 写回计划 ────────────────────────────────────────────────────────────┐
│ 对象       MyMod（本地工程） / 默认 / MyMod.esp                      │
│ 范围       当前版本 · 1,314 条（9 条阻断）                            │
│ 输出       D:\Mods\MyMod_zh.esp                       [选择]         │
│ 覆盖       不覆盖原文件 · 创建备份                                   │
│                                                                      │
│ 预检                                                               │
│ ✓ 输入身份有效   ✓ 目录可写   ! 9 条 locked(9) 空译文                │
│ [定位阻断条目]                                                       │
│                                                                      │
│ [返回编辑]                                    [检查并提交写回]        │
└──────────────────────────────────────────────────────────────────────┘
```

| 状态 | 主动作 | 副作用边界 |
|---|---|---|
| editing | 运行/刷新预检 | 零网络、零正式文件写入 |
| preflight blocked | 修复/定位 | 不允许正式提交，原因可见 |
| preflight ready | typed submit intent | 唯一正式确认点；防重复提交 |
| running | 打开任务 | UI 不拥有终态 |
| partial | 查看成功/失败对象 | retry 失败项前重做必要预检 |
| completed | 打开 artifact/返回上下文 | 保留 Run ID、目标和摘要 |

上传/下载把“输出”区替换为 ParaTranz 云端项目、远端文件和覆盖/合并策略；FOMOD 替换为新旧归档、过滤预设、语言、AI 和归档格式，但状态语义不变。

## 6. 任务中心

```text
┌ 任务 ────────────────────────────────────────────────────────────────┐
│ [进行中 2] [需要处理 1] [历史]                   [仅当前工程 ▾]       │
├──────────────────────────────────────────────────────────────────────┤
│ AI 翻译 · MyMod / MyMod.esp            156/328 · 02:14               │
│ 生成译文 ━━━━━━━━━━━━ 48%                         [停止] [查看]       │
│                                                                      │
│ 写回 · OtherMod / 默认                    失败 · WRITE_PATH_LOCKED    │
│ 输出 D:\…  0 个正式文件已发布                [修复计划] [日志]       │
│                                                                      │
│ 解析 · OldMod                                不可恢复                 │
│ checkpoint 与输入 fingerprint 不匹配       [打开所属工程]            │
└──────────────────────────────────────────────────────────────────────┘
```

| 状态/能力 | 可显示动作 | 禁止动作 |
|---|---|---|
| running + cancellable | 停止、查看 | 无 checkpoint 时不显示暂停 |
| paused + valid checkpoint | 恢复、取消、查看 | 不把历史摘要改回 running |
| failed + retry factory | 修复/重试、日志、结果 | 不复用旧 Run ID |
| failed + non-idempotent | 返回操作计划重新预检 | 不直接“重放” |
| completed + artifact | 打开目录/报告、定位结果、再次运行 | 不显示恢复 |
| stale checkpoint | 打开所属工程、移除记录 | 不显示继续 |
| legacy adapter | 仅真实声明的查看/取消能力 | 不伪造暂停、恢复、日志 |

## 7. 跨页面连续性

```text
开始中心 --project.create_from_source--> 建项 draft --success--> Workbench
   ^                                              |              |
   | project.return_to_start                      | AI           | 发布/同步
   |                                              v              v
   +----------------------------------------- AI 快速运行     操作计划
                                                     \          /
                                                      v        v
                                                        任务中心
                                                            |
                                          locate/open artifact/return
                                                            v
                                                        原 Workbench
```

每条返回边都携带 `project/version/content/filter/selection/revision`；任一 identity 失效时先解释再导航，不静默落到其他工程。
