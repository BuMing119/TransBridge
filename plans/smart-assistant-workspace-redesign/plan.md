# Smart Assistant Workspace Redesign

- **状态**：已完成（2026-08-25，综合 QA 通过）
- **视觉基准**：用户于 2026-08-25 提供的横向“TransBridge 智能助手”设计稿
- **对应需求**：`docs/requirements.md` 中既有智能助手能力；本计划不改变业务行为
- **约束**：[ADR-008](../../docs/adr/008-smart-assistant-code-layering.md) 的 UI/业务分层保持不变

## 目标

把当前低对比、超宽狭长的智能助手 Dock 重构为覆盖工作台的横向浮动工作区。会话、消息、输入和后台任务形成清晰层级，在浅色与深色主题下均可读，并保留现有会话持久化、Markdown、工具、上传、Auto 与任务控制能力。

## 非目标

- 不新增或更改 LLM 模型、对话模式和工具执行语义。
- 不把设计稿中的示例检查结果做成固定业务卡片。
- 不改动智能助手后端、会话存储格式或任务运行时。
- 不逐像素复制生图中的虚构状态；所有状态必须来自真实功能。

## 当前实现事实与约束

- `SmartAssistantPanel` 仍是 `QDockWidget`，由 `ToolWindows` 延迟创建并负责显示/隐藏。
- 现有浮窗几何为接近宿主全宽、约 42% 高，造成超宽低矮形态。
- 会话列表、聊天区和任务区已按独立组件组织，可以局部重构展示层。
- 消息正文通过 `MarkdownRenderer` 创建子控件；当前浅色主题截图中消息子树出现近白文字，必须显式验证渲染后的调色板。
- 图标不得继续依赖可能缺字的 Unicode 字符，统一使用项目内 SVG 图标渲染器。
- 保留延迟 UI 构建，避免 Windows C 栈溢出回归。

## Story 01：浮动助手工作区与品牌标题栏

### 验收标准

- 首次显示时浮窗在宿主窗口内居中，宽度约为宿主的 78%、高度约为 82%，并受 `900×600` 最小值和 `1280×820` 最大值约束；小窗口可安全收缩到可见区域。
- 浮窗覆盖中央工作台，不改变中央控件几何。
- 标题栏显示 TransBridge 智能助手、真实模型配置状态及模型摘要；不提供无后端支持的伪模式切换。
- 关闭、折叠、新建、搜索等图标为清晰 SVG，不显示空方块。

### 文件落点

- 修改 `src/transbridge/ui/shell/tool_windows.py`：集中计算并刷新浮窗几何。
- 修改 `src/transbridge/ui/tools/smart_assistant/panel.py`：装配标题栏和工作区。
- 新增 `src/transbridge/ui/tools/smart_assistant/panel_header.py`：仅负责标题栏展示与窗口意图。
- 扩展 `src/transbridge/ui/foundation/tabler_icons.py`：补齐助手界面需要的同风格图标。

### 验证

- 覆盖 1280×720、1600×900 与小窗口尺寸的几何测试。
- 验证隐藏后重开、宿主移动/缩放后重开和中央工作台几何不变。

## Story 02：会话与消息阅读层级

### 验收标准

- 左侧会话栏展开宽度约 240px，可收起；当前会话使用轻量高亮，并展示标题、消息数和时间。
- 用户消息右对齐为浅强调色气泡，助手消息左对齐为正文流，不再显示孤立的 `U/A` 字符。
- 消息正文在所有内置主题下使用正文色，元数据才使用次要色；Markdown 与超长纯文本均可读且自动换行。
- 消息阅读列限制最大宽度，宽窗口中不会横跨整个聊天区域。

### 文件落点

- 修改 `session_list_widget.py`、`message_bubble.py`、`message_list_view.py`。
- 修改 `theme_support.py`，提供明确的正文、次要正文、卡片和强调表面映射。
- 必要时修改 `chat_composition.py` 的消息区边距和最大阅读宽度容器。

### 验证

- 主题矩阵覆盖用户、助手、系统与 Markdown 消息的前景/背景对比度。
- 覆盖会话栏展开/收起、长标题、长消息和历史恢复。

## Story 03：一体式输入卡片与折叠任务状态

### 验收标准

- 工具按钮、上传、输入框、Auto 与发送按钮组合为固定在底部的一体式输入卡片。
- 输入区高度稳定，不随剩余空间无限拉伸；空输入禁用发送，现有快捷键和上传行为保持不变。
- 无后台任务时只显示约 36px 的折叠状态行；有任务时可展开并保留暂停、恢复、取消与清理操作。
- 空任务区不占用聊天阅读空间。

### 文件落点

- 修改 `input_view.py`、`quick_actions.py`、`task_monitor.py`、`chat_widget.py`。
- 修改现有 UI 测试并补充视觉结构、尺寸和交互回归。

### 验证

- 运行智能助手 UI 聚焦测试、主题迁移测试和布局稳定性测试。
- 生成离屏截图，人工检查横向比例、可读性、输入卡片与任务折叠状态。
- 运行相关 Ruff check/format 门禁。

## 依赖顺序

Story 01 → Story 02 → Story 03 → 综合 QA。标题栏和几何先稳定，后续组件才能按真实可用尺寸调校。

## 风险与回退

- 自定义 Dock 标题栏可能影响拖动/停靠；保留 `QDockWidget` 特性并为浮动/停靠状态添加回归测试。
- 调色板与 Markdown 内联样式的优先级可能再次导致低对比；测试必须读取最终渲染子控件颜色，而非只检查主题 token。
- 当前工作区包含其他未提交改动；只编辑上述文件及本计划，逐文件审查 diff，不回退无关内容。

## 明确假设

- 最新横向设计稿是本次已批准的视觉方向。
- “翻译协作”仅作为设计表达；当前实现继续使用既有单一对话工作流，不增加虚构模式选择器。
- 模型名称只读展示真实配置；未配置时显示“模型未配置”。
