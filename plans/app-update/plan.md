# 应用更新检查与安装

状态：草稿；本地实现与相关验证完成（2026-11-08）。

## 目标与范围

Windows 安装版在启动后后台检查公开 GitHub 仓库 `BuMing119/TransBridge` 的最新正式 Release；侧边栏提供手动检查入口。有更高版本时显示提示，用户可查看更新说明、下载并校验安装包，再通过现有关闭流程保存工程并启动 Inno Setup 覆盖安装。

本轮不创建或发布 GitHub Release，不自动安装未经用户确认的更新，不加入私人仓库令牌、增量补丁、静默安装或安装失败后的自动回滚。源码运行可检查版本，但不得直接触发安装。

## 现状与约束

- `pyproject.toml` 是版本源，打包时 `transbridge.spec` 收集包元数据；Inno Setup 使用相同版本号、稳定 AppId 与 `UsePreviousAppDir=yes`。
- 安装器需要管理员权限，保存用户数据；安装成功后的重新打开由安装器交互选项负责。
- `MainWindow` 的关闭可能异步保存或被取消。只有成功进入 `QApplication.aboutToQuit` 后才能交接安装器。
- 当前工作区含其他功能的未提交修改；本计划只记录应用更新切片。

## S01：可信版本检查与下载

新增无 Qt 依赖的更新服务：只接受固定仓库、严格版本标签和命名匹配的 Windows 安装包；比较四段版本号。404 或未出现更高正式版时返回无更新。使用限时 HTTPS 请求，要求 SHA-256 校验信息，流式下载到用户可写的缓存目录；中断、取消、文件长度或哈希错误须清理未完成文件且不能返回可执行路径。

验证：模拟 Release API、异常响应、版本边界、资产缺失、恶意 URL、错误哈希和取消下载的聚焦测试；不依赖真实发布。

## S02：桌面入口与安全安装交接

侧边栏显示“检查更新”，发现新版后显示可访问的新版本状态。启动后检查与手动检查均在后台执行；手动操作显示无更新或失败原因。用户确认后展示下载进度与取消操作，下载校验完成后再次确认退出安装。沿用窗口关闭中的保存和恢复逻辑；关闭被取消时撤销安装交接；关闭时取消正在进行的下载。独立 Windows helper 等旧进程完全退出并重新核对 SHA-256，再经 UAC 启动 Inno Setup。

验证：导航意图、状态提示、下载取消、关闭取消和安装交接的 UI 测试；相关主窗口与安装器回归。

## 依赖、兼容与回退

S02 依赖 S01。首次带更新功能的版本仍需由现有用户手动安装一次；之后发布更高版本才会触发自动提示。发布时需使用 `vX.Y.Z.W` 标签、对应 `TransBridge_vX.Y.Z.W_Setup.exe`，并提供 GitHub API `digest` 或同名 `.sha256` 资产。无 Release、断网或资产不完整时，现有翻译功能继续可用。更新器不得修改安装目录或用户数据；安装覆盖仍由原 Inno Setup 脚本负责。撤回本功能只需移除更新入口与服务，不迁移业务数据。SHA-256 仅验证下载文件与发布信息一致；未来正式发布宜为安装包签名以提供发行者身份验证。helper 超时、校验失败或 UAC 被取消会留下失败记录，下次启动提示重试；安装器自身错误由其交互窗口显示。已下载文件保留在用户缓存目录，不承诺自动回滚。
