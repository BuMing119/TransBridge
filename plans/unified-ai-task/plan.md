# 统一 AI 翻译任务

- 状态：Story 01～04 已完成（离线综合 QA 通过；扩大回归例外见 QA 记录）
- 对应架构：[ADR-037](../../docs/adr/037-unified-ai-task.md)
- 目标：一个入口、一个配置窗口、一个运行编排；来源数量不决定执行模式。

## Story 01：任务范围与统一入口

- 入口、命令菜单收敛；旧 batch intent 仅兼容委托。
- 左侧选择/排序来源，右侧保留四模式四页；默认当前来源。
- 状态/分类/标签按来源筛选；当前选择和主表视图只指向捕获的当前来源。
- 预估、预检和执行使用同一有效候选，排除锁定/隐藏等不可编辑条目。
- 验证：来源选择、同名 ID 隔离、空范围、状态保护、菜单合同、字体缩放。

## Story 02：统一执行与持久化

- 新 task_scope/source_execution/task_worker/task_session 切片承担范围、阶段执行、线程和发布。
- 所有来源依次执行相同翻译/润色/混合/自定义阶段；混合保留串行/并行配置。
- 共享一次请求预算和冻结术语；保留来源内上下文与动态术语来源。
- 执行前版本快照，独立内容副本，整个任务成功才一次提交；取消、错误、迟到或映射改变不提交。
- 校改预览按来源确认；报告可查看成功、拒绝和失败，保存后创建版本快照。
- 验证：单/多来源所有模式、并发预算、错误/取消/版本变化、提交幂等和快照失败。

## Story 03：配置与结果收口

- 当前任务配置保持草稿，显式保存预设；统一服务设置继续负责长期服务配置。
- 统一进度窗口展示任务/来源/阶段、暂停/取消、来源报告和任务保存。
- 删除失去生产调用的批量弹窗、页面、worker 和进度路径；保留必要公开入口兼容。
- 验证：配置不落全局、预设往返、报告、失败重试及旧入口委托。

## Story 04：综合 QA

- 聚焦 tests/ui/tools、入口测试和持久化合同。
- uv run ruff check src tests；uv run ruff format --check src tests。
- 不调用付费 LLM；离线 fake 验证实际编排，渲染真实 Qt 窗口检查布局。

## 执行记录

### 追加修复：模式切换响应与布局稳定性

- 当前阶段：修复及验证完成。
- 保持翻译业务与配置持久化契约不变；只处理重复信号、范围重算和布局位移。
- 验收：一次选中只切换一次；批量渲染不触发中间态计算；公共布局锚点不随模式变化；快速切换统计对应最终模式。
- 本次验证：`uv run pytest tests/ui/tools -q`（323 passed）；`uv run ruff check src tests`、`uv run ruff format --check src tests` 均通过。真实 Qt 离屏检查了自定义/混合布局，回归覆盖窄窗口、字体放大、快速切换与关闭待刷新窗口；未调用真实 AI。
