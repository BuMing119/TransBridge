# S06：写操作逆操作适配与停止后提示

- 状态：本地接线与联合验证中；用户已明确要求本版扩展其他写操作，不限译文/阶段，并允许有明确撤销限制的操作继续执行。
- [Plan](../plan.md)、[凭证合同](story-05-round-undo.md)。

## 分领域实施范围

1. 既有 Variant 条目：使用 replace_entry_states/replace_entry_records 的局部 CAS 逆修改；记录前后条目修订，保护后续编辑和来源变化。标签及标签库走独立 replace_labels，不能以译文逆修改假装覆盖标签。
2. 文件导出/覆盖：执行前保存目标存在性、内容和路径身份，执行后保存摘要；撤销前匹配后像及安全路径，不覆盖别人后来修改的文件。新建文件与覆盖旧文件分别处理，不接受任意路径恢复。文件备份与操作凭证必须先保存再允许原写入。
3. 本地 ParaTranz 项目绑定：通过正式 Project CAS 命令恢复旧绑定或清除本轮新绑定，严格核对 Project revision；不更改远端。新增来源/条目结构暂不承诺自动撤销：remove_source 会级联关联源与 namespace 条目，不能直接作为 add_source 的逆命令。
4. 本地配置：只捕获明确修改的非敏感字段，ConfigRepository 使用 expected_revision；凭证不含密钥，保留无关配置。旧空 endpoint 不满足现有写入合同，预检明确拒绝，不以默认值替代。词典 save_dictionary 缺跨实例磁盘 CAS 与精确索引变更回执；术语 retired 映射、review/retry/mirror 缺联合补偿合同，明确显示未覆盖，不回写旧 revision。
5. ParaTranz：记录原远端对象与提交结果，区分创建、更新、删除、触发导出。当前 strings/terms 更新与删除缺服务端 CAS，客户端读后比较不能消除并发窗口；export_artifact 无删除工件/撤销导出接口。不得把这些操作标成可安全一键撤销。

## 当前必要产品选择

用户已选择：允许上述无可靠逆操作的远端动作，但提前说明撤销限制，取消后按实际能力显示恢复范围。不自行采用覆盖远端当前值的“尽力恢复”，不禁止原有远端功能。可逆的本地写操作继续扩展，不以远端限制缩减为仅译文/阶段。

已接入文件范围为 pack_archive 与 write_back 的实际授权目标，包括插件伴随输出；extract_archive 的文件/目录尚未纳入。文件后像核对及本程序锁不能隔离不遵守该锁的外部编辑器，不承诺文件系统提供原子比较替换。重复写同一目标先拒绝合并；跨域并非原子事务，故障时逐域事实保留。

## 提示与验收

取消默认不弹选择框；停止完成后显示提示及撤销按钮。点击时先生成当前恢复范围与冲突检查结果，不依赖过期的按钮状态。对全部受支持步骤预检成功后开始；跨资源途中失败要记录已执行/未执行的逆操作，明确“撤销未完成”，不声称分布式原子性。后续重试必须核验凭证，不自动重复外部调用。

每个适配器需要正常撤销、原操作失败、逆操作失败、后像冲突、缺失前像、重复操作、重启、越界、归属不符测试。UI 文案不得因一类适配通过就声称“整轮恢复”。
