# 统一 AI 设置与批量翻译任务弹窗实施计划

- **状态**：已完成（2026-09-06，Story 07 共享任务框架回归通过）
- **日期**：2026-09-05
- **对应架构**：[ADR-036](../../docs/adr/036-unified-ai-settings-and-batch-dialog.md)
- **视觉基线**：用户确认的“批量 AI 翻译”大弹窗效果图

## 目标

让批量 AI 翻译从工作台一级入口直接打开结构清晰的任务弹窗，并把长期 AI、Embedding、ParaTranz、默认参数、术语和高级配置收拢到既有底部设置入口内。

## 非目标

- 不增加主侧栏页面；
- 不改变翻译核心算法、文件格式或 ADR-035 权威提交语义；
- 不伪造跨插件润色、混合、自定义工作流能力；
- 不新增没有持久化模型的通用偏好；
- 不把任务选择、顺序和覆盖策略保存为软件全局设置。

## 当前事实与约束

- 工作台使用一个“AI 翻译”分段菜单控件承载当前内容和批量插件两个稳定 intent。
- 批量运行已具备预检、任务活动、worker、进度与权威提交链，应继续复用。
- `LLMConfig` 与 `ParatranzConfig` 已统一使用配置仓库和凭据存储；预设使用独立安全仓库。
- `settings_dialog.py`、AI `config_view.py` 等文件已接近或超过规模阈值，新增职责必须拆分。
- 工作树已有与 AI 作用域和工作台批量动作相关的用户改动，必须保留。

## Story 01：工作台统一 AI 一级入口

### 验收标准

- AI 翻译当前内容与批量 AI 翻译从工作台同一个分段菜单按钮进入且文案清晰；
- 点击批量入口经独立 intent 打开批量弹窗；
- 主侧栏不新增批量或 AI 设置页面；
- 单次 AI 翻译入口行为不变。

### 文件落点与步骤

- 在 shell action catalog/intent composition 增加 `TRANSLATION_AI_BATCH`，并与当前内容 intent 组合为单一可见控件；
- 在 `ToolWindows`、`WorkbenchWidget` 和 workflow action presenter/view 做最小路由与展示接线；
- 保留现有高级入口为同一启动链的兼容委托。

### 测试

- 更新 intent router、main window shell、modern workbench、AI story08 与可访问性测试。

## Story 02：批量翻译任务草稿与四页弹窗

### 验收标准

- 弹窗包含项目/任务标题、插件列表、基础配置、术语库、质量处理、运行参数、服务摘要与底部操作区；
- 未翻译插件默认勾选，支持全选、清除、仅选有未翻译内容、拖拽顺序与实时统计；
- 目标语言、覆盖、术语、质量与运行参数形成 detached config；取消不写全局；
- 未配置服务、零选择和无有效条目时不能启动并给出明确原因；
- 配置准确传给既有 batch runtime，现有 worker/progress/authoritative publish 不变；
- “打开统一设置”直达 AI 服务页，返回后可刷新摘要。

### 文件落点与步骤

- 新增纯批量任务 draft/config mapper；
- 将插件选择列表和四个配置页拆为窄 Qt 模块；
- 将 `_BatchTranslationDialog` 改为组合根并保持既有查询方法兼容；
- 调整 `batch_runtime` 只消费弹窗返回的执行副本和覆盖策略；
- 服务摘要只显示 provider/model 与配置状态，不显示任何密钥片段。

### 测试

- 新增批量弹窗行为、草稿隔离、配置映射、长名称布局、主题与键盘可达测试；
- 回归 preflight、空术语确认、取消/失败不提交和成功单次提交。

## Story 03：统一设置中心组合与兼容路由

### 验收标准

- 底部“设置”打开内部分类导航的设置中心，不切主页面；
- 支持 `initial_section` 直达 AI、Embedding 或 ParaTranz；
- 原主题草稿、隔离预览、恢复默认和失败补偿保持有效；
- `SETTINGS_SERVICES` 和旧 `show_config()` 进入统一设置对应分类，不再弹出重复服务配置。

### 文件落点与步骤

- 把现有外观 UI 提取为独立 page，保留主题状态/方法兼容；
- 将 `settings_dialog.py` 收敛为分类导航、内容栈和 Apply/Cancel 协调器；
- 新增设置 section id 与页面公共合同；
- 修改 `ToolWindows` 的统一入口与兼容委托。

### 测试

- 扩展 `test_ui_settings_dialog.py`、current user journeys、shell intent 和 200% 缩放测试。

## Story 04：现有软件级配置页面与安全保存

### 验收标准

- 设置中心可加载、编辑、校验和重载 AI 服务、Embedding/语义检索、ParaTranz、AI 默认参数、术语默认值、高级与安全字段；
- API Key、Token 和认证令牌不在 INI 或 UI 状态文本中明文出现；
- Cancel 不保存，校验失败不关闭，凭据失败不误报成功；
- AI/Embedding/ParaTranz 连接测试在后台执行，关闭页面后忽略迟到回调；
- ParaTranz 保存继续更新 user id/config change 通知；环境变量提供的凭据显示为只读来源。

### 文件落点与步骤

- 新增 Qt-free settings draft/presenter，集中字段映射、验证和 repository 提交；
- 新增 AI、Embedding、ParaTranz、AI defaults、terminology、advanced 窄页面；
- 复用或提取现有连接测试 controller，禁止具体页面反向依赖 AI translator window；
- 保持现有 workflow profile 与自定义预设的安全字段白名单。

### 测试

- 页面 round-trip、取消、校验、凭据隔离、连接生命周期和 revision 冲突单测；
- 回归 unified repository、workflow profile repository、Embedding 与 connection controller 测试。

## Story 05：统一当前内容 AI 翻译任务窗口

### 验收标准

- “AI 翻译当前内容”不再显示旧的“高级配置”折叠界面；
- 保留翻译、润色、混合和自定义四种模式，以及原有范围筛选、规则、预设和运行链；
- 任务配置固定组织为“基础配置、术语库、质量处理、运行参数”四页；
- 全局 AI 服务仅显示不含密钥的状态摘要，并可直达统一设置的 AI 服务页；
- 单次窗口不再承载批量翻译入口，批量任务继续从工作台一级入口打开；
- 在 680px 窗口宽度与 200% 字体下保持可滚动、无水平滚动条，关键操作始终可达。

### 文件落点与步骤

- 将单次任务的 Qt 控件构造从 `config_view.py` 提取为独立任务视图；
- 保留 `TranslatorControls`、presenter/controller 与执行配置映射合同，只调整控件编排；
- 为普通 AI 入口补充统一设置深链，并在设置返回后刷新服务摘要；
- 删除旧“高级配置”折叠和窗口内批量按钮的可见入口。

### 测试

- 新增四页结构、服务摘要、设置深链和旧入口消失的布局契约测试；
- 回归四种模式、范围筛选、配置 round-trip、Embedding、预检、主题与版本化运行测试。

## Story 06：单一 AI 入口与批量弹窗视觉收口

### 验收标准

- 工作台只显示一个“AI 翻译”分段菜单按钮，默认点击翻译当前内容，下拉菜单可选择批量翻译多个插件；
- 单任务与批量任务继续使用稳定的独立 intent 和运行链，不因视觉合并产生行为回归；
- 批量任务弹窗按确认原型形成标题、插件卡片、分段配置页、服务摘要和底部主操作的清晰层级；
- 卡片、输入、页签、列表与主按钮均使用全局主题语义属性，随浅色/深色主题切换，不硬编码原型颜色；
- 长名称、键盘焦点与 200% 字体缩放契约继续通过。

### 文件落点与步骤

- 将 `WorkflowActionsView` 的两个可见按钮收敛为一个分段菜单按钮，并独立映射两个 intent 的可用状态；
- 为批量任务组合根和四个配置页补齐 UI Foundation 组件语义与原型层级；
- 在全局主题样式中补齐任务页签、列表、分组卡片和强调操作规则；
- 更新聚焦 UI 契约并回归既有批量执行配置映射。

### 测试

- 覆盖单入口默认动作、批量菜单动作、独立禁用原因与可访问性；
- 覆盖批量弹窗的主题语义、四页文案、主操作和缩放稳定性。

## Story 07：统一单任务与批量任务视觉框架

### 验收标准

- 当前内容与多插件任务使用同一套标题、模式、页签、卡片、服务栏和底部操作视觉规范；
- 用户仅需理解一个“AI 翻译任务”界面模型，两个入口只决定初始处理范围；
- 当前内容继续支持翻译、润色、混合和自定义，多插件继续只开放已有真实后端能力；
- 两条运行链、配置映射、范围 presenter 与权威提交语义保持独立，禁止形成新的全能控制器；
- 深色模式贴近确认原型，浅色模式保持相同层级并跟随主题。

### 文件落点与步骤

- 提取 AI 任务控件的共享语义装配器，由单任务与批量任务组合根共同使用；
- 将单任务标题、模式条、四页签、输入控件、服务栏和主操作接入共享任务视觉；
- 保留当前内容范围控件和多插件列表作为可替换的范围面板；
- 增加共享视觉契约与单任务主题回归。

### 测试

- 覆盖单任务与批量任务共享 task host、tabs、service bar、footer 和 primary action 语义；
- 回归四种单任务模式、批量 detached config、设置深链、主题切换和缩放稳定性。

## 依赖顺序

1. Story 01 与 Story 03 可并行完成入口骨架；
2. Story 02 依赖批量 intent 与设置直达合同；
3. Story 04 依赖设置组合根；
4. Story 05 复用既有单次运行链并与 Story 03 的设置深链集成；
5. 集成 QA 最后统一验证任务草稿、设置保存与启动链。

## 风险与回退

- 若设置全量持久化与旧 AI autosave 出现 revision 冲突，保留任务 UI 只读服务摘要，并先让统一设置成为服务字段唯一编辑入口；
- 若某个高级配置现有 controller 无法安全复用，页面应保持该字段当前值并链接现有编辑器，不能复制一套 autosave；
- 新批量 UI 可回退到同一 `batch_runtime` 的旧对话框，不影响 worker、进度与权威提交。

## 明确假设

- “按照效果图”指结构、层级、入口和交互密度；颜色、字体和控件细节跟随 TransBridge 当前主题，不硬编码图片色值；
- 本期批量模式为现有“翻译 + 可选质量处理”，其他工作流模式只有在真实后端编排完成后开放；
- 目标语言读取全局默认，但在任务弹窗中的修改仅作用于本次运行。
