# 项目术语与多方案导出使用说明

适用于本地源码截至 2026-11-13 的行为；不表示安装版已经重新打包。需求见 [FR5.16 / FR5.18](requirements.md)，验证边界见 [本对话文档核验](test-reports/terminology-conversation-documentation-2026-11-13.md)。

## 项目术语、方案与翻译版本

项目术语是提取和发布得到的基础术语。独立译名方案有自己的名字、草稿和已发布版本，可用于不同社区或发行约定。翻译版本保存正文；切换预览方案不等于改变已保存正文的实际方案关联。

“使用项目默认译名”不是独立方案，不能直接重命名。独立方案在“管理方案…”中重命名、复制、归档或恢复；名称和已发布内容版本分别管理。单纯选中方案、导入或发布新方案版本，不会把当前已保存的正文静默改成该方案。

## 从项目提取

1. 打开项目术语，检查当前翻译版本和提取设置。
2. 使用“规则整理＋LLM 抽取”时，名称字段按规则收集，正文由配置的模型抽取，再由模型初判同术语的候选译名是否是真冲突。只用规则时，不会执行同等的模型判断。
3. 提取范围是当前项目登记且启用的来源，包含该翻译版本已有的未写回调整；不限当前打开的插件，也不扫描磁盘上未登记的插件或其他项目。
4. 无差异项默认采用；正常表达差异可自动归并，剩余冲突在独立窗口处理。人工决定优先。
5. 返回项目术语应用待处理结果。出现“项目术语已生效”“术语发布已完成”即已发布，无需再找第二个发布按钮。

模型冲突判断把同一术语放在一个完整请求中，不按本地合批预算拆开；不同冲突组最多 50 路，仍受现有请求限流和模型真实上下文限制。失败或不确定项保留人工处理，不能把固定失败说明误认为模型已经判断。

## 处理冲突与排除

左侧按待处理、已处理、无需处理查看；选择一个词条后，右侧展示候选译名及使用次数。次数按证据中的来源和词条去重，是参考，不代表译名正确性。

选择译名后保存并处理下一条；查看对应原文、现有译文或展开模型判断依据。完整词条查看和手动编辑在独立窗口中进行。

不想把这一组收进术语库时，点击“排除此术语”。无需先选择译名，成功保存后跳到下一条；写入失败会留在当前项。可以撤销上次决定。排除保存的是草稿决定，仍需返回主界面应用；不删除源词条，不等于清理提取缓存，也不承诺永久屏蔽未来新输入。

## 丢弃结果与清理缓存

“丢弃本次结果”用于放弃本次待处理结果；“清理当前项目提取缓存”是另一项操作，位于提取设置内。

清理范围是当前项目各翻译版本共用的 extraction 缓存。草稿、人工决定、已发布术语、构建记录、解析缓存和其他项目不受影响。操作在后台执行并显示清理数量；当前窗口有术语任务时先等任务完成。清理后再抽取不会复用被清理的片段；即使复用抽取片段，LLM 模式仍会执行冲突判断阶段。

## 导入到现有方案或创建新方案

1. 选中目标独立方案，点击“导入术语…”选择 JSON、CSV 或 Excel；ParaTranz 使用独立入口，读取当前项目绑定的远端术语。
2. 在“导入到”选择当前方案，或选择“创建新方案”。新建时可填写名称，预览时也可修改；现有方案名称保持不变。
3. 选择保留已有译名或采用导入译名，预览新增、覆盖和保留数量，确认导入。

空方案可以直接导入。现有方案以自身内容为基础合并，不会为了填充空方案把项目底板或别的方案全塞进来；新方案沿用项目术语骨架与来源合成。新词在两种策略下都加入。导入会保存方案版本，但不更改原正文或其实际方案关联；外部来源以后变化不会自动同步。读取、预览取消和过时提交不应改动目标。

## 一份译文导出多个插件版本

打开工作台“导出文件…”或“批量导出文件…”，在“术语方案（可多选）”勾选两个或更多方案，选择一个多方案输出目录后导出。

例如根目录选择 `D:/导出`，结果为 `D:/导出/方案 A/mod.esp` 和 `D:/导出/方案 B/mod.esp`。各目录内保留插件原文件名；不要求来回切换方案，不必创建两份翻译版本，也不重新调用 LLM 翻译正文。

来源插件只定位一次：先尝试工程保存的路径；失效时选择一个插件，系统继续在同目录寻找其余缺项。每个方案都从这批已验证来源生成独立副本，再写入该方案的译文，不需要逐方案重复选择插件。输出保留实际来源插件的文件名。

每个输出使用自己的固定方案投影，复用已有预检、覆盖备份、批量结果和取消机制。没有共同映射或可靠来源译名的部分保留原译文。未勾选时沿用当前方案，可选择“写回原插件”或“另存到目录”；另存只选目录，由程序复制插件并写入副本。若需要分别继续编辑或 AI 翻译两份正文，再显式保存独立翻译版本。

## 查看方案译文差异并导出 Excel

在导出窗口勾选至少两个方案，点击“查看译文差异…”。无需先写出插件或选择目录。差异窗口按来源与词条身份展示原文、当前译文和各方案译文，仅列出不同项；选中一行可查看完整长文本。

点击“导出 Excel 工作簿…”会生成一个 `.xlsx`，左下角可切换：

- “译文差异”：来源、词条标识、原文、当前译文及每个方案的译文。
- “方案信息”：方案版本和内容标识、比较时间、比较/差异数量等。

工作簿保存这次比较的快照。超长文本分段并重复来源/词条标识，不截断正文；无差异仍能导出信息页。关闭窗口取消未完成的比较。若套用到其他插件，此处比较当前来源词条，最终匹配范围以插件导出预检为准。

## 三种导出不要混淆

- 冲突窗口的 Excel：一个文件，包含冲突主表、少数译名证据和全部证据；也可单独导出 CSV/JSON。CSV 本身不支持多工作表。
- 项目术语的“导出完整术语…”：导出当前方案已生效术语，不受当前列表分页、搜索限制。
- 文件导出窗口：输出实际翻译文件或插件；其“查看译文差异”导出的是方案间词条对照。

## 性能与退出

读取状态、分页和单组证据尽量复用索引及后台查询；比较和工作簿保存也在后台进行。取消术语模型任务与自动翻译采用同一批次执行器：停止排队、取消活动请求，再等待资源释放。远端不响应取消时仍可能等待请求结束；当前没有真实打包软件整体退出时长的保证。
