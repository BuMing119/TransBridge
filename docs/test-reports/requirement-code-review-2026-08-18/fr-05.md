# FR5 AI 翻译纵向审查

- 审查 Agent：`fr05_vertical_review`
- 状态：完成；只读审查

## 结论

核心翻译主链存在，但 FR5.11 混合模式的真实链路基本未闭环，FR5.12 的 BM25/跨会话增量与配置化未达需求；GUI、Agent、FOMOD 没有共享统一翻译用例。

## 关键偏差

- 三轮策略：`BOOK:FULL` 与 `SCRL:FULL` 集合常量缺逗号被拼成单字符串；未知 context 静默跳过；部分分支破坏同 quest 串行。
- 术语：返回裸 dict，丢来源/分数/匹配方式；按字符长度而非 token 预算截断。
- Embedding：disabled 模式未真正禁用；每个 AutoTranslator 重载本地模型；精确匹配仍全表扫描。
- LLM：无 request ID/usage/cost/finish reason；daemon 监控线程和共享 client cancel 可能产生迟到回调。
- Checkpoint：多线程直接覆写 JSON，无原子性；缺源 hash、Prompt/model/config/action hash；各入口恢复行为不同。
- Pause/Stop：GUI 部分生效；Agent pause 未传给 translator；FOMOD/混合/NounExtractor 不一致。
- 流式写回：网络回调直接修改正式 Collection，无 draft/commit 边界，取消后可能晚到修改。
- Prompt：`PromptBuilder()` 未接 game profile/target lang；FOMOD 语言只影响 XML，不影响 ESP AI Prompt。
- Scope：读取 Step2 私有字段；table_view 分支可绕过 locked/hidden 排除；预览与执行可能不一致。

## P0

1. FR5.11 MixedWorker 构造 TranslatorConfig 缺必填路径、传 list 代替 Collection、错误构造 Polisher、调用不存在的 `polish_single()`；取消和报告均未闭环。
2. Agent 的 mixed/polish mode 被校验后忽略，始终执行普通翻译。
3. mixed 默认将 stage=2 分给 polish，需求要求 skip；规则排序只改显示顺序不改 priority；动作模型不能表达 translate_then_polish。
4. 分类常量错误与 quest 顺序破坏。
5. 并发 checkpoint 非原子。
6. `rank_bm25` 未进入 pyproject/lock，fresh install 实际静默降级；重启加载索引也不会恢复 BM25。
7. 取消后迟到流式回调有继续修改集合风险。

## FR5.12

- 批量召回和 0.7 阈值统一基本完成。
- 跨进程 hash 变化仍全量重建；inactive rows 未持久化，保存后重启可能让失效旧行重新参与召回。
- cache size/压缩阈值硬编码。
- BM25 依赖缺失、加载后未构建、tokenizer 仅空格分词。
- 建议用 benchmark 比较 RRF 与 min-max 加权，RRF 对模型分数量纲更稳健。

## 推荐方案

短期修 P0；主方案建立统一 Translation Job 应用层：

```text
GUI / Agent / MCP / FOMOD
  -> TranslationApplicationService.submit(JobSpec)
  -> ScopeResolver + ActionPlanCompiler
  -> RoundPlanner
  -> JobRuntime(LLMGateway, TermRetrieval, Journal,
                Budget, Pause/Cancel, EventStream)
  -> TranslationMutationPort
```

混合模式不再维护专用 Worker，而是把规则编译为 `EntryActionPlan`：translate / polish / translate_then_polish / skip。

## 验收标准

- 所有 context 恰好进入一个 Round；未知项显式 fallback/skip 统计。
- 同 quest 任意时刻最多一个批次。
- GUI/Agent/MCP/FOMOD 对同 JobSpec+fake LLM 结果一致。
- mixed 四类动作全部可执行，共享并发上限。
- cancel 后 Collection mutation 数为 0。
- checkpoint 并发下可解析且单调前进，配置/源变化拒绝续传。
- target lang/profile 真正改变所有入口 Prompt。
- fresh install/restart 后 BM25 仍启用；删除术语后旧结果不复活。
- embedding disabled 不加载模型/调用 API。
- 每次 LLM 调用有 model/request/tokens/retry/cost 记录。

## 迁移

回写事实状态 → P0 契约测试/热修 → 用应用服务包裹 AutoTranslator → 迁 GUI → Agent/MCP → FOMOD → 引入 JobRuntime/ActionPlan/MutationPort → retrieval benchmark → 删除 MixedWorker 和重复逻辑。
