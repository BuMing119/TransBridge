# ADR-045：插件定位冲突使用原文限定身份

状态：已接受（用户于 2026-10-06 明确要求按该方案实施）

## 背景与约束

插件解析库的 index 不是唯一标识；同一 key 可能对应多条不同日志。用户要求保留本地和插件 key/id 的原值，新增默认 false 的 requires_original_match 字段；冲突组通过 key 与精确原文共同识别。不采用 UUID、位置编号。ParaTranz 传输 key 可按 ADR-047 可逆编码，不改变本地及插件导出 key。

## 决策

扩展 ADR-017 的 EntryKey 身份契约：namespace/local_key 保持不变，增加可选 original 分量。普通身份保持现有两元素序列化；需要原文匹配时增加第三元素。TranslationEntry 的布尔字段与该身份一致，并随 JSON 与工程快照恢复。

插件提取先保留全部物理条目，再按 key 分组；冲突组全体标记。相同 key 下原文不同的条目保留，相同 key+原文的全部条目跳过并记录 warning。不得规范化原文空白、换行或大小写。

集合、编辑、持久化和投影使用完整 EntryKey。标记词条的 original 是身份的一部分，不允许作为普通字段编辑；translation 可独立编辑。插件回写从不可变源快照验证完整身份，并提前保存物理目标，避免译文等于另一条原文时串写。

自动导入对标记词条要求精确原文证明，缺少原文或不相同则跳过并记录 warning。ParaTranz 下载通过当前来源的 key、精确原文及上下文证据匹配，不使用历史远端关联。独立上传/双向同步计划保留其确认关联合同。GUI 文件上传遵守 ADR-047，原文限定词条以版本化原 key/原文哈希生成唯一传输 key，同组保留在正常文件中；在线下载与 JSON 导入还原完整 EntryKey 后匹配，哈希不符明确拒绝，不把后缀写回本地 key。`QUST:CNAM` 的序号错位仅在同一任务记录内按完全相同原文查找；不得以文本前缀、长度、模糊相似或其他任务作为匹配依据。仍有歧义时保持目标端不变并进入人工复核，其他确定项可以先执行。

下载候选的原文、译文、上下文及状态全部相同时，可采用共同内容；混合候选中的相同内容按组展示。历史关联不影响分组或候选可用性，当前快照中重复 ID 仍拒绝使用。人工选择或自动匹配均不保存下载关联，始终保留本地来源顺序。GUI 仅更新已有条目的译文和状态，保留工程原文、上下文及来源元数据，不新增或删除源条目。原文不同须人工确认，限定身份与正文自相矛盾的输入不可选择。

GUI 上传采用 [ADR-047](047-opt-in-categorized-project-upload.md) 的文件 API 合同。用户选择仅原文、仅安全/强制译文或原文加安全译文，原文更新显式增量保留远端余项；词条接口不作为文件上传回退。完整路径定位当前文件，不依赖历史外部 ID，不逐条回读、不保存上传关联，也不改本地来源身份。独立通用同步仍遵守已确认的译文/状态合同；无业务调用的旧分类逐词条执行链及冲突拆文件分支已移除。用户于 2026-10-25 明确授权文件 API 流程替换此前逐词条实时核验与关联保存；实施见 [分类上传计划](../../plans/paratranz-categorized-upload/plan.md)。

## 备选方案

只加布尔字段而不扩展内部身份会在集合和持久化层覆盖记录；UUID/位置身份不符合用户选择；修改本地或插件 key/id 不符合兼容约束。ParaTranz 传输边界编码由用户于 2026-10-25 明确授权。

## 影响、迁移与回退

旧数据缺省为 false；普通 EntryKey 的内部序列化格式不变。新冲突项不能保证被旧程序读取，不自动重写用户工程文件。旧工程若此前已跳过冲突项，需要重新加载/更新源文件才能引入。回退代码前应保留新工程数据备份；不将含冲突项的数据降级为重复裸 key。

实现与验收见 [计划](../../plans/original-match-entries/plan.md)。
