# ParaTranz OpenAPI 0.7.0 接口与流程对齐

- **日期**：2026-11-16
- **范围**：[Story 01～03](../../../../plans/paratranz-openapi-070/plan.md)
- **依据**：[官方 OpenAPI 0.7.0](https://paratranz.cn/api-docs?format=json) · [官方 API 更新历史](https://paratranz.cn/api-docs/changelog)

## 接口

- `paratranz_project_api.py` 增加项目转让、读取与保存标签规则，开放项目列表的游戏、状态、公开加入、搜索和语言筛选。
- `paratranz_files_api.py` 用 `PUT /files` 提供目录重命名与文件合并，补文件列表筛选、multipart 任务关联与导入历史字段，并提供 JSON 词条创建及原文更新。既有上传默认保留，JSON 更新默认增量。可传入已有哈希，客户端不计算新哈希。
- 新增 `paratranz_file_labels_api.py` 的五项标签操作，通过 API 包和惰性包入口导出 `ParatranzFileLabelsAPI`。标签与上传实现各自维护。
- `paratranz_history_api.py` 增加文件归档详情、回滚与删除。术语历史按 0.7.0 获取完整数组，保留旧分页入参以兼容调用。
- `paratranz_strings_api.py` 增加词条术语匹配，支持多文件与多用户过滤、标签排除、定位页、长度及文本操作符。启用 anchor 且省略页码时由服务端定位。
- `paratranz_suggestions_api.py` 增加机器翻译建议与按服务选择的参数，保留 JSON null。该调用禁用自动重试和重定向。
- `paratranz_members_api.py` 增加退出项目，开放统计时段、成员备注和清理通知选项。 `paratranz_terms_api.py` 开放术语搜索、排序和显式覆盖导入。 `paratranz_announcements_api.py` 与 `paratranz_contribution_api.py` 更新分页契约说明。
- `paratranz_tasks_api.py` 增加任务导出查询、触发和下载，支持轻量任务列表。 `paratranz_export_api.py` 增加构建任务列表、详情和压缩包下载记录。两个压缩包下载封装共用 `artifact_response.py` 流式保存与响应关闭。

## 工作流

- `application/ports/paratranz.py` 和 `paratranz_client.py` 增加参数错误、方法不允许、资源锁定和上游依赖失败分类，对瞬态错误有界重试。错误优先保留 JSON 的服务端请求 ID 与错误码。已知 Token 及机翻请求中的凭据用于脱敏诊断。
- `artifact_download.py`、`application/sync/artifact.py`、`workflow/artifact.py`、`service.py` 和助手的 `tool_paratranz.py` 用触发响应中的 ID 查询构建状态。失败尽早结束，成功后检查新产物。桌面导出保留可报障的状态码、请求 ID 和远端错误码。旧注入适配器缺少任务查询能力时继续使用既有产物轮询。开发说明同步更新。
- `paratranz_issues_api.py` 和 `issues_tab.py` 使用页码并可在当前页重试。 `paratranz_mails_api.py` 和 `mails_dialog.py` 支持追加会话页，以及使用消息 ID 加载更早私信。切换项目或联系人时忽略过期返回，当前会话刷新保留重叠历史与草稿。
