## 修改文件

### `src/transbridge/writer/eet_xml_writer.py` (改)
- **修改内容**:
  - import 新增 `STAGE_TRANSLATED, STAGE_LOCKED, STAGE_HIDDEN` from translation_entry
  - `apply_collection` 中 status 判断从 `stage == 1` 单条件改为 4 分支逻辑：
    - `stage == STAGE_HIDDEN` → 强制原文（status="0"，不写 TRADUIT）
    - `stage == STAGE_LOCKED` → 强制译文（status="99"，写 TRADUIT）
    - `stage >= STAGE_TRANSLATED and entry.translation` → 正常有译文（status="99"）
    - 其他 → 未翻译（status="0"）
  - `should_translate` 布尔变量控制是否写 TRADUIT 节点
- **原因**: 原代码 `entry.stage == 1` 仅识别 stage=1（已翻译），stage=2/3/5 的条目被错误写回为未翻译状态（status="0"）；已锁定(9)和已隐藏(-1)完全未处理
