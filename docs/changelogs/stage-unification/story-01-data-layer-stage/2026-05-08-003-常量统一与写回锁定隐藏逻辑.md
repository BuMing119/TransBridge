# 003: STAGE_* 常量统一与写回锁定/隐藏逻辑

**日期**: 2026-05-08
**类型**: 改
**关联**: Epic: Stage 状态系统统一 > Story 1: Stage 常量定义 (含 Story 2 写回联动)

## 修改文件

### `src/transbridge/converter/translation_entry.py` (改)
- **修改内容**: 模块级新增 7 个 STAGE_* 常量（STAGE_UNTRANSLATED/TRANSLATED/QUESTIONABLE/CHECKED/REVIEWED/LOCKED/HIDDEN）、STAGE_LABELS 字典（stage→中文名）、STAGE_COLORS 字典（stage→颜色码）。所有 TranslationEntry 工厂方法（from_eet_entry/from_plugin_string/from_xt_entry/from_dsd）中的硬编码 stage 值（0/1）替换为常量引用
- **原因**: 消除模块间重复定义（原来 _strings_common.py 和 step2.py 各自维护一份 STAGE_COLORS），建立单一数据源。STAGE_LOCKED(9) 和 STAGE_HIDDEN(-1) 常量供 translator 和 writer 使用

### `src/transbridge/converter/translation_entry_collection.py` (改)
- **修改内容**: 所有 TranslationEntry 构造调用中的硬编码 stage=0/stage=1 替换为 STAGE_UNTRANSLATED/STAGE_TRANSLATED 常量引用（6 处：apply_eet_source/apply_eet_source_simple/apply_xt_source/apply_plugin_source/apply_strings_source/apply_dsd_entries）
- **原因**: 与 translation_entry.py 保持一致，避免魔法数字

### `src/transbridge/ui/paratranz/_strings_common.py` (改)
- **修改内容**: 移除本地重复定义的 _STAGE_LABELS 和 _STAGE_COLORS 字典，改为 `from src.transbridge.converter.translation_entry import STAGE_LABELS, STAGE_COLORS`。保留 ParaTranz UI 哨兵值 -2="全部" 的扩展
- **原因**: 消除代码重复，统一数据源

### `src/transbridge/paratranz/workflow/downloader.py` (改)
- **修改内容**: stage 透传逻辑不变，添加注释说明「ParaTranz API stage 值直接透传（0/1/2/3/5/9/-1）」和「直接透传 ParaTranz stage，对齐 STAGE_* 常量语义」
- **原因**: 文档化 stage 透传语义，防止未来维护者误解

### `src/transbridge/ai_translator/translator.py` (改)
- **修改内容**: `_prepare_batch()` 方法中新增排除逻辑——从候选条目中过滤 `stage in (STAGE_LOCKED, STAGE_HIDDEN)` 的条目（已锁定强制译文、已隐藏强制原文均不应被 AI 翻译覆盖）
- **原因**: FR2.5.7 要求 AI 翻译跳过已锁定和已隐藏条目

### `src/transbridge/writer/eet_xml_writer.py` (改)
- **修改内容**: `write()` 方法的条目回写逻辑重写——根据 entry.stage 决定写回策略：STAGE_HIDDEN（强制原文，不写译文/status=0）、STAGE_LOCKED（强制译文/status=99）、有译文 stage≥1（正常写回/status=99）、其他（不写/status=0）。原实现仅按 stage==1 二元判断
- **原因**: FR2.5.6 要求 EET 写回正确处理所有 stage 值，特别是已锁定(9)和已隐藏(-1)
