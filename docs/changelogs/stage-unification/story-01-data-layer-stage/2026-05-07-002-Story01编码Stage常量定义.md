## 修改文件

### `src/transbridge/converter/translation_entry.py` (改)
- **修改内容**: 
  - 新增模块级常量：`STAGE_UNTRANSLATED=0`, `STAGE_TRANSLATED=1`, `STAGE_QUESTIONABLE=2`, `STAGE_CHECKED=3`, `STAGE_REVIEWED=5`, `STAGE_LOCKED=9`, `STAGE_HIDDEN=-1`
  - 新增 `STAGE_LABELS: dict[int, str]`（7 级映射，不含 ParaTranz UI 哨兵值 -2）
  - 新增 `STAGE_COLORS: dict[int, str]`（7 级颜色，对齐已有 `_STAGE_COLORS`）
  - 6 处 stage 赋值改用常量：EET（`stage=STAGE_TRANSLATED/UNTRANSLATED`）、Plugin（`stage=STAGE_UNTRANSLATED`）、XT（`stage=STAGE_TRANSLATED`）、DSD（`stage=STAGE_TRANSLATED/UNTRANSLATED`）
- **原因**: 全项目 stage 语义需要统一的数据源，STAGE_* 常量供所有模块引用，消除 magic number

### `src/transbridge/converter/translation_entry_collection.py` (改)
- **修改内容**: 
  - import 新增 `STAGE_TRANSLATED, STAGE_UNTRANSLATED`
  - 5 处 stage=1/0 赋值改用常量：`update_from_eet_xml`(×2), `apply_xt_entries`, `update_from_translated_plugin`(×2)
- **原因**: 与 translation_entry.py 的 stage 语义对齐，避免 magic number

### `src/transbridge/paratranz/workflow/downloader.py` (改)
- **修改内容**:
  - Line 90: `stage = item.get("stage", 0)` 添加注释说明 ParaTranz API 值直接透传（0/1/2/3/5/9/-1）
  - Line 120: `stage=stage` 添加注释说明与 STAGE_* 常量语义对齐
- **原因**: 明确标注 downloader 是 ParaTranz 外部 stage 的唯一入口点，后续模块可信任 entry.stage 为 ParaTranz 值
