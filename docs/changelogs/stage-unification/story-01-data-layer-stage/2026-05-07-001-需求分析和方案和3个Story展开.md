**日期**: 2026-05-07
**类型**: 增
**关联**: Epic: Stage 状态系统统一 > Story 01~03

## 修改文件

### `docs/requirements.md` (改)
- **修改内容**: 新增/扩展 FR2.5「Stage 状态系统统一」为全项目范围 7 个子需求（FR2.5.1~FR2.5.7），对齐 ParaTranz 7 级 stage 定义（0未翻译/1已翻译/2有疑问/3已检查/5已审核/9已锁定/-1已隐藏）
- **原因**: 发现全项目 stage 语义混乱——downloader 将 ParaTranz 外部值直接写入 TranslationEntry.stage，_STAGE_LABELS 只映射 3 个值，stage≥3/5/9/-1 的条目在 UI 中不可见

### `plans/stage-unification/plan.md` (增)
- **修改内容**: 新建跨模块 Epic plan，3 个 Story——S1: 数据层常量定义 + 注释修正（converter），S2: EET/Plugin 写回修正（writer），S3: UI 7 级标签 + 色条 + AI 翻译排除（ui + ai_translator）
- **原因**: Stage 修正涉及 5+ 模块，需要统一的跨模块方案

### `plans/stage-unification/stories/story-01-data-layer-stage.md` (增)
- **修改内容**: Story-01 详细展开——在 translation_entry.py 新增 STAGE_* 常量、STAGE_LABELS、STAGE_COLORS；确认现有 8 处数据源 stage 赋值语义正确仅需注释更新；downloader 透传已正确仅需注释
- **原因**: 常量定义是后续 Story-02/03 的基础依赖

### `plans/stage-unification/stories/story-02-writer-stage-fix.md` (增)
- **修改内容**: Story-02 详细展开——EET status_node 判断从 `stage==1` 改为 `stage>=1 and translation`；stage=9 强制写译文；stage=-1 强制写原文
- **原因**: 当前 EET 写回只认 stage==1，用户手动编辑的 stage=2 条目被错误写为未翻译状态

### `plans/stage-unification/stories/story-03-ui-stage-visual.md` (增)
- **修改内容**: Story-03 详细展开——7 级 Stage 标签替换 3 级；筛选改为精确 stage 值匹配；Key 列 Stage 色着色；行背景四色；AI 翻译排除 locked(9)/hidden(-1)；_strings_common.py 引用统一常量
- **原因**: UI 是最明显的 stage 错误表现点，stage≥3 的条目在旧标签系统中不可见
