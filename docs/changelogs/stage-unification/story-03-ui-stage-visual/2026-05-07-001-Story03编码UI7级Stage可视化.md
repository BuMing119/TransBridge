## 修改文件

### `src/transbridge/ui/workbench/step2.py` (改)
- **修改内容**:
  - import 从 translation_entry 导入 `STAGE_LABELS, STAGE_COLORS, STAGE_LOCKED, STAGE_HIDDEN, STAGE_TRANSLATED`
  - 移除本地 `_STAGE_COLORS` 常量（已在 translation_entry 统一定义）
  - 移除本地 `_STAGE_LABELS = {0: "未翻译", 1: "有疑问", 2: "已翻译"}`，改为引用导入的 `STAGE_LABELS`
  - `_build_stage_tags` 重写：Counter 直接统计 `e.stage`；遍历 `STAGE_LABELS.items()` 生成 7 个标签（计数为 0 且未选中时隐藏）
  - `_apply_all_filters` Stage 筛选从三分支逻辑简化为 `e.stage in self._stage_filters` 精确匹配
  - 行背景色改为按 ParaTranz stage 值：STAGE_HIDDEN(-1)=浅灰 #F5F5F5, STAGE_LOCKED(9)=浅红 #FFEBEE, stage>=1=浅绿 #E8F5E9, stage=0=白色
  - Key 列文字颜色使用 `STAGE_COLORS[entry.stage]` 着色（Stage 色条效果）
  - `_on_item_changed` 译文编辑后行背景色同步更新
- **原因**: FR2.5.3/FR2.5.4 需求——UI 中 Stage 标签从错误的 3 级简化为正确的 ParaTranz 7 级，行背景色和文字色反映客观平台状态

### `src/transbridge/ai_translator/translator.py` (改)
- **修改内容**:

  - 候选条目筛选增加 `e.stage not in (STAGE_LOCKED, STAGE_HIDDEN)` 排除已锁定和已隐藏条目
- **原因**: FR2.5.7 需求——已锁定(9)和已隐藏(-1)条目不应被 AI 翻译修改
