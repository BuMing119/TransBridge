## 目标与边界

原生 Structured Outputs 已由 Python Schema 统一声明响应结构。本增量移除翻译各阶段提示词中重复的输出 JSON 示例和字段协议，避免提示词文本与运行时 Schema 形成两套可能漂移的结构定义。

本次保留了每个阶段的业务语义约束，包括输入条目与结果一一对应、保留 ID、不得遗漏或杜撰、质量判定语义、润色与仲裁规则等。输入条目继续使用 JSON 作为传输格式；被移除的只有输出结构说明。

当前工作区同时包含提示词英文重构、目录调整和 Structured Outputs 初始实现等并行改动。本记录仅认领下列输出 Schema 去重及其防回归测试，不将其他并行改动归入本增量。

## 变更明细

### 磁盘提示词模板

- `data/prompts/translation/default.toml`
  - 操作：修改。
  - 变更：移除翻译结果的输出 JSON 对象示例和字段级结构说明，保留逐条翻译、ID 对齐及领域约束。
  - 原因：翻译响应结构已由原生 `TranslationBatchSchema` 提供。
- `data/prompts/extraction/default.toml`
  - 操作：修改。
  - 变更：移除术语抽取结果的输出 JSON 结构，保留抽取范围、去重和来源条目约束。
  - 原因：抽取响应结构已由原生 Schema 提供。
- `data/prompts/quality_gate/default.toml`
  - 操作：修改。
  - 变更：移除质量门禁结果的 JSON 示例，保留 verdict、置信度和问题判断的业务语义。
  - 原因：质量门禁字段及类型由原生 Schema 约束。
- `data/prompts/refinement/default.toml`
  - 操作：修改。
  - 变更：移除润色修订结果的 JSON 协议，保留逐条修订及不得遗漏、重复或新增条目的要求。
  - 原因：修订输出结构由原生 Schema 统一声明。
- `data/prompts/polish/default.toml`
  - 操作：修改。
  - 变更：移除最终润色结果的 JSON 示例，保留语义忠实、自然表达与条目对齐约束。
  - 原因：润色输出结构由原生 Schema 统一声明。
- `data/prompts/arbitration/default.toml`
  - 操作：修改。
  - 变更：移除仲裁结果的 JSON 格式描述，保留候选选择、仲裁理由与置信度语义。
  - 原因：仲裁响应结构由原生 Schema 约束。

### Python 内置 fallback 提示词

- `src/transbridge/ai_translator/prompt_builder.py`
  - 操作：修改。
  - 变更：移除翻译 fallback 中重复的输出 JSON Schema；将固定示例从输入/输出 JSON 对改为 `<fixed_examples>` 中的 `Source` / `Translation` 语义示例。
  - 原因：fallback 与磁盘模板必须共同以原生 Schema 为唯一输出结构来源，同时固定示例不应再次暗示响应协议。
- `src/transbridge/ai_translator/post_processor/quality_gate.py`
  - 操作：修改。
  - 变更：移除内置质量门禁提示词中的输出 JSON 示例，保留判定规则。
  - 原因：防止 fallback 与质量门禁原生 Schema 漂移。
- `src/transbridge/ai_translator/post_processor/llm_refiner.py`
  - 操作：修改。
  - 变更：移除内置修订提示词中的输出 JSON 协议，保留修订约束。
  - 原因：防止 fallback 重复声明响应结构。
- `src/transbridge/ai_translator/post_processor/polisher.py`
  - 操作：修改。
  - 变更：移除内置润色提示词中的输出 JSON 协议，保留润色规则。
  - 原因：确保润色阶段仅由原生 Schema 定义字段结构。
- `src/transbridge/ai_translator/post_processor/llm_arbiter.py`
  - 操作：修改。
  - 变更：移除内置仲裁提示词中的输出 JSON 协议，保留仲裁业务语义。
  - 原因：确保仲裁阶段仅由原生 Schema 定义字段结构。

### 防回归测试

- `tests/ai_translator/test_prompt_builder.py`
  - 操作：修改。
  - 变更：新增提示词不得重复原生输出 Schema 的断言；更新 fallback 与固定示例断言，以验证语义示例仍存在且不包含响应字段协议。
  - 原因：锁定翻译主流程的单一 Schema 来源。
- `tests/ai_translator/post_processor/test_quality_gate_prompt.py`
  - 操作：修改。
  - 变更：用“提示词不包含重复输出 Schema”测试替代对旧 JSON 示例的结构校验。
  - 原因：旧测试契约与原生 Structured Outputs 的职责边界相冲突。
- `tests/ai_translator/post_processor/test_refiner_prompt.py`
  - 操作：修改。
  - 变更：移除解析提示词 JSON 示例的测试辅助逻辑，改为验证修订提示词不重复声明响应字段。
  - 原因：测试应保护 Schema 去重，而不是要求提示词继续携带 JSON 协议。
- `tests/ai_translator/post_processor/test_language_neutral_prompt_loading.py`
  - 操作：修改；本增量仅认领新增的 Schema 去重断言。
  - 变更：覆盖 translation、extraction、quality gate、refinement、polish、arbitration 六类默认模板，并检查相关 fallback 渲染结果不包含重复响应字段。
  - 原因：为磁盘模板与 fallback 建立跨阶段统一防回归保护。
