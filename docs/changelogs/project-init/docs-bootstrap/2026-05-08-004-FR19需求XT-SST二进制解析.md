## 修改文件

### `docs/requirements.md` (改)
- **修改内容**: FR1 章节新增 FR1.9「XT SST 二进制解析与迁移源」——解析 xTranslator 的 SST 二进制文件（SSU8 格式），提取 EDID、FormID、字符串文本、序号、内容哈希等字段转为 TranslationEntry。含 4 个子需求：FR1.9.1 二进制解析（魔数校验/记录结构/UTF-16LE/异常跳过）、FR1.9.2 迁移源集成（Step2 迁移源按钮入口/FormID+EDID 匹配合并）、FR1.9.3 格式校验（魔数拒绝/截断警告/解码失败跳过）、FR1.9.4 兼容性（不修改现有 XT_XmlParser）。FR2.1 和 FR2.4 同步更新引用「XT SST」作为数据源和迁移源类型
- **原因**: 用户需要从 xTranslator 的 SST 二进制格式导入翻译数据作为迁移源
