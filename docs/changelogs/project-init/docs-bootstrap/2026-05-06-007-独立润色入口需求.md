**类型**: 增
**关联**: Epic: AI 翻译后处理 > Story: 待方案（独立润色入口）

## 修改文件

### `docs/requirements.md` (改)
- **修改内容**: 在 FR6（AI 翻译后处理）下新增 FR6.9「独立润色入口」需求，含 5 个子需求：
  - FR6.9.1 模式切换：AI 翻译窗口顶部增加翻译/润色模式切换
  - FR6.9.2 配置复用：润色参数复用后处理标签页现有控件
  - FR6.9.3 预览确认模式：新增配置项，可选润色后预览确认或直接写入
  - FR6.9.4 进度反馈：润色过程显示进度窗口，支持暂停/停止
  - FR6.9.5 异常处理：无译文提示、LLM 失败保留原译文
- **原因**: 用户需要在不经过完整翻译流水线的情况下，对已翻译词条独立执行 AI 润色。后端 LLMPolisher 已完备，仅缺 UI 入口
