# 010: project-persistence 方案策划与 8 Story 展开

**日期**: 2026-05-08
**类型**: 增
**关联**: Epic: 项目初始化（文档） > project-persistence 方案

## 修改文件

### `plans/project-persistence/plan.md` (增)
- **修改内容**: 新建 project-persistence Epic 方案文档。定义功能边界（范围内：项目/版本持久化全链路；范围外：术语转化工具/协作同步）。拆分 8 个 Story 按 4 个 Phase 推进——Phase1(S01-S02) 持久化基础设施、Phase2(S03-S04) 项目+版本管理 UI、Phase3(S05-S07) 自动保存+快照+归档、Phase4(S08) 版本写回。每个 Story 含验收标准、实现步骤、涉及文件。引用 ADR-006 架构决策
- **原因**: FR8 项目持久化与翻译版本管理经需求分析和架构设计后，需要可执行的实现方案指导编码

### `plans/project-persistence/stories/story-01-persistence-data-model.md` (增)
- **修改内容**: WorkspaceState/ProjectHandle/VariantStore 三个核心类的详细设计——完整接口签名、数据流（读取/保存/原子写入）、apply_to/collect_from 桥接方法伪代码、JSON 原子写入策略（.tmp → os.replace）、4 个边界条件、分步测试策略
- **原因**: S01 是持久化层基础，后续 7 个 Story 均依赖此 3 个类

### `plans/project-persistence/stories/story-02-appcontext-extension.md` (增)
- **修改内容**: AppContext 扩展详细设计——4 个新属性（workspace/active_project/active_variant/variant_store）+ 2 个新信号（project_list_changed/variant_changed）+ TYPE_CHECKING 避免循环导入 + collection_changed → dirty 联动
- **原因**: S02 在 S01 数据模型和 S03 UI 之间建立桥接

### `plans/project-persistence/stories/story-03-project-management.md` (增)
- **修改内容**: 项目工具栏组件 ProjectBar 设计 + MainWindow 新建/打开/切换项目逻辑 + WorkbenchWidget 集成。含首次启动空白状态处理、项目切换保存流程伪代码
- **原因**: 用户可见的第一个持久化功能入口

### `plans/project-persistence/stories/story-04-variant-management.md` (增)
- **修改内容**: 版本管理完整设计——VariantDialog/新建/复制/删除/切换流程。含保存行为配置(save_behavior: auto/prompt)、版本切换时 VariantStore.apply_to + label_library 替换逻辑、Step2 监听 variant_changed 刷新
- **原因**: 翻译版本管理是本次需求的核心差异化功能

### `plans/project-persistence/stories/story-05-auto-save-and-restore.md` (增)
- **修改内容**: AutoSaveManager 类设计（QTimer 定时 + 防抖 2s）+ 启动恢复流程（workspace → project → 解析源文件 → VariantStore → 筛选状态）+ Ctrl+S 手动保存 + workspace.last_session 会话状态保存
- **原因**: 自动保存确保用户翻译数据不丢失

### `plans/project-persistence/stories/story-06-snapshot-operations.md` (增)
- **修改内容**: VariantStore 快照 CRUD 方法 + SnapshotDialog 快照管理对话框 + 菜单集成。快照为 current.json 完整时间点拷贝
- **原因**: 快照提供版本回退能力

### `plans/project-persistence/stories/story-07-transbridge-archive.md` (增)
- **修改内容**: ZIP 导出/导入实现设计——export_transbridge/import_transbridge 函数签名 + 项目名冲突处理 + 命令行参数支持双击打开 + Windows 文件关联
- **原因**: .transbridge 是项目分享/备份的便携格式

### `plans/project-persistence/stories/story-08-variant-write-back.md` (增)
- **修改内容**: WriteCard 扩展设计——写回模式选择（仅当前版本/所有版本）+ 全版本遍历写回循环 + 版本切换副作用处理（blockSignals 冻结）+ write_back 配置持久化
- **原因**: 分版本写回是多版本管理的最终交付环节
