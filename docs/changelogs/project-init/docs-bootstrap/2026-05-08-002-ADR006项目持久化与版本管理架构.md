## 修改文件

### `docs/adr/006-project-persistence-variant-management.md` (增)
- **修改内容**: 新建 ADR-006，定义 9 项架构决策：(1) 存储格式选 JSON，零依赖可读可 diff；(2) 三层数据分层——持久化(磁盘JSON)/运行时(AppContext扩展)/视图(QSettings)；(3) Variant 子目录模型 `data/projects/{proj}/{variant}/current.json`；(4) workspace.json 全局状态结构；(5) AppContext 扩展方案——添加 workspace/active_project/active_variant/variant_store 属性和 project_list_changed/variant_changed 信号；(6) VariantStore 运行时缓存层设计；(7) 序列化策略——仅持久化 translation+labels+label_library，源文件解析结果每次重建；(8) 快照设计——current.json 完整时间点拷贝；(9) 写回策略——分版本分目录输出
- **原因**: FR8 项目持久化与翻译版本管理需要系统级架构决策指导后续方案策划和编码。当前无任何持久化架构，需从零建立完整的三层数据管理模型
