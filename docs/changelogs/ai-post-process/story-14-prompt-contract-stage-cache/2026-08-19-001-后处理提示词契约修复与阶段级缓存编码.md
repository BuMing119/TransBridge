# 001: 后处理提示词契约修复与阶段级缓存编码实现

**日期**: 2026-08-19
**类型**: 增/改
**关联**: Epic: AI 翻译后处理 > Story 14: 后处理提示词契约修复与阶段级缓存

## 目标

修复质量检测、问题修复、翻译润色和质量裁决提示词与代码之间的既有契约偏差，为每个「阶段 × 单条/批量」提示词建立一个完整稳定 `SYSTEM` 前缀和一个阶段级缓存断点（FINAL）。保持结果模型、单条/批量输出协议、术语匹配、裁决阈值与失败降级兼容。

## 修改文件

### `src/transbridge/ai_translator/post_processor/prompt_contract.py` (增)
- **修改内容**: 新增后处理提示词契约工具。定义 `PostProcessStage` / `PromptShape`、`PromptTemplateContractError`、`validate_prompt_template()`（校验未知/缺失 required 变量，SYSTEM 只允许稳定变量）、`render_prompt_template()`（严格 `Template.substitute()`，检测未解析占位符）、`build_postprocess_cache_key()`（stage+shape+完整渲染 System 决定，`transbridge.postprocess.v1.<stage>.<shape>.<sha24>`）、`build_postprocess_messages()`（组装 SYSTEM(FINAL) -> USER 并挂 `single_stable_prefix`/FINAL 指令）
- **原因**: 统一后处理四阶段的提示词契约与缓存 key 机制，禁止 `$...` 未替换内容进入模型请求

### `src/transbridge/ai_translator/post_processor/quality_gate.py` (改)
- **修改内容**: 改用 prompt_contract 严格渲染；批量 `_build_batch_prompt` 为每条用 `_get_relevant_terms`/`match_terms([entry.original])` 单独渲染术语、不跨条合并；无术语用与 single 一致语义；消息经 `build_postprocess_messages(FINAL)` 组装；契约违规单变体 warning + 回退内置默认模板。公共接口 `check`/`check_batch`、`QualityGateResult`/`QualityVerdict`、阈值/解析/降级不变
- **原因**: 修复「批量 QG 不传术语却要求模型识别术语错误」的契约偏差，使单条/批量检测依据一致

### `data/prompts/quality_gate/zh_CN.toml` (改)
- **修改内容**: single/batch System 整理为「只检测」完整稳定契约（角色=本地化质量检测员、只判不改写、pass/fail/uncertain 边界、回显/异常重复判 fail、拿不准→uncertain、术语仅判断标准译法不替换）；JSON 示例改为合法 JSON，枚举取值移到示例外
- **原因**: 与 prompt_contract 契约对齐并用合法 JSON 减少解析失败

### `src/transbridge/ai_translator/post_processor/llm_refiner.py` (改)
- **修改内容**: 恢复「只修复明确问题」职责，移除 `$polish_level`、`polish_changes` 及润色动作语言；用 prompt_contract 严格渲染 + `build_postprocess_messages(FINAL)`；批量无问题文案改为「保持不变，无需修复」。公共接口 `refine`/`refine_batch`、`RefineResult`/`FixApplied`、批量降级策略不变
- **原因**: 恢复 Story 04 既定边界（Refiner 只修复，Polisher 才润色），消除 `safe_substitute` 泄漏与无字段解析

### `data/prompts/refinement/zh_CN.toml` (改)
- **修改内容**: 从 System/User/输出示例移除润色级别与 `polish_changes`；删除 `[polish_levels]` 段；示例改为合法 JSON
- **原因**: 与 Refiner「只修复」职责和 `RefineResult` 数据模型对齐

### `src/transbridge/ai_translator/post_processor/polisher.py` (改)
- **修改内容**: single/batch System 均用 `$game_name`/`$source_lang`/`$target_lang` 稳定 ctx 严格渲染（修掉原来直接发未渲染 `self._prompts["system"]` 导致模型收到字面量 `$game_name`）；三级别定义稳定保留在 System，当前选中级别进动态 User（`$polish_level`）不改变 key；经 `build_postprocess_messages(FINAL)` 组装。公开接口 `polish`/`polish_batch`、`PolishResult`、失败保留原译文不变
- **原因**: 保证润色 System 语言对正确渲染、级别变化不破坏缓存 key

### `data/prompts/polish/zh_CN.toml` (改)
- **修改内容**: single/batch System 引用稳定变量；三级别定义稳定在 System；批量 JSON 示例去掉 `...`、aspect 枚举移出示例；均为合法 JSON
- **原因**: 与严格渲染契约对齐

### `src/transbridge/ai_translator/post_processor/llm_arbiter.py` (改)
- **修改内容**: single User 严格渲染并传入 `polished_translation`/`polish_details`/`polisher_confidence`（原代码已传入但 TOML 未引用）；System 明确只裁决最终候选（润色>修复>初始）、不生成/不改写新译文；single/batch 经 `build_postprocess_messages(FINAL)` 组装。公开接口 `arbitrate`/`arbitrate_batch`、`ArbiterDecision`/`ArbitrationContext`、Python 快裁路径、strict mode、降级不变
- **原因**: 修复「单条裁决看不到最终润色结果」的偏差，使单条/批量裁决输入一致

### `data/prompts/arbitration/zh_CN.toml` (改)
- **修改内容**: single User 补 `polished_translation`/`polish_details`/`polisher_confidence` 三字段引用；System 明确只裁决、渲染稳定变量；JSON 示例去除联合伪 JSON 与 `...`，均为合法 JSON
- **原因**: 修复单条裁决缺润色字段的契约偏差

### `src/transbridge/infra/prompt_cache.py` (改)
- **修改内容**: 复用 Story 15 新增模块：`validate_prompt_cache_directives` 已支持 `single_stable_prefix`/FINAL 校验；后处理 `build_postprocess_messages` 生成 FINAL 指令即被 `prepare_openai_chat_cache_request` / `build_anthropic_system_blocks` 消费
- **原因**: 后处理不重新实现 Provider 私有协议，与翻译 A/B 同源，保证兼容端点只收清洁消息
