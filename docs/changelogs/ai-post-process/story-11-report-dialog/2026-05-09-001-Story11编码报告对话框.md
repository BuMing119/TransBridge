# 001: Story-11 编码 — 应用内报告对话框

**日期**: 2026-05-09

## 修改文件

### `src/transbridge/ui/tools/ai_translator/_translation_report_dialog.py` (增)
- **修改内容**: 新建 `_TranslationReportDialog(QDialog)` 类（~310行），实现：
  - 双模式自动判断：构造函数根据传入参数（`translate_result` vs `polish_stats`）自动选择翻译或润色模板，窗口标题对应「翻译报告」/「润色报告」
  - 汇总 Tab（`_build_summary_tab`）：翻译模式 3 行×5 列统计卡片（总条目/成功/失败/跳过/新增术语 → 检查数/错误/警告/信息/需审核 → 通过/打回/待审/修复数/润色数）；润色模式 1 行×5 列（润色总数/接受/拒绝/失败/信心度均值）。卡片使用 `_make_stat_card()` 生成 QFrame 含大号数字+描述标签
  - 条目详情 Tab（`_build_entries_tab`）：QTableWidget + QComboBox 筛选栏 + `setSortingEnabled(True)`。翻译模式列=原文/原译文/最终译文/裁决结果/信心度/问题数；润色模式列=原文/原译文/润色结果/接受?/信心度/变更摘要。筛选支持 QComboBox 切换（全部/通过/打回/待审 或 全部/已接受/已拒绝），通过 `setRowHidden` 实现行显隐
  - 问题明细 Tab（`_build_issues_tab`，仅翻译模式）：QTableWidget 5 列（条目ID/问题类型/严重度/描述/建议），严重度列按 error=红/warning=橙/info=灰 着色，支持 QComboBox 按严重度筛选
  - 交互功能：双击条目行发射 `entry_activated(str)` 信号；底部「打开 Excel」按钮调用 `os.startfile(report_path)`；`WA_DeleteOnClose` 非模态
- **原因**: 替代当前翻译/润色完成后的 QMessageBox 纯文本弹窗，提供结构化、可交互的结果报告。双模板设计因翻译和润色产出的数据结构不同（翻译含完整五阶段后处理数据，润色仅有 PolishResult）

### `src/transbridge/ui/main_window.py` (改)
- **修改内容**: 新增 `_on_report_entry_activated(entry_id: str)` 方法（~15行）。检查集合是否已加载 → 在 collection 中查找 entry_id → 切换 `_mode_tabs` 到工作台 → 调用 `step2.locate_entry(entry_id)`。条目不存在时在状态栏显示提示
- **原因**: 建立报告对话框与主窗口 Step2 之间的导航链路，使用户可从报告中的问题条目一键跳转到主表定位审校

### `src/transbridge/ui/workbench/step2.py` (改)
- **修改内容**: 
  - import 新增 `QAbstractItemView`
  - 新增 `locate_entry(entry_id: str)` 方法（~30行）：清除所有筛选条件（分类/阶段/文本搜索/标签/聚焦模式）→ 重建筛选标签 UI → 调用 `_populate_table()` 刷新表格 → 遍历表格行查找匹配 entry_id 的行（通过 Key 列的 UserRole 获取 entry 对象）→ `selectRow()` + `scrollToItem(PositionAtCenter)`
  - 之前 Step2 无定位条目的方法，条目筛选后可能不可见，跳转需要先清筛再定位
- **原因**: 报告对话框中的条目跳转需要 Step2 提供精确的行定位能力，包括清除筛选确保目标行可见
