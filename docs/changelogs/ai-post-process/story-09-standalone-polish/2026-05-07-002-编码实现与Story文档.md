# 002: 独立润色入口编码实现与 Story 文档

**日期**: 2026-05-07
**类型**: 增
**关联**: Epic: AI 翻译后处理 > Story 09: 独立润色入口

## 修改文件

### `src/transbridge/paratranz/config_manager.py` (改)
- **修改内容**: LLMConfig 新增 `polish_preview_enabled: bool = False` 字段。`save_to_file()` 写入 `polish_preview_enabled`，`load_from_file()` 读取 `polish_preview_enabled`
- **原因**: 独立润色入口需要控制润色后是否弹出预览确认窗口，字段需持久化到 INI 配置文件

### `src/transbridge/ui/tools/ai_translator/_polish_worker.py` (增)
- **修改内容**: 新建 `_PolishWorker(QThread)`，封装 LLMPolisher 调用。`run()` 逐条调用 `polisher.polish(entry)`，发出 `progress(current, total, message)`、`entry_done(entry_id, PolishResult)`、`finished_all(dict)` 信号。支持 `stop()`/`pause()`/`resume()` 通过 threading.Event 控制
- **原因**: 润色是 LLM 网络调用，需在后台线程执行避免阻塞 UI，复用 QThread + 信号模式（ADR-004）

### `src/transbridge/ui/tools/ai_translator/_polish_preview_dialog.py` (增)
- **修改内容**: 新建 `_PolishPreviewDialog(QDialog)`，三列 QTableWidget 对比（原文/原译文/润色结果），点击润色列切换接受(绿)/拒绝(红)。工具栏包含「全部接受」「全部拒绝」按钮和统计标签。`get_results()` 返回 `entry_id → str|None` 映射（None=拒绝润色保留原译文）
- **原因**: 用户需要预览润色效果并逐条确认，避免不满意的润色结果覆盖译文

### `src/transbridge/ui/tools/ai_translator/ai_translator_window.py` (改)
- **修改内容**: 
  - `_init_ui()`: 窗口顶部新增模式切换（QButtonGroup + 翻译/润色 QRadioButton），后处理标签页新增「润色后预览确认」checkbox
  - `_on_mode_changed()`: 新增方法，润色模式下隐藏翻译范围选项、按钮变为「开始润色」
  - `_on_start()`: 顶部新增模式检查，润色模式委托给 `_on_polish_start()`
  - `_on_polish_start()`: 新增方法，获取选中已翻译条目 → 创建 LLMPolisher + _PolishWorker → 根据 preview_enabled 分流
  - `_polish_direct()`: 新增方法，润色结果直接写入 collection（`add(overwrite=True)`）
  - `_polish_with_preview()`: 新增方法，润色完成后弹出 _PolishPreviewDialog，用户确认后应用
  - `_apply_polish_results()`: 新增方法，将预览确认结果写入 collection
  - `_load_config()/_save_config()`: 新增 `polish_preview_enabled` 读写
- **原因**: FR6.9 需求实现，在现有 AI 翻译窗口中增加独立润色入口，复用配置和进度窗口模式
