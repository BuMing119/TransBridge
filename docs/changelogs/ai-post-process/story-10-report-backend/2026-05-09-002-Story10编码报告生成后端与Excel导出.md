# 002: Story-10 编码 — 报告生成后端与Excel导出

**日期**: 2026-05-09
**类型**: 增/改
**关联**: Epic: AI 翻译后处理 > Story 10: 报告生成后端与Excel导出

## 修改文件

### `src/transbridge/ai_translator/translator.py` (改)
- **修改内容**: `TranslationResult` dataclass 新增 4 个字段：`refine_results: dict | None`（后处理修复中间数据）、`polish_results: dict | None`（后处理润色中间数据）、`decisions: dict | None`（后处理裁决中间数据）、`report_path: str | None`（生成的 Excel 报告路径）。默认值均为 None，向后兼容
- **原因**: 后处理流水线产生的重要中间数据（修复/润色/裁决结果）原本在 `process_entries()` 返回后即丢弃，现在需要保存到 TranslationResult 以支持报告生成（Story-11/12）和后续查阅

### `src/transbridge/ai_translator/post_processor/base.py` (改)
- **修改内容**: `PostProcessResult` dataclass 新增 3 个字段：`refine_results: dict | None`（{entry_id: RefineResult}）、`polish_results: dict | None`（{entry_id: PolishResult}）、`decisions: dict | None`（{entry_id: ArbiterDecision}）。默认值均为 None，向后兼容所有现有代码
- **原因**: 使 `process_entries()` 能将五阶段后处理的中间数据随 PostProcessResult 一起传出，避免在各阶段结束后丢弃修复/润色/裁决的详细结果

### `src/transbridge/ai_translator/post_processor/post_processor.py` (改)
- **修改内容**: `process_entries()` 方法在 `return result` 之前新增 3 行代码，将局部变量 `refine_results`、`polish_results`、`decisions` 保存到 `result` 的对应字段（通过 `result.refine_results = refine_results if refine_results else None` 等）。非空时才赋值，保持空 dict → None 的语义
- **原因**: 后处理完成后，修复/润色/裁决的逐条详细结果需要随 PostProcessResult 传出供报告生成器使用。之前这些中间数据仅用于阶段间传递，方法返回后即被 GC

### `src/transbridge/ai_translator/post_processor/report_generator.py` (增)
- **修改内容**: 新建 `ReportGenerator` 类（~310 行），核心功能：
  - `__init__(esp_stem)`: 构造函数，通过 `LLMConfig.get_ai_translator_dir()` 确定输出目录 `data/ai_translator/{esp_stem}/reports/`
  - `generate_translate_report(result, ...)`: 生成翻译模式 5 Sheet Excel（Summary/Entries/Issues/Refinements/Arbitrations）。Summary Sheet 含 16 项统计指标；Entries Sheet 含 entry_id/original/initial_translation/refined/polished/final/stage/verdict/confidence；Issues Sheet 含问题类型/严重度/描述/建议；Refinements Sheet 含修复译文/信心度/修复项说明；Arbitrations Sheet 含裁决结果/理由/信心度/建议动作
  - `generate_polish_report(results, entries, stats)`: 生成润色模式 3 Sheet Excel（Summary/Entries/Polish）。Summary 含 8 项统计指标；Entries 含原文/原译文/润色结果/接受状态/信心度/变更摘要；Polish Sheet 每项变更为一行（方面/改前/改后/原因）
  - `_rotate(keep=20)`: 自动清理旧报告，按修改时间排序保留最近 N 份
  - `_save(wb, mode)`: 文件命名格式 `{esp_stem}_{mode}_report_{YYYYMMDD_HHMMSS}.xlsx`
  - Excel 样式：微软雅黑字体、蓝色表头白字、细线边框、自动列宽（中文2字符宽度）、长文本自动换行
- **原因**: 为整个报告系统提供数据聚合和 Excel 输出能力。翻译和润色两种模式产出的数据结构不同，需要不同的 Sheet 结构和统计维度。文件轮转防止报告目录无限膨胀
