## 修改文件

### `src/transbridge/smart_assistant/prompts.py` (改)
- **修改内容**: 重写 `HYBRID_SYSTEM_PROMPT` 常量：
  - 身份描述从"你是 TransBridge 的 AI 翻译助手，通过推理和工具调用帮助用户完成翻译相关任务"改为"你是 TransBridge 的智能操作助手，帮助用户完成本软件能处理的各类本地化任务"，明确绑定 TransBridge 软件本身
  - 新增能力感知：可操作 TransBridge 完成解析 ESP/EET/XT/SST、管理翻译集合、AI 翻译与润色、术语库维护、质量检查与后处理、写回译文、ParaTranz 同步等
  - 新增多 Agent 系统感知：可协调 translator、proofreader 等专职 Agent 协作
  - 新增 Skill 工作流、文件上传处理（纠错表/术语表/风格指南）、跨会话记忆的能力描述
  - 新增 `## 回复风格` 节：用户打招呼时简短友好回应，禁止列出能力清单或主动询问需求
- **原因**: Agent 框架升级后（FR7.13 Phase 1+2，60 工具 + 7 Agent + Skill 系统 + 文件上传 + 记忆），系统提示词未同步更新，导致 AI 自我认知仍停留在 v1 阶段，不知道自己的真实能力范围。同时约束 greeting 行为避免"报菜名"
