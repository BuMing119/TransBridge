# 009: 编码实现 FR7.16 文档流重构（Story-08-2/08-3/08-5）

**日期**: 2026-05-14
**类型**: 改
**关联**: Epic: 智能助手侧边栏面板 > Story 08: AI助手页面体验全面翻新

## 修改文件

### `ui/tools/smart_assistant/message_bubble.py` (重写)
- **修改内容**: 完全重写 MessageBubble 组件，从微信左右气泡风格改为现代 AI 文档流风格。新增 `AvatarLabel` 内部类（24x24px 圆形文字头像，用户=U 深灰底白字，AI=A 品牌绿底白字）。布局改为统一左对齐 `[头像] [内容区 max-width:720px]`，取消左右 addStretch() 气泡对齐。用户消息淡灰背景 #f7f7f7，AI 消息无背景。移除 system role 特殊处理。保留 MarkdownRenderer 渲染 + set_text() 增量更新
- **原因**: FR7.16.1/16.2 要求从气泡左右对齐改为文档流统一左对齐 + 文字头像区分角色

### `ui/tools/smart_assistant/thinking_indicator.py` (增)
- **修改内容**: 新建 `ThinkingIndicator(QWidget)` 组件（~120 行）。默认状态显示"正在思考中" + QLabel 三点循环动画（QTimer 500ms 驱动 `.  `→`.. `→`...`）。紧凑横条样式：#f5f5f5 背景、圆角 8px、max-width 720px。`set_thought(text)` 设置思考文本并启动动画；`toggle_expand()` 展开/折叠 QTextEdit（等宽字体、只读、max-height 200px），展开时暂停动画；`stop_animation()` / `clear()` 停止动画和隐藏
- **原因**: FR7.16.6 / Story-08-5 要求默认折叠思考过程，仅显示简洁动画指示器

### `ui/tools/smart_assistant/chat_widget.py` (改)
- **修改内容**: 
  - **输入框重构**: `_input.setMaximumHeight` 100→200px，placeholder 追加 `/obs` 提示，圆角 12→16px，外层包裹居中 QHBoxLayout（左右 stretch + max-width 720px）
  - **按钮行居中**: `_init_ui_stage4` 中按钮行（清空/Auto/发送）包裹在居中 QHBoxLayout（左右 stretch）
  - **系统消息融入**: `add_system_message()` 重写为轻量横条标签——成功消息绿色左边框+淡绿背景，失败红色左边框+淡红背景，中性灰色。替代原居中 QLabel 和 MessageBubble("system")
  - **观测对话流化**: 移除 `_obs_tabs` QTabWidget 和 `_obs_header`，改为 `_obs_inline_visible` flag + `_toggle_obs_inline()` 方法 + `/obs` 命令解析（`_on_send` 开头检测）
  - **Thought 展示**: `_on_llm_finished` 修复 had_streaming bug（`had_streaming` 在 `_streaming_bubble=None` 前保存），thought 改为 `_show_thinking_indicator()` 创建 ThinkingIndicator；新增 `_hide_thinking_indicator()` / `_toggle_thought_expand()`
  - **Ctrl+O 快捷键**: `_init_ui_stage4` 注册 `QShortcut("Ctrl+O")` → `_toggle_thought_expand()`
  - **生命周期**: `_run_llm_round` 和 `_clear_conversation` 中调用 `_hide_thinking_indicator()` 清理
  - **导入清理**: 移除 `QTabWidget/QTableWidget/QTableWidgetItem/QListWidget/QListWidgetItem/QHeaderView`，新增 `QFrame/QShortcut/QKeySequence/ThinkingIndicator`
- **原因**: FR7.16.3（居中大输入框）、FR7.16.5（系统消息融入）、FR7.16.7（观测对话流化）、Story-08-5（思考折叠）

### `ui/tools/smart_assistant/panel.py` (改)
- **修改内容**: `SmartAssistantPanel.__init__` 中 `setMinimumHeight(200)` 改为 `setMinimumWidth(400)` + `setMinimumHeight(300)`
- **原因**: FR7.16.8 要求放宽面板最小尺寸限制，确保文档流布局在拖拽缩小时不会过度挤压

### `ui/tools/smart_assistant/tool_card.py` (改)
- **修改内容**: `ToolCard` 和 `BatchToolCard` 新增 `setMaximumWidth(720)`，边框颜色从 #FFE082→#E8DCC8（柔和化），圆角 12→10px
- **原因**: FR7.16.4 要求工具卡片内联左对齐，与文档流融合

### `ui/tools/smart_assistant/plan_card.py` (改)
- **修改内容**: `PlanCard` 新增 `setMaximumWidth(720)`，边框颜色从 #90CAF9→#C8D8E8（柔和化），圆角 12→10px
