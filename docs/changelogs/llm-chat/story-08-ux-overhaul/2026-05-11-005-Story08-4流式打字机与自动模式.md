## 修改文件

### `src/transbridge/ui/tools/smart_assistant/chat_widget.py` (改)
- **修改内容**: (1) 新增流式打字机系统：`_streaming_text`（累积文本）、`_streaming_bubble`（当前流式气泡引用）、`_streaming_dirty`（脏标记）、`_streaming_timer`（50ms 节流 QTimer）。`_on_llm_chunk()` 从空实现改为累积 chunk+启动 timer。`_flush_streaming()` 每 50ms 用 MarkdownRenderer 重新渲染流式气泡并替换旧气泡。`_run_llm_round()` 在启动 ChatWorker 前插入占位气泡"..."。(2) 新增自动模式：`_auto_cb` QCheckBox（"Auto"），`_auto_mode` 状态从 QSettings("TransBridge", "SmartAssistant") 加载。`_on_auto_mode_toggled()` 持久化到 QSettings。`_auto_execute_steps()` 自动模式下直接执行工具/计划，检测 admin 级工具时回退到手动确认卡片。(3) `_on_llm_finished()` 自动模式分支：`if self._auto_mode and steps` → 调用 `_auto_execute_steps()`，否则正常显示卡片。流式完成后跳过 thought 单独气泡（流式已显示全量文本）。(4) `_on_send()` 新增流式中断：cancel worker + wait(3000) + 删除 `_streaming_bubble` + 清理状态。(5) `_on_llm_error()` 和 `_clear_conversation()` 新增流式状态清理。(6) 新增导入 `QCheckBox`、`QSettings`。
- **原因**: FR7.14.2 流式打字机提升对话体验——用户无需等待完整响应即可实时看到 LLM 输出；FR7.14.4 自动模式减少手动确认操作——高频工具场景下加速工作流，admin 级工具始终保持安全护栏。
