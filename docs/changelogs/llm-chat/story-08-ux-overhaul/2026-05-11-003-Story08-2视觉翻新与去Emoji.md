# 003: Story-08-2 视觉风格现代化与去Emoji

**日期**: 2026-05-11
**类型**: 改
**关联**: Epic: 智能助手侧边栏面板 > Story 08-2: 视觉风格现代化

## 修改文件

### `src/transbridge/ui/tools/smart_assistant/message_bubble.py` (改/重写)
- **修改内容**: `MessageBubble` 类重写。用户气泡：品牌绿背景(#95EC69)、圆角14px、max-width 420px，内容使用 `MarkdownRenderer().render(text)` 渲染（替代纯文本 QLabel）。AI气泡：白色背景+细边框(#E0E0E0)、圆角14px。系统消息：保持居中灰字 QLabel。布局逻辑不变（user=右对齐、assistant=左对齐、system=居中）。移除旧的 `_STYLES` 字典和 `_build_qss()` 方法。
- **原因**: FR7.14.5 视觉现代化要求气泡向现代聊天应用靠拢；FR7.14.1 MarkdownRenderer 作为共享基础设施驱动内容渲染。

### `src/transbridge/ui/tools/smart_assistant/chat_widget.py` (改)
- **修改内容**: (1) `__init__` 新增全局字体 Microsoft YaHei 10pt；(2) 输入框 `_input` 增加 QSS 样式：圆角12px、min-height 60px、浅灰边框、聚焦绿色高亮；(3) 发送按钮样式：品牌绿(#4CAF50)+白色文字+圆角8px+bold；(4) 清空对话按钮和上传按钮：浅灰(#f5f5f5)+圆角6-8px 次要样式；(5) 观测面板新增可折叠标题栏 `_obs_header`（`[>] 观测面板`），默认 `_obs_tabs.setVisible(False)`，新增 `_toggle_obs_panel()` 方法切换显示/隐藏。同时全局去除所有 emoji 字符：系统消息前缀（🔑⚠🌐❌🔄→移除）、Agent状态指示器（○◉●✕→o/(*)/x）、工具执行结果（✅→[OK]/❌→[FAIL]）、观测面板标题（📊→[>]/[v]）、重试按钮（🔄→移除）、计划结果图标（✅→[OK]/❌→[FAIL]）。
- **原因**: FR7.14.3 观测面板默认折叠释放空间；FR7.14.5 视觉现代化统一输入区和按钮风格；用户要求去除代码中所有 emoji。

### `src/transbridge/ui/tools/smart_assistant/tool_card.py` (改)
- **修改内容**: `ToolCard` 和 `BatchToolCard` 样式翻新：圆角 8→12px、增加边框(#FFE082)、内边距微调。执行按钮改为绿色样式(#4CAF50)+圆角6px，忽略按钮/全部执行按钮改为灰色次要样式+圆角6px。标题文字颜色优化(#333)。去除所有 emoji：🔧→`[Tool]`、✅→`[OK]`、❌→`[FAIL]`。新增 `from PyQt6.QtCore import Qt` 导入以使用 `Qt.CursorShape.PointingHandCursor`。
- **原因**: 视觉现代化，与 chat_widget 按钮风格统一，去除 emoji。

### `src/transbridge/ui/tools/smart_assistant/plan_card.py` (改)
- **修改内容**: `PlanCard` 样式翻新：圆角 8→12px、增加边框(#90CAF9)、内边距微调。步骤列表 `_step_list` 设置透明背景。执行计划按钮绿色样式(#4CAF50)+圆角6px，取消按钮灰色次要样式+圆角6px。进度标签颜色优化(#888)。去除所有 emoji：📋→`[Plan]`、✅→`[OK]`、❌→`[FAIL]`、⏳→`[..]`。新增 `from PyQt6.QtCore import Qt` 导入。
- **原因**: 视觉现代化，与整体风格统一，去除 emoji。
