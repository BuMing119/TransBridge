# 010: FR7.16 修复 — 流式 JSON 泄漏、布局、动画时序

**日期**: 2026-05-14
**类型**: 改
**关联**: Epic: 智能助手侧边栏面板 > Story 08: AI助手页面体验全面翻新

## 修改文件

### `ui/tools/smart_assistant/chat_widget.py` (改)

- **_flush_streaming 属性兼容**: `bubble._inner` → `bubble._content_wrapper`，适配重写后的 MessageBubble 属性名。移除 `_role != "system"` 分支（新 MessageBubble 不再处理 system role）。`set_text()` 的 else 分支移除
- **原因**: MessageBubble 重写后属性改名，`_flush_streaming` 未同步更新导致 AttributeError

- **输入区布局重构**: 移除 `input_wrapper`（左右 addStretch 居中包裹）和 `btn_wrapper`（左右 addStretch 居中包裹），输入框和按钮行改为全宽直接添加。输入框 `setMaximumHeight` 200→100，`setMinimumHeight` 60→40。移除 `setMaximumWidth(720)`、`setSizePolicy`、`setMinimumWidth(300)`。padding 和 font-size 收紧
- **工具栏布局重构**: 移除 `toolbar_wrapper`（左右 addStretch 居中包裹），工具栏改为全宽直接添加。修复 `toolbar_wrapper`→`toolbar` 变量名遗漏
- **原因**: 居中包裹导致输入框/chips 被挤在中间窄条，两边大片空白，视觉割裂

- **_on_llm_finished 思考指示器时序修复**:
  - `_show_thinking_indicator(thought)` 从无条件（`if thought`）改为条件（`if thought and steps`）— 仅在 LLM 计划执行工具时显示
  - 新增 `_finished_bubble` 保存流式气泡引用，当 `thought and steps` 时从布局中 `removeWidget` + `deleteLater` 移除流式气泡— 避免用户看到 JSON 原文
  - `steps` 为空时追加 `_hide_thinking_indicator()` — 纯文本回复不再残留动画
- **原因**: 流式气泡显示 LLM 返回的 JSON 原文（`{"mode":"plan","thought":"...","steps":[...]}`），ThinkingIndicator 在其下方出现，用户先看到原始 JSON 再看到"思考中"。纯文本回复时动画永不停止

- **_on_plan_cancelled 清理**: 追加 `_hide_thinking_indicator()` 调用
- **原因**: 用户取消计划执行时思考指示器遗漏清理

- **导入清理**: 移除 `QSizePolicy`（不再使用），新增 `QShortcut/QKeySequence`（Ctrl+O 快捷键）
