# 004: Story-08-3 布局重组与滚动优化

**日期**: 2026-05-11
**类型**: 改
**关联**: Epic: 智能助手侧边栏面板 > Story 08-3: 布局重组与滚动优化

## 修改文件

### `src/transbridge/ui/tools/smart_assistant/quick_actions.py` (改/重写)
- **修改内容**: `QuickActionsPanel` 类重写为 `QuickActionsChips`。从固定 48px 高度的独立 QWidget（4 个 QPushButton + Skill 下拉按钮）改为紧凑的 chips 标签行（圆角 12px、小字体 11px、浅灰背景 #f0f0f0、hover 变色）。4 个快捷指令 chip + Skill 下拉 chip 嵌入一行，右侧留 stretch 空间。信号接口 `action_clicked(str)` 和 `skill_triggered(str)` 保持不变。Skill 下拉菜单逻辑完全保留。
- **原因**: FR7.14.7 快捷指令面板从固定 Panel 改为 chips 标签式工具栏，释放垂直空间，向现代聊天应用靠拢。

### `src/transbridge/ui/tools/smart_assistant/panel.py` (改)
- **修改内容**: 移除 `QuickActionsPanel` 导入和实例化，移除分割线 `QFrame`，移除 `_quick_actions.action_clicked` 和 `_quick_actions.skill_triggered` 信号连接。布局简化为 ChatWidget 独占（`layout.addWidget(self._chat, stretch=1)`）。Skill 加载逻辑（`SkillRegistry.reload()`）保留。`QDockWidget` 接口不变（`setObjectName`/`setAllowedAreas`/`setFeatures`/`visibility_changed` 信号/`chat` property）。
- **原因**: FR7.14.3 布局重组——快捷指令改为嵌入 chat_widget 的 chips，panel 仅作为容器。

### `src/transbridge/ui/tools/smart_assistant/chat_widget.py` (改)
- **修改内容**: (1) 新增 `from .quick_actions import QuickActionsChips` 导入；(2) 删除独立的 upload_row（上传按钮+标签）和 agent_row（Agent 状态指示器），替换为组合工具栏 `toolbar`：左侧 `QuickActionsChips`（stretch=1）+ 右侧上传按钮（chip 风格圆角 12px）+ 上传标签；(3) 删除 `_agent_indicators` 字典创建和相关 QLabel（translator/proofreader/orchestrator）；(4) 删除 `_update_agent_indicators()` 方法（含 icon_map/color_map/状态更新逻辑）及其在 `_on_plan_confirmed` 和 `_on_plan_all_finished` 中的两处调用；(5) 新增 `_back_to_bottom_btn`：半透明黑色浮动按钮（rgba(0,0,0,0.55)、白色文字、圆角 14px），定位在 QScrollArea 右下角，默认隐藏；(6) `_scroll_to_bottom()` 扩展为同时隐藏回到底部按钮；(7) 新增 `_on_scroll_changed(value)`：检测用户手动上滚超过 50px 时显示浮动按钮并定位到右下角，滚到底部时自动隐藏；(8) 新增 `_on_back_to_bottom()` 和 `resizeEvent()`（窗口 resize 时重新定位浮动按钮）；(9) `_chips.action_clicked` 和 `_chips.skill_triggered` 信号分别连接到 `self.set_input` 和 `self._on_skill`。
- **原因**: FR7.14.3 布局重组——Agent 指示器移除释放空间，上传栏与 chips 合并为一行减少垂直层数；FR7.14.6 消息区滚动优化——用户手动上滚查看历史时不强制拉回，提供浮动按钮一键回底。
