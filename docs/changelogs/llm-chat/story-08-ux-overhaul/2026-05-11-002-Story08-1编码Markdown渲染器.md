# 002: Story-08-1 Markdown渲染器编码实现

**日期**: 2026-05-11
**类型**: 增
**关联**: Epic: 智能助手侧边栏面板 > Story 08-1: Markdown 渲染器基础设施

## 修改文件

### `src/transbridge/infra/markdown_renderer.py` (增)
- **修改内容**: 新建 MarkdownRenderer 类（~270行），架构为 tokenizer + renderer 两阶段。Tokenizer（`_tokenize()`）逐行解析为 block 列表（_HeadingBlock/_ParagraphBlock/_CodeBlock/_ListBlock/_TableBlock/_HRBlock），每个 block 实现 `render() -> QWidget`。支持标题(H1-H6)、粗体/斜体/行内代码、围栏代码块（```，深色背景+Consolas等宽字体 QTextEdit）、无序/有序列表、表格（QTableWidget+自适应列宽）、链接（QDesktopServices.openUrl 可点击）、水平线。内联格式化通过 `_apply_inline()` 将 Markdown 转为 HTML rich text 在 QLabel 中渲染。容错：`render()` 最外层 try/except + tokenize 异常均降级为纯文本 QLabel。零 PyQt 外第三方依赖（纯正则+字符串解析）。
- **原因**: FR7.14.1 要求 Markdown 渲染器作为 infra/ 共享基础设施，供消息气泡、后处理报告、Agent 输出等全局复用。用户明确"不止用于 AI 相关，其他基础页面也要用"。

### `src/transbridge/infra/__init__.py` (改)
- **修改内容**: 新增 `from .markdown_renderer import MarkdownRenderer` 导入，`__all__` 列表追加 `"MarkdownRenderer"`。
- **原因**: 遵循 ADR-010 infra/ 包公开 API 导出惯例，使 `from src.transbridge.infra import MarkdownRenderer` 可直接使用。
