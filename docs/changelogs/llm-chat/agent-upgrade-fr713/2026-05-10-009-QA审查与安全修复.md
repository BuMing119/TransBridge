## 修改文件

### `src/transbridge/smart_assistant/execution_engine.py` (改)
- **修改内容**: 四处安全/质量修复：
  1. **_eval_condition 替代 eval 沙箱**：原 `eval(condition, {"__builtins__": None})` 可被 `().__class__.__bases__[0].__subclasses__()` 绕过。替换为 AST 白名单求值器 `_eval_ast_node()`，递归遍历 AST 节点，仅允许 Constant/Name/Attribute/Subscript/Compare/BoolOp/UnaryOp/Tuple/Call(仅.get()) 等安全节点类型。危险表达式安全返回 False
  2. **_checkpoint_path 路径穿越防御**：`graph_id` 未经校验直接拼入文件路径。新增 `re.sub(r'[^a-zA-Z0-9_.-]', '_', graph_id)` sanitize，阻止 `../` 路径穿越
  3. **移除 execute() 旧版死代码**：原 DAG 拓扑排序版 `execute()` 被 GraphSpec 版覆盖，成为死代码。移除旧 `execute()` 和仅被其调用的 `_topological_levels()`（共~60行）
  4. **pause() 实际生效**：`_paused` Event 只有 set/clear，从未调用 `wait()`。在 `execute_graph()` 的 BFS 循环中添加 `_check_pause()` 调用
- **原因**: 安全审查发现 2 个 Blocker（eval 沙箱逃逸 + 路径穿越）和 2 个 Major 问题（死代码 + pause 不生效），必须修复后方可进入生产。
