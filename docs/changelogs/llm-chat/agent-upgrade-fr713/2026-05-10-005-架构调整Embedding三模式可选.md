### `docs/adr/010-infra-extraction.md` (改)
- **修改内容**: 追加"Embedding/RAG 三模式可选"更新节。新增 EmbeddingConfig 数据类（mode=api/local/disabled, provider, model, api_key, base_url, local_model_path），LLMConfig 新增 embedding 字段。EmbeddingClient 三后端：api 调云端、local 加载 ONNX 模型、disabled 返回 None

- **原因**: 无 embedding 时记忆系统仍可用（降级为结构化查询）
