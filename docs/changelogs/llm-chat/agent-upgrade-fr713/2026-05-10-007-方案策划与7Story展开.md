### `plans/agent-upgrade/stories/story-08-safety-guardrails.md` (增)
- **修改内容**: Story 08 详细展开文档。GuardMiddleware ABC（before_execute/after_execute）+ GuardResult 数据类。PermissionGuard（read/write/admin 三级 + write 可配置确认 + admin 确认弹窗）。InputValidationGuard（类型校验+100KB 长度限制+SQL/XSS/命令注入模式检测）。OutputValidationGuard（类型校验+大小截断+API key 脱敏）。ToolSpec 扩展 3 字段（permission/require_confirmation/max_output_size）。ExecutionEngine 中间件链注入（before→retry→after 洋葱模型）。8 个实现步骤，含完整伪代码和中间件初始化顺序约束。
- **原因**: 安全护栏是用户可感知的核心安全能力，中间件注入模式复用 RetryHandler 范式，需详细设计注入点和执行顺序。

### `plans/agent-upgrade/stories/story-09-graph-engine-core.md` (增)
- **修改内容**: Story 09 详细展开文档。GraphExecutor ABC（execute_graph/cancel/pause/resume）。Graph 类型体系（NodeSpec 基类 + 4 子类 Action/Condition/Loop/HumanConfirm + EdgeSpec + GraphSpec，全 dataclass）。StatefulDAGExecutor 实现（BFS 层级遍历+同层并行+条件路由+循环控制）。条件表达式引擎（受限 eval，__builtins__: None）。execute() 向后兼容适配（steps→线性 GraphSpec 转换）。5 个实现步骤。
- **原因**: Graph 引擎是 7 个 Story 中预估最大（3h），涉及 ExecutionEngine 核心循环重写。需明确 BFS 遍历中 ConditionNode 动态路由和 LoopNode 子节点编号策略。

### `plans/agent-upgrade/stories/story-10-checkpoint-hitl.md` (增)
- **修改内容**: Story 10 详细展开文档。Checkpoint 数据类（graph_id/current_node_id/completed_results/graph_state/timestamp）+ 序列化辅助函数（_serialize_data 递归类型校验）。save/load/resume checkpoint 逻辑（每层自动保存+入口检测未完成 checkpoint+完成后清理）。HumanConfirmNode HITL 实现（后台线程 QEventLoop local loop + QTimer 超时兜底 + provide_decision 接口）。ChatWidget 确认弹窗 UI。4 个实现步骤。
- **原因**: HITL 涉及 QEventLoop 跨线程同步（后台执行线程 ↔ 主线程 UI），是 Phase 2 技术复杂度最高的组件，需详细设计暂停/恢复/超时三条路径。

### `plans/agent-upgrade/stories/story-11-observability.md` (增)
- **修改内容**: Story 11 详细展开文档。ObservabilityCollector（QObject + pyqtSignal 管道连接）+ ConversationTrace/ReActRound/ToolCallRecord/TokenStats 4 个数据模型。观测面板 UI（Token 仪表盘+工具调用列表+对话轮次时间线）。JSON 持久化存储+30 天自动清理。5 个实现步骤，Collector 为可选组件（ExecutionEngine 的 collector 参数默认 None）。
- **原因**: 可观测性复用现有信号管道，无需新建独立遥测系统。Collector 设计为可选注入，不启用时零开销。
