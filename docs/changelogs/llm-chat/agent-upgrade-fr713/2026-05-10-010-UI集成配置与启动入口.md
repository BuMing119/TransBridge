**日期**: 2026-05-10
**类型**: 改
**关联**: Epic: Agent框架升级 > S07/S08/S10/S11/S12 UI 集成 + S06/S12 启动入口

## 修改文件

### `src/transbridge/ui/tools/smart_assistant/chat_widget.py` (改)
- **修改内容**: 五处增量 UI 集成：
  1. **Agent 状态指示器 (S07)**：输入框上方新增 QHBoxLayout，3 个 QLabel 显示 translator/proofreader/orchestrator 状态（○空闲灰色/◉执行蓝色/●完成绿色/✕失败红色）。`_update_agent_indicators()` 方法接收状态字典动态更新
  2. **观测面板 Tab (S11)**：新增 QTabWidget（最大高度 160px），含 Token 仪表盘（今日/本周/本月 3 卡片 QLabel）、工具调用表（QTableWidget 4列：时间/工具/耗时/状态）、对话轮次列表（QListWidget）
  3. **ObservabilityCollector 集成 (S11)**：`__init__` 中创建 ObservabilityCollector 实例（storage_dir="data/observability"），连接 token_stats_updated 信号
  4. **护栏中间件 + 确认弹窗 (S08/S10)**：`_on_plan_confirmed` 中从 LLMConfig 读取 guardrails 配置构建中间件链（InputValidationGuard→PermissionGuard→OutputValidationGuard），传递给 ExecutionEngine。连接 step_requires_confirmation 信号→`_on_confirm_required`→QMessageBox.question 弹窗
  5. **Agent 状态生命周期 (S07)**：`_on_plan_confirmed` 设置 translator/orchestrator 为 exec；`_on_plan_all_finished` 重置全部为 idle + 调用 `_obs_collector.end_conversation()`
- **原因**: S07/S08/S10/S11 story 文档预定义的 UI 集成步骤。安全护栏中间件在计划执行时注入，admin 操作弹窗确认，Agent 状态可视化，观测数据实时展示。

### `src/transbridge/config/llm.py` (改)
- **修改内容**: LLMConfig 新增两段 INI 配置支持：
  1. **guardrails 字段**：guardrails_enable_admin_confirm(bool=True)/guardrails_enable_input_validation(bool=True)/guardrails_enable_output_validation(bool=True)/guardrails_max_input_size(int=102400)/guardrails_write_require_confirm(bool=False)
  2. **mcp 字段**：mcp_enabled(bool=False)/mcp_transport(str="stdio")/mcp_admin_tool_whitelist(str="")/mcp_write_tool_policy(str="deny")
  3. **save_to_file()**：追加写入 [guardrails] 和 [mcp] INI section
  4. **load_from_file()**：追加读取 [guardrails] 和 [mcp] INI section（has_section 判空后读取）
- **原因**: S08 步骤6 和 S12 步骤4 预定义的配置扩展。安全护栏和 MCP Server 的配置与 LLMConfig 共享同一 INI 文件。

### `src/transbridge/ui/app.py` (改)
- **修改内容**: `main()` 函数中 window 创建前追加两段启动逻辑：
  1. **AgentRegistry.init_presets()**：注册 translator/proofreader/orchestrator 三个预置 Agent
  2. **MCPServer 条件启动**：从 LLMConfig 读取 mcp_enabled，enabled=true 时创建 MCPAdapter + MCPServer，在 daemon 线程中调用 run_stdio()
- **原因**: S06 步骤6 和 S12 步骤4 预定义的启动入口集成。Agent 系统在应用启动时初始化，MCP Server 按配置条件启动。
