# 001: 核心后端三组件 + PromptBuilder 扩展

**日期**: 2026-05-06
**类型**: 增
**关联**: Epic: 智能助手侧边栏面板 > Story 02: 核心后端

## 修改文件

### `src/transbridge/ui/tools/smart_assistant/conversation_manager.py` (增)
- **修改内容**: 新建 ConversationManager 类，维护多轮对话历史。add_system() 始终在索引 0 并替换已有 system；add_user() 后调用 _trim() 保持 user+assistant 对数不超过 max_turns(默认20)；add_observation() 和 add_plan_result() 将执行结果作为 user 消息追加供 LLM 继续推理；get_messages() 返回副本
- **原因**: 封装多轮对话状态管理，避免 ChatWidget 直接操作原始消息列表

### `src/transbridge/ui/tools/smart_assistant/chat_worker.py` (增)
- **修改内容**: 新建 ChatWorker(QThread)，chunk/finished/error 三信号。run() 中调用 llm_client.chat_stream()，chunk_callback 检查 _cancelled Event 决定是否继续发射。自定义 _CancelledByStop(BaseException) 穿透 except Exception。cancel() 设置 Event + 调用 llm_client.cancel()
- **原因**: 后台线程封装 LLM 流式调用，支持取消中断，遵循 ADR-004 QThread 模式

### `src/transbridge/ui/tools/smart_assistant/execution_engine.py` (增)
- **修改内容**: 新建 ExecutionEngine(QObject) + StepResult dataclass。step_started/step_finished/all_finished/progress 四信号。_topological_levels() 按 depends_on 分层（有环时兜底单层串行）。execute() 逐层 ThreadPoolExecutor 并行（max_workers=4）。_run_single() 调用 ToolRegistry 执行并构建 StepResult。cancel() 设置 Event 优雅中断
- **原因**: 统一执行引擎，DAG 拓扑排序 + 层级并行，支持计划模式批量执行和 ReAct 单步执行

### `src/transbridge/ai_translator/prompt_builder.py` (改)
- **修改内容**: 新增 parse_hybrid_response() 方法：提取 ```json 块或裸 JSON → 解析 mode/thought/steps → 兼容 tool_calls 旧格式自动转 steps → 纯文本降级 mode=react steps=[]。新增 _try_fix_truncated_json()：补全截断 JSON 的 }]} 等结束符
- **原因**: 支持智能助手的 ReAct + Plan 混合模式响应解析，遵循 ADR-005 自建 PromptBuilder 扩展
