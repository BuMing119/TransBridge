### `src/transbridge/ui/tools/smart_assistant/__init__.py` (增)
- **修改内容**: 新建包初始化文件，导出 SmartAssistantPanel
- **原因**: 为 MainWindow 提供简洁的导入入口

### `src/transbridge/ui/tools/smart_assistant/message_bubble.py` (增)
- **修改内容**: 新建 MessageBubble(QWidget)，根据 role 渲染三种样式：user（绿色#DCF8C6右对齐）、assistant（白色左对齐带边框）、system（灰色#F5F5F5居中11px）。QLabel wordWrap + maxWidth 320px
- **原因**: 统一消息气泡 UI 组件，供 ChatWidget 复用

### `src/transbridge/ui/tools/smart_assistant/quick_actions.py` (增)
- **修改内容**: 新建 QuickActionsPanel(QWidget)，固定宽度 80px，4 个快捷按钮（翻译选中/质量检查/查询术语/导出JSON），点击发射 action_clicked(str) 信号
- **原因**: 提供常用操作的快捷入口，减少用户输入

### `src/transbridge/ui/tools/smart_assistant/chat_widget.py` (增)
- **修改内容**: 新建 ChatWidget(QWidget)，消息滚动区(QScrollArea+QVBoxLayout)+输入框(QTextEdit maxHeight 100)+发送/清空按钮。message_sent 信号。Ctrl+Enter 发送(eventFilter)。预留 add_tool_card/add_plan_card 占位方法(Story-03 实现)
- **原因**: 聊天交互核心 UI，消息发送/显示/清空的基础设施

### `src/transbridge/ui/tools/smart_assistant/panel.py` (增)
- **修改内容**: 新建 SmartAssistantPanel(QDockWidget)，objectName="SmartAssistantPanel"，允许左右停靠+可关闭/可移动/可浮动，最小宽度 360px。水平布局：QuickActionsPanel | VLine | ChatWidget。visibility_changed 信号。暴露 chat 属性
- **原因**: 智能助手主面板，DockWidget 可集成到 MainWindow 任意边缘

### `src/transbridge/ui/main_window.py` (改)
- **修改内容**: (1)新增 QShortcut/QKeySequence 导入；(2)__init__ 新增 _assistant_panel=None + _init_shortcuts() 调用；(3)_init_menu 新增"💬 智能助手"菜单项(Ctrl+Shift+I, checkable) + "视图"菜单含"智能助手面板"checkable 项；(4)新增 _init_shortcuts() 注册 Ctrl+K；(5)新增 _get_assistant_panel() 延迟初始化+addDockWidget；(6)新增 _toggle_smart_assistant() 切换可见性；(7)新增 _on_assistant_visibility_changed() 同步两个 menu action checked 状态
- **原因**: 将智能助手面板集成到主窗口，三个入口（菜单/Ctrl+K/Ctrl+Shift+I）统一 toggle 逻辑
