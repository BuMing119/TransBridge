# 002: 智能助手面板从右侧停靠改为底部停靠

**日期**: 2026-05-06
**类型**: 改
**关联**: Epic: 智能助手侧边栏面板 > Story 01: SmartAssistantPanel 基础框架

## 修改文件

### `src/transbridge/ui/main_window.py` (改)
- **修改内容**: `_get_assistant_panel()` 中 `addDockWidget` 停靠区域从 `Qt.DockWidgetArea.RightDockWidgetArea` 改为 `Qt.DockWidgetArea.BottomDockWidgetArea`
- **原因**: 右侧 DockWidget 展开时挤压工作台水平布局（Step1/2/3 被压缩），改为底部弹出类似 IDE 终端体验，不影响水平空间

### `src/transbridge/ui/tools/smart_assistant/panel.py` (改)
- **修改内容**: (1) 内部布局从 `QHBoxLayout` 改为 `QVBoxLayout`，QuickActionsPanel 置顶、HLine 分隔、ChatWidget 占主体；(2) 分隔线从 `VLine` 改为 `HLine`；(3) `setMinimumWidth(360)` 改为 `setMinimumHeight(200)`；(4) `setAllowedAreas` 增加 `BottomDockWidgetArea`
- **原因**: 底部停靠时面板高度有限，水平布局浪费垂直空间，改为垂直布局（快捷按钮横排在上 + 聊天区在下）更自然

### `src/transbridge/ui/tools/smart_assistant/quick_actions.py` (改)
- **修改内容**: (1) 布局从 `QVBoxLayout` 改为 `QHBoxLayout`；(2) `setFixedWidth(80)` 改为 `setMaximumHeight(48)`；(3) 4 个快捷按钮从竖排改为横排
- **原因**: 适配底部面板，快捷按钮横向排列更节省垂直空间，与 IDE 终端工具栏风格一致
