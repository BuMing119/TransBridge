# 002: v1 废弃标记 + ReAct 重试 + 锁修复 + 权限修正 + 路径脱敏

**日期**: 2026-05-12
**类型**: 改
**关联**: Epic: Smart Assistant QA 全面修复 > Story 06: 代码清理与架构修复

## 修改文件

### `src/transbridge/smart_assistant/tools/tool_v1.py` (改)
- **修改内容**: 6 个 v1 同步工具函数 docstring 添加 `@deprecated` 前缀并指向 namespace 替代工具：`_tool_lookup_terms` → `search_terms`，`_tool_translate_entries` → `start_translation`，`_tool_check_quality` → `check_consistency / validate_format`，`_tool_get_collection_summary` → `get_visible_entries`，`_tool_export_json` → `export_collection_json`，`_tool_write_back` → `write_to_esp / write_to_eet / write_to_xt`
- **原因**: M2 — v1 同步工具与 namespace 异步工具功能重复（translate_entries vs start_translation、check_quality vs proofreader 工具、write_back vs write_to_*），增加维护负担。标记 deprecated 引导 LLM 优先使用 namespace 工具

### `src/transbridge/ui/tools/smart_assistant/chat_widget.py` (改)
- **修改内容**: `_on_tool_executed()` 中添加 ReAct 模式重试循环（最多 3 次）：调用 `execute_with_guardrails` 后检查 `result.success` 和 `result.error_category`，对 network/internal 类错误自动重试，permission/config/input 类错误立即放弃。重试时追加系统消息 `[重试 N/3] tool: message`
- **原因**: M6 — RetryHandler 原仅在 plan 模式（ExecutionEngine._run_single）中生效，ReAct 模式的 `_on_tool_executed` 完全不使用重试。S01 已将 ReAct 改为走 `execute_with_guardrails` 但该函数无内置重试

### `src/transbridge/smart_assistant/tools/task_manager.py` (改)
- **修改内容**: `update_progress()` 方法中 `handle.progress.update(progress)` 从锁外移入锁内（`with self._lock` 块内执行）。新增 `@classmethod reset()` 方法：获取实例锁后遍历所有任务，设置 stop_event + join 线程，最后置 `cls._instance = None`
- **原因**: m10 — 原 `update_progress` 先获取锁拿到 handle，释放锁后再调用 `progress.update()`，存在竞态条件。m18 — TaskManager 单例在会话间永不重置，`reset()` 供会话切换时清理

### `src/transbridge/smart_assistant/tools/tool_editor.py` (改)
- **修改内容**: `clear_all_filters` 工具注册的 permission 参数从 `"write"` 改为 `"read"`
- **原因**: m20 — `clear_all_filters` 仅清除 UI 筛选状态不修改数据，原标记为 write 导致自动模式下可能触发不必要的确认弹窗

### `src/transbridge/smart_assistant/tools/tool_default.py` (改)
- **修改内容**: `_tool_list_local_projects` 返回的 project dict 中移除 `"path"` 字段，仅保留 `"name"`
- **原因**: m21 — 原返回项目绝对路径（如 `D:\Modding\Projects\Dragonborn`），暴露用户文件系统结构
