# 004: checkpoint 数据目录路径修复

**日期**: 2026-05-14
**类型**: 改
**关联**: Epic: Smart Assistant QA 修复 > Story 5: 线程与资源修复

## 修改文件

### `src/transbridge/smart_assistant/execution_engine.py` (改)
- **修改内容**: `_checkpoint_path()` 方法（L551）中 fallback 路径从 `Path("data")` 改为 `Path(ParatranzConfig.get_data_dir())`，新增 top-level import `from src.transbridge.config.paratranz import ParatranzConfig`
- **原因**: `AppContext` 无 `project_path` 属性时触发相对路径 fallback `Path("data")`，由于运行线程 CWD 为 `src/transbridge/`，导致 checkpoint 文件错误写入 `src/transbridge/data/checkpoints/` 而非项目根目录 `data/checkpoints/`。项目中其他模块（ai_translator、persistence、ui、smart_assistant/tools）均统一使用 `ParatranzConfig.get_data_dir()` 获取绝对路径，本次修改消除此不一致
