# 005: 移除 max-width 约束，所有组件撑满面板

**日期**: 2026-05-15
**类型**: 改
**关联**: Epic: Smart Assistant QA 修复 > Story-06: 代码清理与架构修复

## 修改文件

### `src/transbridge/ui/tools/smart_assistant/message_bubble.py` (改)
- **修改内容**: 移除 `_CONTENT_MAX_WIDTH = 720` 类常量，移除 `content_wrapper.setMaximumWidth()` 调用，更新 docstring 注释
- **原因**: 消息气泡被限制为 720px 居中显示，两侧留白过大。移除后气泡自适应撑满面板

### `src/transbridge/ui/tools/smart_assistant/chat_widget.py` (改)
- **修改内容**: (1) `_init_ui_stage4` 中移除 `self._input.setMaximumWidth(800)` 和 `input_wrapper` 居中 stretch 布局，输入框直接加入 `_main_layout`；(2) 系统消息 `frame.setMaximumWidth(720)` 移除
- **原因**: 输入框和系统消息框自适应撑满面板宽度

### `src/transbridge/ui/tools/smart_assistant/tool_card.py` (改)
- **修改内容**: `ToolCard.__init__` 和 `BatchToolCard.__init__` 中 `setMaximumWidth(720)` 移除
- **原因**: 工具卡片和批量工具卡片撑满面板

### `src/transbridge/ui/tools/smart_assistant/plan_card.py` (改)
- **修改内容**: `PlanCard.__init__` 中 `setMaximumWidth(720)` 移除
- **原因**: 计划卡片撑满面板

### `src/transbridge/ui/tools/smart_assistant/thinking_indicator.py` (改)
- **修改内容**: `ThinkingIndicator.__init__` 中 `setMaximumWidth(720)` 移除
- **原因**: 思考指示器撑满面板
