# 002: 第五轮 QA 收尾 — C18/C19/M4 与 Minor 修复

**日期**: 2026-05-15
**类型**: 改/移
**关联**: Epic: Smart Assistant QA 修复 > Story-06: 代码清理与架构修复

## 修改文件

### `src/transbridge/smart_assistant/conversation_orchestrator.py` (移入)
- **修改内容**: 从 `ui/tools/smart_assistant/` 迁移至 `smart_assistant/`，遵循 ADR-008 代码分层。保留 `_SignalBridge(QObject+pyqtSignal)` 作为已批准的跨线程桥接模式，`ConversationOrchestrator(QObject)` 继承不变。内部导入均使用绝对路径，无需修改
- **原因**: C18 — ADR-008 规定 `ui/tools/smart_assistant/` 仅包含 UI，ConversationOrchestrator 包含 LLM 客户端创建、流式处理、ChatWorker 生命周期管理等后端逻辑

### `src/transbridge/smart_assistant/tool_execution_handler.py` (移入)
- **修改内容**: 从 `ui/tools/smart_assistant/` 迁移至 `smart_assistant/`。移除唯一 PyQt6 依赖 `QMessageBox`：`parent_widget` 参数替换为 `on_confirm_permission: Callable[[str, str], bool] | None` 回调，权限确认由 UI 层通过 `QMessageBox.question()` 实现。无回调时自动放行
- **原因**: C19 — 工具执行、护栏中间件链、重试循环、权限检查均为后端逻辑，不应依赖 PyQt6

### `src/transbridge/ui/tools/smart_assistant/conversation_orchestrator.py` (删除)
- **修改内容**: 已迁移至 `smart_assistant/conversation_orchestrator.py`
- **原因**: C18 文件搬迁

### `src/transbridge/ui/tools/smart_assistant/tool_execution_handler.py` (删除)
- **修改内容**: 已迁移至 `smart_assistant/tool_execution_handler.py`
- **原因**: C19 文件搬迁

### `src/transbridge/smart_assistant/execution_engine.py` (改)
- **修改内容**: `_eval_ast_call` 方法从仅支持 `dict.get` 扩展为三类安全函数调用：(1) 属性方法 `.get()`/`.startswith()`/`.endswith()`；(2) 内建函数 `len()`/`str()`/`int()`/`float()`/`bool()`/`any()`/`all()`/`isinstance()`；(3) 新增 `_resolve_isinstance_type` 辅助方法 + `_SAFE_TYPE_WHITELIST` 类属性（白名单：str/int/float/bool/list/dict/tuple/NoneType）。所有函数严格白名单，未知函数仍抛 ValueError
- **原因**: M4 — `ast.Call` 仅处理 `dict.get` 导致其他合法条件函数（如 `len()`、`isinstance()`）静默失败返回 False

### `src/transbridge/smart_assistant/reflexion/retry_handler.py` (改)
- **修改内容**: 第 61 行 `except (json.JSONDecodeError, Exception)` 改为 `except Exception`，`JSONDecodeError` 是 `Exception` 子类，元组中的前者冗余
- **原因**: Minor — 消除冗余异常捕获，避免误导代码阅读者

### `src/transbridge/smart_assistant/agents/agent_registry.py` (改)
- **修改内容**: 新增 7 个模块级常量 `AGENT_TRANSLATOR`/`AGENT_PROOFREADER`/`AGENT_ORCHESTRATOR`/`AGENT_PARSER`/`AGENT_EDITOR`/`AGENT_PARATRANZ`/`AGENT_WRITER` 及 `_ALL_AGENT_IDS` frozenset。`init_presets()` 中 7 个 `agent_id=` 赋值改用常量引用
- **原因**: Minor — Agent ID 使用字符串字面量分散各处，缺乏单一真源

### `src/transbridge/ui/tools/smart_assistant/chat_widget.py` (改)
- **修改内容**: (1) `ConversationOrchestrator` 导入路径由 `.conversation_orchestrator` 改为 `src.transbridge.smart_assistant.conversation_orchestrator`；(2) `ToolExecutionHandler` 导入路径由 `.tool_execution_handler` 改为 `src.transbridge.smart_assistant.tool_execution_handler`；(3) `ToolExecutionHandler` 构造新增 `on_confirm_permission` 回调，使用 `QMessageBox.question(self, ...)` 实现权限确认
- **原因**: 配合 C18/C19 文件搬迁，更新导入路径和权限回调注入

### `src/transbridge/smart_assistant/__init__.py` (改)
- **修改内容**: `__all__` 新增 `"ConversationOrchestrator"`，`_SYMBOL_MODULES` 新增 `"ConversationOrchestrator": ".conversation_orchestrator"` 惰性加载映射
- **原因**: 配合 C18，使 `ConversationOrchestrator` 可通过惰性加载访问

### `src/transbridge/ui/tools/smart_assistant/` 8 文件 (改)
- **修改内容**: `__init__.py`/`chat_widget.py`/`message_bubble.py`/`panel.py`/`plan_card.py`/`quick_actions.py`/`thinking_indicator.py`/`tool_card.py` 文件头部新增 `from __future__ import annotations`
