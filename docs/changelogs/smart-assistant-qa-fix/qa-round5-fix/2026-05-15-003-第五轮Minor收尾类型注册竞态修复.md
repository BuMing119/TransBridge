# 003: 第五轮 Minor 收尾 — 类型标注/注册统一/cancel 竞态修复

**日期**: 2026-05-15
**类型**: 改
**关联**: Epic: Smart Assistant QA 修复 > Story-06: 代码清理与架构修复

## 修改文件

### `src/transbridge/smart_assistant/execution_engine.py` (改)
- **修改内容**: `_run_guard_chain` 方法返回类型由裸 `tuple` 改为 `tuple[StepResult | None, dict]`，与方法 docstring 描述的返回值结构一致
- **原因**: Minor — 裸 `tuple` 缺少类型参数，IDE/类型检查器无法推断返回值具体类型

### `src/transbridge/smart_assistant/tools/__init__.py` (改)
- **修改内容**: 新增 `register_all()` 函数，显式导入全部 7 个工具模块触发注册；原有模块级副作用导入标记为 `# DEPRECATED (QA-007)`；`__all__` 新增 `register_all`
- **原因**: Minor — 工具注册依赖导入副作用，与其他子包模式不一致；新增显式 API 为未来统一铺路

### `src/transbridge/smart_assistant/skills/__init__.py` (改)
- **修改内容**: 新增模块 docstring 描述注册模式；新增 `register_all(directory)` 函数委托给 `SkillRegistry.reload()`；`__all__` 新增 `register_all`
- **原因**: Minor — 补齐显式注册 API，与其他子包一致

### `src/transbridge/smart_assistant/file_parser/__init__.py` (改)
- **修改内容**: 新增模块 docstring 描述双重发现机制（`__subclasses__()` + `_registry`）；新增 `register_all()` 显式注册全部 3 个解析器类
- **原因**: Minor — 补齐显式注册 API，与其他子包一致

### `src/transbridge/infra/llm_client.py` (改)
- **修改内容**: `OpenAICompatibleClient` 和 `AnthropicClient` 的 `__init__` 新增 `_active_requests` 计数器（`_lock` 保护）；`chat()`/`chat_stream()` 在锁内递增计数、finally 块递减；`cancel()` 设置取消标志后轮询 `_active_requests`（每 50ms，最长 3s）等待进行中请求完成后再关闭 HTTP 客户端，超时回退到原有关闭行为
- **原因**: Minor — `cancel()` 关闭 `httpx.Client` 时可能与正在执行 API 调用的 `chat()`/`chat_stream()` 产生竞态，导致连接错误。原锁仅保护引用交换，不保护 API 调用期间
