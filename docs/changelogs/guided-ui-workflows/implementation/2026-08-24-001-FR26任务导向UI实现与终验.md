# FR26 任务导向 UI 实现与终验

- **Epic**：`guided-ui-workflows`
- **Story**：S01～S13
- **日期**：2026-08-24
- **状态**：已完成

## 实现内容

- 新增开始中心、权威插件/空工程建项、最近工程与恢复投影；缺少可选云端配置不再阻塞本地启动。
- 建立 Action Catalog、统一 IntentRouter、任务中心、状态引导及 `auto/guided/compact` 偏好，撤销“小工具”产品分类。
- 重组 Workbench 层级、筛选、上下文动作和保存状态；AI 默认进入当前内容的快速运行，批量能力进入高级入口。
- 上传、下载、hydration 写回与 FOMOD 共用非阻塞操作计划、预检、单次确认和真实 TaskRuntime 任务。
- 增加安全拖放、命令搜索、上下文帮助、键盘/焦点/危险操作与 accessibility 合同；示例工程按可选条款延期。
- 延迟加载 UI、Shell 与 ParaTranz 公共入口并收敛 10k 表格热路径，保持既有公共导出兼容。

## 终验结果

- 固定 P0 Journey：73 passed；J02～J07 的 D/M 从 `20/15` 降至 `8/3`，下降 60%/80%。
- FR26 最终相关回归：102 passed；兼容/parity 证据组：390 passed；S09 生产接线组：98 passed。
- Windows 10k/20 样本/100 生命周期 comparator 连续两次 `failures=[]`；确认运行 heartbeat 40.542 ms，残留 wrapper 0。
- UI modularity audit、Ruff 定向检查和 compileall 通过。
- 全量 pytest 曾得到 1725 passed、22 failed、6 skipped；失败来自当前解释器缺少可选 `faiss/rank_bm25`、子进程未安装包、测试临时目录权限和两项既存 Smart Assistant 行为，不是 FR26 定向回归。
