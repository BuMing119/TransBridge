# 本体汉化术语配置档与非破坏性切换

- 日期：2026-09-06
- Epic：`terminology-localization-profiles`
- Story：Story 01～06
- Plan：[本体汉化术语版本](../../../../plans/terminology-localization-profiles/plan.md)
- Requirement：[FR5.18](../../../../docs/requirements.md)
- ADR：[ADR-039 本体汉化术语配置档与非破坏性译文投影](../../../../docs/adr/039-terminology-localization-profiles.md)

## 范围与原因

同一个 Skyrim 模组需要面向多套国内本体汉化生成术语不同、普通正文一致的成品。复制完整 Project Variant 会让正文、Stage、标签和同步状态产生多份权威副本，直接在中文译文中全文替换又无法可靠处理重叠、多义、人工改写与任务恢复。

本次新增独立于内容 Variant 的术语配置档：公共译文仍是唯一可编辑正文，配置档只保存逻辑术语的目标译名、条目特例和受控位置绑定。Workbench、AI 和写出边界消费不可变配置档修订生成临时派生结果；切换配置档不修改公共集合。无法唯一证明替换位置、映射缺失或候选重叠时整条译文保持不变并返回诊断。

### 配置档领域与安全投影

- `src/transbridge/application/terminology_profiles/models.py`（新增）：定义配置档状态、稳定逻辑术语键、项目/插件作用域映射、条目特例、受控出现位置、草稿、不可变发布修订和选择快照；内容摘要覆盖全部语义输入。
- `src/transbridge/application/terminology_profiles/ports.py`（新增）：定义配置档 repository 窄合同，包括目录、草稿 CAS、不可变发布、精确修订读取和 Project/Variant 选择。
- `src/transbridge/application/terminology_profiles/service.py`（新增）：实现创建、复制、重命名、归档、草稿保存、发布、选择和清除选择；发布与选择在 repository 内再次校验状态和 revision，避免并发竞态。
- `src/transbridge/application/terminology_profiles/in_memory.py`（新增）：提供与正式 repository 语义一致的内存实现，供领域及 UI 测试使用；新发布修订会推进该配置档已有选择，新任务读取最新版，已冻结对象保持旧版。
- `src/transbridge/application/terminology_profiles/projection.py`（新增）：实现纯函数派生投影，优先使用条目特例和显式绑定，再尝试来源可证明且目标译名唯一的历史识别；插件作用域覆盖项目作用域。任一候选缺失、陈旧、重复或重叠时整条 entry 保留公共译文，不执行部分替换或无边界全文替换。
- `src/transbridge/application/terminology_profiles/effective.py`（新增）：组合基础 effective terminology 与指定配置档修订，生成可解析的 `profiled:v1` 版本身份；缺失映射以显式 suppressed shadow 阻止不兼容 legacy fallback，并支持 AI checkpoint 精确恢复基础版本和配置档历史修订。
- `src/transbridge/application/terminology_profiles/write_projection.py`（新增）：冻结 Project/Variant 选择、基础术语版本、配置档修订和摘要，为写出生成临时 `TranslationEntry`；基础快照不可用、映射缺失或位置无法证明时保留整条公共译文并输出诊断。
- `src/transbridge/application/terminology_profiles/__init__.py`（新增）：集中导出配置档模型、服务、投影、effective 组合及写出边界合同。

### SQLite 与运行时装配

- `src/transbridge/persistence/terminology/schema.py`（修改）：术语数据库 schema 从 v3 升至 v4，新增配置档、不可变发布修订和 Variant 选择表，以及唯一约束、外键、索引和不可变触发器；继续复用备份优先迁移与完整性检查。

## 兼容与遗留项

- 未选择配置档时，Workbench、AI、CLI/MCP 和写出继续使用原公共译文及原 effective terminology；旧项目迁移只新增空表，不猜测已有汉化身份。
- ParaTranz 下载和现有同步继续只处理公共译文；未建立显式配置档远端映射时，不向共同远端权威上传 profile overlay。
- 未执行真实 Skyrim 插件/Strings 资产、ParaTranz 联机、安装包构建和人工桌面交互验证。
- 后续增强包括配置档差异视图、聚合影响统计、在 UI 中新建条目特例/精确出现位置绑定，以及显式 ParaTranz 配置档远端映射；底层模型已保留特例和绑定契约。
- 完整测试中上述与本功能无直接关联的既有失败仍待各自 Epic 处理；本次不扩大范围修复。
