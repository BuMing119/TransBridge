# Story 01～03：Embedding 语义检索三态、预检与索引身份

- **日期**：2026-08-27
- **Epic**：`embedding-retrieval-ux-reliability`
- **Story**：Story 1 真实三态配置与独立连接检查、Story 2 Embedding 运行前预检、Story 3 索引身份与模型切换失效
- **关联计划**：[Embedding 语义检索体验与可靠性整改](../../../../plans/embedding-retrieval-ux-reliability/plan.md)

## 目的

修复 Embedding UI 只切换 provider、没有真实控制 `embedding.mode` 的配置断连；将主 LLM 与语义检索检查分离，并在任务启动前暴露缺失配置或依赖。持久化向量索引同时绑定无凭据的 Embedding 身份，避免切换模式、模型、端点或维度后复用不兼容索引。

## 实际变更

### Story 1：真实三态配置与独立连接检查

- **修改** `src/transbridge/ui/tools/ai_translator/config_view.py`
  - Embedding 下拉框改为带稳定 item data 的 `disabled`、`local`、`api` 三态，并以 `embedding.mode` 作为加载事实来源。
  - 保存时同步维护 mode/provider；关闭语义检索时保留已有后端字段，避免用户重新启用后丢失配置。
  - 将“测试连接”明确为“测试 LLM 连接”，新增“检查语义检索”动作，并提示本地模式首次检查可能下载模型。
- **修改** `src/transbridge/ui/tools/ai_translator/view_state.py`、`view_controls.py`
  - disabled 隐藏后端字段，local 仅显示本地模型字段，api 仅显示 API 字段；把独立检查按钮纳入统一控件映射。
- **修改** `src/transbridge/ui/tools/ai_translator/config_presenter.py`
  - 新增用户显式触发的 Embedding 检查：disabled 直接说明当前降级语义，api 先校验 Key/模型/Base URL，local/api 再执行一次最小编码并反馈向量维度。
  - 保留主 LLM 检查边界，并让两类成功、缺配置和失败提示互不混淆。
- **修改** `src/transbridge/ui/tools/ai_translator/ai_translator_window.py`
  - 仅将既有 `on_test_connection` 扩展为 LLM/Embedding 目标分流；该文件其余版本快照差异属于另一增量，不计入本记录。
- **新增** `tests/ui/tools/test_embedding_retrieval_config.py`
  - 覆盖三态配置往返、控件显隐、disabled 不构造客户端、API 网络调用前校验，以及最小编码成功反馈。
- **修改** `tests/contracts/config/test_unified_repository.py`
  - 覆盖 disabled/local/api 的 mode/provider 原子持久化往返。

### Story 2：Embedding 运行前预检

- **修改** `src/transbridge/ui/tools/ai_translator/run_spec.py`
  - 新增 Embedding 配置缺失和依赖缺失两类预检 code。
  - 仅在翻译类路径、术语检索与语义匹配均启用时检查；disabled 不探测向量依赖，也不加载模型或访问网络。
  - local 检查 `sentence_transformers` 与 `faiss`，api 检查 Key、模型、Base URL、`openai` 与 `faiss`。
- **修改** `src/transbridge/dependency_capabilities.py`
  - 将 FAISS 向量检索和 sentence-transformers 本地 Embedding 纳入依赖能力基线。
- **修改** `tests/ui/tools/test_ai_translator_story08.py`、`tests/security/test_dependency_degraded.py`
  - 覆盖 disabled 零探测、local/api 缺配置和依赖，以及统一依赖基线。

### Story 3：索引身份与模型切换失效

- **修改** `src/transbridge/infra/embedding_client.py`
  - 为 Embedding 客户端暴露稳定、无凭据的索引身份：本地后端包含模式、模型、模型目录和维度；OpenAI 兼容后端包含模式、模型、规范化端点和维度语义。
  - 端点身份移除用户信息、查询参数和 fragment；未知 API 模型在实际编码后更新真实维度。
- **新增** `src/transbridge/ai_translator/term_vector_manifest.py`
  - 集中维护 schema v2 metadata、SHA-256 Embedding fingerprint，以及术语 hash、身份和维度校验，避免在索引主类中继续增加元数据职责。
- **修改** `src/transbridge/ai_translator/term_vector_index.py`
  - 保存实际 FAISS 维度与版本化 fingerprint；加载时先校验 schema、术语内容、Embedding 身份和维度，再启用持久化索引。
  - 旧 metadata 或配置变化时安全重建一次；同一配置继续复用，并在持久化加载后同步恢复 BM25 索引。
- **修改** `tests/infra/test_embedding_client.py`、`tests/ai_translator/test_term_vector_index.py`
  - 覆盖端点脱敏、同身份复用、模型变化重建、旧 metadata 重建，以及持久化数据不包含原始模型身份。
- **新增** `tests/ai_translator/test_term_vector_manifest.py`
  - 覆盖同身份通过、模式/后端/模型/端点变化失效、维度变化和旧 schema 失效。
