# ParaTranz 同步操作页重设计与后台化

- **日期**：2026-08-30
- **Epic**：`paratranz-sync-operation-ux`
- **Story**：S01～S04（同步语义、任务化页面、自动预检、恢复保护）
- **关联计划**：[plans/paratranz-sync-operation-ux/plan.md](../../../../plans/paratranz-sync-operation-ux/plan.md)

## 目的

修复 ParaTranz 下载把普通内容差异默认判定为大量未解决冲突的问题，并将暴露项目 ID、`project_binding`、`true/false` 和手动预检步骤的通用窗口替换为任务化同步页面。后续实物使用发现点击“下载并更新本地”后 GUI 会等待远端二次校验直至成功，本增量同时将确认后的准备工作下沉到 `TaskRuntime`，避免主线程无响应。

## 实际变更

### 计划与索引

- **新增** `plans/paratranz-sync-operation-ux/plan.md`：记录问题根因、目标交互、四个 Story、恢复保护和验证策略。
- **修改** `plans/INDEX.md`：登记 `paratranz-sync-operation-ux`，并在实现与聚焦 QA 完成后同步 Story 状态。

### 同步领域与任务执行

- **修改** `src/transbridge/application/sync/models.py`：新增 `DeletionPolicy.APPLY/PRESERVE`；删除策略进入 `SyncPlan`、规范载荷和计划哈希。
- **修改** `src/transbridge/application/sync/planner.py`：下载远端 tombstone 可按独立删除策略保留或删除本地；普通内容差异继续由冲突策略映射为更新、跳过或结构性冲突。
- **修改** `src/transbridge/application/sync/use_case.py`：`CreateSyncPlanRequest` 冻结并向 planner 传递删除策略。
- **修改** `src/transbridge/application/sync/__init__.py`：公开删除策略及后台任务准备 DTO。
- **修改** `src/transbridge/application/sync/task_adapter.py`：新增 `ParaTranzSyncTaskPreparation` 和可选 preparation 回调；目标复核、远端授权和当前本地快照可在任务 worker 内完成，且准备结果必须保持 owner、plan hash 和 namespace 一致。恢复点仍先于正式 executor 执行。

### ParaTranz 操作组合与界面

- **新增** `src/transbridge/ui/operations/errors.py`：承载操作组合错误，避免 ParaTranz 切片依赖原 composition root 私有定义。
- **新增** `src/transbridge/ui/operations/paratranz_sync.py`：从 `production.py` 抽取上传/下载适配器；下载默认 `PREFER_REMOTE + PRESERVE`，上传默认 `PREFER_LOCAL`；将 `SyncPlan.counts` 投影为结构化影响数据；中文化权限和远端错误；正式下载在有本地变化时创建历史还原点。
- **新增** `src/transbridge/ui/operations/paratranz_dialog.py`：实现项目名优先的目标卡、项目选择器、同步策略单选、删除复选、影响摘要和“取消 + 单主动作”页脚；页面打开及选项变化时自动预检，不显示内部 ID、来源枚举或布尔文本。
- **修改** `src/transbridge/ui/operations/production_support.py`：`SyncRequest` 冻结目标名称、冲突策略和删除策略；下载/上传使用不同安全默认值；目标身份复核包含名称、来源、配置 revision 和策略。
- **修改** `src/transbridge/ui/operations/mappers.py`：新增带结构化影响计数的 `DomainPreflightResult`，并采用任务化中英文标题。
- **修改** `src/transbridge/ui/operations/plan_view.py`：为编辑字段增加文本、布尔、选择和远端项目控件语义及展示值、选项、帮助文案。
- **修改** `src/transbridge/ui/operations/preflight_view.py`：预检结果携带结构化预计影响。
- **修改** `src/transbridge/ui/operations/coordinator.py`：支持按 `OperationKind` 注入专用窗口；远端预检加入 generation 和最新请求排队，迟到结果不再弹出英文 stale 错误，并在窗口取消或切换 revision 后释放 draft/cache。
- **修改** `src/transbridge/ui/operations/facade.py`：把按操作类型选择窗口的工厂映射传给 coordinator。
- **修改** `src/transbridge/ui/operations/production.py`：保留 composition root，只装配抽取后的 ParaTranz feature；模块由原 500 行以上职责混合实现收缩为约 321 行。
- **修改** `src/transbridge/ui/workbench/remote_target_view.py`：现有“我的项目”选择器支持调用方注入说明和确认按钮文案，使绑定页与同步页复用同一异步目录能力。

### 非阻塞下载修复

- `submit_sync` 在 GUI 确认路径中只取得已预检的 immutable plan、构造轻量任务对象并提交 `TaskRuntime`。
- 目标/账号/端点复核、工程默认绑定持久化、8,000+ 条本地快照构建、远端新鲜度授权和恢复点内容复制均在后台 workload 中执行。
- 后台 preparation 失败会使任务进入失败终态且不执行正式同步；取消检查继续在准备、恢复点和 executor 边界生效。
