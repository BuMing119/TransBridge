# 004: Story 02 编码 — 旧控制逻辑清理 + ChatWidget 瘦身

**日期**: 2026-08-05
**类型**: 改/删
**关联**: Epic: SessionController 会话控制流提取 > Story 02: 旧逻辑清理 + ChatWidget 瘦身

## 修改文件

### `src/transbridge/ui/tools/smart_assistant/chat_widget.py` (改/删)
- **修改内容**: 删除 8 个方法/属性：`_run_llm_round()`、`_check_react_depth()`、`_check_react_continue()`、`_auto_execute_steps()`、`_get_prompt_builder()`、`_get_llm_client()`、`_react_depth` property、`_MAX_REACT_DEPTH` 常量。清理 11 处旧代码调用点（所有 `_check_react_depth() + _run_llm_round()` 模式替换为 Controller 对应方法）。`on_llm_round_start` 回调从仅日志改为实际触发 `orchestrator.start_round()`。`on_react_continue` → `on_step_completed`：直接调用 `controller.handle_execution_complete([])`。移除 `on_auto_execute_steps`、`on_react_depth_check` 回调接线。净删 ~100 行，从 ~1108 → 1047 行。
- **原因**: Controller 从 Story 01 的影子观察者升级为唯一驱动者。旧控制逻辑不再需要，删除后 ChatWidget 专注 UI 渲染。

### `src/transbridge/smart_assistant/conversation_orchestrator.py` (改)
- **修改内容**: `_on_finished()` 中移除 Plan/Tool/Reply 模式分发块（~9行）：删除 `if self._auto_mode and steps: self._on_auto_execute_steps(...)` / `elif mode == "plan": self._on_plan_card(...)` / `elif len == 1: self._on_tool_card(...)` / `elif len > 1: self._on_batch_tool_card(...)`。分发逻辑完全移交给 SessionController.handle_llm_response()（通过 `on_response_parsed` 回调）。
- **原因**: 模式分发是会话控制流的职责，应由 SessionController 统一管理。Orchestrator 仅负责 LLM 轮次生命周期。

### `src/transbridge/smart_assistant/tool_execution_handler.py` (改)
- **修改内容**: `on_react_continue` 回调参数重命名为 `on_step_completed`，存储属性从 `_on_react_continue` 改为 `_on_step_completed`。`_handle_result()` 中调用从 `self._on_react_continue()` 改为 `self._on_step_completed()`。
- **原因**: 语义更清晰——回调通知的是"步骤执行完成"，而非"继续 ReAct"。下一步决策由 SessionController 做出。
