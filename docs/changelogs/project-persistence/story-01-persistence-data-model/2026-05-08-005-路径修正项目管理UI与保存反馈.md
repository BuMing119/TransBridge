# 005: 路径修正、项目管理 UI 与保存反馈增强

**日期**: 2026-05-08
**类型**: 改
**关联**: Epic: 项目持久化与翻译版本管理 > UX 增强

## 修改文件

### `src/transbridge/persistence/__init__.py` (改)
- **修改内容**: PERSISTENCE_ROOT 从裸相对路径 `Path("data/projects")` 改为 `Path(ParatranzConfig.get_data_dir()) / "projects"`，新增 `workspace_path()` 函数返回 `_data_dir() / "workspace.json"`。新增 `_data_dir()` 内部函数包装 `get_data_dir()`
- **原因**: 裸相对路径依赖于 CWD，从 `src/transbridge/` 运行时产生 `src/transbridge/data/` 嵌套；改用全项目统一的 `get_data_dir()` 确保路径正确

### `src/transbridge/ui/main_window.py` (改)
- **修改内容**: 四处修复——
  1. 导入 `workspace_path`，替换全部 `PathLib("data/workspace.json")` 为 `workspace_path()`
  2. 连接 ProjectBar 新增信号：`variant_add_requested`/`variant_copy_requested`/`variant_delete_requested`/`project_rename_requested`
  3. 新增 `_on_delete_variant(name)`——确认对话框/磁盘清理/至少保留一个版本/切换后删除
  4. 新增 `_on_rename_project(new_name)`——`shutil.move` 目录/更新 project.json/更新 workspace.json
  5. `_on_manual_save()` 保存反馈增强——显示译文条数+标签数，调用 `flash_saved()` 绿色闪烁
- **原因**: 用户反馈找不到修改项目/版本信息的入口，保存反馈感知弱

### `src/transbridge/ui/workbench/_project_bar.py` (改)
- **修改内容**: 全面重写——
  1. 项目名旁新增 `[...]` 重命名按钮
  2. 版本下拉旁新增 `[+]` 版本管理菜单按钮（新建/复制/删除版本/管理快照）
  3. 新增 4 个信号：`variant_add_requested`/`variant_copy_requested`/`variant_delete_requested`/`project_rename_requested`
  4. `_on_variant_menu()` 弹出 QMenu——新建版本/复制版本/删除版本子菜单（列出所有版本名）/管理快照
  5. `_on_rename_project()` 弹出 QInputDialog 修改项目名称
  6. `flash_saved()` 保存按钮变绿显示"已保存"持续 1.5s 后恢复
- **原因**: 用户反馈项目信息修改、版本增删等操作入口不可见
