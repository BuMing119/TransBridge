## 修改文件

### `src/transbridge/persistence/__init__.py` (增)
- **修改内容**: 包初始化，导出 WorkspaceState/ProjectHandle/VariantStore，定义 PERSISTENCE_ROOT = Path("data/projects")
- **原因**: S01 持久化模块入口

### `src/transbridge/persistence/workspace.py` (增)
- **修改内容**: WorkspaceState 类 — load/save workspace.json（原子写入 .tmp → os.replace），_empty_template() 默认模板，属性访问（projects/active_project/settings/last_session），add_project/remove_project/get_project_path 便捷方法
- **原因**: 全局工作区状态管理，对应 ADR-006 workspace.json 结构

### `src/transbridge/persistence/project.py` (增)
- **修改内容**: ProjectHandle 类 — create/load/save project.json，属性（name/sources/variants/active_variant/project_dir），add_variant/remove_variant/has_variant 版本操作，add_source/remove_source 源文件操作，variant_dir() 返回版本子目录路径
- **原因**: 项目配置 CRUD，对应 ADR-006 project.json 结构

### `src/transbridge/persistence/variant_store.py` (增)
- **修改内容**: VariantStore 类 — 管理 current.json 翻译缓存。load/save（原子写入），apply_to(entries) 将缓存注入 TranslationEntry，collect_from(entries, entry_labels, label_library) 从运行时收集数据，快照操作（save_snapshot/load_snapshot/list_snapshots/delete_snapshot），dirty 标记管理
- **原因**: 译文/标签/标签库的版本级持久化缓存层，对应 ADR-006 current.json 结构

### `src/transbridge/ui/context.py` (改)
- **修改内容**: AppContext 扩展——TYPE_CHECKING 导入 persistence 类型，新增 workspace_changed 和 variant_changed 信号，__init__ 初始化 _workspace/_active_project/_active_variant/_variant_store 为 None，新增 4 个 property getter/setter（workspace/active_project/active_variant/variant_store），active_project setter 触发 workspace_changed，active_variant setter 仅值变更时触发 variant_changed
- **原因**: S02 AppContext 扩展——建立「项目→版本→翻译数据」三层模型的运行时引用

### `src/transbridge/ui/workbench/_project_bar.py` (增)
- **修改内容**: ProjectBar 组件——显示当前项目名（加粗）+ 版本名，新建项目/打开项目按钮，workspace_changed 信号监听自动刷新，无项目时显示"无项目"
- **原因**: S03 项目管理入口 UI

### `src/transbridge/ui/workbench/widget.py` (改)
- **修改内容**: WorkbenchWidget._init_ui() 顶部嵌入 ProjectBar 组件（在集合工具栏上方）
- **原因**: S03 在现有工作台布局中集成项目工具栏

### `src/transbridge/ui/main_window.py` (改)
- **修改内容**: 大量新增（~200 行）:
  1. 导入 persistence 模块（WorkspaceState/ProjectHandle/VariantStore/PERSISTENCE_ROOT）
  2. _AutoSaveManager 类——QTimer 定时(5min) + 防抖(2s) 自动保存，trigger_debounce() 供操作触发
  3. 文件菜单新增「新建项目…」「打开项目…」+「版本」子菜单（新建/复制/快照保存/加载）
  4. __init__ 新增 _init_workspace() 和 AutoSaveManager.start()
  5. closeEvent 新增 _save_workspace_session() + workspace.save()
  6. _init_workspace()——启动时读取 workspace.json，恢复活跃项目+版本，后台解析源文件
  7. _save_workspace_session()——关闭前保存 last_session 状态
  8. _on_new_project()——创建项目目录+project.json+默认版本+注册到workspace
  9. _on_open_project()——选择project.json加载项目，保存当前→加载新项目→解析源文件
  10. _save_current_project()——保存 VariantStore + ProjectHandle
  11. _restore_parse_esp()——后台 ApiWorker 解析 ESP 并应用 VariantStore 缓存
  12. _on_new_variant()——创建空白版本
  13. _on_copy_variant()——复制当前版本全部译文+标签
  14. _switch_to_variant()——切换版本+apply_to+emit variant_changed
  15. _on_save_snapshot()/_on_load_snapshot()——快照保存/加载
- **原因**: S03-S06 项目管理+版本管理+自动保存+快照操作的全部 UI 逻辑
