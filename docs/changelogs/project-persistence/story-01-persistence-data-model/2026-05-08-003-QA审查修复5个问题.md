# 003: QA 审查修复 — 3 Critical + 2 Major 问题

**日期**: 2026-05-08
**类型**: 改
**关联**: Epic: 项目持久化与翻译版本管理 > QA 修复

## 修改文件

### `src/transbridge/persistence/variant_store.py` (改)
- **修改内容**: `collect_from()` 方法——translations 从全量字典推导式替换改为增量更新（仅更新传入 entries 中存在的条目，不在 entries 中的已有译文保留不变）。labels 和 label_library 保持全量替换（与 UI 的 `_entry_labels` 一致）。新增文档说明增量语义
- **原因**: QA-Q1 Critical——原实现在筛选视图下调用会自动保存时会丢失未在视图中的条目译文数据

### `src/transbridge/ui/main_window.py` (改)
- **修改内容**: 三处修复——
  1. `_AutoSaveManager._auto_save()`: 添加 try/except + getattr 链式 None 检查（`_workbench` → `_step2` → `_entry_labels`/`_label_library`），异常时静默跳过
  2. `_init_workspace()`: 添加 `show_message()` 调用——无活跃项目提示"请新建或打开项目"、加载失败显示错误原因、成功恢复显示项目名+版本+恢复条数
  3. `closeEvent()`: `_save_workspace_session()` 和 `workspace.save()` 包裹 try/except，保存失败不阻止应用退出
- **原因**: QA-Q2(空指针崩溃)、Q4(静默失败)、Q5(退出崩溃)

### `src/transbridge/ui/workbench/cards/write_card.py` (改)
- **修改内容**: 三处修复——
  1. `_write_esp()` 非本地化路径添加 `_output_dir_override` 检查，有 override 时输出到 `{override_dir}/{src.name}`
  2. `_write_eet()` 添加 `_output_dir_override` 检查
  3. `_write_xt()` 添加 `_output_dir_override` 检查
  4. `WriteCard.__init__()` 中 `_output_dir_override` 赋值修正为在 `super().__init__()` 调用之后
- **原因**: QA-Q3 Critical——`_output_dir_override` 原本仅在 ESP 本地化路径生效，EET/XT/非本地化 ESP 路径未集成，导致全版本写回时分目录不完整。QA 发现的缩进错误导致构造函数参数断裂

### `docs/test-reports/project-persistence.md` (增)
- **修改内容**: QA 测试报告——5 项功能测试通过、3 个 Critical + 2 个 Major + 2 个 Minor 问题清单、审查结论
- **原因**: QA 流程产出
