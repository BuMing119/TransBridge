# 004: UX 补全 — 版本切换/保存按钮/自动保存触发

**日期**: 2026-05-08
**类型**: 改
**关联**: Epic: 项目持久化与翻译版本管理 > UX 改进

## 修改文件

### `src/transbridge/ui/workbench/_project_bar.py` (改)
- **修改内容**: 全面重写——静态版本标签替换为 QComboBox 下拉切换（`variant_switch_requested` 信号），新增保存按钮（`save_requested` 信号，脏数据时橙色高亮+*号），新增 `set_save_dirty()` 方法，`_on_variant_selected()` 处理用户切换，`_on_external_variant_change()` 同步外部切换不触发信号循环，`refresh()` 重建版本下拉列表。移除所有 emoji
- **原因**: 用户反馈无法找到版本切换入口和保存功能

### `src/transbridge/ui/main_window.py` (改)
- **修改内容**: 三处新增——(1) ProjectBar 四个信号连接到 `_on_new_project`/`_on_open_project`/`_switch_variant`/`_on_manual_save`；(2) 新增 `_switch_variant(name)` 方法——检查脏标记/根据 save_behavior 弹出确认或自动保存/保存当前版本/加载目标版本；(3) 新增 `_on_manual_save()` 方法——从 Step2 收集数据到 VariantStore 后保存，更新 ProjectBar 按钮状态；(4) Ctrl+S 快捷键；`_init_workspace()` 末尾连接 `dirty_changed` 到 `trigger_debounce` 和 ProjectBar 脏标记；`_auto_save()` 成功后更新 ProjectBar 状态
- **原因**: 用户反馈保存功能和版本切换入口不可见

### `src/transbridge/ui/context.py` (改)
- **修改内容**: 新增 `dirty_changed` 信号，新增 `mark_dirty()` 方法——设置 `variant_store.dirty = True` 并 emit `dirty_changed`。编辑操作调用 `ctx.mark_dirty()` 即可触发自动保存防抖
- **原因**: 需要编辑操作触发自动保存的机制——dirty_changed → AutoSaveManager.trigger_debounce (2s)
