# 001: 工作台布局简化

**日期**: 2026-05-06
**类型**: 改
**关联**: Epic: UI 工作台 > Story 18: 工作台布局简化

## 修改文件

### `src/transbridge/ui/workbench/step2.py` (改)
- **修改内容**: `_init_ui()` 底部新增操作进度区域：`_op_progress`（QProgressBar，固定高度 14px，初始隐藏）和 `_op_progress_lbl`（QLabel，灰色 12px，初始隐藏），位于计数标签之后。新增 3 个公共方法：`show_progress(total, msg)` 设置进度条范围并显示；`update_progress(current, total, msg)` 更新进度值和文本；`hide_progress()` 隐藏进度条和标签并重置。进度条支持确定模式（total > 0，显示具体进度）和不确定模式（total = 0，忙碌动画）
- **原因**: FR7.7.4 需求——解析和上传/下载/写回操作的进度反馈需嵌入 Step2 面板区域，替代原 Step1 和 Step3 各自的进度条

### `src/transbridge/ui/workbench/widget.py` (改)
- **修改内容**: 移除 `Step1SourceWidget` 和 `Step3OpsWidget` 的导入和 `__init__` 中的实例化（`self._step1`、`self._step3`）。移除 `QScrollArea` 包装（右侧仅剩一个组件无需滚动）。`_init_ui()` 中信号连接移除 `parse_started`/`parse_finished` 联动。`Step2PreviewWidget` 直接放入 splitter 右侧，占据全宽。新增 4 个进度代理方法：`show_step2_progress()` / `update_step2_progress()` / `hide_step2_progress()` / `set_step2_parsing()`，转发到 `self._step2` 对应方法。`open_tool()` 保留，`self._step2` 引用保留（AI 翻译浮窗仍需）
- **原因**: FR7.7.5 需求——移除 Step1 和 Step3 面板，右侧工作台仅保留 Step2 词条预览面板全宽显示，左侧集合统计面板不受影响
