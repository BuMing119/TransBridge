# 002: 集合工具栏回归工作台

**日期**: 2026-05-07
**类型**: 改
**关联**: Epic: UI 工作台 > Story 18: 工作台布局简化

## 修改文件

### `src/transbridge/ui/workbench/widget.py` (改)
- **修改内容**: 
  - 新增导入：`QHBoxLayout`, `QLabel`, `QComboBox`, `QPushButton`, `QFileDialog`, `QMessageBox`, `Path`
  - `_init_ui()` 顶部新增集合管理工具栏（`_collection_bar`），位于 Step2 预览上方，始终可见
  - 新增 `_build_collection_bar()`：创建横向工具栏，包含「集合:」标签、QComboBox 下拉选择器、三个 flat 按钮（+ 新建 / 导入JSON / ✕ 移除），连接 `ctx.collection_list_changed` 到 `_rebuild_collection_combo`
  - 新增 `_rebuild_collection_combo()`：根据 `ctx.slots` 填充下拉列表，无集合时显示「（无集合）」占位并禁用下拉框和移除按钮，有集合时启用控件并选中当前活跃项
  - 新增 `_on_collection_switch()`：下拉切换触发 `ctx.activate_slot()`
  - 新增 `_on_new_slot()`：调用 `ctx.activate_slot("")` 取消选中，准备加载新数据
  - 新增 `_on_import_json()`：QFileDialog 选择 JSON → ApiWorker 后台加载 → 进度反馈 → 创建 CollectionSlot 并注册
  - 新增 `_on_remove_slot()`：QMessageBox 确认后调用 `ctx.remove_slot()`
- **原因**: File 菜单中集合管理入口不够直观，用户希望在工作台直接看到和管理翻译集合；工具栏始终可见（无集合时禁用而非隐藏）让用户始终清楚集合状态

### `src/transbridge/ui/main_window.py` (改)
- **修改内容**: 
  - `_init_menu()` 删除「集合」子菜单段（新建集合 / 导入JSON / 移除 / 切换集合），以及 `file_menu.addSeparator()`
  - 删除 5 个方法：`_rebuild_collection_menu()`、`_update_collection_menu_state()`、`_on_new_slot()`、`_on_import_json()`、`_on_remove_slot()`
  - `_on_collection_changed()` 和 `_on_collection_list_changed()` 中移除菜单更新调用，保留 `_act_migrate.setEnabled()` 内联
  - `_init_menu()` 末尾移除 `self._update_collection_menu_state()` 调用
- **原因**: 集合管理已迁移到工作台顶部工具栏，File 菜单中的集合入口成为冗余；删除后避免双重入口导致维护负担
