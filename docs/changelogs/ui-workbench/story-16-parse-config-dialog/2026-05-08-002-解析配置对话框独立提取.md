# 002: 解析配置对话框 — Step1 表单提取为独立对话框

**日期**: 2026-05-08
**类型**: 增
**关联**: Epic: UI 工作台 > Story 16: 解析配置对话框与解析执行

## 修改文件

### `src/transbridge/ui/workbench/_parse_config_dialog.py` (增，283 行)
- **修改内容**: 新建独立解析配置对话框模块，包含：
  1. **`ParseConfig` 数据类**：esp_paths/eet_path/xt_path/tp_path/strings_dir/strings_lang/strings_apply_all/skip_empty/source_mode 字段
  2. **`ParseConfigDialog` 类**：支持 "parse"（完整表单）和 "migrate"（仅迁移源）两种模式
  3. **表单控件**：来源模式切换（ESP/EET RadioButton）、插件文件（多选文件对话框）、EET XML/XT XML/已翻译插件（带清除按钮）、Strings 目录（带语言选择下拉和"全部"复选框）、跳过空串开关
  4. **文件浏览**：`_browse_esp()` 使用 `QFileDialog.getOpenFileNames` 支持多选，显示 "已选择 N 个文件" 并设置 tooltip
  5. **校验与 API**：`_validate_and_accept()` 根据模式校验必填字段，`get_config()` 返回 `ParseConfig` 数据对象
- **原因**: FR7.7 文件菜单统一入口要求将 Step1 的解析表单从面板中提取为独立对话框，以支持「文件 → 解析插件…」和「文件 → 应用迁移源…」菜单项。对话框模式使 Step1 面板可被完全移除，解析流程从"面板内操作"变为"菜单→对话框→后台解析→进度嵌入 Step2"
