# 001: 文件菜单 — 解析配置对话框与解析执行

**日期**: 2026-05-06
**类型**: 增/改
**关联**: Epic: UI 工作台 > Story 16: 文件菜单 — 解析配置对话框与解析执行

## 修改文件

### `src/transbridge/ui/workbench/_parse_config_dialog.py` (增)
- **修改内容**: 新建 `ParseConfigDialog(QDialog)` 类，包含原 Step1 全部表单控件：来源模式切换（ESP/EET 单选按钮）、5 行文件路径输入（ESP 多选、EET XML、XT XML、已翻译插件、Strings 目录+语言下拉+全部复选框）、跳过空串下拉。支持两种模式：`parse`（完整表单，含 ESP 行和来源切换）和 `migrate`（仅迁移源部分）。`get_config()` 返回 `ParseConfig` 数据类（esp_paths, eet_path, xt_path, tp_path, strings_dir, strings_lang, strings_apply_all, skip_empty, source_mode）。各文件路径行均含浏览+清除按钮。`_validate_and_accept()` 在确认前校验必填项
- **原因**: FR7.7.2 需求——将 Step1 面板中的表单控件提取为独立对话框，供文件菜单项「解析插件…」和「应用迁移源…」弹出使用

### `src/transbridge/ui/main_window.py` (改)
- **修改内容**: `_init_menu()` 中添加「解析插件…」（Ctrl+O）和「应用迁移源…」菜单项。新增方法：`_on_parse_plugin()` 弹出 ParseConfigDialog→根据 source_mode 分发到 `_run_parse_esp`/`_run_batch_parse_esp`/`_run_parse_eet`；`_on_apply_migration()` 弹出 migate 模式对话框→调用 `_run_migrate()`。解析实现方法 `_run_parse_esp`、`_run_batch_parse_esp`、`_run_parse_eet` 复用与 step1.py 等效的 PluginParser/EET_XmlParser/XT_XmlParser/PluginStringsLookup 逻辑，通过 ApiWorker 后台执行，进度通过 `_workbench.show_step2_progress()` 反馈。`_finish_parse()` 处理 slot 注册与重复覆盖确认。`_run_migrate()` 支持 Strings 应用到全部集合
- **原因**: FR7.7.2 需求——将 Step1 面板中的解析按钮和迁移源按钮迁移到文件菜单，解析进度嵌入 Step2 区域
