# 001: 分类筛选标签组与面板精简

**日期**: 2026-05-06
**类型**: 改
**关联**: Epic: UI 工作台 > Story 19: 分类筛选标签组与面板精简

## 修改文件

### `src/transbridge/ui/workbench/step2.py` (改)
- **修改内容**: `__init__()` 新增 `_category_filter: str | None` 和 `_tag_buttons: dict[str, QPushButton]` 属性。`_init_ui()` 去除 QGroupBox「步骤2：解析结果预览」包装，内容直接放入外层 QVBoxLayout；四格统计卡与提示标签之间新增 `_tags_widget` 分类标签行（QHBoxLayout 中 QPushButton 组），标签使用 flat 圆角样式（_TAG_NORMAL 灰色 / _TAG_ACTIVE 蓝色高亮），初始隐藏。新增 `_build_category_tags()` 从 `_entries` 统计各分类计数，创建「全部」和各分类标签按钮，无词条时隐藏。新增 `_on_category_tag_clicked(category)` 单选切换逻辑（再次点击同一标签取消选中恢复全部）。新增 `_update_tag_styles()` 遍历按钮更新样式。`_populate_table()` 在 `_filtered_entries` 基础上叠加 `_category_filter` 筛选。`refresh()` 中无集合时隐藏标签行并重置 `_category_filter`，有集合时重建标签并重置分类筛选
- **原因**: FR7.8.1/FR7.8.3 需求——去除冗余标题，将左侧面板的分类统计转为可交互筛选标签嵌入 Step2 表格上方

### `src/transbridge/ui/workbench/widget.py` (改)
- **修改内容**: 移除 `QSplitter`、`Qt` 导入和 `CollectionStatsPanel` 导入。`_init_ui()` 中移除左侧面板和 QSplitter 实例化，`self._step2` 直接通过 `QVBoxLayout` 放入，占满全宽。`open_tool()` 和其他方法保持不变
- **原因**: FR7.8.2 需求——移除左侧集合统计面板释放水平空间，Step2 全宽显示
