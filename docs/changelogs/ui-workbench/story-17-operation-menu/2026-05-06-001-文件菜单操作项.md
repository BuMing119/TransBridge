## 修改文件

### `src/transbridge/ui/main_window.py` (改)
- **修改内容**: `_setup_op_cards()` 创建隐藏的 UploadCard/DownloadCard/WriteCard 实例（仅逻辑，不可见），传入 `_op_run_worker` 作为 worker 回调。`_init_menu()` 中添加操作菜单组：上传至 ParaTranz / 批量上传… / 下载合并 / 批量下载… / 写回文件… / 批量写回…，各菜单项连接到对应 handler（`_on_upload`→`card._do_upload()` 等）。`_update_operation_menu_state()` 复制原 step3.py `_update_button_states()` 逻辑：无集合→全禁用，无项目→上传/下载禁用，非成员→上传/下载禁用，多 slot 时显示批量变体。连接 `ctx.collection_changed`、`ctx.project_selected`、`ctx.collection_list_changed` 到状态更新。`_op_run_worker()` 替代原 step3.py `_run_worker()`：禁用操作菜单项→通过 `_workbench` 代理显示/更新/隐藏 Step2 进度→完成后恢复菜单状态。`_on_project_selected()` 增强状态栏项目标签含 id
- **原因**: FR7.7.3 需求——将 Step3 面板中的上传/下载/写回操作卡片按钮迁移到文件菜单，菜单项根据集合和项目状态动态启用/禁用
