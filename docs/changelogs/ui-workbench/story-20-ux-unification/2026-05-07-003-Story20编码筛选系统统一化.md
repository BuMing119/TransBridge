## 修改文件

### `src/transbridge/ui/workbench/step2.py` (改/删)
- **修改内容**:
  - **新增分类标签多选**: `_category_filter: str | None` → `_category_filters: set[str]`；`_on_category_tag_clicked` 改为 toggle 添加/移除（点击已选中→移除，未选中→添加，点击「全部」→清空）；`_build_category_tags` 每次点击后完整重建标签行以保证样式同步
  - **新增翻译状态标签行**: `_stage_filters: set[int]`（0=未翻译,1=机翻,2=已翻译）；新增 `_build_stage_tags()` 和 `_on_stage_tag_clicked()` 方法；`_STAGE_LABELS = {0: "未翻译", 1: "机翻", 2: "已翻译"}`；`_init_ui` 中新增 `_stage_tags_widget` 带 `_stage_tags_container`；复用 _TAG_NORMAL/_TAG_ACTIVE 样式
  - **新增文本搜索栏**: Key/原文/译文 QLineEdit + 清除按钮；QTimer 150ms 防抖后触发 `_populate_table`；`_apply_all_filters` 直接从控件读取文本做子串匹配；`_clear_search` 清空三个搜索框
  - **新增 `_apply_all_filters()`**: 叠加分类多选(AND) + 状态多选(AND) + 文本搜索(AND) 三条件筛选，返回过滤后的词条列表
  - **`_populate_table` 重构**: 原有独立分类筛选逻辑替换为调用 `_apply_all_filters()` 获取过滤结果
  - **移除 `_EntryDetailDialog` 类**（原 line 92-375，约 280 行）: 对话框类及其多选/筛选/确定逻辑全部删除
  - **移除 `_apply_filter_to_table` 方法**: 该方法的唯一调用方是对话框确定按钮，随对话框一并移除
  - **`_on_double_clicked` 改为空方法**: 保留 `pass` 占位，Story-21 将赋予行内编辑行为
  - **`refresh()` 更新**: 重置 `_category_filters`/`_stage_filters`，新增 `_build_stage_tags()` 和 `_search_widget.show()` 调用；空集合时隐藏 `_stage_tags_widget` 和 `_search_widget`
  - **移除 `_search_filters` dict 及 `_filtered_entries`**: 搜索改为直接读取 QLineEdit 控件值，不再维护中间状态
- **原因**: FR7.9 需求——将主表筛选从单选标签+弹窗模式升级为多选标签+内嵌搜索，消除 _EntryDetailDialog 带来的两层筛选认知负担，所有筛选操作在单一视图中完成
