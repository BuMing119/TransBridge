## 修改文件

### `src/transbridge/ui/workbench/step2.py` (改/删)
- **修改内容**:
  - **列常量重构**: 移除 `_COL_CHECK=0`，`_COL_KEY/ORIG/TRANS/CTX` 各减 1，`_NUM_COLS` 5→4
  - **`_init_ui` 表格重构**: 表头 `["", "Key", "原文", "译文", "类型"]` → `["Key", "原文", "译文", "类型"]`；移除 `_COL_CHECK` 列宽设置；新增 `setSelectionMode(ExtendedSelection)` 支持 Ctrl/Shift 多选；`setEditTriggers` 由 `NoEditTriggers` 改为 `DoubleClicked`
  - **移除复选框相关代码**: 删除 `_header_check` QCheckBox 控件及 `stateChanged` 信号连接；删除 `_on_item_changed` 方法（原复选框变化回调）；删除 `_on_header_check_changed` 方法（原表头全选/全不选）；删除 `_selected_entry_ids` 属性
  - **行内编辑**: `_on_double_clicked` 改为仅在译文列（`_COL_TRANS`）调用 `self._table.editItem(item)` 进入编辑；新增 `_on_translation_changed` 方法连接 `itemChanged`，检测译文列变化后更新 `entry.translation` 和 `entry.stage`（stage<2 且有译文→stage=2），刷新单元格前景色（有译文绿色/无译文灰色）；编辑时 `blockSignals` 防止递归触发
  - **`_populate_table` 简化**: 移除 Col 0 复选框的 QTableWidgetItem 创建逻辑，译文列不再设置 `~ItemIsEditable` flag（允许双击编辑）
  - **`get_selected_entries()` 重写**: 原从 `_selected_entry_ids` 集合查找 → 改为遍历 `self._table.selectedItems()`，按 `entry.id` 去重后返回，接口签名不变
  - **`_update_count_label()`**: 选中计数改为调用 `get_selected_entries()` 结果
  - **`refresh()` 清理**: 移除所有 `_selected_entry_ids` 初始化和清理逻辑
  - **import 清理**: 移除 `QDialog`、`QComboBox`、`QCheckBox`、`QGroupBox` 四个不再使用的导入
- **原因**: FR7.9.4/FR7.9.5 需求——以标准表格行选（Ctrl/Shift+点击）替代非标准的复选框列，以双击行内编辑替代弹窗间接操作，降低交互复杂度；`get_selected_entries()` 保持接口兼容确保 AI 翻译窗口等调用方无缝衔接
