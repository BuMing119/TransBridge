## 实现增量

- cancel/stop 在同一运行时锁内原子提交状态、CancellationToken、checkpoint 请求与 permit 失效，取消后不再接受迟到 completed。
- CommitPermit 绑定完整 OwnerRef、revision 和 runtime 私有一次性 nonce；伪造、重放、过期与终态提交均被拒绝并记录 ignored event。
- mutation 在运行时锁内形成唯一提交边界；异常会消费 permit、产生结构化诊断并 fail-closed，不返回 completed。
- 新增 thread、最大并发 3 的 thread-pool 和无 PyQt 依赖的 callback/QThread wrapper backend；backend 不拥有业务终态。
- 区分 cancel、策略化 stop 与进程级 shutdown；shutdown 先关闭 admission，再按 WAIT/CANCEL/CHECKPOINT_AND_CANCEL drain，并如实报告 timeout 与 `backend_released=False`。
- Composition Root 显式注入 TaskRuntime；AppRuntime 退出时先 shutdown 任务，再逆序释放其他资源；Task Monitor 控制由 capability 投影。
