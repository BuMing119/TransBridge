# Story 07：Task Monitor、Session/Agent/GUI 集成与兼容删除门禁

- 所属 Plan：`unified-task-translation-runtime-v2`
- 增量日期：2026-08-18
- 状态：实现完成，增量验证通过；待综合 QA

## 增量内容

将生产入口的任务生命周期收敛到统一 TaskRuntime，并提供兼容删除门禁：

1. **AWAITING_TASK 生产路径**（`application/tasks/entrypoints.py`）：`RuntimeTaskBridge.submit` 提交 workload 并返回 `Deferred[JobRef]`（不再伪造同步结果）；`wait_terminal` 轮询到终态并映射 `TerminalOutcome`（outcome/diagnostics）；`to_operation_result` 按操作合同序列化（COMPLETED 携带 snapshot，FAILED/CANCELLED 不带 value）。
2. **只读投影**（`application/tasks/projection.py`）：`job_snapshot_to_view` 从不可变 `JobSnapshot` 派生 GUI/Agent/MCP 共用的 public view，保留旧 Monitor 键（task_id/status/progress/metadata/created_at）；`RuntimeTaskProjection` 只读（list/get/controls），按钮按 capability/状态启用并经 `control()` 路由到 runtime，cleanup 为视图本地动作；不存在任何 writable mirror。
3. **Session 门禁**（`SessionJobGate`）：只接受活动 session 的 FINISHED 事件；旧 session 迟到完成事件仅审计（`audited()`），绝不改变状态；订阅可释放。
4. **兼容清单与删除门禁**（`docs/dev/task-runtime-compat.md`）：登记旧 `TaskManager`/`set_status`/`start_thread`/`is_long_running`/`handle_task_started/completed`/`graph_executor TaskManager()` 的全部调用方、parity 证据与六条删除门禁；本 Story 不删除任何公开入口。

## 验收对应

- 提交→终态→`OperationResult` 链路与旧同步结果类型区分不变；workload 失败映射 FAILED（value=None）、取消映射 CANCELLED；投影视图与旧 Monitor 键完全兼容；控制按 capability 拒绝（pause 缺失/未知动作不触碰 runtime）；同 session 事件接受、旧 session 事件仅审计；门禁无写路径。
