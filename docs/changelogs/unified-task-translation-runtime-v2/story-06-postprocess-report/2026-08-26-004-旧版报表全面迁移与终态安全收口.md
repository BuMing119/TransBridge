# Story 06：旧版报表全面迁移与终态安全收口

- 所属 Epic：`unified-task-translation-runtime-v2`
- 所属 Story：`story-06-postprocess-report`
- 增量日期：2026-08-26
- 前序记录：[2026-08-25-003-AI翻译完成报表统一与生产链修复](./2026-08-25-003-AI翻译完成报表统一与生产链修复.md)
- 状态：全面迁移完成，相关回归与定向静态检查通过

## 背景与原因

前序增量已将单次、批量 AI 翻译完成报表接入 canonical `ReportSnapshot`，但仍保留 legacy `ReportGenerator` 的翻译/润色兼容分支；Smart Assistant、独立润色和 Mixed 模式也尚未全部使用同一快照、`run_id` 与三格式 renderer。旧路径继续存在会让用户决定、任务终态、应用内统计和 Excel 产物再次分叉。

本次增量完成剩余生产入口迁移，删除旧生成器，并针对 QA 发现的终态快照缺失、主线程渲染、Mixed 预览时机、敏感数据泄漏、Spreadsheet 公式注入和报告轮转语义进行收口。

## 范围边界

本记录只归档与 canonical 报表迁移直接相关的符号和测试。工作区中并行存在的 AI 工作流预设、校对流水线算法、LLM 配置、Workbench、ADR-026、`plans/ai-workflow-presets/` 及其测试不属于本次增量；即使部分共享文件同时包含这些差异，本文也不将其归入 Story 06 报表工作。

## 应用层增量

- `src/transbridge/application/translation/polish_report.py`（新增）：增加 `build_polish_report_snapshot()`，把独立润色候选和最终 accepted/rejected/failed entry IDs 投影为 `transbridge.polish-report.v1`；保留 confidence、changes、note、needs_arbitration、verdict、refined translation 和 issue 明细。用户全部拒绝属于完成的审核结果，只有真实失败进入 failure count。
- `src/transbridge/application/translation/mixed_report.py`（新增）：增加 `build_mixed_report_snapshot()`，将翻译与润色分支合并为 `transbridge.mixed-report.v1`；要求父运行、分支快照和候选使用同一 `run_id`，并合并终态、计数、诊断、阶段和耗时。
- `src/transbridge/application/translation/postprocess.py`：
  - `PostProcessCandidate.report_details` 成为润色/裁决扩展字段的 canonical 容器；
  - `ReportSnapshot.__post_init__()` 对 run spec、总诊断、阶段诊断和候选详情递归执行 JSON normalization、深拷贝与敏感信息脱敏；
  - 新增 `PostProcessRunResult` 与 `PostProcessWorkload.run_with_snapshot()`，在保持 FAILED/CANCELLED 的 `OperationResult.value is None` 兼容语义时，额外提供不可变终态快照。
- `src/transbridge/application/translation/postprocess_execution.py`：`PostProcessExecutionResult.report_snapshot` 始终暴露终态快照；失败或取消不提交正式集合。
- `src/transbridge/application/translation/postprocess_report.py`：
  - JSON、CSV、Excel bundle 支持 translation、polish、mixed 三类 snapshot，润色与 Mixed 分别使用 `polish-report-<hash>`、`mixed-report-<hash>` 文件名前缀；
  - CSV/Excel 投影增加润色状态、信心度、裁决、修复候选、changes、note 和 issues；
  - 所有不可信 Spreadsheet 字符串在以 `= + - @ TAB CR` 开头时增加文本前缀，防止公式执行；
  - `REPORT_ROTATION_FAILED` 降为 WARNING，不再篡改已成功 bundle 的 outcome、counts 或 renderer failed 数；单个 renderer 失败仍以 PARTIAL/FAILED 报表操作表达，但不回滚业务提交。
- `src/transbridge/application/translation/__init__.py`：公开 polish、mixed 构建器和统一 bundle renderer 合同。
- `src/transbridge/ai_translator/translator.py`：后处理完成后使用 `PostProcessExecutionResult.report_snapshot` 合成翻译完成快照，使阶段失败或取消的诊断仍进入最终 canonical 报表。
- `src/transbridge/ai_translator/post_processor/report_generator.py`（删除）：移除 463 行五 Sheet 翻译投影、三 Sheet 润色投影、独立命名/轮转和吞异常逻辑。生产代码中已无 `ReportGenerator`、`generate_translate_report()` 或 `generate_polish_report()` 引用。

## Smart Assistant 增量

- `src/transbridge/smart_assistant/tools/tool_proofreader.py`：`run_postprocess` 改为消费终态 `report_snapshot` 并调用 `render_report_bundle()`；JSON、CSV、Excel 均登记到最近报告，`report_file` 优先 Excel，renderer diagnostics 保持结构化。任务失败或取消时先持久化终态报告再更新任务状态；`auto_fixed` 只统计已接受、已提交且文本实际变化的候选。删除 `_generate_report()` 和 `_summarize_*()` legacy 假对象投影。

## UI 与 Mixed 增量

- `src/transbridge/ui/tools/ai_translator/reporting.py`：增加通用 `render_snapshot_report()`，让翻译、润色和 Mixed 共用输出目录、三格式 bundle、20 份轮转和诊断投影。
- `src/transbridge/ui/tools/ai_translator/_report_render_worker.py`（新增）：使用受保留生命周期的 `QThread` 在后台渲染报表，通过 completed/failed 信号回到 Qt 线程，避免独立润色和 Mixed 预览在主线程写 JSON/CSV/XLSX。
- `src/transbridge/ui/tools/ai_translator/result_presenter.py`：`PolishApplySummary` 保存逐条 accepted/rejected/failed IDs；`build_polish_report()` 只构建 canonical snapshot，不再调用旧生成器；direct/preview 提交边界准确区分拒绝与失败。
- `src/transbridge/ui/tools/ai_translator/result_view.py`：独立润色对话框先展示快照和“正在生成”状态，再异步接收真实产物及诊断；Mixed 预览在用户最终接受、拒绝或关闭后才构建快照和启动渲染，避免记录预览前状态。
- `src/transbridge/ui/tools/ai_translator/_translation_report_dialog.py`：构造边界收敛为 `snapshot`，按 schema 展示翻译或润色详情；支持 pending、部分产物和致命渲染诊断，并在 Excel 真正生成后才启用打开动作。
- `src/transbridge/ui/tools/ai_translator/_mixed_worker.py`：父 `request.run_id` 注入 worker，内部 `AutoTranslator.run_id_factory` 返回同一 ID；非预览模式在线程内构建并渲染 Mixed 报表，预览模式显式延迟到 UI 最终决定。
- `src/transbridge/ui/tools/ai_translator/run_controller.py`：Mixed 结果动作登记真实 Excel artifact，不再固定 `report=None`；失败条目和报告动作由同一最终结果投影。
- `src/transbridge/ui/tools/ai_translator/ai_translator_window.py`：保存 Mixed 的冻结 run spec、预览偏好和进度窗口；独立润色把完整 `PolishApplySummary` 交给报表边界。
- `src/transbridge/ui/tools/ai_translator/_report_history_dialog.py`：新增 `polish-report-<hash>` → “润色”和 `mixed-report-<hash>` → “混合”的识别，继续读取 legacy 时间戳 Excel；兼容仅限历史读取，不再保留旧生产入口。
