## 修改文件

### `src/transbridge/smart_assistant/tool_registry.py` (改, +118行)
- **修改内容**: 
  - `ToolSpec` dataclass 新增 `summary: str = ""` 字段，新增 `__post_init__` 方法，自动从 description 的 ① 段提取 summary（正则 `①(.+?)(?:②|$)`，截断 80 字符）。已手动填写的 summary 不覆盖。
  - `_ToolRegistry` 新增 5 个类方法：
    - `build_tool_directory()` — 构建精简工具目录，按 namespace 分组，`[ns] name — summary` 格式，默认 ~500 tokens，default namespace 排最前，过滤 deprecated 工具
    - `build_tool_help(tool, namespace)` — 三种模式路由：单工具/namespace 批量/全局概览，支持逗号分隔多 namespace
    - `_help_single_tool(name)` — 单工具查找 + Levenshtein 模糊匹配（距离 ≤3），返回结构化参数表格
    - `_help_namespaces(ns_str)` — 逗号分隔多 namespace 批量加载
    - `_help_overview()` — 全局概览，按 ns 分组列出工具名+摘要
    - `_format_tool_schema(spec)` — 静态方法，将 ToolSpec 格式化为参数表格（参数名/类型/必填/说明）+ 长运行/需确认标注
  - 模块级新增 `_levenshtein_distance(a, b)` 辅助函数
- **原因**: 为工具提示词分层加载机制提供核心基础设施——LLM 可通过精简目录了解工具概况（~500 tokens vs ~14,000 tokens），按需通过 build_tool_help 获取完整定义。summary 字段零改动兼容现有 41 个工具（自动提取）
