用户要求多 Agent 排查生产流程中不必要的防御性校验，再按影响优先取消、缩小或修改。审查与实施由三个子 Agent 分别覆盖文件写回、AI/助手文本处理、UI/远端同步，主会话处理工程恢复和集成复核。

## 兼容边界与遗留项

- 远端写入取消按 key 自动解析身份；调用方若需要覆盖，必须提供目标项目已有远端 ID 并授权覆盖。没有 ID 或没有覆盖授权时走创建端点，冲突由服务端返回，不因本地扫描推断可覆盖。原有同步计划快照读取仍存在，不承诺整个同步流程零读取。
- `mixed_has_translation` 为可选关键字参数；实际混合 UI 入口传已有阶段信息。旧 mixed 调用方未提供时保留原翻译前提，不重新扫描；并未全局取消 API 配置检查。

- 来源失效只开放已保存状态的只读恢复；不自动重定位、重新绑定或信任变化后的来源。恢复原始来源后才可正常编辑，损坏版本不能伪装为成功恢复。
- Project/Variant schema、依赖、锁文件和构建配置未变，无需新增数据迁移步骤；只读查看旧 schema 仅内存转换，正常激活仍沿用已有迁移。
- 独立恢复模型/视图放入新模块；既有较大工具与窗口文件仅作局部身份透传和阶段信息接线，未承担新的扫描或恢复存储职责。
