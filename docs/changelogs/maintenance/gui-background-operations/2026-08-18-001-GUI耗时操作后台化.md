# GUI 耗时操作后台化

- 日期：2026-08-18
- 归属：maintenance/gui-background-operations
- 类型：纯 Bug 修复

## 变更

- `src/transbridge/ui/main_window.py`
  - 将项目恢复、打开、保存、自动保存、版本加载/复制、快照读写以及 `.transbridge` 导入导出迁移到 `ApiWorker`。
  - 复用工作台不定进度条展示后台状态，并在同一持久化操作期间阻止相互冲突的操作。
  - 主窗口关闭改为“后台保存完成后关闭”；保存失败时保持窗口打开，避免静默丢失修改。
  - 删除 `.transbridge` 解压后的 500 MiB 固定上限，改为根据归档声明体积、目标磁盘可用空间和动态预留量进行门禁。
- `src/transbridge/ui/workers.py`
  - `ApiWorker` 增加可选的 HTTP 错误局部路由，使 Token 验证对话框可显示 401/403，而不被全局错误总线吞掉。
- `src/transbridge/ui/paratranz/config_dialog.py`
  - Token 验证和用户查询改为后台执行，验证期间显示不定进度条并锁定输入控件。
- `src/transbridge/ui/paratranz/string_detail_dialog.py`
  - 关闭时不再无期限阻塞 `QThread.wait()`；窗口保持响应并显示“等待后台同步”进度。
- `src/transbridge/ui/tools/ai_translator/_translation_progress_window.py`
- `src/transbridge/ui/tools/ai_translator/_batch_translation_progress_window.py`
  - 停止翻译后的关闭过程改为异步等待，并复用进度条显示正在停止。
- `src/transbridge/ui/tools/smart_assistant/chat_widget.py`
- `src/transbridge/ui/tools/smart_assistant/panel.py`
  - GUI 关闭路径只发送取消，不再在主线程执行最长三秒的 worker join。
- `src/transbridge/ui/context.py`
  - 后台持久化产生的 Project projection 通知通过 Qt queued connection 回到 GUI 线程应用。
- `tests/ui/test_background_gui_operations.py`
  - 新增后台磁盘任务、后台保存、Token 验证、异步关闭、HTTP 认证错误和无固定 500 MiB 上限回归。
- `tests/integration/gui/test_app_context_projection.py`
  - 新增 worker 线程 projection 通知回到 Qt 主线程的集成验证。
- `tests/application/projections/test_projection_ownership_audit.py`
  - 清理仍强制要求 `projects-v2` 的陈旧断言，改为验证无版本号数据根约束。
