# UI 滚轮防误触与窗口导航统一修复

- 日期：2026-08-19
- 归属：maintenance/ui-interaction-hardening
- 类型：UI Bug 修复与交互一致性加固

## 目标

修复两类用户可见问题：下拉框和数值输入框会被鼠标滚轮意外修改；AI 翻译启动、批量翻译、润色报告、翻译报告及日志窗口存在未置前、焦点被启动器关闭流程抢回，或非模态报告因缺少所有权而刚显示即销毁的风险。

## 变更

### `src/transbridge/ui/input_guard.py`（新增）

- 新增应用级 `AccidentalWheelGuard`，拦截发送给 `QComboBox` 和 `QAbstractSpinBox` 的滚轮事件。
- 下拉选择和数值字段继续支持点击、键盘与显式编辑，但不再因指针悬停滚动而静默改变值。

### `src/transbridge/ui/app.py`（修改）

- GUI composition root 安装并持有唯一的滚轮防误触 guard，使当前和后续创建的业务窗口使用相同行为。

### `src/transbridge/ui/windowing.py`（新增）

- 新增公共 `show_and_activate()`：统一普通显示、最小化恢复、`raise_()`、`activateWindow()` 和延迟激活。
- 对启动器会在当前 callback 末尾关闭的路径提供 deferred 模式；执行前检查 QObject 是否已删除。
- 明确 helper 不拥有窗口，调用方必须通过 QObject parent、字段或功能级 registry 保持所有权。

### `src/transbridge/ui/workbench/widget.py`（修改）

- 单插件与批量翻译进度窗口统一登记到 Workbench 工具窗口 registry。
- 配置/目标对话框关闭后，在下一轮 Qt 事件循环恢复、置前并激活进度窗口。
- 已运行进度窗口和其他工具窗口复用公共窗口呈现入口。

### `src/transbridge/ui/tools/ai_translator/run_controller.py`（修改）

- 单插件和批量进度窗口的初始显示改用公共窗口呈现入口，保留 worker 启动与原有运行时所有权。

### `src/transbridge/ui/tools/ai_translator/result_view.py`（修改）

- 润色报告使用 deferred 激活，避免 AI 配置窗口随后关闭时把焦点送回主窗口。

### `src/transbridge/ui/tools/ai_translator/ai_translator_window.py`（修改）

- AI 配置窗口和历史报告接入公共窗口呈现入口。
- 润色报告继续由配置窗口字段显式持有，关闭启动器后仍保持有效。

### `src/transbridge/ui/tools/ai_translator/_translation_progress_window.py`（修改）

- 翻译报告以进度窗口为 parent，并由 `_report_dialog` 持有，消除无 parent 局部窗口函数返回后立即销毁的问题。
- LLM 日志查看器接入公共置前与激活行为。

### `src/transbridge/ui/tools/ai_translator/_batch_translation_progress_window.py`（修改）

- 批量汇总、插件详情报告和日志查看器统一使用公共窗口呈现入口。
- 插件详情报告由批量进度窗口 parent/字段共同持有，关闭 owner 时随 Qt 生命周期释放。

### 测试（新增/修改）

- `tests/ui/test_input_guard.py`：验证下拉框和数值输入框不会被滚轮修改。
- `tests/ui/test_windowing.py`：验证普通显示、最小化恢复和 deferred 激活时序。
- `tests/ui/test_workbench_slices.py`：验证配置窗口 callback 返回后才激活 AI 翻译进度窗口。
- `tests/ui/tools/test_ai_translator_slices.py`：验证单/批量报告具有 parent ownership、owner 销毁后释放，以及润色报告延迟激活。
