# 写回保留原名与单文件、批量另存为

- 日期：2026-10-26
- Epic / Story：maintenance / write-save-feedback（非计划维护）
- 入口：用户要求取消写回自动添加 `_translated`，在写回 UI 提供另存为，并支持多个文件保存到同一目录；授权 bm-pilot 端到端实施。

## 行为与边界

默认写回各来源原位置、保留原名。单文件在输出路径旁提供「另存为…」文件选择，批量在「另存目录（可选）」旁提供目录选择；多个来源按原名保存到该目录。「写回原位置」恢复原路径或清空批量另存目录。插件来源的套用目标也保持用户选定的插件名。

更换输出位置清除覆盖确认并使旧预检失效，取消选择不改变选项。沿用已有覆盖确认、备份、完整文件及 STRINGS 冲突检查、后台执行和逐来源回执；不同来源的同名输出不会互相覆盖。另存本地化插件时，插件及其配套 `Strings/{插件名}_{语言}.*strings` 保持对应关系；纯外部字符串翻译保留插件本体字节。

无需工程数据迁移，不主动重命名历史输出，不改变底层发布协议、语言标签、STRINGS 格式或条目身份。

## 逐文件变更

- 修改 `src/transbridge/ui/operations/write_feature.py`：单文件和批量默认目标使用来源原路径；批量接受 `output_directory`，编辑时重新生成各来源目标，保留失败来源的原路径用于恢复。
- 修改 `src/transbridge/ui/operations/write_batch.py`：批量请求保存输出目录，新增按原名计算目标及切换目录的函数；失败回执补充来源路径，避免更换目录后仍显示旧目标；批量计划增加可编辑另存目录及对应模式说明。
- 修改 `src/transbridge/ui/operations/write_dialog.py`：单文件明确显示「另存为…」，批量提供目录选择，二者均可恢复原位置；取消自动后缀，输出变化清除覆盖确认，运行及预检期间禁止目标选择动作。
- 新增 `tests/ui/operations/test_write_save_as.py`：11 项回归，覆盖默认原位写回、覆盖确认、批量统一目录、目录切换/恢复、失败回执重定位、不同目录同名来源冲突、插件及全部 STRINGS 原名输出、取消选择，以及真实 Qt→预检→确认→任务执行流程和旧确认失效。
- 修改 `tests/ui/operations/test_plugin_transfer_ui.py`：套用目标按原名写回，需要覆盖时显式确认，保留后台解析和预检所有权断言。
