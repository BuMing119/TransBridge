## 背景与归属边界

用户要求检查迭代中已淘汰或不应再使用的旧模块是否仍被错误调用，复验后授权修复。问题主要发生在正式 V2 服务已经存在、但入口仍沿用旧 worker、集合写入、会话恢复或文件 writer 的位置。

本轮接通任务运行时控制与最终提交许可，恢复完整版本和会话投影，将 Agent 来源导入、词典应用、上传 ID 回写纳入权威状态边界，并将写回迁移到来源快照和受控发布。独立复审另确认并修复了 ParaTranz 扩展字段再次导出丢失、部分上传成功后取消缺少结果收据两项遗漏。

工作区原有的 [UI 全链路修复记录](../ui-workflow-chain-closure/2026-08-31-001-UI全链路修复与全库回归.md) 保持不变。以下内容不重复归入本轮：

- `source_hydration.py` 已有的 `string_id` 传递；本轮仅新增 XT 路径映射。
- `panel.py` 已有的 V2 会话重命名、删除、失败提示和操作中止；本轮记录恢复、逐轮保存及投影回写抑制的增量。
- `test_tool_consolidation.py` 已有的工具数量断言纠偏。
- 既有插件/Strings bundle 发布器、项目归档/快照、术语 UI、AI 混合模式等变更。本轮复用这些能力，不将其底层实现记为本轮新增。

本轮没有删除整个模块文件或移动文件。删除的是下文明确列出的旧函数、旧初始化与错误回退入口；仍承担迁移兼容职责的 facade 保留。

## 逐文件生产变更

### 任务控制、提交许可与 Graph 依赖（10 个文件）

- **修改** `src/transbridge/smart_assistant/tools/task_manager.py`：`register()` 通过 `TaskRuntime.schedule()` 登记实际 backend；`start_thread()` 启动已登记 workload 并拒绝未知任务；`TaskHandle` 保存 execution、终态结果和消息。取消等待真实 worker 收尾，清理在锁外 join 并释放订阅，避免只有状态变化而 worker 继续运行。
- **新增** `src/transbridge/smart_assistant/tools/task_runtime_bridge.py`：`TaskRuntimeBridge` 将统一运行时的暂停/取消映射到既有 worker Events，提供延迟启动、join 和带许可的 `commit()`；`task_metadata()` 传递调用方 owner/project/variant/session。提交前重新检查运行态，暂停等待恢复，取消拒绝提交。
- **修改** `src/transbridge/smart_assistant/tools/tool_translator.py`：翻译与润色任务使用注册句柄的控制信号及 caller metadata，最终 V2 发布经运行时提交许可；被拒绝时在许可之外回滚旧集合暂态值，避免取消后的结果写入权威版本。
- **修改** `src/transbridge/smart_assistant/tools/tool_proofreader.py`：后处理任务复用注册句柄的 pause/stop Events，并向 workload 和最终权威发布传入同一运行时边界；终态根据实际执行结果决定。
- **修改** `src/transbridge/smart_assistant/tools/_postprocess_tool_runtime.py`：`execute_postprocess_task()` 接受调用方 commit guard，替换只看本地 stop Event 的 `ImmediateCommitGuard`；区分取消、提交失败与提交成功，避免取消仍被当作已提交。
- **修改** `src/transbridge/smart_assistant/tools/_polish_llm_runtime.py`：`create_polish_llm_runtime()` 增加可选 `pause_event` 并传给共享 LLM runtime，使润色使用实际任务控制信号。
- **修改** `src/transbridge/smart_assistant/tools/types.py`：`publish_collection_modified()` 与 `_commit_authoritative_entries()` 增加默认开启的 `rollback_on_failure` 参数；运行时许可内的调用可关闭内部 UI 回滚，在外层收尾时回滚，避免持有运行时锁等待 UI 线程。
- **修改** `src/transbridge/smart_assistant/graph_executor.py`：仅对 `is_long_running` 工具等待实际任务结果；暂停、恢复、取消传播给活跃子任务。Action 节点在依赖失败或取消后不执行，不等深 DAG 合流等待全部前驱完成；`shutdown(wait=...)` 允许 UI 非阻塞关闭。
- **新增** `src/transbridge/smart_assistant/graph_tasks.py`：`GraphTaskAwaiter` 订阅运行时事件，同时等待任务终态与 worker 退出，再将实际结果交给 Graph；避免把返回 `task_id` 的准入结果当成业务完成。
- **修改** `src/transbridge/ui/tools/smart_assistant/confirmation_view.py`：取消计划后使用非阻塞 shutdown，避免 Qt 主线程等待仍在退出的后台 I/O。

## 兼容性与真实遗留项

- 本轮复验确认问题的修复阻塞项：**无**。结论限于所核对调用链和回归覆盖，不代表所有旧模块已删除或全库不存在其他缺陷。
- V2 旧批量写回保持明确拒绝，使用逐项正式计划发布；缺少来源快照的写回不再自动回退。尚未补齐 V2 批量写回计划入口。
- V2 append 只更新已登记完整 EntryKey；跨来源、来源文本/定位元数据变化不猜测映射。内部 JSON/DSD/SST 缺正式来源 adapter 时不允许新增权威来源；此轮未实现这些 adapter。旧模式保留可用的只读/兼容处理。
- JSON 歧义需显式指定 format；ParaTranz project ID 未知时外部引用使用 offline scope。词典应用必须有可验证来源和已知语言，未知语言存词典继续禁用，不推断默认值。
- 写回默认禁止覆盖；显式覆盖保留备份。`write_back` 返回后台 task ID，Graph 等待实际完成。`strings` 使用 output_dir 并与插件一并发布，不提供孤立 Strings 的旧写法。
- 远端请求与本地权威提交不是同一原子事务。远端已接受而本地 revision 冲突时返回核对收据，不自动重试创建；上传部分完成后取消也不会隐藏已发生的远端操作。
- 旧 AutoTranslator/polish 仍可能暂时修改兼容 Collection，取消后沿既有路径回滚；本轮保障取消后的权威提交被拒绝，没有实施完整的独立候选缓冲重构。仍在执行的远端网络调用不承诺即时中断。
- 成组发布复用既有校验、备份与补偿机制，不新增跨多个文件的断电原子性承诺。迟到来源回调被拒绝时，已成功提交的原版本状态保留，不回滚之后的用户操作。
- 未运行全仓 pytest、真实外部 API、真实桌面手工点击或安装包发布验证；offscreen 自动化不替代这些验证。
- 本轮没有新增待清理的仓库临时目录；既有 `qa-tmp-s03` 未删除，未把用户或其他任务的缓存/临时文件归入本次清理。
