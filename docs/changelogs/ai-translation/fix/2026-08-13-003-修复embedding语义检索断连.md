# 003: 修复 embedding 语义检索断连

**日期**: 2026-08-13
**类型**: 改
**关联**: Epic: AI 翻译 > fix（关联 vector-term-retrieval Epic 与 ADR-010 infra 提取）

## 修改文件

### `src/transbridge/ai_translator/term_database.py` (改)
- **修改内容**: `_init_vector_index()` 中的过期导入路径 `from .embedding_client import create_embedding_client` 改为 `from ..infra.embedding_client import create_embedding_client`，对齐 infra 包
- **原因**: 原导入指向已删除的 `ai_translator/embedding_client.py`，触发 ImportError 被 `except ImportError` 吞掉，导致 `self._vector_index=None`，向量语义召回静默禁用

### `src/transbridge/infra/embedding_client.py` (改)
- **修改内容**: `create_embedding_client()` 工厂函数从读旧平铺字段（`getattr(config, "embedding_provider", ...)`、`config.embedding_local_model`、`config.embedding_api_key`、`config.embedding_base_url`）改为读 `config.embedding.*` 子对象（EmbeddingConfig 的 provider/local_model_path/api_key/base_url/model），按 provider 分派；local 模式映射 local_model_path，api 模式回退到 LLM 主配置的 api_key/base_url
- **原因**: EmbeddingConfig 三模式（ADR-010 更新）后配置收进 `config.embedding` 子对象，工厂函数仍读旧平铺字段导致永远 fallback 到 local + 默认模型，用户配置的 api/custom 失效

### `tests/infra/__init__.py` (增)
- **修改内容**: 新建 tests/infra 包
- **原因**: 镜像源码 `src/transbridge/infra/` 子包结构（ADR-002）

### `tests/infra/test_embedding_client.py` (增)
- **修改内容**: 新增 5 个用例，覆盖 create_embedding_client 的 provider 分派：local 默认模型、local 带路径、openai 完整配置、openai 回退 LLM 主配置、未知 provider 回退本地
- **原因**: 回归保护工厂函数字段映射，防止再次出现字段名/路径断连
