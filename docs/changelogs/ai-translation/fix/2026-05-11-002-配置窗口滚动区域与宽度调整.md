# 002: 配置窗口滚动区域与宽度调整

**日期**: 2026-05-11
**类型**: 改
**关联**: Epic: AI 自动翻译 > 回归修复

## 修改文件

### `src/transbridge/ui/tools/ai_translator/ai_translator_window.py` (改)
- **修改内容**: 
  - `_init_ui()` 重构布局：将翻译范围区（`_scope_stack`）和 TabWidget（`_tabs`）包裹进 `QScrollArea`（`setWidgetResizable(True)`，`stretch=1`），模式切换行和底部按钮行保持在滚动区外，固定在窗口顶部和底部
  - `__init__()` 窗口默认宽度从 560 调大到 680（`self.resize(560, 520)` → `self.resize(680, 520)`）
  - import 新增 `QScrollArea`
- **原因**: 翻译范围区展开后（状态/标记/分类三维度标签按钮 + 快捷预设），总内容高度超出屏幕范围，原来的固定 `QVBoxLayout` 无滚动机制导致窗口被撑出屏幕。加宽是为了给标签按钮行更多水平空间
