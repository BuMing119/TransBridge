# 逐条术语 JSON 绑定实现

- **日期**: 2026-08-24
- **Epic**: `ai-translation`
- **Story**: Story 16：逐条术语作用域与翻译 JSON 绑定
- **关联计划**: `plans/ai-translation/plan.md`

## 目的

保持术语库、现有筛选优先级、语义 Top 3、批次上限、精确直填和模型返回协议不变，在请求期保留条目与术语的归属，并把术语放入对应翻译 JSON 项，避免批次级术语污染无关条目。

## 变更

- **新增** `plans/ai-translation/stories/story-16-entry-scoped-terminology.md`
  - 记录请求期数据结构、接口契约、逐条归属规则、直填边界、缓存边界、测试和回退策略。
- **修改** `plans/ai-translation/plan.md`、`plans/INDEX.md`
  - 增加 Story 16，并在实现和验证完成后回写为已实现。
- **修改** `src/transbridge/ai_translator/term_database.py`
  - 新增请求期 `ScopedTermMatches` 和 `match_terms_scoped()`。
  - 保留 `match_terms_enhanced()` 的平面 `{term: translation}` 返回协议。
  - 为显式、variant、冠词、反向、相关 in-flight 和语义召回保留逐条归属；最终仍以批次级优先级和 `max_terms` 统一裁剪。
- **修改** `src/transbridge/ai_translator/translator.py`
  - 使用 scoped 匹配结果；现有精确直填代码块不变。
  - 直填后仅把剩余 `llm_entries` 的逐条绑定传给 PromptBuilder。
- **修改** `src/transbridge/ai_translator/prompt_builder.py`
  - 动态输入改为 `{id: {source, terms?}}`，空术语省略 `terms`。
  - 移除批次级术语段；旧 `$terms_section` 只兼容渲染为空并告警。
  - SYSTEM(A) → SYSTEM(B) → USER、缓存元数据和扁平响应解析协议保持不变。
- **新增/修改测试** `tests/ai_translator/test_term_database.py`、`tests/ai_translator/test_prompt_builder.py`、`tests/contracts/translation/test_workload_commit.py`
  - 覆盖平面兼容、逐条归属、大小写、in-flight、语义 Top 3、重复原文、批次上限、嵌套输入、空字段省略、翻译器接线和流式提交。
- **修改测试隔离** `tests/infra/test_llm_client_prompt_cache.py`
  - 为 Provider mock 用例增加逐用例离线 tokenizer，并同时清理编码与 token 估算缓存，避免测试顺序和网络状态影响缓存资格断言。

## 本地运行模板

`data/prompts/langs/zh_CN.toml` 位于仓库忽略的 `/data/` 下，本地副本同步为逐条术语规则和扁平输出说明；可追溯实现同时存在于 `PromptBuilder` 的内置 fallback 中。

## 验证

- `uv run --no-sync python -m pytest tests/ai_translator/test_term_database.py tests/ai_translator/test_prompt_builder.py tests/infra/test_llm_client_prompt_cache.py tests/contracts/translation/test_workload_commit.py -q -p no:cacheprovider ...`
  - **结果**: 75 passed。
- `uv run --no-sync ...ruff.exe check`（术语管理、PromptBuilder 及相关测试）
  - **结果**: All checks passed。
- 实际 `zh_CN.toml` 模板冒烟
  - **结果**: 消息顺序为 SYSTEM/SYSTEM/USER，缓存断点为 A/B，术语仅出现在相关条目，空条目省略 `terms`，不存在 `mandatory_terminology`。
- 代表性动态段测量（12 条、12 个唯一术语）
  - **结果**: 旧结构 709 字符，新结构 1260 字符，增加 551 字符；增长全部位于缓存断点 B 后。

## 遗留项

- 当前可用 `uv --no-sync` 环境为 Python 3.13.5，项目请求 Python 3.12.12，命令会输出版本不匹配警告；本次没有重建或覆盖用户现有 `.venv`。
- `translator.py` 全文件 Ruff 仍报告 43 个既有格式/现代化告警；本 Story 修改区未新增对应告警，未扩大范围清理用户现有代码。
- Ruff format 全文件检查会要求格式化多个历史文件；为避免大范围改写无关差异，本次未执行批量格式化。
