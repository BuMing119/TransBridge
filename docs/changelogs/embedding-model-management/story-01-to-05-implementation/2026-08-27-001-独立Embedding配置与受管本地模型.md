# Story 01～05：独立 Embedding 配置与受管本地模型

- **日期**：2026-08-27
- **Epic**：`embedding-model-management`
- **Story**：Story 1 独立 API 配置、Story 2 受管模型存储、Story 3 模型管理 UI、Story 4 无模型引导、Story 5 迁移与综合门禁
- **关联需求**：[FR5.14](../../../../docs/requirements.md#fr514-embedding-服务与本地模型管理)
- **关联架构**：[ADR-030](../../../../docs/adr/030-independent-embedding-and-managed-local-models.md)
- **关联计划**：[Embedding 服务与本地模型管理](../../../../plans/embedding-model-management/plan.md)

## 目的

将 Embedding 从主 LLM 配置和本地模型隐式下载中彻底解耦：API 用户获得独立、可验证的服务配置；本地用户通过应用内预设目录显式下载和管理模型；缺少模型时用可恢复的引导闭环保持语义检索关闭，同时不影响普通翻译和字面术语匹配。

### Story 1：Embedding API 独立配置

- **修改** `src/transbridge/config/llm.py`
  - 为 `EmbeddingConfig` 增加稳定的 `local_model_id`，通过统一配置仓库持久化；保留旧 `local_model_path` 仅用于兼容读取，不再作为运行身份。
- **新增** `src/transbridge/ui/tools/ai_translator/embedding_config_view.py`
  - 将 Embedding 设置从主配置 View 提取为独立 UI 切片，提供 disabled/local/api 三态、受管模型入口和独立 API Provider、模型、Key、Base URL、连接检查。
  - OpenAI Provider 仅在用户主动选择且对应字段为空时填入 Embedding 自身的建议模型和端点。
- **修改** `src/transbridge/ui/tools/ai_translator/config_view.py`
  - 接入独立 Embedding View；加载和保存 `mode`、API Provider、稳定 model ID，并停止持久化自由文本模型路径。
- **修改** `src/transbridge/ui/tools/ai_translator/config_presenter.py`
  - Embedding 连接检查在请求前校验自身 Provider、API Key、模型和 Base URL；不读取主 LLM 对应字段。
- **修改** `src/transbridge/infra/embedding_client.py`
  - `create_embedding_client()` 仅按 `embedding.mode` 和 Embedding 自身字段分派；移除 API→LLM 和未知 Provider→本地模型回退。
  - disabled 或非法配置返回不加载后端的 unavailable client。
- **修改** `tests/contracts/config/test_unified_repository.py`、`tests/infra/test_embedding_client.py`
  - 覆盖三态配置和稳定 model ID 原子往返、独立凭据参数、禁止 fallback、disabled 零加载及无凭据索引身份。

### Story 2：版本化预设与受管模型存储

- **新增** `src/transbridge/infra/embedding_model_store.py`
  - 提供两个固定 Hugging Face revision 的多语言预设，记录稳定 ID、展示信息、维度、预估大小和推荐标记。
  - 下载写入任务专属 staging，校验 `modules.json`、运行配置、safetensors 权重和版本化 `transbridge-model.json` 后原子发布。
  - 支持取消、幂等安装、无效目标保护和基于受管根目录/model ID 的安全删除；未知、越界、符号链接或未验证目标均 fail closed。
- **修改** `src/transbridge/infra/embedding_client.py`
  - 本地工厂只把受管 store 验证后的路径交给 `SentenceTransformer`，并显式传入 `local_files_only=True`。
  - 将 manifest 中的 model ID、revision 和维度合入无秘密索引身份；旧自由文本路径不会触发加载或联网。
- **修改** `pyproject.toml`、`uv.lock`
  - 将模型快照下载所需的 `huggingface-hub>=0.20` 声明为直接依赖并同步锁文件。
- **新增** `tests/infra/test_embedding_model_store.py`
  - 覆盖预设目录、成功安装、manifest 身份、幂等、取消、无效快照清理、无效既有目标保护、安全删除和未知 ID。

### Story 3：模型管理 UI 与后台生命周期

- **新增** `src/transbridge/ui/tools/ai_translator/embedding_model_dialog.py`
  - 新增模型管理对话框，展示预设说明、维度、大小、推荐、安装与当前状态。
  - 使用专用 `QThread` 执行下载，支持取消、失败提示、重试、下载后自动选择、已安装模型切换和删除确认；下载中禁止关闭造成悬空线程。
- **新增** `src/transbridge/ui/tools/ai_translator/embedding_model_controller.py`
  - 集中协调引导、管理器、稳定模型选择、启动迁移和 disabled 持久化，并用回调适配器隔离主窗口的 Embedding UI 责任。
- **修改** `src/transbridge/ui/tools/ai_translator/ai_translator_window.py`
  - 仅接入 `EmbeddingModelController` 和回调适配器；模型管理细节不留在窗口类。
  - 主窗口最终为 447 行、29 个方法，满足仓库 500 行/30 方法责任门禁；该文件中的版本快照差异属于另一增量，不计入本记录。
- **修改** `src/transbridge/ui/tools/ai_translator/view_controls.py`、`view_state.py`
  - 注册新增控件并按真实 mode 显隐；本地模式展示已解析安装摘要，API 模式只展示独立 API 字段。
- **新增** `tests/ui/tools/test_embedding_model_dialog.py`
  - 覆盖预设元数据、已安装选择、异步下载与自动选择、删除顺序、运行中拒绝关闭。
- **新增** `tests/ui/tools/test_embedding_retrieval_config.py`
  - 覆盖三态往返/显隐、独立连接检查、OpenAI 非破坏性预填、稳定 model ID 保存和无效旧本地配置静默归一化。

### Story 4：无模型引导与关闭语义

- **新增** `LocalEmbeddingGuideDialog`（`embedding_model_dialog.py`）
  - 明确说明语义检索不可用但翻译和字面术语匹配可继续，提供“关闭语义检索”和“前往模型配置”。
  - reject、Esc 和窗口关闭统一返回 disable；只有显式点击配置才返回 configure。
- **修改** `EmbeddingModelController.resolve_missing()`
  - 在打开模态引导前先持久化 `mode=disabled`，避免 Qt 自动保存计时器在用户尚未安装模型时写入不可用的 local 状态。
  - 只有管理器返回完整安装和稳定 model ID 后才重新持久化 local。
- **修改** `src/transbridge/ui/tools/ai_translator/_window_actions.py`
  - 运行前发现本地模型缺失时复用同一 Controller 引导，完成选择后重算预检，不复制第二套弹窗逻辑。
- **修改** `tests/ui/tools/test_ai_translator_story08.py`
  - 覆盖 disabled 不探测向量依赖、local/API 缺失诊断，以及引导显示前已经持久化 disabled 的状态时序。

### Story 5：迁移、预检与综合门禁

- **修改** `src/transbridge/ui/tools/ai_translator/run_spec.py`
  - local 预检只接受 store 解析出的完整安装；API 预检只接受独立 Provider、Key、模型和 Base URL；disabled 不探测 sentence-transformers、FAISS 或模型目录。
- **修改** `EmbeddingModelController.restore_managed_path()`
  - 启动时不弹窗；旧自由文本路径或无效稳定 ID 被静默归一化为 disabled，避免隐式下载和“显示开启但不可用”。
- **修改** `src/transbridge/infra/embedding_model_store.py`
  - manifest 只包含 schema、安装状态、model ID、repo、revision 和维度，不包含 API Key 或其他凭据。
