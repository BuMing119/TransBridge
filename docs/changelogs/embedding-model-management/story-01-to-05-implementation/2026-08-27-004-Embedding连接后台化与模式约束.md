# Story 01/05 跟进：Embedding 连接后台化与模式约束

- **日期**：2026-08-27
- **Epic**：`embedding-model-management`
- **Story**：Story 1 Embedding API 独立配置与产品对齐、Story 5 综合门禁
- **关联计划**：[Embedding 服务与本地模型管理](../../../../plans/embedding-model-management/plan.md)

## 目的

修复“测试 Embedding 连接”在 Qt 主线程同步创建客户端并执行向量编码、导致窗口显示未响应的问题；同时将该动作收敛为独立 API 配置专用能力，避免在本地模型或关闭语义检索模式下继续显示并接受点击。

## 实际变更

### 后台连接测试生命周期

- **新增** `src/transbridge/ui/tools/ai_translator/embedding_connection_controller.py`
  - 新增 `EmbeddingConnectionController`，在 GUI 线程冻结当前配置快照，只将客户端创建和最小向量编码交给既有 `ApiWorker` 后台执行。
  - 单次测试期间将按钮改为“正在测试…”并禁用；控制器内部同时拒绝重复启动，不依赖按钮状态作为唯一并发门禁。
  - 使用模块级活动 worker 集合保留已经脱离窗口但尚未结束的只读任务，避免运行中的 `QThread` 被提前销毁。
  - 窗口关闭时不调用 `wait()`、`terminate()` 或同步等待，而是断开 UI 回调并允许请求自行结束；迟到结果不再弹出消息框，也不继续持有原窗口控制器。
- **修改** `src/transbridge/ui/tools/ai_translator/config_presenter.py`
  - `test_embedding_connection()` 接受可选的已冻结 `LLMConfig`；既有无参数调用仍可由 presenter 自行构建配置，UI 异步路径则避免在工作线程读取 Qt 控件。
- **修改** `src/transbridge/ui/tools/ai_translator/ai_translator_window.py`
  - 将 Embedding 测试动作路由到专用后台控制器，主 LLM 测试行为保持原样。
  - 在窗口关闭边界调用控制器的非阻塞 `close()`，抑制已关闭页面的迟到反馈。

### API-only 按钮状态

- **修改** `src/transbridge/ui/tools/ai_translator/view_state.py`
  - “测试 Embedding 连接”仅在 `mode=api` 时显示并启用；`disabled` 与 `local` 模式均隐藏且禁用。
  - mode 切换刷新时同时读取连接测试 busy property，防止进行中的请求因界面刷新被错误重新启用。
- **修改** `src/transbridge/ui/tools/ai_translator/embedding_config_view.py`
  - 将 tooltip 明确为“使用当前独立 API 配置在后台执行一次最小向量编码请求”，与实际模式和线程语义保持一致。

### 回归测试

- **修改** `tests/ui/tools/test_embedding_retrieval_config.py`
  - 扩展 disabled/local/api 三态测试，验证按钮的显隐与 enablement。
  - 增加后台执行测试，证明 `start()` 在 0.1 秒内返回、实际检查运行在非 GUI 线程、测试期间按钮禁用且结束后恢复。
  - 增加重复启动拒绝、本地/关闭模式拒绝，以及关闭控制器不等待且不呈现迟到结果的生命周期覆盖。
  - 保留模块级 `QApplication` 引用，使含 QThread 的整文件回归不在参数化用例之间反复销毁 Qt 应用实例。
