# Story 02/05 跟进：模型目录配置化与构建解耦

- **日期**：2026-08-27
- **Epic**：`embedding-model-management`
- **Story**：Story 2 版本化预设目录与受管模型存储、Story 5 迁移与综合门禁
- **关联计划**：[Embedding 服务与本地模型管理](../../../../plans/embedding-model-management/plan.md)

## 目的

将应用内模型下载列表从 Python 硬编码中提取为可独立维护的 TOML 目录，使后续新增、下架或调整预设模型不需要修改模型存储代码；同时清除旧构建流程中预下载并随安装包携带默认向量模型的遗留路径，保持“由用户在 UI 中显式下载”的产品合同。

## 实际变更

### 模型目录资源与加载合同

- **新增** `src/transbridge/resources/__init__.py`
  - 建立可由 Python 资源系统和发行包读取的资源包边界。
- **新增** `src/transbridge/resources/embedding_models.toml`
  - 将两个既有模型预设迁移为有序 TOML 数据，包含稳定 ID、标题、Hugging Face 仓库、固定 commit revision、说明、维度、预估下载大小和推荐标记。
  - 冻结 `transbridge.embedding-model-catalog` 文档类型与 schema version 1；文件顺序直接决定 UI 顺序。
  - 明确仓库、revision 或维度变化时必须发布新 ID 并保留旧条目，避免已安装 manifest 与索引身份被同名配置悄然改写。
- **新增** `src/transbridge/infra/embedding_model_catalog.py`
  - 提供 `EmbeddingModelPreset`、`load_embedding_model_catalog()`、`user_embedding_model_catalog_path()` 和带来源上下文的 `EmbeddingModelCatalogError`。
  - 默认读取随包目录；当用户数据目录下存在 `config/embedding_models.toml` 时，将其作为权威覆盖文件读取。
  - 对文档大小、字段集合、模型数量、ID、仓库名、固定 40 位 revision、正整数维度/大小、重复 ID 和唯一推荐项执行严格校验；无效覆盖配置直接报错，不静默回落到内置目录。
- **修改** `src/transbridge/infra/embedding_model_store.py`
  - 移除模型预设硬编码，构造时通过目录加载器取得有序预设，并支持测试或工具显式传入 `catalog_path`。
  - 继续按稳定 ID 建立查询映射，同时保留配置文件顺序供 UI 展示。

### 运行时错误边界与构建解耦

- **修改** `src/transbridge/infra/embedding_client.py`
  - 将模型存储构造纳入本地客户端工厂的失败边界；目录不可读或校验失败时返回不可用的本地客户端，不让配置错误导致应用构造崩溃，也不触发模型下载。
- **修改** `src/transbridge/ui/tools/ai_translator/embedding_model_controller.py`
  - 打开模型管理器前捕获目录读取错误，通过“无法读取模型目录”消息提示配置文件位置和修复方向，不打开数据不可信的模型列表。
- **修改** `build.bat`
  - 删除构建阶段通过 `SentenceTransformer` 预下载约 465 MB 默认模型的步骤，并将构建步骤从四步调整为三步。
- **修改** `transbridge.spec`
  - 将 `embedding_models.toml` 纳入 PyInstaller 资源，移除旧 `data/models` 模型目录打包项。
  - 该文件当前受仓库既有 `*.spec` 忽略规则影响，因此本项记录的是本地构建配置的实际变化。

### 回归测试

- **新增** `tests/infra/test_embedding_model_catalog.py`
  - 覆盖内置目录、用户覆盖优先级和 UI 顺序。
  - 覆盖非法根字段、不安全 ID、浮动 revision、布尔维度、缺少推荐项、重复 ID、缺失显式路径等 fail-closed 场景，并验证配置失败不会创建模型根目录或调用下载器。
- **修改** `tests/infra/test_embedding_model_store.py`
  - 改用显式默认目录夹具，验证 store 不再依赖 Python 硬编码预设。
- **修改** `tests/infra/test_embedding_client.py`
  - 增加无效模型目录不会使客户端工厂崩溃的回归覆盖。
- **修改** `tests/ui/tools/test_embedding_retrieval_config.py`
  - 增加目录读取失败时显示错误且不打开管理对话框的 UI 回归覆盖。
- **修改** `tests/packaging/test_package_baseline.py`
  - 验证 TOML 资源存在并进入 PyInstaller 配置，同时验证构建脚本不再调用 `SentenceTransformer`、spec 不再携带 `data/models`。
