# 001: FR16 通用文件与词条工具需求分析

**日期**: 2026-08-14
**类型**: 增
**关联**: Epic: 通用文件与词条工具 > 需求分析

## 修改文件

### `docs/requirements.md` (增)
- **修改内容**: 在 FR15 之后新增「### FR16: 通用文件与词条工具（Agent 可调用）」需求条目，包含 5 个子需求：
  - FR16.1 归档解包与打包（7z/zip/rar 统一接口 + 分层提取 + 进度回调 + Agent 工具）
  - FR16.2 目录与文件差异分析（相对路径对齐 + 内容哈希 + Agent 工具）
  - FR16.3 资源过滤规则引擎（可配置扩展名清单 + 目录级规则 + Agent 工具）
  - FR16.4 词条键对齐迁移（新旧集合键对齐，与词典套用严格区分）
  - FR16.5 词典套用与存词典（Agent 工具注册补全，复用 translation_memory 已有能力）
  同时在「需求变更历史」表追加一行记录。
- **原因**: 用户要求把 FR15 FOMOD 流水线中的通用能力（解包/对比/过滤/词条迁移）独立为通用工具需求，避免被 FOMOD 特有逻辑锁死，且这些工具需注册为 Agent 工具供 AI 助手调用。词条对齐迁移与词典套用是两个不同工具，需严格区分。
