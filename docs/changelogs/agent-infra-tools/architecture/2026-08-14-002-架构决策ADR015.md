## 修改文件

### docs/adr/015-generic-file-entry-tools.md (增)
- **修改内容**: 新建 ADR-015，确立 FR16 通用文件与词条工具的 4 项架构决策——
  1. 模块归属：新建 src/transbridge/fileops/（archive.py + differ.py + filter_rules.py）与 src/transbridge/migrator/（key_migrator.py）两个独立包，不并入 infra/（LLM 基础设施）或 converter/（格式转换）
  2. 词条键对齐 vs 词典套用严格分离：前者仅 entry.key 精确匹配 + 原文变化检测，不做文本兜底；后者已有 translation_memory/apply_to_collection 做键+文本两级匹配
  3. Agent namespace：新建 archive（extract_archive/pack_archive/diff_directories/filter_files），词条对齐挂 editor，词典套用/存词典挂 translator（补齐 Agent 缺口）
  4. 归档实现复用 ADR-014 决策 4（py7zr + zipfile + rarfile）
- **原因**: 用户要求把 FR15 流水线的通用能力独立为通用工具，避免被 FOMOD 特有逻辑锁死；且这些工具需注册为 Agent 工具供 AI 助手调用。词条对齐与词典套用是两个独立工具，需严格区分。
