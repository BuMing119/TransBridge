# 003: Story 26 编码实现 — 断点续传与暂停/恢复

**日期**: 2026-05-21
**类型**: 改
**关联**: Epic: Agent 工具系统全面扩展 > Story 26: 后处理断点续传与暂停/恢复

## 修改文件

### `src/transbridge/smart_assistant/tools/task_manager.py` (改)
- **修改内容**: 新增 `pause(task_id)` 方法 — clear pause_event + status="paused"。新增 `resume(task_id)` 方法 — set pause_event + status="running"。`register()` 默认创建 `pause_event=threading.Event()` 并设为 set（初始非暂停）。`list_active()` 返回 `status in ("running", "paused")` 的任务（移除过时注释）。`cancel()` 在被取消任务处于暂停状态时 set pause_event 以唤醒线程退出
- **原因**: 为 Story 26 提供暂停/恢复基础设施，TaskHandle 预留字段正式启用

### `src/transbridge/smart_assistant/tools/tool_proofreader.py` (改)
- **修改内容**: `_run()` 增强 — 处理前从文件加载 PostProcessCheckpoint（损坏/不存在则从头开始并记录日志）；创建 pause_event 回写到 TaskHandle.pause_event 使 stop_task 可访问；进度回调 `_progress()` 新增阶段切换检测：`last_phase` 闭包跟踪，阶段切换时 `cp.mark_batch_completed()` + `cp.save()`；`process_entries()` 调用增加 `pause_event=pause_event` 和 `checkpoint=cp` 参数；正常完成后 `cp.delete()` 清理 checkpoint 文件；异常中断保留 checkpoint 以便恢复
- **原因**: 在工具层串联 PostProcessor 已有的 checkpoint 和 pause_event 原生支持，实现断点续传和暂停功能

### `src/transbridge/smart_assistant/tools/tool_translator.py` (改)
- **修改内容**: `_tool_stop_task()` 新增 `action` 参数（"stop"默认/"pause"/"resume"），无效 action 返回错误。批量模式（无 task_id）按 action 类型分发：pause→tm.pause()、resume→tm.resume()、stop→tm.cancel()。新增 `_action_label()` 辅助函数返回中文标签。`_PARAM_SCHEMAS["stop_task"]` 新增 action 字段。`stop_task` 工具注册信息更新 display_name 为"停止/暂停/恢复"，描述含三操作说明和示例
- **原因**: 统一任务控制入口，LLM/用户通过单一工具即可完成停止/暂停/恢复三种操作
