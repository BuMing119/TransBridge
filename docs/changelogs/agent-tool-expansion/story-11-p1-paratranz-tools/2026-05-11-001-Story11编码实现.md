## 修改文件

### `src/transbridge/smart_assistant/tools/tool_paratranz.py` (增)
- **修改内容**: 创建 paratranz namespace 平台工具(~170行)，8个工具+自动注册：
  - `list_projects(view=all/mine)`: 调用ParatranzClient.list_projects，返回id/name/visibility摘要
  - `get_project_info(project_id)`: 项目详情(名称/成员数/可见性)
  - `compare_with_remote`: 遍历local collection与remote entries对比(key+translation)，返回only_local/only_remote/different/same计数+前20条diff详情
  - `upload_entries(project_id,entry_ids,force_overwrite)`: 批量upsert_entry，返回uploaded/total
  - `download_entries(project_id)`: O7单阶段——下载+自动附加对比摘要(新增/更新数量)到ToolResult.data.diff_summary
  - `sync_terms(project_id)`: 获取术语列表
  - `export_artifact(project_id)`: 提交导出请求
  - `get_upload_history(project_id,limit)`: 获取上传历史
  - upload/download/export标记is_long_running，download require_confirmation=true
- **原因**: ParaTranz平台集成工具，Agent可执行上传/下载/对比/同步等完整平台操作
