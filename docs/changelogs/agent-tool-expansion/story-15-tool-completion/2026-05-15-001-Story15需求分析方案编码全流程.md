### `src/transbridge/smart_assistant/tools/tool_editor.py` (改)
- **修改内容**: `_PARAM_SCHEMAS["search_entries"]` 的 field description 更新为 `id/key/original/translation/context/all`（默认 original）；`_tool_search_entries()` 的 field 校验从 `("id", "key", "text", "all")` 扩展为 `("id", "key", "original", "translation", "context", "all")`，"text" 向后兼容自动映射为 "original"，默认值从 "text" 改为 "original"，无效 field 错误消息列出所有有效值

### `src/transbridge/smart_assistant/tools/base.py` (改)
- **修改内容**: `filter_entries()` 搜索分支从单个 `else` 扩展为 5 个显式分支 — `original`/`text` 匹配 `e.original`、`translation` 匹配 `e.translation`、`context` 匹配 `e.context`、`all` 对 key/original/translation/context 四字段 OR 匹配；默认 search_field 从 "text" 改为 "original"
- **原因**: 底层筛选逻辑需与工具参数对齐，all 字段之前无实际分支，translation/context 从未覆盖

- **原因**: 需一个运行时状态存储用户当前选中的 PT 项目 ID，会话内有效不持久化

### `src/transbridge/smart_assistant/tools/tool_paratranz.py` (改)
- **修改内容**:
  - 新增 `_tool_get_paratranz_project()` — 读取 `ctx.paratranz_project_id`，通过 API 查询项目详情返回 ToolResult；未选择时返回"未选择 ParaTranz 项目"

  - 更新 `_get_paratranz_client()` — project_id 默认值优先级：显式传入 → `ctx.paratranz_project_id` → `ctx.current_project`
  - 新增 `_PARAM_SCHEMAS["switch_paratranz_project"]` schema
  - `_register_paratranz_tools()` 注册 2 个新工具到 paratranz namespace（get_paratranz_project: read / switch_paratranz_project: write）
- **原因**: 实现 FR9.11.2，让 LLM 能查询和切换 PT 项目，并让已有 PT 工具自动使用选中项目作为默认值
