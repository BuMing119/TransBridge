## 修改文件

### `src/transbridge/ui/context.py` (改)
- **修改内容**: AppContext 新增以下属性和方法：
  - **新增信号**: `filter_changed = pyqtSignal(dict)` / `label_data_changed = pyqtSignal()` (Story03)
  - **_filter_state 字典 + DEFAULT_FILTER_STATE 类常量**: stage/category/label/search_query/search_field 五个筛选维度
  - **filter_state property**: getter返回副本(防外部修改)，setter整体替换+emit信号。`set_filter(**kwargs)` 合并更新。`clear_filters()` 重置为默认值
  - **B1: 标签数据上移**: `_label_library: dict[str, dict]`(标签库) + `_entry_labels: dict[str, set[str]]`(条目-标签映射) + `label_data_changed` 信号。property getter/setter 中发射信号
  - **E8: translation_scope 正式属性**: property getter返回副本，setter做类型校验(stages必须为list[int]，action必须为include/exclude/only之一)
  - **H2: _selected_ids 独立集合**: `_selected_ids: set[str]` + `select_entries(entry_ids, action)` 方法(select/deselect/clear)，与用户标签系统完全隔离
- **原因**: 标签数据从 UI 层(Step2PreviewWidget)上移至 AppContext，消除跨组基础设施缺口(B1)。translation_scope 从临时属性升级为带类型校验的正式属性(E8)。Agent 选择集合与用户标签系统解耦(H2)。筛选状态成为一等 AppContext 属性，工具无需访问 UI 层即可读写
