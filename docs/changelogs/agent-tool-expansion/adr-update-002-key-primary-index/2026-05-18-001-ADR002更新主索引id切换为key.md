# 001: ADR-002 更新 — Collection 主索引 id → key

**日期**: 2026-05-18
**类型**: 改
**关联**: Epic: Agent 工具系统全面扩展 > ADR-002 架构更新

## 修改文件

### `docs/adr/002-collection-central-data-hub.md` (改)
- **修改内容**: 文末追加 `### 更新: 2026-05-18 — 主索引从 id 切换为 key` 节。决策内容包括:
  - `_entries` 主索引 key 从 `entry.id` 改为 `entry.key`
  - `_key_index` 更名为 `_id_index: {id → entry}`（辅助索引，保留供内部合并逻辑）
  - `get(key)` 按 key 主查找，`get_by_id(id)` 新增辅助查找，`get_by_key(key)` deprecated
  - `add(entry)` 主索引 key 由 `entry.key` 构建，`remove(key)` / `__contains__(key)` 同步改为按 key
  - 工具层 `entry_id`/`entry_ids` 语义从 "entry.id 值" 改为 "entry.key 值"
  - `get_visible_entries` 返回条目中突出 `key` 为 LLM 标识字段
- **原因**: ParaTranz 上传后平台重新生成 `entry.id`，下载回来不再匹配本地数据，导致跨同步后工具查询断裂。`entry.key` 为稳定标识符，升为主索引确保跨同步操作一致
