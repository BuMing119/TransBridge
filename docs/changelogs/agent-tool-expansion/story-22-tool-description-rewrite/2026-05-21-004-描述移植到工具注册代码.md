# 004: 描述移植 — batch1-5 文档内容移植到工具注册代码

**日期**: 2026-05-21
**类型**: 改
**关联**: Epic: Agent 工具系统全面扩展 > Story 22: 工具描述全面重写

## 修改文件

### `src/transbridge/smart_assistant/tools/tool_editor.py` (改)
- **修改内容**: `_register_editor_tools()` 中 7 个工具的 `description` 字段替换为 ①②③ 三段式描述。涵盖：set_filters（参数+返回+get_current_filters预检）、get_visible_entries（200字截断标注+分页规则）、select_entries（action类型+selected_ids返回+临时状态）、edit_translation（错误路径+4/6/7/8预留说明）、set_stage（stage流转0→1→2→3→5）、manage_entry_labels（action区分+name非id规则+batch_assign确认）、list_labels（id vs name选用规则）
- **原因**: 原描述仅一句话，LLM 无法从中获取参数有效值、返回 schema、关键规则。移植后每个工具描述包含完整调用信息

### `src/transbridge/smart_assistant/tools/tool_translator.py` (改)
- **修改内容**: `_register_translator_tools()` 中 9 个工具的 `description` 字段替换。涵盖：start_translation（mixed模式说明+并行任务+API key前置）、start_polish（scope=1/3/4/5/6+intensity）、stop_task（stop/pause/resume+活跃=running+paused）、get_task_status（progress结构+单/全差异）、get/set_translation_config（post_process key名+profile限制+model不可发现）、set_scope（AND/OR组合+action语义）、set_term_config（dynamic来源+优先级）、get_scope_preview（默认stage=0+仅计数）
- **原因**: 原描述信息密度低，缺少参数有效值、返回字段结构、前置条件、工具间区分

### `src/transbridge/smart_assistant/tools/tool_parser.py` (改)
- **修改内容**: `_register_parser_tools()` 中 5 个工具的 `description` 字段替换（不含已移除的 import_strings）。每个工具包含：action(create_slot/append)、write_back target推断关系、路径安全规则、get_app_state 查询指引。parse_sst 标注 SSU8/SSU9 格式差异+仅查看限制，import_json 标注标准/DSD 格式
- **原因**: Parser 工具共享 action 参数但各工具 target 推断规则不同，原描述未体现差异

### `src/transbridge/smart_assistant/tools/tool_writer.py` (改)
- **修改内容**: `_register_writer_tools()` 中 write_back 的 `description` 替换。包含：target 四种选项、路径推断优先级、各 target 返回格式、前置条件（parse_esp→esp/strings, parse_eet→eet, parse_xt→xt）
- **原因**: write_back 是最复杂的单一工具（4 种 target），原一行描述远不足

### `src/transbridge/smart_assistant/tools/tool_paratranz.py` (改)
- **修改内容**: `_register_paratranz_tools()` 中 9 个工具的 `description` 字段替换。关键修正：list_projects uid 默认"my"、export_artifact 异步模型（trigger_export→poll 30s）、get_project_info vs get_paratranz_project 选择指南、upload_entries key 格式定义、switch_paratranz_project 鉴权前置
- **原因**: 原描述有错误（uid默认值）+ 缺少选择指南 + 缺少异步模型说明

### `src/transbridge/smart_assistant/tools/tool_proofreader.py` (改)
- **修改内容**: `_register_proofreader_tools()` 中 3 个工具的 `description` 字段替换。run_postprocess：六阶段名称+单句解释+scope来源+max_workers；get_quality_report：聚合单条语义+polish-only字段差异；list_quality_reports：降序排列+仅元数据（LLM不可读Excel）
- **原因**: 后处理工具属复杂流水线，原描述缺少阶段解释和使用流程

### `src/transbridge/smart_assistant/tools/tool_default.py` (改)
- **修改内容**: `_register_default_tools()` 中 7 个工具的 `description` 字段替换。新增：get_app_state variant定义+文件路径仅basename、list_collections 集合生命周期+esp_name null场景、get_current_filters stage语义映射表、get_statistics 全量不受筛选影响+distribution结构、list_local_projects workspace概念、get_current_project vs get_app_state区分表
- **原因**: 状态查询工具是 LLM 获取上下文的唯一途径，原描述缺少字段语义和工具间区分
