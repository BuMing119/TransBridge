# 001: QA 审查 28 项修复 — 安全护栏/参数校验/代码缺陷

**日期**: 2026-05-11
**类型**: 改
**关联**: Epic: Agent工具扩展 > QA 审查修复（跨 Story）

## 修改文件

### `src/transbridge/smart_assistant/tools/base.py` (改)
- **修改内容**: (B1) 新增 `_build_guard_chain()` 函数统一构建护栏中间件链，消除 `execute_with_guardrails` 和 `ExecutionEngine` 的双重路径分歧。(B2) 护栏模块导入失败时改为 `logger.critical()` + 返回 `ToolResult.fail("安全护栏不可用，工具执行被拒绝")`，不再静默降级。(M1) `_filter_entries()` 标签筛选从 `getattr(filter_state, '_label_entry_map', {})` 改为 `entry_labels` 参数 + 正确匹配逻辑，新增 `entry_labels` 可选参数。
- **原因**: B1 防止配置不一致导致护栏绕过；B2 防止护栏损坏时所有安全检查消失；M1 修复标签筛选始终返回 0 结果的问题。

### `src/transbridge/smart_assistant/tools/task_manager.py` (改)
- **修改内容**: (M5) 新增 `set_status(task_id, status) -> bool` 和 `get_handle(task_id) -> TaskHandle | None` 公共方法，替代外部直接访问 `_lock`/`_tasks` 私有成员。
- **原因**: 封装保护——tool_translator.py 和 tool_proofreader.py 中多处 `with tm._lock: handle = tm._tasks.get(...)` 模式改用公共 API。

### `src/transbridge/smart_assistant/guardrails/input_validator.py` (改)
- **修改内容**: (C5) `_INJECTION_PATTERNS` 从 6 组扩展到 14 组。SQL 注入增加 OR/'--/WAITFOR/SELECT...FROM 模式；XSS 增加 iframe/embed/object/6 种事件处理器/javascript: 协议；命令注入增加 python/perl/ruby/php/node/nc/ssh/socat/telnet/wmic 等 20+ 命令 + PowerShell Invoke-Expression/EncodedCommand。
- **原因**: 原 6 组模式覆盖严重不足，大量注入绕过路径（如 `' OR '1'='1`、`<img onload=...>`、`nc -e /bin/sh` 等均未被检测）。

### `src/transbridge/smart_assistant/guardrails/output_validator.py` (改)
- **修改内容**: (m11) `_SENSITIVE_PATTERNS` 从 3 组扩展到 8 组——新增 AWS Access Key (AKIA...)、GitHub Token (ghp/gho/github_pat)、JWT Token (eyJ...)、Slack Token (xoxb/xoxp)、通用凭据模式 (password/secret/token=...)。(m3) `_redact_dict` 和 `_redact_list` 增加 `isinstance(v, tuple)` 分支递归处理。
- **原因**: 原仅脱敏 OpenAI/Anthropic/Bearer 三种 Key，大量常见凭据格式未被保护；tuple 类型返回值中的敏感信息未被脱敏。

### `src/transbridge/smart_assistant/execution_engine.py` (改)
- **修改内容**: (B1) 构造函数改用 `_build_guard_chain()` 替代 `self._middlewares` 列表，`_guards` 变量名同步更新。(M7) `_run_single()` 中将 `exec_ctx` 从裸 `AppContext` 包装为 `ExecutionContext(app_context=..., task_manager=TaskManager())`，确保引擎路径可访问 TaskManager。
- **原因**: B1 确保引擎和 execute_with_guardrails 使用同一护栏链；M7 修复引擎路径中工具无法访问 TaskManager 的问题。

### `src/transbridge/smart_assistant/tools/tool_translator.py` (改)
- **修改内容**: (C1) `set_translation_config` 可设置字段列表移除 `base_url`（仅通过 profile 预设方案间接切换）。(C3) `start_translation` 空 entry_ids 且无作用域时默认设为 stage=0（全部未翻译）。(C2) `start_translation`/`start_polish` 注册时 `require_confirmation=True`。(M5) 4 处 `with tm._lock` 替换为 `tm.set_status()`/`tm.get_handle()`。(m5) 增加未知参数警告日志。(m6) `get_translation_config` 返回数据增加 `post_process_stages` 和 `term_database` 字段。
- **原因**: C1 防止 LLM 重定向 API 端点窃取 Key；C3 提供合理的默认翻译范围；C2 产生 API 费用的操作需用户确认；M5 封装对齐。

### `src/transbridge/smart_assistant/tools/tool_parser.py` (改)
- **修改内容**: (C4) `_tool_parse_sst` 增加 `_validate_path(path)` 调用，与其余 5 个解析工具统一。(M4) `_validate_path` 增加 `os.path.isabs(path)` 拒绝绝对路径。(m9) `_VALID_EXTENSIONS` 添加 `.sst`。
- **原因**: C4 修复 SST 解析器绕过扩展名白名单和路径遍历检测的安全漏洞；M4 补全绝对路径注入防御。

### `src/transbridge/smart_assistant/tools/tool_writer.py` (改)
- **修改内容**: (C6) 新增 `_validate_output_path()` 函数，所有写回工具输出路径经过校验。(M8) `_tool_write_to_eet` 改用 `EETWriter`，`_tool_write_to_xt` 改用 `XTWriter`，不再委托给 ESP 写入器。(m10) 注册元组从 4 元组统一为 5 元组格式。
- **原因**: C6 防止 admin 确认后可写入磁盘任意位置；M8 修复 EET/XT 写回实际调用 ESP 写入器的格式错误。

### `src/transbridge/smart_assistant/tools/tool_proofreader.py` (改)
- **修改内容**: (M3) `_tool_run_consistency_check` 等 5 个函数传入实际处理器类（ConsistencyChecker/FormatValidator/LLMRefiner/LLMPolisher/LLMArbiter），替代原来的 `processor_class=None`。(M5) 3 处 `with tm._lock` 替换为 `tm.set_status()`/`tm.get_handle()`。
- **原因**: M3 修复 processor_class=None 导致 `None()` TypeError，5 个后处理工具全部静默失败的问题。

### `src/transbridge/smart_assistant/tools/tool_editor.py` (改)
- **修改内容**: (M2) `_PARAM_SCHEMAS` 移到函数定义之前，为 12 个工具函数添加 `@validate_params(...)` 装饰器。(m8) `_tool_list_labels`/`_tool_create_label` 等增加 `label_library`/`entry_labels` 的 None 判空保护。(m1) 未使用的 `validate_params` 导入已实际使用。
- **原因**: M2 补全运行时参数校验（此前 schema 仅作为 LLM 文档，不实际校验）；m8 防止标签库未初始化时崩溃。

### `src/transbridge/smart_assistant/tools/tool_paratranz.py` (改)
- **修改内容**: (C2) `upload_entries` 注册时 `require_confirmation=True`（原仅 `download_entries` 需确认）。
- **原因**: 上传操作影响 ParaTranz 平台数据，需用户确认。

### `src/transbridge/smart_assistant/tools/tool_default.py` (改)
- **修改内容**: (m4) `get_app_state` 返回的路径从绝对路径改为 `os.path.basename()` 文件名。(m7) `active_project.name` 访问改为 `getattr()` + dict 类型兼容。
- **原因**: m4 防止泄露用户本地目录结构；m7 防止非对象类型的 active_project 引发 AttributeError。

### `src/transbridge/smart_assistant/mcp/adapter.py` (改)
- **修改内容**: (M6) `call_tool` 创建 `ExecutionContext` 时传入 `task_manager=TaskManager()`。(m2) `_build_json_schema` 的 `required` 列表仅包含 `required=True` 的参数，不再将所有参数标记为必填。
- **原因**: M6 修复 MCP 通道长运行任务无法访问 TaskManager；m2 修复 MCP Client 因全部参数标 required 而拒绝调用可选参数工具。
