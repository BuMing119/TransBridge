## 修改文件

### `src/transbridge/smart_assistant/tools/base.py` (改)
- **m5**: 提取 `_apply_after_guards()` 辅助函数，消除 `execute_with_guardrails` 中 ToolResult/dict 两个分支的 after 中间件链重复代码（~30 行重复 → 1 个共享函数）
- **M3**: 新增 `resolve_scope_to_entry_ids(ctx, collection)` 公共函数，从 `ctx.translation_scope` 解析条目 ID 列表，供 `start_translation` 和 `run_postprocess` 复用
- **原因**: 消除代码重复，统一 scope 解析逻辑，减少未来维护成本

### `src/transbridge/smart_assistant/tools/task_manager.py` (改)
- **m3**: `get_status()` 中 `copy.deepcopy(handle.progress)` 改为 `dict(handle.progress)` — progress 为扁平 dict，浅拷贝足够；移除 `import copy`
- **m4**: `cleanup_all()` 重构为先持锁收集句柄，释放锁后再 `thread.join(timeout=2)`，避免阻塞其他 TaskManager 操作
- **M2**: 新增 `start_thread(task_id, target)` 方法，封装 `threading.Thread` 创建+句柄关联+启动样板
- **原因**: 深拷贝无谓消耗、锁内 join 阻塞所有操作、线程创建样板 3 处重复

### `src/transbridge/smart_assistant/tools/tool_paratranz.py` (改)
- **M4**: 添加 `import logging` + `logger = logging.getLogger(__name__)`，9 个函数的所有 `except Exception` 分支添加 `logger.exception()` 调用
- **m7**: `_tool_compare_with_remote` 的 `limit=500` 改为 `args.get("limit", 500)`
- **m8**: `_tool_download_entries` 的 `limit=2000` 改为 `args.get("limit", 2000)`
- **m9**: `_tool_export_artifact` 阻塞轮询循环上方添加 `# m9: 后续可优化为异步回调` 注释
- **原因**: 线上问题排查无日志盲区、硬编码限制不灵活、阻塞设计已知待优化

### `src/transbridge/smart_assistant/tools/tool_parser.py` (改)
- **M1**: DRY 重构 — 提取 `_PARSER_DISPATCH` 分派表 + `_parse_file()` 工厂函数，5 个 parser 函数从 ~115 行缩减为 5 个 1 行委托函数
- **M9**: `_register_parser_tools()` 上方添加注释，说明 parser 工具权限 `write`（非 Plan 原定 `read`）由 Story 24 的 create_slot/append 副作用所致
- **原因**: 消除 95% 重复代码、记录权限设计变更依据

### `src/transbridge/smart_assistant/tools/tool_translator.py` (改)
- **M2**: `_tool_start_translation` 和 `_tool_start_polish` 中 4 行线程创建样板替换为 `tm.start_thread(task_id, _run)`
- **M3**: `_tool_start_translation` 中 scope 解析逻辑替换为 `resolve_scope_to_entry_ids()` 调用
- **M8**: `tool_proofreader._last_report = {...}` 直接跨模块写入改为 `set_last_report({...})`
- **m6**: 添加无全局线程池设计注释
- **m10**: 添加注释解释为何 translator 工具未使用 `@validate_params`（所有参数均为可选）
- **原因**: 消除线程样板重复、scope 解析代码重复、跨模块全局变量耦合

### `src/transbridge/smart_assistant/tools/tool_proofreader.py` (改)
- **M5**: `list_quality_reports` 返回数据中移除 `"directory"` 字段，不再暴露绝对路径
- **M8**: 模块级 `_last_report` 变量改为通过 `set_last_report()` / `get_last_report()` 函数访问，内部使用 `threading.Lock` 保护
- **M10**: 从 `_tool_run_postprocess._run()` 闭包中提取 `_build_postprocessor()` 辅助函数（~40 行）

- **M3**: `_tool_run_postprocess` 中 scope 解析替换为 `resolve_scope_to_entry_ids()`
- **m6**: 添加无全局线程池设计注释
- **原因**: 路径泄露安全风险、跨线程竞态、208 行函数需拆分、代码重复

### `src/transbridge/smart_assistant/tools/tool_editor.py` (改)
