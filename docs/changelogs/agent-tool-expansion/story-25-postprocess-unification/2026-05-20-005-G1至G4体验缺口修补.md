## 修改文件

### `src/transbridge/smart_assistant/tools/tool_proofreader.py` (改)
- **修改内容**: `_tool_run_postprocess` 新增 4 项修补：
  - **G4 (L62-65)**: API Key 前置检查 — `llm_cfg.load_from_file()` 后立即检查 `api_key` 是否配置，未配置时返回 `ToolResult.fail(error_category="config", error_code="API_KEY_MISSING")`，含恢复建议。参照 `tool_translator.py:40-44` 的 `start_translation` 模式
  - **G1 (L100-105)**: 实时进度回调 — 在 `_run()` 内定义 `_progress(phase, current, total, message)` 函数，通过 `tm.update_progress()` 将阶段/进度写入 TaskManager。传入 `processor.process_entries(progress_callback=_progress)`
  - **G2 (L107-117)**: 断点续传 — 创建 `PostProcessCheckpoint()` 实例，传入 `process_entries(checkpoint=checkpoint, esp_path=...)`。中断后可从最近完成的批次恢复，避免重复 LLM 费用
  - **G3 (L148-149)**: UI 刷新通知 — 后处理完成后调用 `ctx.safe_mutate(lambda: ctx.notify_collection_modified())`，确保 Step2 表格自动刷新显示更新后的 stage/translation。参照 `tool_editor.py:193` 的 `edit_translation` 模式
- **原因**: QA 复验 (004) 确认核心管线等价后，发现的 4 个体验缺口。G1 解决长时间运行无反馈问题，G2 避免中断后重跑产生重复费用，G3 解决 UI 不自动刷新问题，G4 改善未配置 Key 时的错误提示
