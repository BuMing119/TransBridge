# 007: 后处理报告补全与润色范围增强

**日期**: 2026-05-20
**类型**: 改
**关联**: Epic: Agent工具系统全面扩展 > Story 25: 后处理工具统一

## 修改文件

### `src/transbridge/smart_assistant/tools/tool_proofreader.py` (改)

- **修改内容**:
  - `_tool_run_postprocess` 新增 `max_workers` 参数（默认1），传入 `processor.process_entries(max_workers=max_workers)`
  - `_run()` 回调增强：完成后调用 `_generate_report()` 集成 ReportGenerator 生成 Excel 报告（5-Sheet）
  - `_last_report` 扩展：新增 `verdict_stats`（passed/rejected/pending）、`refine_results`（修复摘要列表）、`polish_results`（润色摘要列表）、`decisions`（裁决摘要列表）、`report_file`（Excel文件路径）
  - `_tool_get_quality_report` 增强：输出含裁决统计和报告文件路径
  - 新增 `_tool_list_quality_reports`：扫描 `data/ai_translator/{esp_stem}/reports/` 目录，列出历史 Excel 报告文件（按时间倒序）
  - 新增辅助函数：`_summarize_refine_results`、`_summarize_polish_results`、`_summarize_decisions`、`_generate_report`
  - proofreader namespace 工具 2→3（新增 `list_quality_reports`）
- **原因**: QA审计发现 run_postprocess 缺失 Excel 报告生成能力（Blocker）、中间数据被丢弃（Critical）、无历史报告访问（Critical）

### `src/transbridge/smart_assistant/tools/tool_translator.py` (改)

- **修改内容**:
  - `_tool_start_polish` 新增 `scope` 参数（all/passed/has_issues，默认 all）
  - scope 自动筛选：all=全部有译文条目、passed=stage in {1,3,4,5,6}（已通过检查）、has_issues=stage==2（待审核条目）
  - `entry_ids` 改为可选（与 scope 至少提供一个，同时提供时以 entry_ids 为准）
  - 参数 schema 和注册描述同步更新
- **原因**: QA审计发现 start_polish 缺少润色范围选择（polish_scope），Agent无法像GUI一样按范围筛选条目（Major）
