# 008: QA 二次复核 P0+P1 共 14 项修复

**日期**: 2026-05-20
**类型**: 改
**关联**: Epic: Agent 工具系统全面扩展 > Story 25: 后处理工具统一

## 修改文件

### `src/transbridge/smart_assistant/tools/tool_proofreader.py` (改)

- **C1**: `_tool_run_postprocess` 第 59 行 `if entry_ids` → `if entry_ids is not None`，修复空列表 `[]` 被 Python falsy 语义回退到全部条目的 Bug
- **C2**: `_tool_get_quality_report` 按 `_last_report["phase"]` 分发处理，`"polish"` 格式使用 `entry_count`/`polish_level`/`scope`/`total`，`"postprocess"` 格式使用 `total_checked`/`issue_count`/`auto_fixed`，全部通过 `.get()` 安全访问
- **C3**: LLM 配置加载、API Key 检查、`create_llm_client()`、`TermDatabaseManager` 构造及 `load_all()`、`PostProcessorConfig.from_llm_config()` 全部移入 `_run()` try/except 块，异常不再直接传播
- **C4**: 新增 `if phases is None: phases = [默认全部6阶段]` 守卫，防止 LLM 显式传 `None` 导致 `TypeError`
- **B3**: 移除未完成的 checkpoint 断点续传代码（`PostProcessCheckpoint()` 无参构造缺少必填 `esp_stem` 导致崩溃），`process_entries()` 不再传 `checkpoint=` 参数
- **M3**: 新增 `max_workers` 校验（非 int 或 <1 → 1，>8 → 8）
- **M4**: 新增 `phases` 合法性校验（非法阶段名返回 `ToolResult.fail`）
- **M6**: 3 个工具注册新增 `parameters` schema：`run_postprocess`(phases/entry_ids/max_workers)、`get_quality_report`({})、`list_quality_reports`(limit)
- **M10**: 若 `entry_ids` 已提供但全部无效，返回 `"所有指定的 entry_id 均无效，未找到匹配条目"` 而非静默启动空任务

### `src/transbridge/smart_assistant/tools/tool_translator.py` (改)

- **B1**: `_tool_start_polish` 的 `LLMPolisher` 构造新增 `term_manager`（新建 `TermDatabaseManager` 并 `load_all()`）、`game_profile`（来自 `llm_cfg.game_profile`）、`target_lang`（来自 `llm_cfg.target_lang`），与 GUI 后处理保持一致
- **B2**: 润色循环改为捕获 `PolishResult` 返回值，`confidence > 0` 时创建新 `TranslationEntry` 通过 `collection.add(updated, overwrite=True)` 写回。`_last_report` 新增 `polished_count` 字段
- **M9**: `_tool_start_translation._run()` 和 `_tool_start_polish._run()` 完成后新增 `ctx.safe_mutate(lambda: ctx.notify_collection_modified())`，Step2 表格自动刷新
- **M10**: `entry_ids` 默认值从 `[]` 改为 `None`，新增 `elif not entry_ids:` 分支返回 `"请指定要润色的 entry_ids"`，区分「未提供」与「提供空列表」

### `src/transbridge/smart_assistant/agents/agent_registry.py` (改)

- **C6**: Orchestrator 系统提示词 `check_quality` → `run_postprocess`，与 Story 25 工具重命名保持一致
- **M7**: proofreader Agent 工具列表新增 `translator:get_task_status` 和 `translator:stop_task`，可查询/停止自己启动的后处理任务
- **M8**: Orchestrator Agent 工具列表新增 `proofreader:run_postprocess`，编排引擎可调度后处理

### `src/transbridge/ai_translator/post_processor/post_processor.py` (改)

- **M11**: 仲裁上下文构建前预建 `qg_verdicts: dict[str, str|None]` 查找表（O(N) 单次扫描），循环内改为 `qg_verdicts.get(entry.id)` O(1) 查找，消除原 O(N×M) 二次复杂度

### `tests/test_postprocess_tool_parity.py` (改)

- 15 个测试用例更新以匹配修复后的正确行为：C1 修复后空 scope 返回 fail、C3 异步初始化后返回 task_id、M4 校验非法阶段返回 fail、M10 空 entry_ids 返回明确错误、start_polish 测试移除 `"entry_ids": []` 改用 scope 选择
