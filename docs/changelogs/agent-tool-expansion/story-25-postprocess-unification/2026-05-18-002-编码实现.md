# 002: Story 25 编码实现 — 后处理工具统一

**日期**: 2026-05-18
**类型**: 改
**关联**: Epic: Agent 工具系统全面扩展 > Story 25: 后处理工具统一

## 修改文件

### `src/transbridge/smart_assistant/tools/tool_proofreader.py` (改)
- **修改内容**: 
  - 新增 `_tool_run_postprocess()` — 统一后处理工具，创建 `LLMClient` + `TermDatabaseManager` + `PostProcessor` + 调用 `process_entries()` 五阶段流水线，后台线程运行，支持 `phases`/`entry_ids` 参数和 scope 解析
  - 废弃 5 个旧函数体（`_tool_run_consistency_check` / `_tool_run_format_validation` / `_tool_run_llm_refinement` / `_tool_run_llm_polish` / `_tool_run_llm_arbitration`）— 改为 `warnings.warn` + 返回 `ToolResult.fail` 提示使用 `run_postprocess`
  - 删除 `_run_postprocess_phase` 工厂函数（原 5 个工具共享的胶水代码）
  - 保留 `_tool_get_quality_report` 和 `_last_report` 缓存机制
  - `_register_proofreader_tools()` 注册列表从 6 工具减为 2 工具：`run_postprocess` + `get_quality_report`
  - Agent 注册使用 `proofreader:*` 通配符，自动适配新工具列表，无需修改 `agent_registry.py`
- **原因**: QA审计发现 5 个旧工具全部运行时崩溃——调用不存在的 `processor.process(collection)` + LLM 工具缺少必填 `llm_client` 参数。统一为 `run_postprocess` 包装 GUI 同款 `PostProcessor.process_entries()`，恢复五阶段串行流水线。
