## 修改文件

### `src/transbridge/smart_assistant/tools/__init__.py` (增)
- **修改内容**: 创建 tools 子包入口。导出 ToolResult, ExecutionContext, HITLRequest, HITLResponse, HITLType, execute_with_guardrails, _filter_entries, require_collection, validate_params
- **原因**: 新建 tools/ 子包，归属 smart_assistant 业务逻辑层，承载后续所有工具

### `src/transbridge/smart_assistant/tools/base.py` (增)
- **修改内容**: 工具系统核心基础设施 (~230行)：
  - **ToolResult v2**: `success: bool` + `partial: bool` (B3)，`get()/__getitem__` 字典兼容 (B2)，`to_dict()` 向后兼容
  - **ExecutionContext**: 包装 app_context + task_manager，`__getattr__` 代理转发 (B4+H9)
  - **HITL 协议**: HITLType 枚举 + HITLRequest/HITLResponse 数据类 (H5)
  - **execute_with_guardrails()**: 统一中间件入口 PermissionGuard→InputValidationGuard→执行→OutputValidationGuard (B6)
  - **_filter_entries()**: 公共筛选函数，供 Story 04/08/10 复用 (H8)
  - **@require_collection**: 集合前置检查装饰器
  - **@validate_params**: 参数校验装饰器工厂，支持 str/int/float/bool/list/dict
- **原因**: Story 01 从基础搭建升级为工具系统核心基础设施，为后续所有 Story 提供统一底座

### `src/transbridge/smart_assistant/tools/tool_v1.py` (增)
- **修改内容**: 迁移 6 个 v1 工具函数至 tools/ 子包：_tool_lookup_terms / _tool_translate_entries / _tool_check_quality / _tool_get_collection_summary / _tool_export_json / _tool_write_back。函数体逻辑不变，返回格式从 `{"success": bool}` dict 升级为 `ToolResult` dataclass
- **原因**: v1 工具返回格式标准化，统一走 ToolResult，消除自由字典格式

### `src/transbridge/smart_assistant/tool_registry.py` (改)
- **修改内容**: 删除 76 行 v1 工具函数体（6个函数），改为 `from .tools.tool_v1 import _tool_lookup_terms, ...`。ToolSpec.execute 类型标注从 `Callable[[dict, Any], dict]` 更新为 `Callable[[dict, Any], Any]`
- **原因**: 工具函数体移入 tools/ 子包，tool_registry.py 仅保留 ToolSpec + ToolRegistry + 注册调用入口

### `src/transbridge/smart_assistant/__init__.py` (改)
- **修改内容**: 新增 8 个导出：ToolResult, ExecutionContext, HITLRequest, HITLResponse, HITLType, execute_with_guardrails, _filter_entries
- **原因**: 新类型对外暴露，供 execution_engine / mcp / agents 等模块引用

### `src/transbridge/smart_assistant/guardrails/input_validator.py` (改)
- **修改内容**: 新增 `_detect_path_traversal()` 方法，检测 `../`、`..\\` 路径遍历和绝对路径注入 (E1)。`before_execute()` 增加路径检测调用。新增 `_PATH_TRAVERSAL_PATTERNS` 正则列表
- **原因**: ADR-012 设计了路径遍历检测但代码未实现，parser/writer 工具接收文件路径参数存在攻击面

### `src/transbridge/smart_assistant/guardrails/output_validator.py` (改)
- **修改内容**: `_redact_dict()` 追加 list 类型递归处理分支。新增 `_redact_list()` 方法，递归脱敏 list 内的字符串（匹配敏感 key 模式）和嵌套字典 (E12)
- **原因**: 原实现仅处理 dict 嵌套，list 内的敏感字符串直接跳过，存在脱敏盲区
