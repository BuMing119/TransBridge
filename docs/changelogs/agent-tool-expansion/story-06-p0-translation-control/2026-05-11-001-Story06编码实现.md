## 修改文件

### `src/transbridge/smart_assistant/tools/tool_translator.py` (增)
- **修改内容**: 创建 translator namespace 翻译控制工具（~220行），5个工具 + 自动注册：
  - `start_translation`: 参数 mode(translate/polish/mixed)+entry_ids，后台daemon线程启动AutoTranslator，TaskManager注册返回task_id，进度回调更新TaskManager。stop_event检查响应取消信号
  - `start_polish`: 后台线程启动LLMPolisher，逐条润色entry_ids指定条目，intensity参数(light/medium/heavy)
  - `stop_task`: **task_id必传**(E7:不再隐式全停)，调用TaskManager.cancel()，require_confirmation=true
  - `stop_all_tasks`: 显式独立工具(E7)，遍历list_active()全部cancel
  - `get_task_status`: 代理TaskManager.get_status()，不传task_id返回所有任务摘要
  - **已移除**: pause_task (B5: 假暂停，status和实际行为不同步)
  - 工具注册到translator namespace，与v1的lookup_terms/translate_entries同namespace
- **原因**: P0翻译执行控制闭环，统一通过TaskManager管理长运行任务生命周期，E7显式化停止语义防止误操作
