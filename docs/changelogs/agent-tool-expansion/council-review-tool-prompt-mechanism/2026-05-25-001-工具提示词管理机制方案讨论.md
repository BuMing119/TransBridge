## 修改文件

### `docs/council-reviews/council-review-tool-prompt-mechanism.md` (增)
- **修改内容**: 4角色（架构师/开发者/QA/产品）并行独立评审，讨论 TransBridge 智能助手是否可借鉴 Claude Code 的工具提示词分层加载机制。核心结论：(1) 不能照搬 CC 的 `tool_reference` 懒加载——TransBridge 使用 text JSON parsing 而非原生 function calling，无拦截-懒加载-重注入循环；(2) 4角色一致推荐实施路线为「工具描述瘦身 → namespace 预过滤 → 核心工具层」三步走；(3) 产出 6 项共识建议 + 分三阶段优先级清单（高4项/中5项/低4项）
- **原因**: 用户希望为智能助手设计工具提示词分层加载机制以减少 context 消耗，但对 CC 方案能否直接移植存疑。评审委员会通过多角色分析厘清了技术约束和可行路径
