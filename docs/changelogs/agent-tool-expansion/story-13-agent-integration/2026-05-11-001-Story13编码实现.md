## 修改文件

### `src/transbridge/smart_assistant/agents/agent_registry.py` (改)
- **修改内容**: init_presets()全面更新：
  - **扩展3个现有Agent**: translator/proofreader改为namespace:*通配符(O3)，orchestrator扩充为7个跨namespace工具(editor/translator/paratranz)。新增_expand_wildcard()函数在register()时自动展开namespace:*为具体工具名
  - **新增4个Agent**: parser(parser:*)/editor(editor:*)/paratranz(paratranz:*)/writer(writer:*)
- **原因**: 7个Agent覆盖全部7个namespace，namespace:*通配符自动同步工具列表，无需手动维护

### `src/transbridge/smart_assistant/agents/orchestrator.py` (改)
- **修改内容**: map_to_steps()中tool_name从固定取agent_spec.tools[0]改为优先从LLM输出的st.action/tool_name字段获取，仅fallback时取tools[0](E4)
- **原因**: 修复多工具场景下工具路由错误——LLM决定调用edit_translation时不应错误执行filter_by_stage

### `src/transbridge/smart_assistant/mcp/adapter.py` (改)
- **修改内容**: call_tool()中spec.execute(arguments, self._ctx)改为execute_with_guardrails(spec, arguments, ExecutionContext(app_context=self._ctx))(B6联动)。MCP通道现在与GUI共享同一条PermissionGuard→InputValidationGuard→执行→OutputValidationGuard中间件链
- **原因**: B6消除MCP安全分叉——原MCP通道绕过全部安全护栏，admin/write工具零校验执行。现在MCP模式下admin/write确认自动拒绝(无UI通道降级策略)
