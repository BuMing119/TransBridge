## 评审核心发现

### 阻塞项（6 项，编码前必须解决）
1. 标签数据上移至 AppContext（Story 03 追加 `label_library`/`entry_labels`/`label_data_changed`）— 三组共识
2. ToolResult 字典兼容 — 添加 `get()`/`__getitem__` 修复 execution_engine.py 兼容断裂
3. ToolResult.success 语义修正 — 改为 `success: bool` + `partial: bool = False`
4. ExecutionContext 提前至 Story 01 — 含 `__getattr__` 代理
5. 移除 pause_task 工具 — 假暂停比无暂停更危险
6. MCP 护栏中间件注入点预留 — `execute_with_guardrails()` 统一入口

### 安全漏洞（4 个高优，已代码审计确认）
1. MCP 通道绕过安全护栏中间件链（Critical）
2. API Key/Token 明文存储于 INI 文件
3. `set_translation_config` 的 `base_url` 可被 MITM 注入
4. InputValidationGuard 路径遍历检测缺失（ADR-012 设计但未实现）

### 功能缺口
- 缺失 `set_stage` 批量标记工具（核心闭环断裂）
- `select_entries` 标签系统污染 UI
- `edit_translation` 无差别设 stage=2

## 对 plan.md 的修改影响

- Story 01 范围扩大（+ExecutionContext +HITL协议 +统一安全入口）
- Story 03 追加标签数据上移
- Story 05 合并至 Story 04
- Story 06 移除 pause_task
- Story 12 parser 权限 write→read
- 净增工作量 +2-4h
