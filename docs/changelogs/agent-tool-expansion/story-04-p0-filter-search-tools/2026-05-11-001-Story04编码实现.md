## 修改文件

### `src/transbridge/smart_assistant/tools/tool_editor.py` (增)
- **修改内容**: 创建 editor namespace 工具模块（~210行），实现 9 个工具并自动注册：
  - **筛选(5)**: `filter_by_stage`(校验stage值∈{0,1,2,3,5,9,-1}) / `filter_by_category` / `filter_by_label` / `search_entries`(支持id/key/text/all字段) / `clear_all_filters` — 全部调用 ctx.set_filter/clear_filters
  - **数据查询(1)**: `get_visible_entries` — @require_collection装饰器，调用 _filter_entries()公共函数(H8)，分页limit(最大200)+offset，返回条目摘要含id/key/original/translation/stage，truncated标志
  - **选择(1)**: `select_entries` — 调用 ctx.select_entries()操作独立 _selected_ids 集合(H2)，支持select/deselect/clear三种action，与用户标签系统完全隔离
  - **编辑(1)**: `edit_translation` — @require_collection，直接修改 TranslationEntry.translation，new_stage参数可选(H4:不传保持原stage，传入则显式设定)
  - **批量标记(1)**: `set_stage` — @require_collection，批量更新多个entry.stage，部分成功时返回 ToolResult.partial_ok(H3:填补批量标记缺口)
  - **_register_editor_tools()**: 模块加载时自动向 ToolRegistry 注册 9 个工具到 editor namespace，筛选工具permission=read，编辑/标记工具permission=write
  - **_PARAM_SCHEMAS**: 9个工具的参数schema字典
- **原因**: 合并原 Story 04（筛选搜索）和 Story 05（编辑选择），统一负责「筛选→选择→编辑→标记」完整操作链，消除跨Story依赖
