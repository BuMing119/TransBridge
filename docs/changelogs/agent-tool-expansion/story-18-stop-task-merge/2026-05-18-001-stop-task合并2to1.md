### `src/transbridge/smart_assistant/tools/tool_translator.py` (改)
- **修改内容**:

  2. `_tool_stop_task()` 重写——`task_id` 参数从 `required: True` 改为 `required: False`，默认 `None`。`None` 或 `""` 时通过 `TaskManager.list_active()` 获取所有活跃任务并逐个 cancel，返回 `stopped_task_ids` 和可选的 `failed_task_ids`（partial=True）。有值时保持原有单任务停止逻辑。无活跃任务时返回 "当前无运行中的任务"
  3. `_tool_stop_all_tasks()` 改为 deprecated wrapper——发出 `DeprecationWarning("use stop_task without task_id instead")` 后转发到 `_tool_stop_task({}, ctx)`
  4. `_PARAM_SCHEMAS["stop_task"].task_id` 的 `required` 从 `True` 改为 `False`，描述更新
  5. `_register_translator_tools()` 注册表：移除 `stop_all_tasks` 条目，`stop_task` 描述更新为 "Story 18 合并 2→1"
- **原因**: Story 18（工具架构合并路线A）——`stop_task` + `stop_all_tasks` 功能高度重叠（停止翻译/润色任务），合并到单一入口 `stop_task`，task_id 可选化消除两个工具的碎片
