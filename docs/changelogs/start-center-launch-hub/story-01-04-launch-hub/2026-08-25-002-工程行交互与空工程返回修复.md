# 工程行交互与空工程返回修复

- **日期**：2026-08-25
- **Epic**：`start-center-launch-hub`
- **Story**：S02 任务入口与本地工程双栏 Landing、S04 QA 与视觉合同
- **需求关联**：FR28.2、NFR1.4～NFR1.7
- **类型**：真实截图缺陷修复

## 目的

根据用户在真实应用中的复验截图，修复本地工程面板中默认 `QListWidgetItem` 文本与自定义工程行同时绘制造成的重叠内容，并解决自定义行覆盖列表鼠标事件后普通工程无法按整行单击打开的问题。同时把空工程创建页中位于表单底部、难以发现的文字返回按钮改为标题栏左侧的图标返回入口。

## 真实变更

### 本地工程行绘制与激活

- `src/transbridge/ui/shell/start_center_landing.py`（修改）
  - 工程条目不再设置可见的默认 item 文本，只通过自定义 `_ProjectRow` 呈现名称、路径、状态和箭头，消除“艺术馆，可打开”等底层文字与自定义行重叠。
  - 将工程名称与状态写入 `AccessibleTextRole`，继续为屏幕阅读器保留活动、可用和不可用语义。
  - 让 `_ProjectRow` 对鼠标事件透明，并增加 `_ProjectList`：鼠标左键释放按整行触发一次工程动作，Enter/Return 触发同一调用路径。
  - 激活规则保持不变：当前工程返回工作台，其他可用工程按 catalog 路径打开，不可用工程不发出打开请求。

### 空工程创建页返回入口

- `src/transbridge/ui/shell/start_center.py`（修改）
  - 移除表单操作区左下角的文字“返回”按钮，在“创建本地翻译工程”标题左侧增加 40×40 的纯左箭头按钮。
  - 返回按钮继续发出既有 `return_to_landing_requested`，并保留“返回开始中心”的可访问名称和“返回开始”的悬浮提示；Escape 返回语义未改变。
- `src/transbridge/ui/foundation/tabler_icons.py`（修改）
  - 在现有主题感知 Tabler 图标子集中增加 `arrow-left`，供创建页返回按钮使用，不引入硬编码前景色。

### 回归测试

- `tests/ui/test_start_center_guided_project.py`（修改）
  - 由直接发射 `itemActivated` 改为 `QTest.mouseClick` 真实点击项目行，覆盖当前工程、普通工程和不可用工程三种行为。
  - 新增工程行 Enter/Return 激活回归，锁定默认 item 文本为空、可访问文本保留状态的合同。
  - 新增创建页返回按钮合同，验证无文字、图标存在、tooltip、可访问名称和返回信号。
- `tests/ui/foundation/test_tabler_icons.py`（修改）
  - 将 `arrow-left` 纳入透明矢量图标渲染测试。
