# 插件来源与不兼容导入

- 日期：2026-11-17。
- Epic：`start-center-launch-hub`；Story：[S07](../../../../plans/start-center-launch-hub/plan.md#story-07插件主来源与不兼容导入)。
- 动机：用户要求普通来源只接受插件，非插件经独立“不兼容导入”入口并提示功能限制。

## 文件与行为

- `src/transbridge/ui/workbench/file_source_formats.py`：新增插件/非插件选择筛选器，复用现有 FormatCatalog 后缀映射验证路径和确定草稿可选格式；原有工作台及译文格式集合不变。
- `src/transbridge/ui/shell/start_center_controller.py`：普通选取和追加限定 ESP/ESM/ESL；非插件主来源使用独立路径验证、警告与确认。对已选路径入口应用相同规则，取消、忙碌及选择期间草稿变化不覆盖原草稿。中文确认按钮为“继续导入”和“取消”，默认及 Escape 均取消。
- `src/transbridge/ui/shell/start_center_landing.py`：主卡片副文案限定插件，在既有高级入口行加入小型“不兼容导入”；恢复或打开工程期间沿用禁用状态。
- `src/transbridge/ui/shell/project_creation_form.py`：来源区改为“添加插件…”、“不兼容导入”、“移除选中”；插件格式固定，非插件仅显示适用选项，已有译文区域支持不变。
- `src/transbridge/ui/shell/start_center.py`：转发新入口信号；`intent_composition.py`：同一 `PROJECT_CREATE` 接受 incompatible 模式，不新增独立建项业务流程。本轮仅记录该模式路由，不重复记录前序菜单修改。
- `src/transbridge/ui/coordinators/guided_project_coordinator.py`：约束格式与来源相符，逐插件强制插件解析；混合来源不被单一格式误标，追加/移除保留用户选项。内容伪装为插件仍由真实解析器拒绝。
- `tests/ui/test_project_creation_form.py`、`test_project_creation_file_workflow.py`：更新对应入口合同，新增过滤、警告、取消、忙碌、混合格式、实际创建与伪装插件拒绝的回归覆盖。
- `docs/requirements.md`：对齐 FR26.2、FR26.3、FR28.1；计划和索引登记 S07 完成与 QA 证据。
