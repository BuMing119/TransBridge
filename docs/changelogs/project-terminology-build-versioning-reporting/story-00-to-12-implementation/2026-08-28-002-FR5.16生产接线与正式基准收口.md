## 增量结果

正常 `build_runtime` 现在构造项目隔离 SQLite repository factory、权威来源捕获、真实 TaskRuntime workload handlers、commit guard、UI commands/services、release gate 与 effective terminology factory。GUI 从正式入口形成 preflight、构建、分页预览、冲突/人工决定、草稿、发布、报告、历史/比较/新版本回退、changelog/retry 闭环，不再依赖测试手工注入。

已发布术语通过冻结的 Project/Variant context 接入 translator、term database、vector identity、proofread/polish/quality gate、批量/混合 worker 与 Smart Assistant。插件作用域优先于项目作用域；suppression、未解决冲突和待复核项阻止同作用域 legacy fallback 回流。无版本、门禁关闭、仓储只读或损坏时保持既有 legacy 行为。

feature gate 已进入 capability、command、UI 与 translator 路径，顺序固定且不能越级；partial publish 由固定策略关闭。缺少 digest-bound release evidence 时所有 stage 默认 OFF，已有 Project v3、SQLite、版本、报告和 changelog 资产不删除、不降级。

## 关键实现与修复

- 将生产 terminology composition 从单个超大模块拆分为 `bootstrap/terminology.py`、`terminology_storage.py`、`terminology_workloads.py`，正常路径绑定 build/publish/report/changelog/history-compare runner。
- 增加真实 Draft/Decision/Conflict SQLite 事务命令、历史比较、以新不可变版本实现回退、changelog 失败重试和 production build→publish→consume 跨层测试。
- 增加 SQLite effective snapshot port；READY snapshot 的 blocked/suppressed 项不会被 legacy 重引入，OFF/no-version/read-only/corrupt 保持 legacy。
- 正式 runner 实现 regular/stress 十场景、五轮缓存边界、10% 真实变化与全量 digest parity、真实质量 Excel 和 Markdown/Excel changelog、RSS baseline/peak/recovered/stable growth、LLM/I/O 分桶。
- 增加 Qt/TaskRuntime supplemental runner与 regular+stress bundle aggregator；单场景永不直接开启 release gate，diagnostic smoke 永远不合格。
- ProgressHeartbeat 默认间隔从 2.0 秒收紧到 1.5 秒，为 2 秒 SHALL 留出调度裕量。
- SQLite candidates/conflicts/evidence/history 首屏改为标量 ref 校验与 keyset SQL，不再先解码完整 BuildResult 或全部 Version payload；仍核对 payload ref/digest，损坏时 fail-closed。
- 相邻版本 compare 直接读取发布事务同步持久化且 digest-bound 的 canonical diff；GUI 提交不再在主线程解码 5 万术语版本，旧 schema-v2 兼容回退，非相邻版本保留完整重算。
- 非流式生产 preflight 在任何来源字节常驻前限制最多 50 个启用来源、单源 64 MiB、总量 256 MiB；租约改为 1 MiB 分块哈希和 path-backed snapshot，并防住 `stat` 后文件增长。超限返回 `TERMINOLOGY_STREAMING_REQUIRED`，当前不宣称支持 200-source stress 生产输入。

## 正式证据与门禁结论

本机 Windows 11/NVMe/24 物理核/约 32 GiB 环境完成 regular 与 stress 各 10 场景、每场景 5 轮，以及 Qt supplemental。聚合 bundle digest 为 `f0e0b08aeaded79146b2db8020a0270d13ef4af478debc7d5152d0db96739d75`。

通过项包括参考环境/规模、regular/stress 构建耗时、UI 可见反馈/主线程/heartbeat、取消、五轮稳定增长、重复复用、10% 变化、digest parity、质量 Excel、无截断和外部等待分桶。失败项：regular/stress 峰值额外 RSS 分别 `1,295,310,848`/`5,143,638,016 bytes`；原始 regular query/history/compare/changelog 分别 `13.8054`/`6.82123`/`7.48440`/`95.4002 s`；`incremental-vs-full` 未独立测量。最终 query/history 独立五轮复测已进入预算，相邻 compare 已增加快路，但最终工作树没有完整正式重测。

因此 analysis/report、draft/publish、effective、history/revert/changelog、partial publish 全部为 **OFF**；ADR 不接受，Plan 不完成。完整细节见 [`2026-08-28-release-candidate.md`](../../../test-reports/terminology-benchmarks/2026-08-28-release-candidate.md)。
