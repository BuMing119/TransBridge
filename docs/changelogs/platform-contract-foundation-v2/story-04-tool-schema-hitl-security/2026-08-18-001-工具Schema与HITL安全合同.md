## 实现增量

- 建立 canonical JSON Schema 与 legacy 参数转换，注册阶段拒绝非法 schema、重复工具，并在完整注册后冻结 Agent wildcard 能力。
- HITL token 绑定 owner、请求快照和 plan hash，且只能消费一次；拒绝、超时、重放、上下文或参数变化均在副作用前终止。
- 路径授权统一为“规范化并解析链接后落在 RuntimeContext 授权根内”；无授权根 fail-closed，根内相对/绝对路径可用，逃逸、symlink 与 Windows junction 被拒绝。
- 共享 SecretRedactor 覆盖 ToolResult、Observation、OutputGuard 与 storage；结构化 Observation 与展示摘要分离，不再因截断丢失执行 schema。
- 旧 Parser 只保留存在性与扩展名业务校验，安全授权由公共 guard 负责；兼容工具注册和调用方式保留。
