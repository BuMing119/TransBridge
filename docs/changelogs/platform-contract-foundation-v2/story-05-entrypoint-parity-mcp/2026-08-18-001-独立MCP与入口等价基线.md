## 实现增量

- `transbridge-mcp` 生产入口从 Composition Root 创建独立 headless runtime，不注册 legacy GUI tools，也不读取 GUI 未保存内存或 stdin daemon thread。
- MCP stdio 实现严格 initialize/initialized、tools/list、tools/call、shutdown/EOF 生命周期；notification 不输出 `id:null` 错误，runtime 只关闭一次。
- JSON-RPC 严格拒绝 NaN/Infinity、非法容器 request id 与无效参数；stdout 仅协议帧，日志固定到 stderr，凭据在 stderr、Tool payload 与 structuredContent 中统一脱敏。
- GUI、Agent、CLI、MCP transport adapter 接收同一已构造 runtime binding，复用 EntrypointOperations；无状态 capability 与需 Project 上下文能力形成语义 parity。
- 保留旧 `smart_assistant.mcp` import facade 和 canonical schema，不把未迁移业务工具伪装为 headless 可用。
