## 实现增量

- 新增 Clock/Id/FileSystem/Security/Repository/Format/Task/Secret/Closable application ports；具体 I/O、持久化和任务 adapter 留给 ADR-017/018/019 下游 Story，不以空实现宣称能力可用。
- 新增 `build_runtime()`、`AppRuntime`、`RuntimeContext`、每 runtime 独立的 use-case/capability/config/state 和显式 binding；默认 headless adapter 不导入 PyQt。
- 新增 ContextRequirements use case；缺 Project/Secret 返回 S02 的 prerequisite `OperationResult`，凭据值不进入序列化结果。
- `AppRuntime.close()` 逆序释放、线程安全、幂等；单个资源失败不阻止其余资源释放，结果保持 completed/partial/failed 互斥语义。
- GUI 权威入口构造并注入同一个 runtime、AppContext projection 和 RuntimeContext；移除 GUI 进程内启动 stdio MCP 的旧拓扑。
- editor/proofreader/translator controller 清除隐式 `AppContext()+TaskManager()` getter；`ExecutionContext(app_context=None)` 在副作用前返回结构化 prerequisite。
