## 能力矩阵结论

- 每格式（11 个 FormatId）每入口（7 个 entrypoint）= 77 cell 全闭合。
- SST Writer（sst.ssu8/sst.ssu9）write/roundtrip/publish 固定 `unavailable`；BINARY_EET write 也 `unavailable`。
- JSON_DSD ceiling 为 experimental 但无 V2 adapter → 实际为 unavailable（绝不宣称 supported）。
- XML_EET/XML_XT/PLUGIN_SSE/strings 系列 read/write/roundtrip/publish 为 available。
- 缺可选依赖（rank-bm25/faiss/py7zr/rarfile）时相关 feature 降级为 degraded。

## 无法覆盖项与边界

- 真实 junction 创建需 Windows 开发者模式/管理员特权：本机不可用时跳过关卡并说明，不以跳过算通过。
- 真实 >260 长路径需系统长路径开关：本机未开启时跳过关卡并说明。
- RAR 完整恶意 corpus 的落地压缩成员验证依赖 `unrar.exe`/rarfile 后端，本机以 capability 上报（`ARCHIVE_RAR_BACKEND_UNAVAILABLE`）而非伪造通过。
- 依赖缺失隔离采用 `find_spec` 拦截/子进程近似，未真删环境依赖（明确边界）。
