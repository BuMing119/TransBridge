## 修改文件

### `docs/adr/014-fomod-translation-memory.md` (改)
- **修改内容**: 决策 3 目录结构收敛为 `model.py`/`manager.py`（原 `entry.py`/`store.py`/`sources/`），新增勘误；决策 3.1 从「三级 scope + 双层独立副本」改为「两档 scope（project/global）+ 单表权威对象 + 双索引 + EXACT/STALE」；Consequences 接口签名对齐 `TranslationMemoryManager`/`QueryContext`/`QueryResult`/`ApplyResult`
- **原因**: 议会评审发现实现与 ADR 契约失配 + 双表共享引用在 save/load 后分裂的 Critical 隐患，按用户四项拍板（以代码为准、scope 两档、单表+双索引）收敛

### `docs/requirements.md` (改)
- **修改内容**: FR15.1.1 数据模型重写为「两档 scope + 单表权威对象 + 双索引 + EXACT/STALE」；FR15.2.1 归档补充 rar 经 rarfile+unrar.exe（仅解压）
- **原因**: 与 ADR-014 勘误同步，反映议会评审后的最终数据模型

### `src/transbridge/translation_memory/model.py` (增)
- **修改内容**: `DictionaryEntry`（translation/original/source/imported_at/updated_at/tags，不含 hit_count）+ `Dictionary`（scope/scope_id/entries 权威表/key_index/text_index 双索引，命中计数 hits 落在索引值）。`VALID_SCOPES`={project,global}，`SCOPE_RANK` 优先级
- **原因**: 落实「单表权威对象 + 双索引」，译文只存一份，键/文本两条索引各自独立计数，从数据模型消除双副本分裂

### `src/transbridge/translation_memory/manager.py` (增)
- **修改内容**: `TranslationMemoryManager` 完整实现——`add`（_stable_id 派生主键 + 双索引登记）、`query`（逐级兜底 project→global，键命中即停返回 EXACT/STALE，文本命中兜底）、`save_from_collection`（排除 stage 9/-1 与空条目）、`apply_to_collection`（填空译文 + needs_review 收集 STALE）、`save`/`load`（atomic_write_json + schema_version + 损坏文件抛错保留 .corrupt-*）、`merge`、`_normalize` 缓存。`QueryContext`（project_id/game_id 顺序）、`QueryResult`（translation/matched_scope/matched_via/match_status/conflicts）、`ApplyResult`（key_hits/text_hits/misses/applied/needs_review/conflicts）
- **原因**: 词典系统的核心逻辑，支持存/查/套用/持久化，供后续 fomod 翻译与批量翻译复用

### `src/transbridge/translation_memory/__init__.py` (改)
- **修改内容**: 修复 import 不存在的 `manager.py` 导致的 ImportError（此前 `from ...manager import ...` 配空目录，一 import 即崩溃）；现正确导出 `Dictionary`/`DictionaryEntry`/`TranslationMemoryManager`/`QueryContext`/`QueryResult`/`ApplyResult`
- **原因**: 议会评审发现的事实性阻断 bug，优先修复使包可导入

### `tests/test_translation_memory.py` (增)
- **修改内容**: 17 个单元测试覆盖数据模型往返、add 双索引、query 键优先+EXACT/STALE+文本兜底、存为词典跳过空/锁定、套用填空/排除锁定、save/load 往返（中文+损坏文件）、hit_count 独立性、merge、换行规范化。测试临时目录改用 workspace 内 fixture（`tm_tmp_dir`）绕开 sandbox 对外部 Temp 的写限制
- **原因**: 覆盖双表一致性、逐级兜底顺序、冲突仲裁、持久化往返等议会评审点名的关键测试矩阵
