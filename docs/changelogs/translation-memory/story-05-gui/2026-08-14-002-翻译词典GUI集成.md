# 002: 翻译词典 GUI 集成（存为词典 + 词典库面板）

**日期**: 2026-08-14
**类型**: 增
**关联**: Epic: translation-memory > Story 05: GUI 集成

## 修改文件

### `src/transbridge/ui/tools/dictionary_dialog.py` (增)
- **修改内容**: `SaveToDictionaryDialog`（QDialog）——收集「存为词典」参数：scope 下拉（project/global）、scope_id 输入（项目名/游戏标签）、粒度 radio（整个集合/仅选中条目）、标签输入（逗号分隔，去重保序）。project scope 强制填 scope_id（置红提示）。`result()` 返回 `(scope, scope_id, selected_only, tags)`
- **原因**: 提供「存为词典」的交互入口，落实 scope 两档 + 粒度 + 自由标签的输入契约

### `src/transbridge/ui/tools/dictionary_panel.py` (增)
- **修改内容**: `DictionaryPanel`（QDialog）——顶部词典下拉（含「全部词典」）+ 标签筛选 + 「存为词典…」「刷新」按钮；主体表格展示条目（原文/译文/来源/命中数/标签/表类型 键/文本）；`_load` 经 manager 加载词典，`_rebuild_combo` 聚合词典与标签下拉，`_refresh_table` 按词典+标签筛选填充表格（键表/文本表去重展示），`_on_save_to_dict` 调 `save_from_collection` + `save()` 并弹结果
- **原因**: 词典库查看与存词典操作的最小闭环 GUI，复用 AppContext.active_slot.collection 与 selected_ids

### `src/transbridge/ui/main_window.py` (改)
- **修改内容**: 「小工具」菜单新增「📖 翻译词典」动作（`self._dictionary_act`），新增 `_open_dictionary_panel` handler 打开 `DictionaryPanel`
- **原因**: 提供词典功能的用户入口，与 AI 翻译器/智能助手并列

### `tests/test_translation_memory_gui.py` (增)
- **修改内容**: 2 个 offscreen GUI 测试——`test_save_dialog_result_parsing`（scope 切换 + tags 分割去重）、`test_dictionary_panel_loads_empty`（空词典面板表格为空 + 「全部词典」下拉）。模块级 `qapp` fixture（offscreen 平台）
- **原因**: 覆盖对话框参数解析与面板空态，脱离真实 collection 的纯逻辑测试
