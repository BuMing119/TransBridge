# 004: 存词典对话框默认值智能预填

**日期**: 2026-08-14
**类型**: 改
**关联**: Epic: translation-memory > Story 05: GUI 集成（存词典对话框体验优化）

## 修改文件

### `src/transbridge/ui/tools/dictionary_dialog.py` (改)
- **修改内容**: `SaveToDictionaryDialog` 构造函数新增 `project_name`/`game_id` 关键参数；scope 下拉顺序改为 global 居首（默认选中 global）；`_on_scope_changed` 在切换 scope 时用对应默认值预填 scope_id（global→游戏标签、project→项目名）
- **原因**: 用户希望开箱即用——默认存全局词典，scope_id 自动填好，减少每次手动输入

### `src/transbridge/ui/tools/dictionary_panel.py` (改)
- **修改内容**: 新增 `_default_project_name()`（从 `ctx.active_project.name` 或 `ctx.current_project["name"]` 取当前项目名）与 `_default_game_id()`（从 `LLMConfig.game_profile` 取游戏标签，回退 `skyrim_se`）；`_on_save_to_dict` 创建 dialog 时传入这两个默认值
- **原因**: 提供默认值的运行时来源，连接对话框预填与当前项目/游戏上下文

### `tests/test_translation_memory_gui.py` (改)
- **修改内容**: `test_save_dialog_result_parsing` 更新——默认 global + 预填 game_id、切 project 预填 project_name、切回 global 重新预填 game_id
- **原因**: 覆盖新的预填与切换行为
