# 005: 词典应用机制（解析时自动套用 + 手动套用按钮）

**日期**: 2026-08-14
**类型**: 增
**关联**: Epic: translation-memory > Story 04（套用到集合）+ Story 05（GUI 套用入口）

## 修改文件

### `src/transbridge/ui/main_window.py` (改)
- **修改内容**: 新增模块级函数 `_apply_dictionary_to_collection(collection)`——加载词典后，用 `QueryContext(game_id=LLMConfig.game_profile)` 对 collection 做 `apply_to_collection`（仅填未翻译空译文，不覆盖已有译文），返回填充条数。`_run_parse_esp` 与 `_run_batch_parse_esp` 的 `_do()` 在迁移源链末尾调用它，命中数累加进 `migrate_count`
- **原因**: 实现「解析新 ESP 时自动套用词典」——词典成为与 EET/XT/已译插件并列的迁移源；只填未翻译保证安全，词典为空/加载失败静默降级不影响解析

### `src/transbridge/ui/tools/dictionary_panel.py` (改)
- **修改内容**: 顶栏新增「套用词典」按钮（`_apply_btn`）；新增 `_on_apply_dict`——加载词典后用完整 `QueryContext(project_id=当前项目名, game_id=游戏标签)` 对当前集合套用（含 project 项目词典 + global 全局词典），弹窗展示键命中/文本命中/实际填充/未命中统计 + needs_review 提示（键命中但原文已变化）；构造函数新增 `base_dir` 参数（测试隔离用）
- **原因**: 实现「手动套用词典」——手动按钮在主线程能拿完整项目上下文（含项目专属词典），弥补自动套用仅覆盖全局词典的局限

### `tests/conftest.py` (改)
- **修改内容**: 新增共享 fixture `tm_tmp_dir`（workspace 内临时目录，绕开 sandbox 对外部 %TEMP% 写限制，后清理）
- **原因**: 测试隔离需要；原 fixture 分散在 test_translation_memory.py，迁移到 conftest 供多文件复用

### `tests/test_translation_memory.py` (改)
- **修改内容**: 移除本地的 `tm_tmp_dir` 定义（改用 conftest 共享 fixture）
- **原因**: 消除重复定义

### `tests/test_translation_memory_gui.py` (改)
- **修改内容**: `test_dictionary_panel_loads_empty` 改用 `base_dir=tm_tmp_dir` 隔离默认数据目录，避免加载真实 data/translation_memory 数据
- **原因**: 修复测试污染（此前端到端验证在默认目录留下了词典数据，导致面板加载到 8809 条真实数据）
