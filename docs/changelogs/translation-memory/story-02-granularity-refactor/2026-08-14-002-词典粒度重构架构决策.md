**日期**: 2026-08-14

## 修改文件

### `docs/adr/014-fomod-translation-memory.md` (改)
- **修改内容**: 在文末追加 `### 更新: 2026-08-14 - 词典粒度重构` 节，替换决策 3.1 的词典数据模型：①词典粒度改为一文件一 mod（文件名=mod 名，后缀 `.tbdict`，内容 JSON）；②数据模型 `Dictionary{mod_file_id, scope, entries, key_index, text_index}` / `DictionaryEntry{translation, original, source_mod, form_id_with_plugin, imported_at, updated_at, tags}`，移除 `source`/`scope_id`；③词条主键 `sha1(mod_file_id|原文)` 不含 scope；④更新语义（同名 mod 一本、新增追加/已存覆盖/从不删除）；⑤多词典全查兜底 + 冲突可视化仲裁；⑥分享/导入三按钮；⑦旧数据弃置。
- **原因**: 用户要求词典「共享使用、一个 mod 一个文件」，当前大库混装模型词条缺 mod 身份字段，无法按 mod 隔离/分享，需结构性重构。
