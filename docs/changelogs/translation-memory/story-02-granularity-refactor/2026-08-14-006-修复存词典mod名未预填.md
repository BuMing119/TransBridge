# 006: 修复存词典 mod 名未预填

**日期**: 2026-08-14
**类型**: 改
**关联**: Epic: 翻译记忆（词典）系统 > Story 10: GUI 面板改造 + 冲突可视化仲裁界面

## 修改文件

### `src/transbridge/ui/tools/dictionary_panel.py` (改)
- **修改内容**: `_default_source_path()` 从读取 `ctx.active_project.source_path`/`.path`（字段不存在，恒返回空）改为读取 `ctx.esp_path`（当前解析插件的完整路径，来自 `CollectionSlot.esp_path`），并按 `eet_path` → `xt_path` 顺序兜底。
- **原因**: 存词典对话框的「mod 名」输入框无法从打开文件路径推断预填（`ProjectHandle` 无 `source_path`/`path` 字段，正确的源路径在 `CollectionSlot.esp_path`）。

### `tests/test_translation_memory_gui.py` (改)
- **修改内容**: 新增 `test_panel_default_source_path_from_esp`——构造含 `esp_path` 的 `CollectionSlot`，验证 `_default_source_path()` 返回完整路径、`_default_mod_id()` 正确去掉扩展名返回 `LegacyPatch`。
- **原因**: 锁定 mod 名预填行为，防止回归。
