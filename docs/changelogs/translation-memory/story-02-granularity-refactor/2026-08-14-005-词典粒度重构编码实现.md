# 005: 词典粒度重构编码实现（S06-10）

**日期**: 2026-08-14
**类型**: 改
**关联**: Epic: 翻译记忆（词典）系统 > Story 02: 词典粒度重构（一文件一 mod + 多词典组合查询）

## 修改文件

### `src/transbridge/translation_memory/model.py` (改)
- **修改内容**: `DictionaryEntry` 字段重构——移除 `source`，新增 `source_mod`（来源 mod 名）与 `form_id_with_plugin`（完整 FormID|插件名）；`Dictionary` 字段重构——移除 `scope_id`，新增 `mod_file_id`（定位键）、`scope` 降为单值标签；新增模块级 `entry_id(mod_file_id, original)` = `sha1(mod名|原文)`（不含 scope）；`SCOPE_RANK` 保留供仲裁使用。
- **原因**: 一文件一 mod 粒度重构（FR15.1.6），词条身份与词典位置解耦。

### `src/transbridge/translation_memory/manager.py` (改)
- **修改内容**: ①定位键 `(scope, scope_id)` → `mod_file_id`（`_key`/`_dict`/`dictionaries` 全链路）；②文件命名 `{mod}.tbdict`（`DICT_SUFFIX`），`load` 仅扫描 `*.tbdict`、同名重复硬校验抛错、旧 `*.json` 弃置；③`add` 写词典 scope、持久化 source_mod/form_id_with_plugin；④`QueryContext` 改 `mod_file_id`；⑤`query` 改多词典全查兜底（同名 mod 键命中即停 → 其余 project/global 候选收集 → `_arbitrate` 按 scope+hits 仲裁，`conflicts` 真正填充）；⑥`_normalize` 缓存加锁；⑦新增 `set_scope`/`import_dict`/`export_dict`。
- **原因**: 多词典组合查询 + 冲突仲裁 + scope 切换 + 分享导入。

### `src/transbridge/translation_memory/__init__.py` (改)
- **修改内容**: 更新模块 docstring 与 `__all__`，新增导出 `entry_id`。
- **原因**: 与新数据模型保持一致。

### `src/transbridge/ui/tools/dictionary_dialog.py` (改)
- **修改内容**: 从「scope/scope_id」改为「mod 名 + scope」——新增 mod 名输入框（从打开文件路径 `source_path` 推断去扩展名）、scope 单值下拉；`result()` 返回 `(mod_file_id, scope, selected_only, tags)`。
- **原因**: 存词典适配 mod 粒度。

### `src/transbridge/ui/tools/dictionary_panel.py` (改)
- **修改内容**: ①词典列表按 `mod_file_id` 展示（含 `[scope]` 标签）；②套用词典用 `QueryContext(mod_file_id=当前 mod)` 激活集默认自动，冲突时弹仲裁对话框；③新增「导入/导出/打开目录」三按钮；④存词典传 `source_path` 推断 mod 名。
- **原因**: GUI 适配 mod 粒度 + 分享导入 + 冲突仲裁接入。

### `src/transbridge/ui/tools/conflict_dialog.py` (增)
- **修改内容**: 新建 `DictionaryConflictDialog`——逐条展示多词典命中冲突（原文 + 候选译文 + 来源词典），用户采纳/拒绝，`result()` 返回 `[(entry_id, 译文)]`；提供「全部采用自动仲裁结果」快捷按钮。
- **原因**: 冲突可视化仲裁（FR15.1.6.3）。

### `src/transbridge/ui/main_window.py` (改)
- **修改内容**: `_apply_dictionary_to_collection` 从 `QueryContext(project_id=, game_id=)` 改为 `QueryContext(mod_file_id="")`（自动套用走全词典兜底），移除 LLMConfig game_profile 读取。
- **原因**: 适配新 QueryContext 签名。

### `tests/test_translation_memory.py` (改)
- **修改内容**: 全部测试适配新模型（`mod_file_id` 定位、`add(mod_file_id=, scope=)`、`save_from_collection(mod_file_id=)`、`QueryContext(mod_file_id=)`、`.tbdict` 往返），新增主键 scope 解耦、多词典冲突仲裁、无冲突去重、requires mod_file_id、set_scope、import_dict、同名 load 抛错等测试。24 个测试。
- **原因**: 覆盖重构后的新行为。

### `tests/test_translation_memory_gui.py` (改)
- **修改内容**: 适配 `SaveToDictionaryDialog(source_path=, mod_file_id=)` 新签名，测试 mod 名推断/手填/scope 切换。3 个测试。
- **原因**: GUI 逻辑适配。
