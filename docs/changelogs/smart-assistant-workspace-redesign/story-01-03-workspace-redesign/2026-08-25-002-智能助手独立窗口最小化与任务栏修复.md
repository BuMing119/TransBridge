## 背景与动机

001 完成后，用户在真实 Windows 主窗口中连续复验，确认助手虽然已经覆盖在工作台上方，但仍存在四项实际问题：外框颜色过弱、消息阅读区视觉层级不足、标题栏原停靠操作会把主界面压扁，以及助手最小化后没有形成可独立恢复的 Windows 任务栏项。

本次增量只修正浮动窗口外壳、标题栏意图和 Windows 任务栏集成，不改变会话、消息、工具、上传、Auto 模式、后台任务或持久化契约。先前 001 记录保持 append-only；其中关于停靠操作的描述由本增量中的后续实现取代。

## 文件级变更

### `src/transbridge/ui/shell/tool_windows.py`

- 将 `SmartAssistantPanel` 创建为无 Qt 父级的顶层窗口，不再调用 `QMainWindow.addDockWidget()`，从对象所有权和布局层面阻止助手重新停靠并压缩中央工作台。
- 继续由 `ToolWindows` 持有并复用窗口引用；创建时继承主程序图标，销毁时关闭运行时、安排 Qt 对象删除并清理缓存几何。
- `toggle_smart_assistant()` 增加最小化恢复路径：已最小化时执行 `showNormal()`、置前并激活；普通可见状态仍执行隐藏，再次打开时按宿主几何居中。

### `src/transbridge/ui/tools/smart_assistant/panel.py`

- 将窗口类型显式固定为 `Qt.Window`，禁用所有 Dock 区域和重新停靠能力，保留可复用的关闭隐藏行为。
- 标题栏操作改接 `minimize_requested`；最小化只改变独立窗口状态，不再触发停靠或改变主界面布局。
- 引入 `TASKBAR_APP_USER_MODEL_ID = "TransBridge.SmartAssistant"`，并在第一次 `ShowWindow` 之前准备原生 HWND 的任务栏身份；显示事件只在准备失败时重试。
- `dispose()` 在原生窗口销毁前清除显式 AppUserModelID，避免任务栏属性残留到失效 HWND。

### `src/transbridge/ui/tools/smart_assistant/panel_header.py`

- 删除停靠信号和方格按钮，新增语义明确的最小化信号、`minus` 图标、工具提示和无障碍名称。
- 双击标题栏不再切换停靠状态；拖动仍只移动当前浮动窗口。

### `src/transbridge/ui/tools/smart_assistant/theme_support.py`

- 用 `palette(text)` 的 2 px 实线构成标题栏和主体的连续深色外框，替代难以辨认的蓝色/浅色轮廓。
- 外层 `QDockWidget` 自身保持无额外边框，避免黑框叠加；圆角由标题栏上沿和主体下沿共同构成。

### `src/transbridge/ui/foundation/tabler_icons.py`

- 增加标题栏最小化按钮使用的 Tabler `minus` 路径，避免空白按钮或字体字形差异。

### `src/transbridge/ui/windows_taskbar.py`

- 新增跨平台安全的 Windows 任务栏适配：非 Windows 或非原生 Windows Qt 平台直接返回，不调用 Win32 API。
- 通过 `SHGetPropertyStoreForWindow` 和 `IPropertyStore.SetValue` 为单个 HWND 写入/清除 `System.AppUserModel.ID`，使助手与主窗口使用不同的任务栏分组身份。
- 根据真实复验补充任务栏资格修复：首次显示前为助手 HWND 添加 `WS_EX_APPWINDOW`、移除 `WS_EX_TOOLWINDOW`，再通过 `SetWindowPos(..., SWP_FRAMECHANGED)` 刷新扩展窗口样式。
- 对 AppUserModelID 长度、HRESULT、Win32 last-error 和 COM `Release()` 做显式处理；原生调用失败时记录上下文并安全降级，不阻断助手打开。

### `tests/ui/test_windows_taskbar.py`

- 新增 AppUserModelID 设置/清除到同一 HWND 的适配测试。
- 覆盖非 Windows Qt 平台的 no-op 行为，以及空值和超过 128 字符标识的拒绝路径。
- 验证任务栏资格准备发生在 AppUserModelID 写入之前。

### `tests/ui/tools/smart_assistant/test_chat_bindings.py`

- 验证助手无父级、为独立 `Qt.Window`、没有可停靠区域，且打开/隐藏不会改变主窗口中央控件几何。
- 覆盖最小化后恢复、隐藏窗口复用、宿主尺寸变化后重新居中和销毁清理。
- 验证任务栏身份在首次显示前只准备一次，并在 `dispose()` 时清除。
- 验证标题栏最小化按钮具备可见 SVG 图标和“最小化智能助手”无障碍名称。

## 兼容性与范围边界

- 原生 Windows Qt 平台使用窗口级 AppUserModelID 和扩展窗口样式；其他平台保持独立顶层 Qt 窗口行为，不执行 Win32 调用。
- 没有新增第三方依赖，没有修改锁文件、会话格式或公共业务 API。

- 没有执行 Git commit 或 push。
