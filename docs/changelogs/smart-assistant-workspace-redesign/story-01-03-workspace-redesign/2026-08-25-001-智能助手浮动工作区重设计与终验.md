# 智能助手浮动工作区重设计与终验

- 日期：2026-08-25
- Epic：`smart-assistant-workspace-redesign`
- Story：S01～S03（浮动工作区、会话与消息区、输入与后台任务区）
- 类型：实现、缺陷修复、UI/UX 重设计、综合 QA
- 视觉基线：用户提供的 TransBridge 智能助手高保真参考图
- 实现计划：[plan.md](../../../../plans/smart-assistant-workspace-redesign/plan.md)
- ADR：无；本次没有改变业务架构、持久化格式或公共后端契约

## 背景与动机

原智能助手以底部浅高 Dock 的形式出现，主内容被压缩且面板内部存在大面积空白、文字与背景对比不足、输入区和后台任务区争抢高度等问题。用户确认的新方向是把助手设计为覆盖工作台上方的居中浮动工作区，并以参考图为视觉基线重排标题栏、会话侧栏、消息阅读区、组合输入框和后台任务栏。

本次改动仅重构智能助手的展示与交互外壳，继续复用既有会话、消息、工具调用、上传、Auto 模式和后台任务能力。

## S01：浮动工作区与面板外壳

- `src/transbridge/ui/shell/tool_windows.py`
  - 新增 `_assistant_overlay_rect()`，按宿主可用区域计算居中覆盖几何：四周保留 24 px 安全边距，目标宽高比例为 78%/82%，在大窗口中限制到 1280×820，并在小窗口中安全收缩。
  - `ToolWindows.get_assistant_panel()` / `toggle_smart_assistant()` 将智能助手作为浮动覆盖层展示，不再让它占用底部 Dock 区域并挤压中央工作台。
  - 面板从停靠状态切换或宿主尺寸变化时重新居中；同一宿主尺寸下复用已隐藏面板时保留用户调整后的几何。
- `src/transbridge/ui/tools/smart_assistant/panel.py`
  - 重排 `SmartAssistantPanel` 的根布局、尺寸约束和浮动窗口行为，接入自定义标题栏、响应式会话侧栏、聊天区与折叠后台任务区。
  - 保留隐藏、复用、销毁和主题订阅生命周期，关闭浮动窗口时隐藏而非提前销毁运行时资源。
- `src/transbridge/ui/tools/smart_assistant/panel_header.py`
  - 新增 `AssistantPanelHeader`，呈现 TransBridge 智能助手标识、真实配置状态、只读“翻译协作”工作模式、当前模型，以及停靠/关闭操作。
  - 模型名称通过公开配置读取，不访问凭据；状态使用“已配置/待配置”，避免显示没有事实依据的“在线”。
  - 支持拖动浮动面板，并使用双击标题栏切换浮动/停靠。
- `src/transbridge/ui/foundation/tabler_icons.py`
  - 为智能助手补充 `search`、`x`、`dots`、`chevron-left`、`sparkles`、`paperclip`、`send`、`shield-check`、`book`、`trash`、`user` 等 Tabler SVG 路径，替代字体符号与字母占位。
  - 修正 on-accent 图标的 `ButtonText` 语义，使主按钮图标跟随按钮前景色并满足主题切换要求。

## S02：会话侧栏与消息阅读区

- `src/transbridge/ui/tools/smart_assistant/session_list_widget.py`
  - 将会话侧栏改为可读的卡片式列表：展开宽度限制在 220～260 px，折叠宽度为 48 px，会话卡片高度为 84 px。
  - 实现本地搜索过滤、当前会话高亮、悬停反馈、创建/删除菜单以及底部收起动作；折叠后保留核心入口。
- `src/transbridge/ui/tools/smart_assistant/message_bubble.py`
  - 移除 `U` / `A` 字母头像，改用统一 SVG 角色图标。
  - 用户消息右对齐为紧凑气泡，助手消息左对齐为阅读流；用户/助手内容最大宽度分别限制为 540/760 px，并保留角色标签。
- `src/transbridge/ui/tools/smart_assistant/chat_widget.py`
  - 重新组织聊天主体并通过 `_update_reading_width()` 将消息阅读列约束在约 840 px 内，宽窗口下保持舒适行长。
  - `resizeEvent()` 同步更新阅读宽度与组合输入区的响应式状态。
- `src/transbridge/ui/tools/smart_assistant/chat_composition.py`
  - 调整消息区和组合输入区的装配顺序，继续沿用原有运行时、会话绑定、工具卡、流式响应和恢复状态。
- `src/transbridge/ui/tools/smart_assistant/theme_support.py`
  - 新增 `SmartAssistantTheme.apply_surface()`，把中性表面背景与状态前景语义分离；新增 `apply_accent()` 统一主操作按钮配色。
  - 为主题快照与应用回退调色板都显式构建 Markdown 主题，并为用户气泡提供 alternate 变体，修复浅色文字落在浅色背景上导致内容难以辨认的问题。

## S03：组合输入框、快捷操作与后台任务

- `src/transbridge/ui/tools/smart_assistant/input_view.py`
  - 将上下文标签、文本输入、附件/清空操作、Auto 模式和发送按钮合并为一个底部 composer 卡片。
  - 输入区高度限制在 96～112 px，避免窗口高度被输入框无边界占用；主发送按钮使用 accent 语义和 SVG 图标。
- `src/transbridge/ui/tools/smart_assistant/quick_actions.py`
  - 快捷工具改用语义化 SVG 图标；窄宽度下响应式隐藏次要工具，同时保留翻译选中、质量检查等核心操作。
- `src/transbridge/ui/tools/smart_assistant/task_monitor.py`
  - 后台任务区默认折叠到 36 px；展开时限制在 140～300 px，并保留暂停、恢复、取消、清理等既有动作。
  - 空任务状态不再预留大块内容空间，任务卡状态继续同时通过文字和颜色表达。
