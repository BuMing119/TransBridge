# Story 01～02：AI 翻译前后版本快照与显式保存

- **日期**：2026-08-27
- **Epic**：`ai-translation-version-snapshots`
- **Story**：Story 1 统一 AI 版本快照事务、Story 2 完成报告的“保存翻译”动作
- **关联计划**：[AI 翻译版本快照与显式保存计划](../../../../plans/ai-translation-version-snapshots/plan.md)

## 目的

让单一活动项目版本上的翻译、润色、混合和自定义 AI 工作流在启动前先形成可恢复快照；只有工作流正常完成后，报告才提供“保存翻译”动作，并按“提交当前结果 → 保存版本 → 创建完成后快照”的顺序持久化。保存失败保持可见且可重试，项目或版本发生切换时拒绝误写。

## 实际变更

### Story 1：统一 AI 版本快照事务

- **新增** `src/transbridge/ui/version_persistence.py`
  - 新增 `VersionPersistence`，统一 V2 权威投影与旧版 `VariantStore` 的保存、快照适配。
  - 保存时校验启动阶段捕获的 Project/Variant 身份；V2 按条目稳定身份一次性提交译文和 Stage，旧版通过集合投影写入。
  - 记录“结果已提交”和“版本已保存”状态，使完成后快照失败重试时不会重复提交或重复保存。
- **新增** `src/transbridge/ui/tools/ai_translator/version_snapshot.py`
  - 新增单次运行级 `AiVersionSnapshotSession`，生成带模式、时间和 run id 的执行前/保存后快照名称。
  - 使用后台 `ApiWorker` 执行磁盘操作；前置快照持久化成功后才放行 AI，完成后仅在正常终态开放保存。
  - 冻结当前集合条目并提供忙碌、完成、已保存和幂等状态，避免并发保存或重复后置快照。
- **新增** `src/transbridge/ui/tools/ai_translator/versioned_run.py`
  - 为 translate、mixed、polish/custom 入口提供统一的前置快照门禁和启动编排。
  - 前置快照失败时结束对应任务、展示可操作错误并恢复快速运行界面，不启动模型调用。
  - 仅在翻译未停止、混合流程完成或润色 worker 未取消时标记会话可保存。
- **修改** `src/transbridge/application/projects/gui_facade.py`
  - 暴露生命周期 `save_snapshot` 命令。
  - 新增 `replace_entry_states`，先完整校验 `EntryKey` 后一次提交译文和 Stage；缺失身份时拒绝整个写入，避免部分保存。
- **修改** `src/transbridge/ui/context.py`
  - 暴露稳定的 `active_version_identity`，同时为 V2 保存适配器提供项目命令和运行上下文只读入口。
- **修改** `src/transbridge/ui/tools/ai_translator/_polish_worker.py`
  - 暴露 `was_cancelled`，使润色完成路径能够区分正常结束与取消，取消运行不开放保存。
- **修改** `src/transbridge/ui/tools/ai_translator/ai_translator_window.py`
  - 将三类启动逻辑委托给版本化运行模块，并在混合流程成功完成后标记快照会话可保存。
  - 同步移出原窗口内的启动编排，避免继续扩大窗口类职责。
- **修改** `src/transbridge/ui/tools/ai_translator/run_controller.py`
  - 将版本快照会话传入翻译进度窗口，保持既有运行控制器和 TaskRuntime 契约。

### Story 2：完成报告显式保存与后置快照

- **修改** `src/transbridge/ui/tools/ai_translator/_translation_progress_window.py`
  - 翻译正常完成时标记会话完成，并只在未停止且仍可保存时把保存动作传给报告。
- **修改** `src/transbridge/ui/tools/ai_translator/result_view.py`
  - 为混合与润色报告绑定当前可用的保存动作；没有成功会话时不展示入口。
- **修改** `src/transbridge/ui/tools/ai_translator/_translation_report_dialog.py`
  - 新增“保存翻译”按钮；保存期间禁用按钮和关闭动作，成功后锁定为“已保存”。
  - 失败时恢复按钮并显示错误，允许重试；关闭报告不会隐式保存。
