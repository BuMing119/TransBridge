## 实现增量

- 新增 `CredentialRef`、无明文 `str/repr` 的 `SecretValue`、Windows Credential Manager adapter 与只读环境变量 provider；配置 INI 仅保存 credential reference，不再持久化 token。
- 旧 INI token 迁移先写入并回读验证 secure store，成功后以临时文件、fsync、replace 原子删除明文；任何 store 或 replace 失败都会保留原文件、标记 degraded，并使网络请求无凭据失败。
- ParaTranz client 在真正请求边界创建 Authorization，缺失凭据返回稳定 `PARATRANZ_CREDENTIAL_REQUIRED`。401、response body、URL/query、网络异常与嵌套结构通过共享 redactor 及已知 secret canary 脱敏。
- 补齐 `update_file_translation` 和 `download_artifacts` 两个 direct requests 旁路的 prerequisite 与异常脱敏；空 token 和历史/Mock context config 被兼容归一化为无凭据，而不在构造期间抛异常。
- 离线 ParaTranz JSON adapter 的依赖边界保持不读取 credential/client。
