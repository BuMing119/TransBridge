## 实现增量

- 新增应用层 `ParaTranzPort`、项目/词条/上传历史 DTO，以及不携带 secret 的稳定 `ExternalServiceError` 分类；Agent 不再调用不存在的 `get_entries`、`upsert_entry`、`get_upload_history` 方法，而经 typed service 映射到真实项目、词条、历史和 artifact API。
- 将 HTTP 状态、超时、传输失败、畸形 JSON 和响应 schema 映射为 typed error，并生成 correlation request ID；401/403/404/409/429/5xx 分别保留可判定类别，错误上下文经凭据 redactor 处理。
- 仅对 GET/HEAD/OPTIONS/PUT/DELETE 或显式 idempotency key/业务确认启用有界指数退避，并尊重受上限约束的 `Retry-After`；普通 POST 不自动重试。
- 在请求前、退避期、收到响应后以及 artifact 二进制流每个 chunk 前检查 TaskRuntime cancellation。历史 `update_file_translation` 与 `download_artifacts` 已进入同一 typed transport；取消写出的暂存/原子发布责任仍归 S04。
