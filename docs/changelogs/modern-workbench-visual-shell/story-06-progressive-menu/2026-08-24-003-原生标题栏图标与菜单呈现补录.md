# 原生标题栏图标与菜单呈现补录

- **日期**：2026-08-24

## 目的

补录本次对话中尚未进入增量历史的窗口与菜单呈现调整：保留 Windows 原生标题栏，使用 TransBridge 安装器图标作为应用/窗口图标；渐进菜单的紧凑触发项只显示汉堡图标，避免与原生标题栏中的 `TransBridge` 重复；普通可用子菜单项具备统一 hover 反馈。

## 真实变更

### 应用与标题栏图标

- `src/transbridge/ui/assets/transbridge.ico`（新增）
  - 从 `installer/transbridge.ico` 复制应用图标到可随 Python 包分发的 UI 资源目录。
  - 两个文件的 SHA-256 均为 `3D66596C9FE69CAAC62A4B7D9A3E4E933ECDA536A912171BA867223C63E4246E`。

- `src/transbridge/ui/app.py`（修改）
  - `_application_icon_path()` 同时解析源码布局和 PyInstaller `_MEIPASS` 布局中的图标资源。
  - `_apply_application_icon()` 校验文件与 `QIcon` 后调用 `QApplication.setWindowIcon()`；资源缺失或无法加载时记录警告但不阻断启动。
  - GUI 入口在创建业务窗口前应用图标，使保留的原生标题栏和任务栏共享同一品牌图标。

- `tests/ui/test_application_icon.py`（新增）
  - 验证源码资源路径可解析、文件存在且能设置为非空 QApplication 图标。

### 渐进菜单紧凑标题与 hover

- `src/transbridge/ui/shell/progressive_menu_bar.py`（修改）
  - 默认紧凑 QAction 文本收敛为 `☰`，移除重复的 `TransBridge` 字样；accessible name、说明、tooltip 与完整七菜单展开行为保持不变。

- `src/transbridge/ui/foundation/visual_style.py`（修改）
  - 使用主题 token 为 `QMenu::item:selected` 编译统一文字和背景反馈；分隔线继续使用 subtle border。
  - 云端上下文不足导致的两个同步 QAction 无法 hover 的后续根因修复，另见同 Story 的 [002 记录](2026-08-24-002-同步菜单悬停与可用性路由修复.md)。

- `tests/ui/test_main_window_shell.py`（修改）
  - 验证紧凑 QAction 只显示 `☰` 且不含 `TransBridge`，同时保留 `TransBridge 主菜单` 可访问名称。

- `tests/ui/foundation/test_visual_style.py`（修改）
  - 验证菜单栏 selected 规则与子菜单 enabled/disabled selected 规则均进入统一编译样式，且不产生硬编码颜色。

## 当前窗口边界

- `MainWindow` 继续使用标准 `QMainWindow` 原生标题栏；本次没有引入 FramelessWindowHint、自绘拖动区或自绘最小化/最大化/关闭按钮。
- 渐进菜单仍复用 MenuBuilder 创建的同一组 QAction，不复制业务回调或快捷键。
