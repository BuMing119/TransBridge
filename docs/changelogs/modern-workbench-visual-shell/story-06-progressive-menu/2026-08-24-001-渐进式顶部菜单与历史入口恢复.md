# 渐进式顶部菜单与历史入口恢复

- **日期**：2026-08-24
- **Epic**：`modern-workbench-visual-shell`
- **Story**：S06「渐进式顶部菜单与历史入口恢复」
- **需求**：FR27.9
- **架构**：ADR-022

## 目的

现代工作台隐藏传统菜单栏后，账户资料、私信以及其他低频功能缺少可发现入口。本次增量参考 PyCharm 新 UI 的渐进式菜单交互：默认保持顶部区域紧凑，用户悬停菜单触发项或通过键盘聚焦时，在同一位置展开原有完整菜单；同时确保头像资料入口不再错误依赖已选择的 ParaTranz 云端项目。

## 真实变更

### 新增

- `src/transbridge/ui/shell/progressive_menu_bar.py`
  - 新增 `ProgressiveMenuBar`，默认只显示 `☰ TransBridge` 紧凑触发项。
  - `bind_existing_menus()` 捕获 `MenuBuilder` 已创建的七个顶层 QAction，只切换可见性，不复制菜单、Intent、快捷键或业务回调。
  - 鼠标悬停触发项、菜单栏键盘聚焦或下拉菜单打开时保持展开；指针离开后使用单次 350ms 计时器延迟收起，不引入周期轮询。
  - 区分启动时的自动窗口焦点与键盘菜单焦点，避免窗口首次显示时错误展开。
  - 提供可访问名称、说明、状态提示和工具提示。

### 修改

- `src/transbridge/ui/main_window.py`
  - 在 `MenuBuilder` 构造菜单前安装 `ProgressiveMenuBar`，构造后绑定现有顶层菜单。
  - 移除直接隐藏 `QMenuBar` 的呈现路径，保留原 `MenuHandles` 和 MainWindow composition 边界。

- `src/transbridge/ui/shell/__init__.py`
  - 将 `ProgressiveMenuBar` 加入 shell 懒加载公共导出。

- `src/transbridge/ui/shell/intent_composition.py`
  - 将“ParaTranz 账户信息”和“私信”入口的可用性从“已选择云端项目”改为“已登录 ParaTranz 用户”。
  - 未登录时返回明确的 API Token/账户验证恢复提示；账户资料入口不再被无关的项目选择状态阻断。

- `src/transbridge/ui/foundation/visual_style.py`
  - 为统一 ThemeService 编译样式增加 QMenuBar 的背景、边界、间距及选中/按压状态。
  - 全部颜色继续通过 QPalette 角色解析，未引入独立硬编码产品配色或局部主题 owner。

- `tests/ui/test_main_window_shell.py`
  - 覆盖默认紧凑态、悬停展开、键盘菜单焦点展开、离开延迟收起和单次计时器合同。
  - 验证七个既有菜单原位复用、“ParaTranz 账户信息” QAction 身份不变且只触发一次原回调。
  - 回归验证账户入口依据登录用户而非云端项目选择状态。

- `tests/ui/foundation/test_visual_style.py`
  - 增加菜单栏及菜单项选中状态的统一编译样式合同断言。

- `docs/requirements.md`
  - 新增并完成 FR27.9，固化渐进式顶部菜单、延迟收起、下拉保护、键盘可达和单一 QAction owner 验收要求。

- `docs/adr/022-modern-workbench-visual-composition.md`
  - 将原“V1 可隐藏菜单栏”决定修订为复用同一 QMenuBar 的渐进式呈现，并补充状态、风险和回退合同。

- `plans/modern-workbench-visual-shell/plan.md`
  - 追加并完成 S06，记录实现边界、文件落点和 38 项 QA 证据。
