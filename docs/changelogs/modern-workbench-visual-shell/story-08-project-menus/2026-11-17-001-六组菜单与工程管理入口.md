# 六组菜单与工程管理入口

- 日期：2026-11-17。
- Epic：`modern-workbench-visual-shell`；Story：[S08](../../../../plans/modern-workbench-visual-shell/plan.md#s08-六组主菜单与工程管理入口)。
- 动机：用户讨论确认完整六组菜单后授权试做，减少名称混淆和菜单内铺开的管理动作。本记录仅覆盖本轮 S08，先前 S07 工作台布局及引导横条变更保留原增量记录。

## 文件与行为

- `src/transbridge/ui/shell/menu_builder.py`：文件与项目合并为工程；本地翻译输出归翻译，云端操作与账户归 ParaTranz；加入三个管理窗口入口。保留旧 MenuHandles 对象及兼容动作，快捷键 QAction 同时关联主窗口，保证收缩时可用且不重复分发。
- `src/transbridge/ui/shell/action_catalog.py`：新增版本管理、历史还原、工程属性三个 Intent；调整标签、分组和状态提示，保留旧名字搜索别名。工程包入口不再把扩展名作为名称。
- `src/transbridge/ui/shell/intent_composition.py`：注册和释放管理入口，复用权威路由和可用性判断，不在壳层增加数据处理职责。
- 新增 `src/transbridge/ui/coordinators/project_dialogs.py`：保持每类管理窗口单实例、重用当前目标窗口、关闭旧目标并安全延迟激活。
- 新增 `src/transbridge/ui/project_management_dialogs.py`：版本列表提供新建、复制当前版本、切换及当前版本定位缓存清理；历史列表提供创建、恢复、删除及刷新；属性窗口集中重命名与编码入口。包含空态、错误、后台加载、目标变化和关闭后回调保护。
- `src/transbridge/ui/coordinators/project_transfer_coordinator.py`：提取快照列表读取及选中对象操作，供新旧 UI 共用；冻结工程/版本上下文，复查确认后的目标；恢复前备份及来源修订恢复沿用应用服务。工程包文件选择窗口标题使用用途名称，后缀和格式不变。
- `src/transbridge/ui/coordinators/variant_coordinator.py`：复用新建/复制协调流程，保存结束和版本切换前复查原目标，避免旧窗口操作作用于新上下文。
- `src/transbridge/ui/shell/alignment_cache_actions.py`：保留权威可用性与 Intent 路由，移除已无调用者的菜单绑定；缓存操作进入版本管理窗口。
- `src/transbridge/ui/shell/progressive_menu_bar.py`：仅调整展开提示文案，原有悬停、键盘展开及延迟收缩机制保留。
- `src/transbridge/ui/drop_router.py`、`src/transbridge/ui/i18n/messages.pot`：同步工程包拖放预览和菜单翻译源目录。
- `src/transbridge/ui/workbench/widget.py`：仅将“更多”中的添加文件名称复用同一 ActionCatalog 标签；保留 S07 布局、入口数量和路由。
- `tests/ui/test_main_window_shell.py`、`test_alignment_settings_menu.py`、`test_command_palette_help.py`、`test_source_update.py`、`foundation/test_locale_service.py`：验证新归属、快捷键、管理 Intent、可用性、旧搜索词与本地化；`operations/test_batch_download_production.py` 仅同步新菜单名称断言。
- 新增 `tests/ui/test_project_management_dialogs.py`：覆盖新窗口路由、稳定标识、关闭、异步读取、失败重试及目标切换。
- 新增 `tests/ui/test_project_management_integration.py`：以真实持久化服务验证新历史列表创建、恢复前备份、恢复和删除行为。
- `plans/modern-workbench-visual-shell/plan.md` 及相关索引：登记六组方案、验证和记录状态，不修改既有 S07 增量。

精确命令、首轮失败及修复、权限环境和界面产物见 [QA 报告](../../../test-reports/modern-workbench-s08-project-menus-2026-11-17.md)。无数据格式迁移，未执行真实云端写入；未提交 Git。
