# 用户头像展示、下载与 ParaTranz 媒体 URL 修复

- **日期**：2026-08-24
- **Epic**：`modern-workbench-visual-shell`
- **Story**：S01 后续修复
- **需求关联**：FR27.1

## 目的

补齐现代左侧导航中的 ParaTranz 用户身份反馈：显示真实头像和明确的在线状态，并修复 ParaTranz 用户 API 返回 `/media/...` 相对头像路径时无法加载的历史问题。头像下载不得因本地 2 MiB 硬限制而失败，资料保存也不得把展示层拼接后的错误格式写回服务端。

## 真实变更

### 左侧用户身份与头像下载

- `src/transbridge/ui/shell/navigation_rail.py`（新增）
  - 用户区增加头像、昵称和独立连接状态点；ParaTranz 用户使用绿色“在线”，无远端用户时显示“本地模式”。
  - 设置、帮助、关于按钮继续使用现有 Intent，并具备可感知的 hover 状态。
  - 通过 `QNetworkAccessManager` 异步加载头像；切换用户时取消旧请求，避免迟到响应覆盖新用户。
  - 下载按流读取完整响应，不再使用 2 MiB 大小阈值主动中止；成功后居中裁剪为圆形头像，失败时回退为昵称首字。
- `src/transbridge/ui/main_window.py`（修改）
  - 初始化导航时同步当前用户，并监听 `user_changed`，保证登录资料变化后头像和在线状态同步刷新。

### ParaTranz 媒体 URL 边界

- `src/transbridge/paratranz/api/paratranz_user_api.py`（修改）
  - `resolve_paratranz_media_url()` 从配置的 API base URL 提取公开站点 origin，将 `/media/avatar.jpeg!320` 解析为 `https://paratranz.cn/media/avatar.jpeg!320`。
  - `get_my_user()`、`get_user()` 和 `update_user()` 统一返回可直接展示的完整头像 URL；已有 `http/https` 外部头像地址保持不变。
  - `prepare_paratranz_media_url()` 在保存同站 `/media/` 头像前恢复相对路径，避免把展示层 URL 形态错误写回 API；外站 URL 保持原样。

### 回归测试

- `tests/ui/test_modern_workbench_visual_shell.py`（新增）
  - 验证设置/帮助/关于 hover 合同、头像请求、在线/本地语义状态和圆形居中裁剪。
- `tests/paratranz/test_user_api.py`（新增）
  - 验证相对媒体路径解析、外部绝对 URL 保留，以及同站 URL 保存前恢复相对路径并规范化响应。
