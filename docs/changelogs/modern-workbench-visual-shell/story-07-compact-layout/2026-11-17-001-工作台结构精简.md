# 工作台结构精简

- 日期为 2026-11-17。
- Epic 为 `modern-workbench-visual-shell`，归属 [S07 工作台结构精简](../../../../plans/modern-workbench-visual-shell/plan.md#s07-工作台结构精简)。

## 变更

- `src/transbridge/ui/workbench/_project_bar.py` 将工程名合并为工程菜单入口。菜单包含新建、打开、项目配置、版本与快照、AI 任务记录及原有工程管理动作。顶行保留版本切换、保存操作和简短保存状态。
- `src/transbridge/ui/workbench/widget.py` 在内容选择行安置 AI 翻译、导出和“更多”，由“更多”直接承接打开翻译文件、导入译文、构建术语库、移除内容和原有管理 Intent。配置和 AI 任务记录转入工程菜单。
- 新增 `src/transbridge/ui/workbench/project_configuration_view.py`，管理按需展开的项目配置。菜单提供当前译名和绑定摘要，配置收起时保留读取、预览尚未应用、定位和绑定异常提示。
- `remote_target_presenter.py` 与 `remote_target_view.py` 投影 ParaTranz 目标名称和验证状态。 `terminology_profile_bar.py`、`terminology_profile_controller.py` 和 `terminology_alignment.py` 共享方案读取、实际应用、预览和定位状态，受理重试时刷新旧错误。
- `workflow_actions_view.py` 和 `workflow_presenter.py` 将四项统计压成可点击的一行。快捷状态跟随组合条件中的阶段集合，复核 Intent 与统计口径继续覆盖原有状态。
- `filters_view.py` 把高级筛选、精确字段和标签管理收进筛选区，有条件时才显示重置。 `step2.py` 装配状态区与内容操作，渲染或解析时显示进度并保留布局槽。
- 新增 `src/transbridge/ui/foundation/components/elided_combo_box.py`，按控件宽度省略长版本、文件及方案显示文字。 `visual_style.py` 用现有主题颜色绘制状态筛选，`src/transbridge/ui/guidance/qt.py` 移除引导文本前的装饰字符。
- `tests/ui/test_workbench_context_layout.py` 覆盖工程菜单、真实内容弹出菜单、长名与紧凑尺寸、配置错误及预览状态。 `test_layout_stability.py` 验证进度槽稳定。
- `tests/ui/test_workbench_filter_layout.py`、`test_interaction_filters.py`、`test_workbench_story07.py` 验证筛选展开和键盘行为、快捷选中态及重置。 `test_v2_project_transfer.py`、`test_workbench_translation_import.py` 和 `workbench/test_profile_refresh_async.py` 验证工程菜单内的快照、内容菜单内的导入和失败后重试。
