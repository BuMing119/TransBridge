# 默认工作台隐去普通引导

- 日期为 2026-11-17。
- Epic 为 `modern-workbench-visual-shell`，归属 [S07 工作台结构精简](../../../../plans/modern-workbench-visual-shell/plan.md#s07-工作台结构精简)。

## 变更

- `src/transbridge/ui/guidance/presentation.py` 通过 `GuidancePresentation.show_banner` 统一决策。默认 AUTO 只在缺少配置、任务失败或部分失败时显示引导横条。显式详细和紧凑模式继续显示引导。
- `src/transbridge/ui/guidance/qt.py` 让框架随投影显隐，普通状态下移除整条横条和收起按钮，空间交回工作台。保存与项目配置等反馈仍由各自的视图提供。
- `tests/ui/guidance/test_state_matrix.py` 验证九种状态在三种模式下的展示与 Intent 合同。 `tests/ui/guidance/test_qt_binding.py` 验证显式模式、失败提示及恢复常态后释放布局空间。
