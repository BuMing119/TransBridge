# 004: SST Hash 自生成 (FNV-1a) 与从零创建 SSU9 文件

**日期**: 2026-05-15
**类型**: 增
**关联**: Epic: 文件解析 > Story 11: SST 二进制序列化器

## 修改文件

### `src/transbridge/parser/xt/sst_parser.py` (改)
- **修改内容**: 模块级新增 `sst_string_hash(s: str) -> int` 函数，实现 FNV-1a 32-bit hash（offset=0x811C9DC5, prime=0x01000193, salt=""），与 xTranslator `TESVT_Const.stringHash()` 字节级一致。新增 `_FNV_OFFSET` / `_FNV_PRIME` 模块常量。更新 `SST_Entry.f2` 字段注释：f2 实际为 `rEspPointerLite.index(2B word) | indexMax(2B word)`，非独立 hash 值
- **原因**: 从 xTranslator 源码（`TESVT_Const.pas` + `TESVT_typedef.pas`）逆向出 SST 字典使用的字符串 hash 算法，为从零创建 SST 文件提供 hash 能力；f2 生成链路也已通过 `loadSstEdit`/`SaveSSTFile`/`AssignEspdata` 完整追溯

### `src/transbridge/parser/xt/sst_serializer.py` (改)
- **修改内容**: 新增 `create_new(plugin_name, entries)` 类方法 — 从零创建 SSU9 SST 文件（无需模板）。新增 `_build_ssu9_header(plugin_name)` 静态方法 — 构建最小 SSU9 header（含 BIG-ENDIAN name_len）。新增 `_build_ssu9_record(entry)` 静态方法 — 从 SST_Entry 字段构建完整 26B 头 + eng_text + chn_len + chn_text，unk12 从 index+group_index 反向计算。修改 `to_bytes()` 兼容双路径：模板路径（entry._raw 非空时走 `_rebuild_ssu9`）和从零创建路径（_raw 为空时走 `_build_ssu9_record`）
- **原因**: 现有 `SST_Serializer` 只能基于已有 SST 文件模板重建（FR1.9.5 范围内），新增能力突破"范围外：从零创建"的限制，支持将任意 TranslationEntry 列表直接序列化为合法 SSU9 文件

### `src/transbridge/parser/xt/__init__.py` (改)
- **修改内容**: 导出新增 `sst_string_hash` 符号
- **原因**: 对外暴露 FNV-1a hash 函数，供其他模块（如 SST 字典查找、EDID hash 校验）使用

## 算法溯源

| 算法组件 | xTranslator 源文件 | Pascal 常量/函数 | Python 实现 |
|---------|-------------------|-----------------|------------|
| FNV-1a hash | `TESVT_Const.pas` | `FNV_offset_basis=2166136261`, `FNV_prime=16777619` | `sst_string_hash()` |
| HashSalt | `TESVT_Const.pas` | `HashSalt=''` | 空字符串 |
| edidNameHash | `TESVT_espDefinition.pas` | `stringHash(EdidName(true, true))` | `sst_string_hash(edid)` |
| f2 字段 | `TESVT_typedef.pas` | `rEspPointerLite.index` + `indexMax` (各 2B word) | entry.f2 (4B LE) |
| f2 赋值 | `TESVT_typedef.pas` | `AssignEspdata()` — 来自 `f.rIndex.index/indexMax` | xTranslator 加载 SST 后会覆盖，从零创建时可设 0 |
