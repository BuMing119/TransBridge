# 006: SSU9 extra 子记录解析

**日期**: 2026-05-09
**类型**: 增
**关联**: Epic: file-parsing > Story 09: SST 解析器

## 修改文件

### `src/transbridge/parser/xt/sst_parser.py` (改)
- **修改内容**:
  - 新增 `SST_Subrecord` frozen dataclass（字段: form_id, rec, unk12, f2, str_idx, texts），表示 SSU9 tail 中的嵌套关联记录
  - `SST_Entry` 新增 `subrecords: tuple[SST_Subrecord, ...]` 字段（默认空元组）
  - 新增 `_parse_ssu9_extra()` 类方法：解析主记录 Chinese text 之后的嵌套子记录数据，子记录头 22 字节（form_id + rec + unk12 + f2 + str_idx）+ 变长文本块，支持 5B marker（02/00/01 00000000）分隔多个子记录
  - 新增 `_entry_to_dict()` 静态方法：重构 to_json()，子记录以 `"subrecords"` 数组导出，rec 使用冒号格式
  - `_parse_ssu9()` Phase 2 调用 `_parse_ssu9_extra()` 填充 subrecords
- **原因**: SSU9 tail 中除主记录中文翻译外，还包含关联记录的完整双语数据（form_id + edid + unk12 + f2 + 英/中文本块），用于对话系统的 INFO↔DIAL、BOOK↔INFO 等关联关系。此前解析器丢弃了这些数据

### `scripts/sst2json.py` (改)
- **修改内容**: `--pretty` 和普通模式均新增子记录导出逻辑，使用 `SST_Entry.subrecords` 字段
- **原因**: 确保 CLI 导出工具与 `to_json()` 方法输出一致，均包含关联数据
