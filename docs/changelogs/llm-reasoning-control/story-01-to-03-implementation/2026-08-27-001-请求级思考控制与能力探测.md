## 目的

在不修改全局 `LLMConfig` 的前提下，让 AI 翻译请求优先关闭思考，并让严格校对中经过本地快速判断后仍需模型裁决的条目优先使用低强度思考。不同 OpenAI-compatible 服务的控制字段由程序隐式探测并持久化，智能助手自身的 LLM 运行时继续继承 Provider 默认行为。

## 本次增量

### Story 01：能力模型、单飞初始化与持久化

- **新增** `src/transbridge/infra/llm_reasoning.py`
  - 定义 `INHERIT`、`PREFER_DIRECT`、`PREFER_LOW` 三种工作流意图，以及 `supported`、`unsupported`、`indeterminate` 能力状态。
  - direct 与 low 机制分别记录，支持“模型不能关闭思考，但可使用 low”的能力组合；低强度不可表达时按 low → direct → inherit 降级。
  - 新增进程内单飞探测管理器和请求作用域客户端。作用域创建时后台预热；首个业务请求最多等待 2 秒，随后本次继承执行，避免 Provider 探测长期阻塞翻译。
  - 能力结果写入独立、版本化的 `llm_reasoning_capabilities.json`。持久化键只包含协议、端点不可逆摘要、模型和探测版本，不写入 API Key、端点原文、提示词、响应正文或思考内容。
  - 稳定结果缓存 30 天，`indeterminate` 与正式请求拒绝形成 24 小时短期负缓存；缓存损坏、未来 schema、过期记录和 I/O 失败均安全降级。

### Story 02：Provider 协议探测与正式请求控制

- **新增** `src/transbridge/infra/llm_reasoning_protocols.py`
  - OpenAI-compatible 协议按固定候选探测 `reasoning_effort`、`thinking.type`、`enable_thinking`，不维护供应商或模型能力表。
  - 每个候选先发送非法哨兵值；只有服务端明确校验字段后，才分别验证合法 direct/low 值。静默接受非法值的兼容网关不会被误判为支持。
  - 响应中的 reasoning 内容和 reasoning token 作为 direct 未关闭成功的辅助证据；low 请求出现 reasoning 证据视为预期。
  - Anthropic Messages 协议以省略 `thinking` 表达直接回答，不猜测跨版本低强度参数。
- **修改** `src/transbridge/infra/llm_client.py`
  - OpenAI-compatible 与 Anthropic 客户端接入各自协议 mixin，既有 `chat` / `chat_stream` 公共接口不变。
  - 已验证的控制参数与 Prompt cache `extra_body` 合并；Provider 拒绝缓存字段后的无缓存重试仍保留思考控制。
  - 正式请求明确拒绝已缓存的控制字段时，由作用域客户端记录短期负缓存并以 inherit 语义重试一次；认证、限流、超时和普通模型错误不被吞掉。

### Story 03：AI 翻译与严格裁决作用域接线

- **修改** `src/transbridge/ai_translator/translator.py`
  - `AutoTranslator` 的翻译和术语客户端在共享并发限制与日志包装之前安装 `PREFER_DIRECT` 作用域，覆盖单插件、批量、FOMOD 插件和翻译工具等复用入口。
- **修改** `src/transbridge/ai_translator/post_processor/post_processor.py`、`proofread_pipeline.py`
  - 增加可选裁决专用客户端；未提供时保持复用普通客户端的兼容行为。
  - combined 校对继续只使用普通 direct 客户端，不增加第二次业务调用；strict 链继续用既有 `_quick_decide` 先筛选，只把无法规则裁决的条目交给低强度客户端。
- **修改** `src/transbridge/ui/tools/ai_translator/polish_runtime.py`、`_mixed_worker.py`
  - 独立和混合校对从同一个 Provider 客户端派生 direct/low 两个请求作用域，并共享同一 `AiRequestBudget`、暂停/停止事件。
  - 裁决日志使用独立 `arbitration_call` 通道，避免与普通校对调用编号混写。
- **修改** `src/transbridge/fomod/pipeline.py`
  - FOMOD XML 翻译补齐 `PREFER_DIRECT`，与经 `AutoTranslator` 的插件翻译保持一致。
- 智能助手的 `_workflow_llm_runtime.py` 未安装思考作用域，继续保持 `INHERIT`；该边界由新增路由测试锁定。
