## 修改文件

### `src/transbridge/ui/tools/smart_assistant/task_monitor.py` (增, ~280行)
- **修改内容**: 新建 TaskMonitorWidget(QWidget) 后台任务监控组件：
  - `TaskMonitorWidget`：可折叠任务列表，`pyqtSignal(str, str)` 发射操作 (task_id, action)，`refresh(tasks)` 全量刷新列表，`reset()` 清空，`_toggle_collapse()` 折叠展开
  - `_TaskCard(QFrame)`：单任务卡片 — 状态指示灯(5色: #4CAF50/#2196F3/#D32F2F/#9E9E9E/#FF9800) + 名称 + QProgressBar进度条 + 详细信息 + 运行时长格式化 + 操作按钮(暂停/取消/恢复/清除)
  - `_STATUS_COLORS` / `_STATUS_LABELS`：状态到颜色/中文标签的映射表
- **原因**: 用户无法在 UI 层看到后台任务的执行状态和进度，需要可视化监控面板

### `src/transbridge/ui/tools/smart_assistant/panel.py` (改)
- **修改内容**:
  - `_init_ui()`: 右侧从单一 ChatWidget 改为垂直 QSplitter —— 上方 ChatWidget (7) + 下方 TaskMonitorWidget (3)；导入 TaskMonitorWidget
  - 新增 `_on_task_action(task_id, action)`: 处理 TaskMonitorWidget 发出的操作信号，调用 TaskManager.cancel/pause/resume/cleanup，操作后立即刷新
  - `_init_ui` 末尾调用 `self._chat.set_task_monitor(self._task_monitor)` 传递引用
- **原因**: 将任务监控集成到面板布局中，实现操作闭环

### `src/transbridge/ui/tools/smart_assistant/chat_widget.py` (改)
- **修改内容**:
  - `__init__`: 新增 `_task_monitor` / `_task_monitor_timer` 属性初始化
  - `set_task_monitor(monitor)`: 从 Panel 接收 TaskMonitorWidget 引用
  - `_start_task_monitor_polling()`: 启动 1s QTimer 定时调用 `_refresh_task_monitor()`
  - `_refresh_task_monitor()`: 从 TaskManager.list_all() 拉取最新任务列表，调用 monitor.refresh()
  - `_ensure_task_manager()`: 注册 `on_finished` 回调 → 任务完成/失败时立即刷新；若 monitor 已注入则启动轮询
  - `shutdown()`: 停止 `_task_monitor_timer`
  - `load_session()`: 会话切换时调用 `_task_monitor.reset()` 清空任务显示
- **原因**: 实现实时刷新机制（回调驱动 + 定时轮询双保险），以及会话切换时的任务列表清理
