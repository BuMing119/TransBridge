# 原生 Function Calling 文本 JSON 协议残留清理

- **日期**：2026-08-28
- **Epic**：`native-function-calling`
- **Story**：Story 04～05（原生编排、调用闭环补漏）
- **Plan**：[plans/native-function-calling/plan.md](../../../../plans/native-function-calling/plan.md)
- **ADR**：[ADR-031](../../../adr/031-native-llm-function-calling.md)

## 目的

清除原生 Function Calling 上线后仍未删除的文本 JSON 工具协议入口，确保生产代码、测试和手工 LLM 回归工具均以 Provider 返回的原生 tool call 为唯一可执行信号。业务型 Structured Outputs schema、内部 ReAct/Plan controller DTO，以及旧会话 system prompt 迁移检测继续保留。

## 文件级变更

### 生产代码

- **修改 `src/transbridge/ai_translator/prompt_builder.py`**：删除已无调用方的 `parse_hybrid_response()` 和 `_try_fix_truncated_json()`，不再提供从 assistant 可见文本解析 `mode`、`thought`、`steps` 或 `tool_calls` 的兼容入口；翻译和术语抽取的业务结果解析不变。
- **修改 `src/transbridge/smart_assistant/tool_registry.py`**：删除把完整工具说明和参数序列化进 prompt 的 `build_tool_schema_for_prompt()`；Provider 工具面统一由 `ToolSpec.to_llm_tool_definition()` 与 `build_native_tool_definitions()` 构建。
- **修改 `src/transbridge/smart_assistant/prompts.py`**：将历史命名 `HYBRID_SYSTEM_PROMPT` 收敛为模块私有 `_SYSTEM_PROMPT`，避免继续暗示文本 JSON 混合协议；实际 prompt 仍只指示 API 原生工具调用。

### 回归工具与测试

- **重写 `tests/smart_assistant/test_data/run_llm_regression.py`**：移除 OpenAI SDK 直连、旧/新 prompt 对比和正文正则提取；改用 `create_llm_client()` 与 `chat_stream_with_tools()`，因此同一脚本同时覆盖 OpenAI-compatible 和 Anthropic。脚本只响应真实 `get_tool_help` 调用并动态加载 namespace，不执行任何业务工具；原生协议校验通过后记录工具选择和路由准确率。
- **新增 `tests/smart_assistant/test_llm_regression_harness.py`**：覆盖 help 后动态加载 namespace、JSON-looking 普通文本不会被当作工具调用，以及原生 `propose_plan` 首步骤路由识别。
- **修改 `tests/smart_assistant/test_mcp.py`、`tests/smart_assistant/test_tool_consolidation.py`**：废弃工具和合并工具的暴露断言从 prompt 字符串改为 Provider-neutral 原生工具定义集合。
- **修改 `tests/smart_assistant/tools/test_run_postprocess.py`**：隔离临时输出目录与规范 prompt 资源目录，避免严格语言档案加载把报告临时目录误当成 prompt 根目录。

## 边界与兼容性

- 保留 `src/transbridge/smart_assistant/native_tools.py` 中的 `mode`/`steps` 映射；它是原生 tool call 进入既有 controller 的内部 DTO，不是要求模型输出的 JSON 协议。
- 保留 `conversation_orchestrator.py` 对旧 system prompt 中 `"mode": "plan"` 的检测；它只用于自动替换历史会话 prompt，不会解析或执行模型正文。
- 保留翻译、术语抽取、校对和后处理的 Structured Outputs schema 与 JSON 结果校验；这些是业务数据契约，不是工具调用协议。
- 手工网络回归脚本仍会写入 `tests/smart_assistant/test_data/result.json`，但只有显式运行时才调用已配置 Provider，自动化测试使用假客户端且不访问网络。
