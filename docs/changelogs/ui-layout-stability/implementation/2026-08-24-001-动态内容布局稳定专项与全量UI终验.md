# 动态内容布局稳定专项与全量 UI 终验

- **日期**：2026-08-24
- **Epic**：`ui-layout-stability`
- **Story**：S01～S05
- **类型**：跨模块 UI 缺陷修复与回归终验
- **关联计划**：[plan.md](../../../../plans/ui-layout-stability/plan.md)
- **关联能力**：`ui-foundation-framework`、`modern-workbench-visual-shell`、`paratranz-project-binding`

## 问题

运行时项目名、版本名、文件名、状态说明、任务信息和表格数据长度变化会进入 Qt 的 `sizeHint`、最小宽度或 `ResizeToContents` 计算，进而推动同一行的按钮、相邻上下文区、表格列和底部操作区。典型表现包括长 ParaTranz 项目名把后续控件推向右侧、状态或进度控件显隐引起界面跳动、刷新数据后表格列宽被重新计算，以及长路径或错误信息扩大工具窗口最小宽度。

本次专项把“固定父控件尺寸下，动态内容变化不得改变固定操作控件几何”作为统一约束；窗口缩放、Splitter 拖动以及用户主动展开/收起仍保留原有响应式行为。

## 变更

### S01：共享稳定布局原语

- `src/transbridge/ui/foundation/components/__init__.py`
  - 新增公开 `ElidedLabel`，完整文本独立保存，屏幕文本随可用宽度执行单行右省略；水平尺寸策略不再让全文抬高父布局最小宽度。
  - `set_full_text()` 同步维护 Tooltip/无障碍所需的完整语义，并在 resize 后重新计算可见文本。
  - 新增 `reserve_text_width()`，按按钮或状态控件所有已知候选文案预留稳定宽度，避免状态切换推动相邻控件。
- `tests/ui/foundation/test_layout_stability_components.py`
  - 覆盖长短文本、省略重算、完整文本保存、最小宽度和候选文案宽度预留。

### S02：Workbench、引导与壳层

- `src/transbridge/ui/workbench/_project_bar.py`、`widget.py`、`remote_target_view.py`
  - 项目名、保存状态和 ParaTranz 目标改用有界省略文本；版本/集合下拉框不再按最长内容自动扩张；保存、重试、已保存和绑定操作按钮预留稳定宽度。
  - 清除远端目标按钮隐藏时保留布局槽，绑定状态变化不再移动“选择/更换”操作。
- `src/transbridge/ui/workbench/translation_table.py`
  - 停止每次渲染按内容自动调整 Key 列，保留稳定列宽和用户拖动后的列宽。
- `src/transbridge/ui/workbench/step2.py`、`progress_view.py`、`workflow_actions_view.py`、`filters_view.py`
  - 渲染/操作进度槽在显隐切换时保持几何；运行状态、禁用理由和用户标签使用有界省略展示；动作按钮按候选状态预留宽度。
- `src/transbridge/ui/guidance/qt.py`、`src/transbridge/ui/shell/status_presenter.py`
  - 引导标题/说明、用户名、项目名和 API 状态采用稳定文本配额，长说明和状态变化不再推动尾部按钮或状态栏区段。
- `tests/ui/test_layout_stability.py`、`tests/ui/test_remote_target_layout.py`
  - 固定父控件尺寸后切换极短/超长运行时内容，直接比较关键按钮和布局槽几何。

### S03：ParaTranz 管理页

- `src/transbridge/ui/paratranz/_layout_stability.py`
  - 新增统一表格列策略：辅助列使用固定或可交互宽度，主要文本列使用稳定 Stretch 配额，禁止数据刷新触发全量 `ResizeToContents`。
- `src/transbridge/ui/paratranz/overview_tab.py`、`strings_tab.py`、`members_tab.py`、`history_tab.py`、`files_tab.py`、`terms_tab.py`、`contribution_tab.py`

- `src/transbridge/ui/paratranz/files_tab.py`、`export_tab.py`、`issues_tab.py`
  - 文件/导出进度与状态区域保留稳定槽位；长问题标题改为单行省略，不再推动操作区。
- `tests/ui/test_paratranz_layout_stability.py`
  - 覆盖长短数据批次切换、表格 section 位置、进度显隐和操作区几何。

审计中未能复现字符串文件筛选框、联系人标签和项目列表面板的实际漂移，因此未为了形式一致而修改；`StringDetail` 在裸对话框几何探针中出现原生崩溃，未在缺少可靠证据时扩大修改范围。

## 遗留项

- 尚未在用户真实 Windows 窗口中执行最终人工视觉复验；当前证据来自固定尺寸的 Qt 几何回归和完整 `tests/ui` 回归。
- AI 作用域中的极端超长自定义文案在不允许水平滚动的内容区仍可能被截断，但不会推动底部操作区；后续若改善可读性，应作为单独 UX 需求处理。
- `StringDetail` 的裸对话框几何探针曾触发原生崩溃，当前没有可靠证据支持进一步修改；需在可稳定复现的真实窗口路径下另行排查。
- 仓库级 Ruff/format 历史债务不属于本次专项，未处理。
