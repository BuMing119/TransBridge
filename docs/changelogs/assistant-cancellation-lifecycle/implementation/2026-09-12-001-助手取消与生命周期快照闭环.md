# 助手取消与生命周期快照闭环

- 日期：2026-09-12
- Epic：`assistant-cancellation-lifecycle`
- Story：`implementation`（对应计划实施项 1～4 与 QA，未另建独立 Story 文档）。
- Plan：[助手取消与生命周期快照闭环](../../../../plans/assistant-cancellation-lifecycle/plan.md)

## 问题、范围与证据

用户要求完善长会话中换题、取消旧任务以及生命周期恢复的处理。修复前，新消息重置控制器后，后台任务仍可能运行；旧任务结束事件可能先写入当前历史，旧确认卡片仍能触发执行；恢复等待状态时没有核对对应运行时任务。纯同步计划也缺少可查询、可取消的父任务身份。

本次将轮次中断、后台取消、实际终态与快照恢复分别接入其生命周期。快照指助手控制器阶段和任务引用，不涉及新增翻译项目内容快照或项目版本回滚。三个子 Agent 分别负责控制器与恢复、确认与计划执行、任务控制与事件，主会话完成接线和集成验证。

记录依据当前任务上下文、目标文件 Git 差异、新增文件与已执行测试输出。归档时实现尚未提交，暂存区为空。工作区中既有 `ai-task-project-terminology` 的生产代码、测试、计划和历史记录不属于本增量；共享索引仅增加本 Epic 的入口。

## 逐文件变更

### 控制器、快照与恢复

以下路径相对仓库根目录。

- **修改 `src/transbridge/smart_assistant/session_controller.py`**：`handle_round_interrupted` 保留已启动任务，`handle_abort` 支持完整解绑；用活动与脱离当前轮次的任务身份处理终态，取消不启动下一轮推理。确认保存代次标识及步骤副本，拒绝过期载荷。`to_snapshot`、`restore` 保存任务/运行身份，并在验证不足时降级为 IDLE，保留恢复原因。明确单任务停止可直接执行，全部操作仍进入确认。
- **修改 `src/transbridge/application/sessions/models.py`**：`ControllerSnapshot` 增加可选 `active_task_id`、`active_run_id` 及序列化；校验运行身份必须从属于任务，旧格式缺省字段仍可读取。
- **修改 `src/transbridge/application/sessions/recovery.py`**：`SessionRecoveryReconciler` 按任务和运行身份核对实际任务；终态、缺失任务和无法重建的确认载荷不恢复为等待。中断的模型轮次回到空闲，仍存活的任务引用可以保留；移除不可执行的待确认记录。
- **修改 `src/transbridge/application/sessions/gui_facade.py`**：`save_conversation` 接收生命周期任务引用，`_merge_job_refs` 保留已结束任务证据，对丢失的非终态引用记录不可恢复原因，避免运行时清理后丢失历史。
- **新增 `src/transbridge/ui/tools/smart_assistant/session_runtime.py`**：`SessionRuntimeBinding` 统一会话 RequestContext、任务作用域与生命周期引用；`reconcile_controller` 在 GUI 恢复前核对 owner/session/project/variant 和 task/run，拒绝跨会话或失效引用。

### 任务控制与图执行

- **新增 `src/transbridge/smart_assistant/tools/task_control.py`**：提取 `control_tasks`、`get_scoped_task_status` 和 `task_scope_matches`，限定操作范围；省略目标仅选择唯一活跃顶层任务，多目标要求明确选择，`all_tasks=True` 表示显式范围内全部操作。活动父任务存在时不将其子任务重复视为默认候选；显式子任务操作仍可用。
- **修改 `src/transbridge/smart_assistant/tools/tool_translator.py`**：停止、暂停、恢复和状态查询接入独立任务控制模块；更新参数与工具说明，启动翻译/润色返回 `run_id`。移除原内联的隐式全部任务操作实现，单任务停止不再要求重复确认。
- **修改 `src/transbridge/smart_assistant/tools/task_manager.py`**：取消重复请求幂等，重新检查取消竞态；未启动任务的取消也发出真实终态通知。增加携带原始身份快照的终态回调并去重，避免延迟消费时查询到已清理或替换的任务。
- **修改 `src/transbridge/smart_assistant/tools/task_runtime_bridge.py`**：`task_metadata` 将请求元数据中的 `parent_task_id` 传入任务记录，使计划内后台工作可关联父任务。
- **新增 `src/transbridge/smart_assistant/plan_task_runtime.py`**：`PlanTaskRuntime` 为计划注册 `assistant-plan` 父任务，复制已接纳的上下文并为子任务写入父任务身份；在 TaskManager 工作线程执行图，转发取消/暂停/恢复，按运行时终态收敛回调并解除订阅。订阅后补核对已发生的取消，避免启动前终态丢失。
- **修改 `src/transbridge/smart_assistant/graph_executor.py`**：复用并复制已有 ExecutionContext，保留请求归属与捕获的写入目标；后台子任务取消使整图停止，避免进入失败恢复分支。删除图入口无条件清除取消标记的行为，关闭启动前取消被覆盖的竞态。
- **修改 `src/transbridge/smart_assistant/guardrails/permission.py`**：`PermissionGuard` 允许明确的单任务 stop，显式 all_tasks 操作保留确认要求；实际范围与歧义判断由任务控制工具执行。
- **修改 `src/transbridge/smart_assistant/tool_execution_handler.py`**：注入请求上下文提供器，并公开 `build_execution_context` 供计划复用；动态判断全部操作的确认要求，避免 UI 与工具执行使用不同会话身份。
- **修改 `src/transbridge/smart_assistant/prompts.py`**：要求取消调用真实工具，目标不明时先查询；区分取消请求与已取消终态，禁止自动重启取消的工作或重放历史确认；将任务取消加入 translator 路由说明。

### 确认、消息提交与 UI 接线

以下生产文件位于 `src/transbridge/ui/tools/smart_assistant/`。

- **修改 `confirmation_view.py`**：`invalidate_pending` 使旧卡片与排队决策失效；确认绑定代次和控制器令牌，模态对话框返回后再次检查身份。计划执行职责迁至 `plan_execution_binding.py`，保留原导入入口兼容。
- **新增 `plan_execution_binding.py`**：承接原 `PlanExecutionBinding`，通过父任务运行计划；`interrupt_round` 保留脱离当前轮次的执行器，旧结果不写入新对话；关闭时取消并释放相关执行器。取消结果单独展示，终态完成控制器清理后保存生命周期；过期人工决策不能重新驱动旧图。
- **修改 `tool_card.py`**：工具和批量工具确认卡片增加可见失效状态及一次性决策保护，过期或重复信号无法继续执行。
- **修改 `plan_card.py`**：计划卡片增加失效状态，关闭旧确认入口，避免用户点击旧计划作用于新轮次。
- **新增 `submission_binding.py`**：`SubmissionBinding` 统一消息提交，先中断旧轮次，再追加消息并排队启动；代次检查使被替换、切换会话或关闭后的排队输入失效。
- **修改 `chat_widget.py`**：程序发送和输入框发送统一通过 SubmissionBinding；切换、清空和关闭时使相关排队状态失效；恢复控制器前连接任务通知并核对运行时，提供 `lifecycle_jobs` 给持久化边界。
- **修改 `chat_composition.py`**：装配统一请求上下文、提交绑定、任务范围与生命周期保存回调；轮次切换先分离计划再使确认失效；`_task_started` 立即保存并安排终态补核对，覆盖任务先结束、控制器后注册的竞态。
- **修改 `session_binding.py`**：`ConversationBinding.start_round` 使用轮次中断语义，避免开始新问题时抹除仍需管理的后台任务关联。
- **修改 `task_binding.py`**：终态在写历史前核对作用域、任务/运行身份及真实状态；当前等待任务生成观察结果，其余同会话结束只通知，外会话事件丢弃。取消不恢复模型推理；通知与控制器收敛分别去重，`reconcile_task` 补偿先结束后注册的竞态；取消中与终态均触发保存。
- **修改 `panel.py`**：会话端口提供运行时 RequestContext，保存对话时传入 `lifecycle_jobs`，使控制器与任务引用一起落盘。
