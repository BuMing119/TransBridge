# 多窗口来源筛选与独立任务栏

- 日期：2026-09-06
- Epic：`history-translation-term-search`
- Story：Story 05
- Plan：[历史翻译与术语统一搜索](../../../../plans/history-translation-term-search/plan.md)
- Requirement：FR29.2、FR29.9
- ADR：[ADR-038 可重建历史搜索投影](../../../../docs/adr/038-rebuildable-history-search-projection.md)

## 范围与原因

首版搜索窗口只能复用一个实例，且空关键词不展示结果。用户要求同时打开多个窗口，在每个窗口独立选择全部来源、单个 Project 或单个 `.tbdict`，并确认关键词留空时默认浏览当前范围的全部内容。真实 Windows 截图进一步证明：仅创建多个带主窗口 owner 的 Qt 窗口仍会被任务栏归入主窗口缩略图，无法方便切换。因此本增量把搜索实例改为独立顶级窗口，并为每个实例分配唯一任务栏身份和序号标题。

## 逐文件变更

- `src/transbridge/application/history_search/models.py`
  - 新增 `HistorySearchScopeKind` 与不可变 `HistorySearchScope`，明确 Project 和词典两种可选范围。
  - 为 `HistoryQuery` 增加可选 `scope`，保留原有位置参数顺序，并校验范围类型。
- `src/transbridge/application/history_search/service.py`、`src/transbridge/application/history_search/__init__.py`
  - 在查询端口和应用服务中公开 `scopes()`，统一向 UI 提供可选 Project/词典范围；导出新增范围契约。
- `src/transbridge/persistence/history_search.py`
  - 将派生搜索 schema 升级为版本 2；记录只读 `project_id`、`dictionary_id`，新增 `search_scopes` 投影及范围索引。旧派生索引因版本不匹配自动进入可重建状态，不迁移或修改权威资产。
  - 空关键词不再直接返回空页，而是在当前类型与来源范围内读取有界候选；Project 过滤同时覆盖其 Variant 译文和生效术语，词典过滤只命中对应 dictionary ID。
  - 从来源投影稳定生成去重的 Project/词典选项；查询仍保持 200 条首屏和 5000 条候选上限。
- `src/transbridge/ui/tools/history_search/window.py`
  - 增加“全部来源 / 项目 / 词典”范围下拉框，每个窗口独立保存关键词、类型和范围；空关键词默认查询全部来源首屏。
  - 索引刷新完成后重新加载范围；其他窗口完成刷新时，当前窗口也保留自身筛选并重新查询。
  - 结果超过首屏时明确显示当前行数和候选集上限，不把有界首屏表述为已展示全部行。
  - 支持在首次显示前设置窗口级 Windows `AppUserModelID`，关闭时清理该身份；非 Windows/offscreen 环境保持安全退化。
- `src/transbridge/ui/shell/tool_windows.py`
  - 将单例 `_history_search_window` 改为活动窗口集合；每次触发菜单均创建新实例，单独跟踪和释放。
  - 搜索窗口使用 `parent=None`，不再拥有主窗口 HWND；任务栏 ID 组合进程 ID 与窗口序号，避免同一进程内、不同 TransBridge 进程间的搜索实例互相分组。
  - 为窗口设置主程序图标及“历史翻译与术语搜索 1/2/…”序号标题；主程序退出时统一关闭仍活动的全部搜索窗口。
- `tests/persistence/test_history_search.py`
  - 覆盖空关键词浏览、Project 范围同时包含完整译文与术语、词典范围隔离、范围枚举，以及一万条记录下关键词/空关键词首屏预算。
- `tests/ui/tools/test_history_search_window.py`
  - 覆盖默认全部来源、独立范围请求、首屏截断提示，以及显式任务栏身份的设置与关闭清理。
  - 范围请求断言按 generation 语义验证实际提交，避免依赖后台初始查询与测试线程的偶发完成顺序。
- `tests/ui/ux/test_current_user_journeys.py`
  - 覆盖连续触发入口创建两个不同对象、无 Qt parent、进程/实例唯一任务栏 ID、不同序号标题，以及统一 dispose。
- `docs/requirements.md`

## 兼容与遗留项

- Project/Variant JSON、`.tbdict` 和术语 SQLite 权威格式均未改变；schema v2 仅属于可删除、可重建的搜索投影。
- 多窗口共用同一派生索引，但关键词、类型、来源范围、选择和结果 generation 均由各窗口独立持有。
- 自动化测试已覆盖无父窗口、唯一任务栏 ID 及设置/清理调用；修复后的 Windows 任务栏最终视觉仍需用户完全重启 TransBridge 后实机复验。
