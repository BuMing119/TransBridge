# AI 工作流交互与术语长尾修复

- **日期**：2026-08-27
- **Epic/Story**：`ai-workflow-ui-resilience` / Story 1～3
- **目的**：修复翻译入口估算文字裁切、混合规则编辑与即时生效失真，以及术语抽取尾批长期无反馈且无法可靠停止的问题。

## 变更

### 入口布局与混合规则

- `src/transbridge/ui/tools/ai_translator/scope_view.py`
  - 将标准与混合估算标签改为受 viewport 约束的自动换行布局，完整文字不再被禁用水平滚动的容器裁切。
- `src/transbridge/ui/tools/ai_translator/_rule_editor_widget.py`
  - 将优先级改为由行顺序生成的只读值；状态与分类改为支持“全部”的多选下拉；动作保留单选下拉。
  - 新增统一 `rules_changed` 信号，覆盖新增、删除、移动、重置和字段变化。
  - 载入旧配置时先按持久化 priority 稳定排序，再连续重编号；历史 raw/未知筛选值以“兼容原始值”显式显示。
- `src/transbridge/ui/tools/ai_translator/config_view.py`
  - 将规则变化和混合执行顺序接入既有防抖保存；模型、批次 Token、并发和规则变化同时立即刷新估算及快速运行摘要。

### 分类规则运行语义

- `src/transbridge/converter/context_categories.py`
  - 提炼共享的用户显示分类表和 `context_category()`，统一工作台筛选与混合规则的分类口径。
- `src/transbridge/ui/workbench/filters_presenter.py`
  - 改为复用共享分类函数，移除 UI 层重复映射。
- `src/transbridge/application/translation/planning.py`
- `src/transbridge/paratranz/config_manager.py`
  - 动作规则同时兼容用户显示分类和历史 raw context，保证下拉选择及旧配置都真实影响首匹配运行结果。

### 术语阶段长尾恢复

- `src/transbridge/ai_translator/noun_extractor.py`
  - 增加向底层 LLM 客户端转发的取消入口。
- `src/transbridge/ai_translator/existing_term_extractor.py`
  - 增加 10 秒 Provider 等待心跳和 90 秒术语阶段专用长尾上限。
  - 长尾超限或用户停止时主动取消 Provider；客户端不可取消或取消失败时分离运行 Future，避免线程池 `shutdown(wait=True)` 再次卡住当前流程。
  - 最终失败保持文本术语整轮原子不提交，并把阶段进度收口后交回 `AutoTranslator` 的既有降级路径继续翻译。
- `src/transbridge/ui/tools/ai_translator/_mixed_worker.py`
  - 终止失败时将未执行批次计入失败统计，保证完成、失败、剩余与总批次数闭合。

### 计划与测试
