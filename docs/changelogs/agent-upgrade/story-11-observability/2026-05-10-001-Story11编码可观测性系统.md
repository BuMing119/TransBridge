# 001: Story-11 可观测性系统编码实现

**日期**: 2026-05-10
**类型**: 增/改
**关联**: Epic: Agent框架升级 > Story 11: 可观测性系统

## 修改文件

### `src/transbridge/smart_assistant/observability/models.py` (增)
- **修改内容**: 四个观测数据模型——TokenStats（input/output/by_model + add() 累加 + to_dict()）/ToolCallRecord（timestamp/tool_name/input_summary 截断500字符/output_summary 截断500字符/duration_ms/success/retry_count）/ReActRound（round_num/llm_input_tokens/llm_output_summary/tools/duration_ms）/ConversationTrace（conv_id/rounds/tools_called/token_stats/started_at/finished_at + to_dict()）。全 dataclass，支持 JSON 序列化。
- **原因**: FR7.13.9 可观测性数据模型。涵盖对话追踪、工具调用链、Token 统计三个观测维度。

### `src/transbridge/smart_assistant/observability/collector.py` (增)
- **修改内容**: ObservabilityCollector(QObject)，信号 token_stats_updated。完整观测生命周期：start_conversation→on_step_started→on_step_finished→on_step_retrying→on_llm_tokens→end_conversation。end_conversation 自动保存 JSON 到 storage_dir（`data/projects/{project}/{variant}/observability/{conv_id}.json`）。_cleanup_old 自动清理 30 天以上文件。Collector 支持可选模式（storage_dir=None 时仅内存保留）。
- **原因**: FR7.13.9 数据采集层。通过连接 ExecutionEngine 现有 pyqtSignal 管道收集遥测，无需新建独立遥测系统。

### `src/transbridge/smart_assistant/observability/__init__.py` (增)
- **修改内容**: 导出 ObservabilityCollector/ConversationTrace/ReActRound/ToolCallRecord/TokenStats 5 个公开符号。
- **原因**: observability/ 子包公开 API。

### `src/transbridge/smart_assistant/execution_engine.py` (改)
- **修改内容**: ExecutionEngine 初始化时可注入 ObservabilityCollector，在 step_started/step_finished/step_retrying 信号发射时同步通知 Collector。
- **原因**: FR7.13.9 遥测管道集成——利用现有 pyqtSignal 发射点，Collector 作为观察者订阅事件。

### `src/transbridge/ui/tools/smart_assistant/chat_widget.py` (改)
- **修改内容**: 三处集成：
  1. __init__ 中创建 ObservabilityCollector 实例（storage_dir="data/observability"），连接 token_stats_updated 信号
  2. 新增观测面板 QTabWidget（最大高度 160px）——Token 仪表盘（今日/本周/本月 3 卡片）、工具调用表（QTableWidget 4列：时间/工具/耗时/状态）、对话轮次列表（QListWidget）
  3. _on_plan_all_finished 时调用 `_obs_collector.end_conversation()` 保存观测数据，对话结束时在消息底部显示本轮 token 消耗摘要
- **原因**: S11 步骤5 UI 集成——观测数据实时展示 + 对话结束持久化。面板仅160px 高，不挤占对话区域。

### `src/transbridge/smart_assistant/__init__.py` (改)
- **修改内容**: 新增导入 observability/子包（ObservabilityCollector/ConversationTrace/TokenStats）。__all__ 扩展。
- **原因**: 包公开 API 随新增子包同步更新（QA 修复 m3）。
