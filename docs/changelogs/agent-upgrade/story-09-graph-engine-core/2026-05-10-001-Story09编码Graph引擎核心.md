**日期**: 2026-05-10

## 修改文件

### `src/transbridge/smart_assistant/graph_types.py` (增)
- **修改内容**: Graph 类型体系全量定义——NodeSpec 基类 + 4 种子类 ActionNode（tool+args+agent+retry）/ConditionNode（condition+true_node+false_node）/LoopNode（sub_nodes+max_iterations+exit_condition）/HumanConfirmNode（prompt+choices+timeout+default_choice）+ EdgeSpec（from/to/type:"always"/"conditional"/"loop_back"）+ GraphSpec（graph_id/nodes/edges/entry_node）。所有类为 dataclass。
- **原因**: FR7.13.7 Graph 编排的类型系统。自研轻量方案，零外部依赖。

### `src/transbridge/smart_assistant/graph_executor.py` (增)
- **修改内容**: GraphExecutor ABC 四元抽象接口（execute_graph/cancel/pause/resume）。预留 LangGraph 替换路径（未来实现 LangGraphExecutor(GraphExecutor)）。
- **原因**: FR7.13.7 抽象层——约20行代码的保险措施，未来如需切换编排引擎仅需实现新子类，无需修改调用方。

### `src/transbridge/smart_assistant/execution_engine.py` (改)
- **修改内容**: 新增 execute_graph() 图执行方法——BFS 层级遍历 + 4 种 Node 类型 dispatch（ActionNode→_run_single 工具执行/ConditionNode→条件路由/LoopNode→子图循环 + max_iterations 硬上限/HumanConfirmNode→暂停等待确认）+ 条件表达式受限 eval + Checkpoint 自动保存/恢复。execute() 向后兼容适配：内部将 steps 转为线性 GraphSpec 委托给 execute_graph()。新增 pause()/resume() 方法。
- **原因**: FR7.13.7 ExecutionEngine 从 DAG 执行器演进为有状态图执行器。execute() 向后兼容保证现有 ChatWidget 和 PlanCard 调用方式不变。BFS 层级遍历同层并行，保留 ThreadPoolExecutor 并行能力。
