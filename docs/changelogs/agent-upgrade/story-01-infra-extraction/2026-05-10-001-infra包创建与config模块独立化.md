# 001: infra/ 包创建 + config/ 模块独立化编码

**日期**: 2026-05-10
**类型**: 增/移/改
**关联**: Epic: agent-upgrade > Story 01: infra/ 提取与搬迁

## 修改文件

### `src/transbridge/infra/__init__.py` (增)
- **修改内容**: 新建 infra 包入口，导出 5 符号：LLMClient/create_llm_client/EmbeddingClient/LLMConfig/VectorStore
- **原因**: 按 ADR-010 契约建立共享基础设施包

### `src/transbridge/infra/llm_client.py` (移)
- **修改内容**: 从 ai_translator/ git mv 搬迁，内容不变（LLMClient ABC + OpenAICompatibleClient + AnthropicClient + create_llm_client）
- **原因**: LLM 客户端是共享基础设施，非 ai_translator 私有

### `src/transbridge/infra/embedding_client.py` (移)
- **修改内容**: 从 ai_translator/ git mv 搬迁，内容不变
- **原因**: 嵌入客户端将被 smart_assistant/memory 复用

### `src/transbridge/infra/config.py` (改)
- **修改内容**: 从原先的 LLMConfig+EmbeddingConfig 定义改为 re-export，指向 src/transbridge/config/
- **原因**: config 已独立为一级模块，infra 保持向后兼容

### `src/transbridge/infra/vector_store.py` (增)
- **修改内容**: VectorStore 类，封装 FAISS IndexFlatIP。6 方法：create_index/add/search/remove/save/load。支持条件初始化（FAISS 不可用时抛 ImportError），search 在空索引时返回空列表
- **原因**: 统一 FAISS 索引操作，ai_translator 和 smart_assistant/memory 共享

### `src/transbridge/config/__init__.py` (增)
- **修改内容**: 独立配置模块入口，导出 LLMConfig/EmbeddingConfig/ParatranzConfig/get_data_dir/get_config_file_path
- **原因**: 配置提升为一级模块，不再从属于 paratranz 或 infra

### `src/transbridge/config/paths.py` (增)
- **修改内容**: get_data_dir()（打包/开发环境自适应）+ get_config_file_path()
- **原因**: 路径工具独立，解除 LLMConfig 对 ParatranzConfig 的循环依赖

### `src/transbridge/config/llm.py` (增)
- **修改内容**: LLMConfig（~80字段含向量检索+后处理+混合模式）+ EmbeddingConfig（三模式：api/local/disabled）。save_to_file/load_from_file 使用 config.paths 而非 ParatranzConfig
- **原因**: LLM 配置从 paratranz 中独立

### `src/transbridge/config/paratranz.py` (增)
- **修改内容**: ParatranzConfig 类，保留 get_data_dir/get_config_file_path 静态方法委托到 paths
- **原因**: 保持 10 个旧调用方零改动兼容

### `src/transbridge/paratranz/config_manager.py` (改)
- **修改内容**: 大幅精简——LLMConfig/ParatranzConfig 类定义替换为 re-export，仅保留 ActionRule 在文件中
- **原因**: 向后兼容旧 import 路径

### `src/transbridge/ai_translator/translator.py` (改)
- **修改内容**: `from src.transbridge.ai_translator.llm_client import create_llm_client` → `from src.transbridge.infra.llm_client import create_llm_client`
- **原因**: 搬迁后 import 路径更新

### `src/transbridge/ai_translator/noun_extractor.py` (改)
- **修改内容**: llm_client import → infra.llm_client
- **原因**: 同上

### `src/transbridge/ui/tools/smart_assistant/chat_widget.py` (改)
- **修改内容**: create_llm_client import → infra.llm_client
- **原因**: 同上

### `src/transbridge/ui/tools/ai_translator/_batch_config_dialog.py` (改)
- **修改内容**: create_llm_client import → infra.llm_client
- **原因**: 同上

### `src/transbridge/ui/tools/ai_translator/ai_translator_window.py` (改)
- **修改内容**: 2 处 create_llm_client import → infra.llm_client
- **原因**: 同上
