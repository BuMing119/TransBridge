# 术语格式最大化兼容实现

- **日期**：2026-08-26
- **Epic**：`terminology-format-compatibility`
- **Story**：Story 1 规范模型与无损格式适配器；Story 2 CSV 来源接入所有运行入口；Story 3 动态库与 ParaTranz 边界兼容
- **架构关联**：ADR-027
- **状态**：实现完成，相关 QA 通过

## 目的

让动态术语库、ParaTranz、本地 JSON、CSV、`.xlsx` 和旧式 `.xls` 通过同一规范术语模型互操作。已知字段完整映射，未知字段在规范格式间尽量保留；已有大半翻译成果的项目可以继续加载旧术语数据，并把 CSV 作为正式术语来源参与既有优先级、缓存、批量预检与智能助手配置流程。

## 真实变更

### 需求、架构与计划

- `docs/adr/027-canonical-terminology-format-adapters.md`（新增）
  - 选择单一 `TermEntry` 规范模型和独立格式适配器，约束动态库、ParaTranz、JSON、CSV 与 Excel 的字段映射、错误语义及依赖方向。
  - 明确“完全兼容”为字段级最大化互操作，而非所有来源采用相同字面格式；ParaTranz 只读字段仅在本地保留，不提交到写接口。

### Story 1：规范模型与格式适配器

- `src/transbridge/ai_translator/term_formats.py`（新增）
  - 定义与 UI、配置仓储和网络客户端解耦的 `TermEntry`，覆盖原文、译文、来源、上下文、创建时间、大小写敏感、变体、词性、注释、外部标识和未知元数据。
  - JSON 同时兼容规范数组、简单键值对象以及 `terms`、`results`、`items`、`data` 包装结构，并提供规范格式与 ParaTranz payload 序列化。
  - CSV 支持 UTF-8 BOM、规范/ParaTranz 风格表头及无表头两列文件；复杂字段使用 JSON 文本往返。
  - `.xlsx` 通过 `openpyxl`、旧式 BIFF `.xls` 通过 `xlrd` 直接读取，不依赖本机 Excel 或 LibreOffice；可识别完整表头，也保留旧两列配置回退。
- `pyproject.toml`、`uv.lock`（修改）
  - 增加并锁定 `xlrd 2.0.2`，用于原生读取旧式 `.xls`。
- `src/transbridge/ai_translator/term_database.py`（修改）
  - 保留原 `TermEntry` 公共导入路径，将 JSON、CSV、Excel、动态库与缓存解析委托给规范适配器，避免继续扩张已超规模阈值的数据库模块。

### Story 2：CSV 来源接入运行时、配置、UI 与智能助手

- `src/transbridge/ui/tools/ai_translator/config_view.py`、`view_controls.py`（修改，本记录仅归属术语来源 UI）

- `src/transbridge/ui/tools/ai_translator/batch_runtime.py`（修改）
  - 批量翻译的空术语预检通过规范加载器识别 JSON、CSV 与 Excel，避免有文件但误判为空。

- `tests/conftest.py`、`tests/contracts/config/test_unified_repository.py`（修改）

### Story 3：动态库、缓存与 ParaTranz 边界

- `src/transbridge/ai_translator/term_database.py`（修改）
  - 动态库与来源/合并缓存使用兼容解析和规范序列化；旧记录缺少新字段时继续读取，既有 `source="manual"` 等来源语义不被覆盖。
  - CSV 获得独立来源加载器和缓存；损坏的本地来源继续沿用既有缓存回退并产生可定位日志。
  - ParaTranz 分页响应兼容 `results`、`terms`、`items` 和 `data` 包装，已知字段进入规范模型，只读及未知字段保存到本地元数据。
- ParaTranz 写入边界
  - 规范序列化器仅输出服务端可写字段，不把服务端标识、项目、时间等只读字段回写；本次没有触发自动远端上传。

## 兼容性、迁移与遗留项

- 旧动态 JSON、简单键值 JSON、旧缓存和两列 Excel 无需批量迁移；动态库只在正常保存时升级为包含新字段的规范结构。
- 已保存为新结构的动态库可能无法被使用严格 `TermEntry(**item)` 的旧版本读取；降级旧版前应保留动态库备份。
- CSV 使用独立路径并进入可排序优先级；旧配置缺少该字段时使用空路径，原有自定义优先级不被强制改写。
- ParaTranz 只读及未知字段只能在本地规范格式间保留，受远端 API 写入能力限制；本次未执行真实网络写入测试。
- 仓库全量 `ruff check src tests` 与 `ruff format --check src tests` 曾尝试执行，但分别被本次范围外的历史 lint 问题及 142 个待格式化文件阻断；本次核心文件的定向门禁已通过。`tool_translator.py` 还存在与本增量无关的既有 Ruff 问题，其 CSV 行为已由聚焦测试覆盖。
