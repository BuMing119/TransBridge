# 005: 标签库 UI 集成 — 管理对话框、标签列、筛选行与右键菜单

**日期**: 2026-05-08
**类型**: 增
**关联**: Epic: 自定义标签系统 > Story 1-4: 标签模型+右键菜单+筛选+聚焦（集成完善）

## 修改文件

### `src/transbridge/ui/workbench/step2.py` (改)
- **修改内容**:
  1. **标签管理对话框**（新增 `_LabelManagerDialog` 类，~130 行）：创建/编辑/删除标签，设置名称和颜色（8 色预设），左侧列表展示已有标签（带颜色圆点），右侧编辑区支持名称输入和颜色选择
  2. **标签库与条目标签数据结构**：`_label_library: dict[str, dict]`（label_id → {name, color}），`_entry_labels: dict[str, set[str]]`（entry_id → set[label_id]），替代 FR7.10 的 `_entry_marks`
  3. **标记列替代复选框列**：`_COL_CHECK` → `_COL_MARK`，列宽 28→32px，标记列显示彩色圆点（每个标签一个圆点）
  4. **标签筛选行**：新增 `_mark_tags_widget`，动态显示标签库中的标签按钮（计数为 0 的隐藏），支持多选筛选，[已标记] 聚焦按钮
  5. **右键菜单**：表格右键弹出标签分配菜单（勾选/取消勾选），底部「管理标签…」和「+ 新建标签…」入口
  6. **行背景色**：导入 `_ROW_BG_GREEN = #E8F5E9`，已翻译行着色
  7. **`get_selected_entries()` 语义变更**：从返回选中 checkbox 条目改为返回所有有标签的条目，供 AI 翻译浮窗使用
  8. **导入 STAGE_LABELS/STAGE_COLORS** 从 translation_entry 模块，不再本地定义
- **原因**: FR7.11 自定义标签系统需要完整的 UI 集成——标签管理、分配、显示、筛选。替代 FR7.10 的固定三态标记（★/?/✓），实现用户自定义多标签。标签数据通过 `_entry_labels` 和 `_label_library` 与会话绑定，支持跨筛选/搜索持久化
