## 目的与用户可见行为

用户参考 xTranslator，要求双击词条后打开独立编辑窗口，在同一任务内查看相关记录与对白；随后明确不要主导航里的常驻“对话编辑”页面，并要求左侧采用 XT 的记录标识，而不是对白句子。

- 双击工作台词条的数据列打开可复用、非模态的“词条编辑”窗口；复选框仍只负责选择。主导航保留原有三个页面，原列表与位置保留，F2 继续支持译文行内编辑。
- 弹窗左侧选择 Quest，并按 FormID 平列记录。标题采用 `QUST {EditorID} [FormID]`、`DIAL {EditorID/类别} [FormID]`、`SCEN {EditorID} [FormID]`；无 EditorID 的场景话题可显示 `DIAL {Scene}`。悬停可查看完整标识与关联词条数。
- 右侧显示相关原文、译文和状态，底部编辑完整译文。DIAL 内保留来源顺序；SCEN 汇总其明确引用的话题文本，重复引用不重复显示，不解释条件分支或实际演出时序。
- SCEN 内应用译文、刷新、上一条/下一条保持场景选中；主表再次双击词条时定位其 DIAL。空场景清空底部编辑区，避免继续修改上一个词条。
- 普通词条和纯 EET 内容仍可弹窗编辑。EET 的左侧关联区域置灰并说明原因；插件叠加 EET/XT 译文不会禁用插件关联浏览。
- 未应用草稿在窗口使用期间保留；关闭按钮、窗口 ×、Esc 和关闭主窗口均检查草稿。提交失败、词条被外部修改或工程/版本/来源改变时，不覆盖新数据并保留草稿。

## 逐文件变更

### 解析与应用层

- 新增 [src/transbridge/parser/plugin/dialogue_catalog.py](../../../../src/transbridge/parser/plugin/dialogue_catalog.py)：`DialogueRecord` / `DialogueCatalog` 保存只读记录目录，`read_dialogue_catalog()` 读取 QUST、DIAL、SCEN 标识及显式关联，DIAL 可由 DLBR 补全父任务。`_scene_links()` 区分动作内外的 PNAM，只接收 Dialogue 动作的 DATA 作为话题引用，避免将 PACK 或演员标志误认成任务/话题。字段依据为 [xEdit TES5 定义](https://github.com/TES5Edit/TES5Edit/blob/dev-4.1.6/Core/wbDefinitionsTES5.pas)。SCEN 不生成虚构翻译词条。
- 新增 [src/transbridge/application/dialogue/index.py](../../../../src/transbridge/application/dialogue/index.py)：`build_dialogue_index()` 用完整 EntryKey 和来源命名空间构建任务、话题、场景投影，保留词条到原始 DIAL 的规范定位；场景引用不覆盖该定位。`_editor_id()` 可从旧词条 key 恢复标识，`_record_order()` 只排序左侧节点。缺失关系采用明确未知分组；混合命名空间不盲目复用同一个插件目录。`source_unavailable_reason()` 区分插件、EET 和缺少原始插件上下文的来源。
- 新增 [src/transbridge/application/dialogue/loading.py](../../../../src/transbridge/application/dialogue/loading.py)：`DialogueIndexLoader.build()` 在后台读取已加载插件或 `SourceSnapshot.content`，以锁保护单一来源目录缓存；译文刷新复用目录，快照恢复不重新读取可能已变化的磁盘插件。
- 新增 [src/transbridge/application/dialogue/__init__.py](../../../../src/transbridge/application/dialogue/__init__.py)：声明独立的只读对话投影包，避免把新职责继续加入现有转换或主窗口模块。

### 弹窗、草稿与导航

- 新增 [src/transbridge/ui/dialogue/dialog.py](../../../../src/transbridge/ui/dialogue/dialog.py)：`EntryEditorDialog` 由主窗口持有，组合编辑视图，支持缩放和最小化/最大化；`reject()` 将 Esc 纳入同一关闭检查，`closeEvent()` 在允许关闭后通知控制器清理选择。
- 新增 [src/transbridge/ui/dialogue/view.py](../../../../src/transbridge/ui/dialogue/view.py)：`DialogueEditorView` 组合任务选择、记录列表、原文/译文表和底部编辑区。`set_context_available()` 只禁用左侧关联区域；`show_entry()` 在同一草稿的异步索引刷新中保留光标与撤销历史，切换词条时重置编辑内容；操作按钮提供应用、应用并下一条、放弃草稿和导航。
- 新增 [src/transbridge/ui/dialogue/models.py](../../../../src/transbridge/ui/dialogue/models.py)：`TopicTreeModel` 按当前任务平列记录，不重复插入任务根节点；显示内部标识并在 tooltip 展示关联信息。`DialogueTableModel` 只读呈现关联词条，保留完整身份并突出 DIAL 行，将写入职责留给草稿提交路径。
- 新增 [src/transbridge/ui/dialogue/controller.py](../../../../src/transbridge/ui/dialogue/controller.py)：`DialogueEditorController` 持有唯一弹窗、索引代次和按内容作用域保存的草稿，通过 `ApiWorker` 加载目录并忽略过期结果；`open_entry()`、`select_topic()`、`_selected_location()` 处理词条与场景定位；`apply()` / `discard()` 同步已有投影；空记录清空编辑区，后台完成不会重新弹出已关闭窗口。`can_close()` 统一草稿提示，`close()` 幂等释放信号连接。
- 新增 [src/transbridge/ui/dialogue/editing.py](../../../../src/transbridge/ui/dialogue/editing.py)：`EntryDraft.capture()` 保存原词条快照，`commit()` 检查作用域、词条快照及权威版本修订。正式工程调用既有 `replace_entry_states()`，旧集合使用带 provenance 与预期修订的 `Collection.apply()`；失败保留草稿，成功后同步主表与工程脏状态，不直接修改投影字段。
- 新增 [src/transbridge/ui/dialogue/__init__.py](../../../../src/transbridge/ui/dialogue/__init__.py)：声明弹窗展示包，将视图、提交和控制职责分开组织。
