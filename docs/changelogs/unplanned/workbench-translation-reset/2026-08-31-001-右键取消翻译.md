# 右键取消翻译与批量清空保护

- **日期**：2026-08-31
- **Epic**：`unplanned`
- **Story / 主题**：`workbench-translation-reset`（计划外小功能，无对应的已规划 Story）
- **需求来源**：用户提供工作台词条多选截图，要求右键菜单增加“取消翻译”。
- **相关背景**：[现代工作台计划](../../../../plans/modern-workbench-visual-shell/plan.md)中的表格选择和刷新机制；本次不扩大该计划的视觉改造范围，也不更改其完成状态。

## 目的与用户可见行为

在现有“标签”“翻译状态”菜单之外，提供直接清空译文并恢复“未翻译”的操作，避免逐条编辑译文和状态。

- 右键已选中的词条时，操作范围为全部选中词条；右键未选中词条时，仅处理该词条。
- 以稳定词条 ID 获取选择范围，支持表头排序，以及排序后仍在等待渲染的选中行。
- 仅处理有译文或状态不是“未翻译”的词条；全部已为空译文且未翻译时，菜单项禁用。
- 确认框显示实际受影响条数，说明清空后不能直接撤销，默认选择“否”。确认后将译文设为空字符串、状态设为 `STAGE_UNTRANSLATED`，保留原文和标签。
- 工程模式通过现有命令一次提交整批变更；提交失败时保留原译文和状态并显示原因。确认期间来源、集合、版本身份或目标词条内容变化时，不继续清空。
- 成功后更新统计和状态筛选选项，按原筛选条件重新填充表格；已有排序和批次机制继续生效。

此操作修改本地词条内容，不是停止正在运行的 AI 翻译任务；不新增自动上传、导出、文件格式或数据迁移行为。

## 逐文件变更

### 修改：右键菜单入口

[src/transbridge/ui/workbench/entry_menu.py](../../../../src/transbridge/ui/workbench/entry_menu.py)

- `build_entry_menu()` 新增可选的 `on_cancel_translation` 回调和 `cancel_translation_enabled` 参数，保留现有调用方式。
- 在原有菜单之后增加分隔线和“取消翻译”动作，提供清空译文、重置状态和多选范围的提示。
- 菜单只负责表达动作与可用性，不直接修改词条或提交工程。

### 新增：确认与批量提交边界

[src/transbridge/ui/workbench/translation_reset.py](../../../../src/transbridge/ui/workbench/translation_reset.py)

- `TranslationResetAction.__init__()` 捕获有效选择、当前集合、来源、版本身份与修订号，以及目标词条原有译文和状态；不持有可能被刷新销毁的 Qt item。
- `enabled` 排除整批无需修改的情况。
- `run()` 负责确认、变化检查、错误反馈及成功后的可见对象同步。
- 工程模式复用 `GuiProjectCommandFacade.replace_entry_states()`，使用完整 `EntryKey` 提交，携带预期 Project/Variant 修订号和 `VariantRef`，避免跨来源同名词条误改和过期写入。
- 仅在整批权威提交成功后同步兼容的可见 `TranslationEntry` 对象；非工程投影模式同时调用 `mark_dirty()`。
- 将该动作独立成模块，避免继续向已有较大的 `Step2PreviewWidget` 添加批量提交职责。可见对象同步沿用现有行内编辑的兼容边界；未来统一迁移工作台投影写入接口时，应一并替换此处字段写入及对应边界测试。

### 修改：工作台接线与刷新

[src/transbridge/ui/workbench/step2.py](../../../../src/transbridge/ui/workbench/step2.py)

- `_build_context_menu()` 将当前词条、全部词条和 `selected_row_entry_ids()` 传给独立动作，再把回调和可用性接到菜单。
- 成功回调重新计算 `StatisticsSummary`、更新状态筛选项并调用 `_populate_table()`，不清除用户的筛选条件。
- `_on_context_menu()` 在 `finally` 中释放菜单，避免关闭菜单后继续保留选择与回调对象。

### 新增：用户行为与提交失败回归

[tests/ui/test_translation_reset.py](../../../../tests/ui/test_translation_reset.py)

- 新增 33 个参数化后测试用例，覆盖直接菜单入口、单选与多选、右键未选中行、排序后的目标身份、拒绝确认、空操作禁用与实际变更计数。
- 覆盖全部既有 Stage 和空/非空译文组合，以及状态、译文、统一搜索三类筛选成员关系与统计更新。
- 通过 Qt 右键及上下文菜单事件验证多选范围；通过 600 条词条在排序后仅渲染首批 250 行的场景，验证尚未显示的选中词条也会被处理。
- 使用真实 `GuiProjectCommandFacade` 与 `VariantAggregate` 配合测试生命周期适配器，验证单次整批提交、同名其他来源不受影响、标签保留，以及提交期间同步重建 Qt 表格后的刷新。
- 覆盖来源、集合或译文在确认期间变化，以及过期修订、提交失败、服务缺失、工程身份缺失时不修改可见或聚合内的译文。
