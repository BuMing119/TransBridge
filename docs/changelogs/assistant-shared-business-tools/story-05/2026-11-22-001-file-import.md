# 文件登记与译文导入复用桌面命令

2026-11-22 · [助手工具复用桌面功能](../../../../plans/assistant-shared-business-tools/plan.md) · S5 第一批

- `parse_esp`、`parse_eet`、`parse_xt`、`parse_sst` 和 `import_json` 的 `create_slot` 调用桌面“打开翻译文件”的 `prepare_open_file`。两端都以当前工程编码读取文件，再通过 `register_opened_source` 将准备好的内容交给 `add_prepared_source`。命令核验工程、版本和准备时的两项修订。插件共用原文过滤、自动套用词典及本地化附件读取，并在解析时捕获工程写回需要的 SST 导出资料。[共享来源命令](../../../../src/transbridge/application/io/open_translation_file.py) · [桌面后台打开流程](../../../../src/transbridge/ui/coordinators/open_file_coordinator.py) · [原词典调用点](../../../../src/transbridge/ui/coordinators/parse_coordinator.py)
- 桌面接纳完整解析结果。记录级错误仅解析出部分词条时，整份来源拒绝登记并展示诊断。DSD 与 ParaTranz JSON 可以登记。内部 JSON 用于向已有来源导入译文。自动识别存在歧义时，用户可指定 JSON 格式。ParaTranz 登记沿用桌面的来源身份及离线远端引用，两个文件仅修改原文、译文或远端 ID 而保留相同键集合时，重复登记会被拒绝。助手专有的 `project_id` 已移除。[工具参数](../../../../src/transbridge/smart_assistant/tools/tool_parser.py) · [来源保存与重新打开测试](../../../../tests/smart_assistant/tools/test_source_import_authority.py)
- `append` 使用桌面“导入译文”的 `MigrationTarget`、`prepare_translation_import` 与 `replace_entry_states`，只提交身份匹配且内容改变的译文和阶段。默认填充未翻译的空词条；`replace_existing=true` 替换可编辑词条，隐藏与锁定状态沿用桌面保护。SSU8、SSU9 和二进制 EET 按定位信息与原文处理重复或无法证明的对应关系；内部 JSON 重复声明同一身份会拒绝整份导入。同键且要求核验原文的记录只更新原文匹配项。已保存译文的旧工程可从保留的完整身份取得原文，缺原文时两端都要求补充输入。[共享导入](../../../../src/transbridge/application/io/translation_import.py) · [桌面迁移提交](../../../../src/transbridge/ui/coordinators/migration_coordinator.py) · [双入口对照](../../../../tests/smart_assistant/tools/test_file_import_parity.py)
- 助手相对路径按请求授权根或已授权的工作目录解析，插件发现的 Strings 和 BSA 文件也要在授权范围内。提交前重新检查取消状态、修订和来源。登记提交后只重试工作台显示；如果仍失败，工具返回已登记、`activated=false` 和刷新提示。已经提交的登记在停止请求后保留。已导入的词条修改按命令采集本轮撤销凭证。同一请求登记成功后继续“套用词典”，会使用新来源的词典上下文。[文件输入授权](../../../../src/transbridge/smart_assistant/tools/file_input_access.py) · [助手提交](../../../../src/transbridge/smart_assistant/tools/_source_import.py) · [工程目标更新](../../../../src/transbridge/smart_assistant/tools/_project_tool_mutations.py)
- 删除助手的 `_eet_import.py`、`_sst_import.py`、`_record_import.py`、`_json_import.py` 和 `entry_task_results.py`。新操作直接返回登记或更新数量，既有历史文件保留。SST/EET、部分解析、重复候选和工作台视图失败的测试已改为验证现行工程状态。水合来源的写回用例使用桌面目录与插件原名，历史窗口的测试夹具补齐实际命令需要的工程和请求上下文。[EET](../../../../tests/smart_assistant/tools/test_eet_workflow.py) · [SST](../../../../tests/smart_assistant/tools/test_sst_append.py) · [部分解析与身份冲突](../../../../tests/smart_assistant/tools/test_entry_result_lifecycle.py) · [来源写回](../../../../tests/ui/test_parse_hydration_authority.py)
