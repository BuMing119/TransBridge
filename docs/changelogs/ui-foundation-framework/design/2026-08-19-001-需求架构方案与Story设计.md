# 001: FR24 高性能 UI Foundation 需求、架构与 Story 设计

**日期**: 2026-08-19
**类型**: 需求/架构/方案
**关联**: Epic: 高性能统一 UI 基础框架 > FR24 / NFR1.4 > Story 01～09

## 目标

设计一个性能优先、可渐进迁移的 PyQt6 UI Foundation：首期提供浅色、深色和跟随系统三种模式，以应用级 ThemeService、不可变语义令牌和 Palette-first 渲染形成单一主题状态链；不实现完整主题编辑器、用户皮肤或主题市场，但预留经过 schema、版本和资源预算校验的声明式 Theme Provider 接口。

本增量只沉淀需求、架构决策、实施计划和 Story 交接文档，未实施主题服务、组件迁移或设置界面。

## 修改文件

### `docs/requirements.md`（改）

- **具体变化**: 新增 FR24.1～FR24.10，覆盖统一设计令牌、内置主题模式、应用级主题服务、公共组件与适配边界、设置/预览/恢复、主题扩展合同、无障碍、i18n、渐进迁移和可诊断失败回退。
- **具体变化**: 新增 NFR1.4，规定主题初始化、运行时切换、窗口打开、heartbeat、RSS、缓存和连续 100 次主题往返切换的性能与资源预算。
- **原因**: 把“主题切换等 UI 框架”的想法转为可验收需求，并落实用户确认的“性能最重要、首期不做完整编辑器但必须保留接口”。

### `docs/adr/020-high-performance-ui-foundation.md`（增）

- **具体变化**: 提议 GUI 专属 UI Foundation，确定 Palette-first、基础/语义/业务三层令牌、ThemeService 单一 owner、不可变 ThemeSnapshot、声明式 Provider、revision 有界资源缓存，以及主题/i18n/accessibility 相互独立的合同。
- **具体变化**: 明确不采用第三方主题框架、全局动态 QSS、仅依赖系统原生主题或全面自绘 QStyle；记录主题解析、配置写入、系统模式和运行时应用失败时的原子回退语义。
- **原因**: 避免主题状态散落在窗口、QSettings 和局部 QSS 中，同时防止主题扩展成为任意代码或无界资源执行入口。

### `plans/ui-foundation-framework/plan.md`（增/改）

- **具体变化**: 建立 S01～S09 实施路线：性能基线与样式清单、令牌/Provider/Registry、ThemeService 与系统模式、公共组件和缓存、设置与预览、Main/Workbench 迁移、工具窗口/ParaTranz 迁移、i18n/accessibility 基础、扩展与最终门禁。
- **具体变化**: 将 FR25 UI 展示层模块化设为生产接入前置；FR25 完成后补充稳定 composition/View ports、独立 revision、生命周期合同和共享性能基线的接入约束，状态更新为“FR25 前置门禁已通过，可进入生产实现”。
- **具体变化**: 明确渐进迁移、切片级回退、旧样式兼容期、性能失败停止扩散和不与新结构重构混杂等门禁。
- **原因**: 让大范围视觉迁移有可回退的依赖顺序，并将主题热路径接到 FR25 拆分后的公开 View/adapter 边界。

### `plans/ui-foundation-framework/stories/story-01-*.md` ～ `story-09-*.md`（增）

- **具体变化**: 为 9 个 Story 分别补充目标、接口与数据流、实施步骤、边界条件、性能/生命周期测试、文件落点和验收标准。
- **原因**: 将跨组件、高风险的主题框架方案展开为可独立实施和验收的交接单元。

### `plans/INDEX.md`（改）

- **具体变化**: 登记 `ui-foundation-framework`、9 个 Story 和当前“FR25 前置已通过，可实施”状态。
- **原因**: 保持计划索引与 FR24 当前阶段一致。

## 设计结果

- 首期范围包含浅色、深色、跟随系统、统一配置持久化、公共组件/自绘适配、基础 i18n/accessibility 合同和失败回退。
- 首期明确排除完整主题编辑器、任意皮肤导入、主题市场、在线下载、任意 Python widget/QSS 扩展、复杂动效和布局密度编辑。
- 未来扩展通过版本化 Theme Provider 接入；Provider 只提供声明式令牌和受预算约束的资源，注册失败时原子拒绝，不产生半主题。
- FR25 已提供稳定 View/Presenter/Binding 接入面，但 FR24 的生产代码、视觉迁移和 NFR1.4 性能门禁尚未开始。
