# 001: FR24 统一 UI 基础框架实现与终验

**日期**: 2026-08-24
**类型**: 实现 / 迁移 / QA 终验
**关联**: Epic: `ui-foundation-framework` > FR24.1～FR24.11 / NFR1.4 > Story 01～09

**计划**: [plan.md](../../../../plans/ui-foundation-framework/plan.md)

## 目标

按 S01～S09 交付性能优先的 PyQt6 UI Foundation：建立单一 ThemeService、不可变语义/业务令牌、浅色/深色/跟随系统、Palette-first 渲染、声明式 Provider、设置预览、locale/accessibility 基础合同，并迁移当前生产可达的 Shell、Workbench、AI Translator、Smart Assistant、ParaTranz、Operation Plan 与 FOMOD。主题或 locale revision 不得改变 FR25/FR26 已冻结的业务状态、intent、Run ID、确认 token、任务和副作用。

## 关键实现结果

- GUI 只有一个 ThemeService owner；ThemeView 仅进入 composition/View，自定义绘制共享有界 DomainBrushes，application/domain 和 AppRuntime 保持 Qt-free。
- 内置 light/dark/system、兼容浅色、Provider 校验、原子应用、last-good 回滚、设置预览和 `[ui]` 持久化已接通。
- 生产可达的 Shell、Workbench、AI Translator、Smart Assistant、ParaTranz、Operation Plan 与 FOMOD 已迁移；不可达 Step1/Step3/prompt-overlay 等兼容模块没有重新接回生产。
- 主题切换不重建表格/报告/RunSpec，不提交 intent、网络/文件命令或新 Run ID；状态均保留文字、符号、边框或 accessible metadata。
- 最终静态审计覆盖 135 个生产可达模块，`blocker_count=0`、`error_count=0`；126 条 non-blocking pending inventory 归属于不可达兼容/迁移清单，不是生产 blocker。
