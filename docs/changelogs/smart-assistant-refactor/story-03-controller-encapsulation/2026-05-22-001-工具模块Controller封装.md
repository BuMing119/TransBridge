# 001: 工具模块函数封装为 Controller 类

**日期**: 2026-05-22
**类型**: 增/改
**关联**: Epic: Smart Assistant 超重文件拆分重构 > Story 03: 工具模块 Controller 封装

## 修改文件

### `src/transbridge/smart_assistant/tools/_common.py` (增)
- **修改内容**: 新建共享函数模块（7行），定义 `load_llm_config()` 函数——从 `LLMConfig.load_from_file()` 加载 LLM 配置，返回 `_LLMConfig` 对象
- **原因**: `tool_translator.py` 和 `tool_proofreader.py` 各自实现了相同的 10 行 LLM 配置加载代码。提取为共享函数消除重复，未来新增工具模块复用同一入口

### `src/transbridge/smart_assistant/tools/tool_translator.py` (改)
- **修改内容**: 新增 `TranslationController` 类（构造器注入 `AppContext` + `TaskManager`），9 个 `_tool_*` 函数转为公开方法（`start_translation`/`start_polish`/`stop_task` 等），4 个辅助函数转为私有方法（`_action_label`/`_get_profiles`/`_get_post_process_config`/`_get_term_db_info`）。`_load_llm_config()` 替换为 `from ._common import load_llm_config`。新增惰性初始化 `_get_translator_controller()` 和 9 个模块级 wrapper 函数（`_tool_*`），`@require_collection` 装饰器在 wrapper 上（因 Python 描述器协议不支持实例方法）。`_register_translator_tools()` 保留为模块级
- **原因**: 15 个模块级函数通过闭包引用外部状态，导致隐式耦合、测试困难。封装为 Controller 类后依赖显式注入（构造器），方法间通过 self 共享状态

### `src/transbridge/smart_assistant/tools/tool_proofreader.py` (改)
- **修改内容**: 新增 `ProofreaderController` 类，3 个 `_tool_*` 函数转为公开方法（`run_postprocess`/`get_quality_report`/`list_quality_reports`），5 个辅助函数转为私有方法（`_build_postprocessor`/`_summarize_*`/`_generate_report`）。`set_last_report`/`get_last_report` 保留为模块级函数（`tool_translator.py:260` 跨模块导入）。`_load_llm_config()` 替换为 `_common.load_llm_config()`。新增惰性初始化和 3 个模块级 wrapper
- **原因**: 与 TranslationController 同理，消除模块级函数反模式，依赖显式注入

### `src/transbridge/smart_assistant/tools/tool_editor.py` (改)
- **修改内容**: 新增 `EditorController` 类，7 个 `_tool_*` 函数转为公开方法（`set_filters`/`get_visible_entries`/`select_entries`/`edit_translation`/`set_stage`/`list_labels`/`manage_entry_labels`），1 个辅助函数转为私有方法（`_resolve_label_id`）。7 个模块级 wrapper 上正确配置 `@require_collection`/`@validate_params` 装饰器（从 Controller 方法移除，因 Python 描述器协议将 self 注入为第一个参数导致装饰器失效）。wrapper 签名增加 `collection=None` 参数以兼容 `@require_collection` 的 collection 注入
- **原因**: 同上。装饰器必须在模块级 wrapper 上而非实例方法上，是受 Python bound method 机制约束的技术决策

### `tests/smart_assistant/postprocess/test_report_system.py` (改)
- **修改内容**: `TestReportSystem.setUpClass` 改为实例化 `ProofreaderController`（替代 `import tool_proofreader as tpr`）；`TestLastReportIntegrity` 改为使用 `set_last_report()`/`get_last_report()` 模块级函数操作报告状态（替代直接访问 `_last_report` 模块变量）
- **原因**: 内部辅助函数迁移到 Controller 后不再是模块级属性，测试需通过 Controller 实例访问

### `tests/smart_assistant/postprocess/test_task_manager.py` (改)
- **修改内容**: `test_g8_action_label_helper` 改为实例化 `TranslationController` 后调用 `ctrl._action_label()`（替代 `from tool_translator import _action_label`）
- **原因**: `_action_label` 迁移为 TranslationController 私有方法

### `tests/smart_assistant/tools/test_run_postprocess.py` (改)
- **修改内容**: `TestSummarizeHelpers.setUpClass` 新增，实例化 `ProofreaderController`；3 个测试用例改为 `self._ctrl._summarize_*()` 调用（替代直接 import 模块级函数）
- **原因**: 辅助函数迁移到 Controller 后不再是模块级属性
