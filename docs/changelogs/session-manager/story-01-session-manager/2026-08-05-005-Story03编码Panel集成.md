# 005: Story 03 编码 — Panel 集成 + ChatWidget 会话切换

**日期**: 2026-08-05
**类型**: 改
**关联**: Epic: Session 管理系统 > Story 03: Panel 集成 + ChatWidget 会话切换

## 修改文件

### `src/transbridge/ui/tools/smart_assistant/panel.py` (改)
- **修改内容**: 重写为完整会话管理集成。新增 _init_session_manager() 创建 SessionManager(get_data_dir())；_init_ui 改为 QSplitter 水平分割布局（左:SessionListWidget 220px + 右:ChatWidget 500px，手柄 1px #e0e0e0）；新增 6 个会话槽函数：_on_create_session→_switch_to、_on_switch_session→_switch_to、_on_delete_session→清理+回退、_switch_to(保存当前→加载目标→刷新列表)、_refresh_session_list、_get_project_name(从 ctx.active_project.name 或 esp_path.stem 提取)；新增 _restore_last_session() 启动恢复（无会话自动创建默认，有会话恢复上次活跃+load_history）；closeEvent 增强（关闭前自动保存）；setMinimumWidth 400→600。
- **原因**: ADR-008 D16：Panel 作为会话切换的协调者，持有 SessionManager+SessionListWidget+ChatWidget，协调保存→清空→加载→渲染流程。

### `src/transbridge/ui/tools/smart_assistant/chat_widget.py` (改)
- **修改内容**: 新增 7 个会话持久化方法：set_session_manager(mgr) 存储引用、save_current_session(sid) 调用 conv.to_dict→mgr.save、load_session(data) 调用 handle_abort+清空UI+conv.from_dict+load_history、load_history(messages) 遍历渲染 MessageBubble（system跳过/user渲染气泡/observation渲染系统消息/assistant渲染气泡）、_clear_all_bubbles() 清空聊天区控件、_auto_save_hook() 向上查找Panel获取active_sid→save_current_session、_find_panel() 遍历父组件链。on_response_parsed 回调增强：追加 _auto_save_hook() 实现每轮 LLM 后自动保存。
- **原因**: ChatWidget 需要支持会话数据的保存/加载/历史渲染，以及在每轮对话后自动持久化。
