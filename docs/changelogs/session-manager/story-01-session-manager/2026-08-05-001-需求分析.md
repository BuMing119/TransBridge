**日期**: 2026-08-05
**类型**: 增
**关联**: Epic: Session 管理系统 > 需求分析

## 修改文件

### `docs/requirements.md` (改)
- **修改内容**: 新增 FR13 节 — Session 管理系统（多会话支持）。5 项子需求：FR13.1 SessionManager 后端组件（会话 CRUD + JSON 持久化 + 全局存储）、FR13.2 ConversationManager 序列化扩展（to_dict/from_dict）、FR13.3 会话列表 UI（左侧可折叠侧边栏 + 高亮 + 新建/删除按钮）、FR13.4 ChatWidget 会话切换集成（保存/清空/加载/渲染历史消息）、FR13.5 跨项目访问（全局存储不绑定项目，元数据记录创建项目名）。更新需求变更历史表。
- **原因**: 当前无多会话支持——ConversationManager 仅内存中维护单对话，重启即丢失。用户测试 FR12 时遇到反复重打提示词的痛点，需要类似 Codex CLI 的会话管理能力。
