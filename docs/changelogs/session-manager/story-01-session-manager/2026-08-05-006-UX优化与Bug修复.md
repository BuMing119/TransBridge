# 006: UX优化与会话管理增强 + 多项Bug修复

**日期**: 2026-08-05
**类型**: 改
**关联**: Epic: Session 管理系统 / SessionController / 跨模块Bug修复

## 修改文件

### `src/transbridge/ui/tools/smart_assistant/session_list_widget.py` (改)
- **修改内容**:
  - `_on_create()`: 移除 QInputDialog 弹窗，直接 emit "新对话"（秒建会话）
  - `_SessionRow`: "×" 删除按钮替换为 "⋯" 更多按钮，悬停显示，点击弹出 QMenu（重命名 / 删除）
  - `_SessionRow`: 新增 `_on_menu()` 方法构建 QMenu，显式设置样式（白底/圆角/选中蓝底蓝字）
  - `_SessionRow`: `mouseDoubleClickEvent` 删除，重命名改为菜弹触发
  - 新增 `rename_session` 信号 (str, str) — session_id + 当前名称
  - "⋯" 按钮使用 `rgba(0,0,0,0.06)` 半透明背景，悬停加深，不受行高亮色影响
- **原因**: 用户反馈新建会话还要手动输入名称太蠢；删除/重命名入口需要更直观

### `src/transbridge/ui/tools/smart_assistant/panel.py` (改)
- **修改内容**:
  - 新增 `_on_rename_session(session_id, current_name)`: QInputDialog 预填当前名，确认后调用 SessionManager.rename_session
  - 连接 `session_list.rename_session` 信号
  - 初始分割器尺寸 `[220, 500]` → `[220, 800]`；minimumWidth `600` → `900`
  - 移除 `setSizes()` 硬编码（改由 stretch factor 自适应）
- **原因**: 面板默认宽度太窄（720px），聊天区仅 500px；重命名功能需要 UI 入口

### `src/transbridge/ui/tools/smart_assistant/message_bubble.py` (改)
- **修改内容**: `MessageBubble.__init__`: `outer.addWidget(content_wrapper)` 改为 `outer.addWidget(content_wrapper, stretch=1)`，移除末尾 `outer.addStretch()`
- **原因**: 中文无空格文本在 QLabel word wrap 下 preferred width 仅几个字符宽，原 `addStretch()` 吃掉全部剩余空间导致气泡被压成窄条

### `src/transbridge/smart_assistant/session_controller.py` (改)
- **修改内容**: `handle_llm_response`: auto_mode 条件增加 `mode != "plan"`，plan 模式始终走确认流程展示 PlanCard（不再直接进入 EXECUTING 死锁）
- **原因**: `_execute_plan()` 是 no-op，实际执行依赖 ChatWidget._on_plan_confirmed 创建 ExecutionEngine，auto_mode 跳过 PlanCard 展示导致控制器永久卡在 EXECUTING 状态

### `src/transbridge/ui/tools/smart_assistant/chat_widget.py` (改)
- **修改内容**:
  - `_on_tool_executed` / `_on_batch_executed`: 删除旧的直接 `execute_step()` 调用，Controller 成为唯一执行驱动（Story 02 清理彻底完成）
  - `_on_confirm_required`: 新增线程检测——非主线程时通过 `QTimer.singleShot + threading.Event` 桥接到主线程创建 QMessageBox
  - `_ensure_task_manager`: `QMetaObject.invokeMethod` → `QTimer.singleShot(0, fn)`（修复 invokeMethod 参数类型错误）
  - `_ensure_task_manager`: 注册 `on_finished` 回调 → 立即刷新 TaskMonitorWidget
  - `shutdown`: 停止 `_task_monitor_timer`
  - `load_session`: 会话切换时重置任务监控
- **原因**: Story 02 未清理的旧代码路径导致工具双重执行（两个弹窗）；QMessageBox 从 worker 线程创建导致空白弹框+卡死；invokeMethod 参数签名错误导致 TaskManager 回调崩溃

### `src/transbridge/smart_assistant/tools/types.py` (改)
- **修改内容**: `_serialize_data`: 增加 `isinstance(self.data, dict)` 守卫，非 dict 类型直接截断返回，不再对字符串调用 `.items()`
- **原因**: `get_tool_help` 返回字符串 data，`_serialize_data` 按字典处理导致 AttributeError crash

### `src/transbridge/smart_assistant/tools/tool_default.py` (改)
- **修改内容**: `_tool_get_tool_help`: `ToolResult.ok(data=result)` → `ToolResult.ok(data={"help": result})`（字符串包进字典）
- **原因**: ToolResult.data 类型定义为 `dict | None`，裸字符串违反契约

### `src/transbridge/smart_assistant/tools/tool_proofreader.py` (改)
- **修改内容**: `result.execution_result` → `getattr(result, "execution_result", None)` + `getattr` 嵌套安全访问
- **原因**: `PostProcessResult` 类没有 `execution_result` 属性，直接访问触发 AttributeError

### `tests/smart_assistant/test_tool_prompt_layering.py` (改)
- **修改内容**: `result.data` → `result.data["help"]`（适配 get_tool_help 返回的 dict 结构）
- **原因**: 测试需匹配修复后的 data 结构
